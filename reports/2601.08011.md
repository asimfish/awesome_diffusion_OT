# TP-Blend: Textual-Prompt Attention Pairing for Precise Object-Style Blending in Diffusion Models

> Xin Jin, Yichuan Zhong, Yapeng Tian · arXiv 2026 · [arXiv](https://arxiv.org/abs/2601.08011) · 证据级 [R] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：TP-Blend 用熵正则 OT 在 cross-attention 中按完整多头维度重分配特征向量，实现对象与风格双 prompt 的精确融合。

## 1. 问题

本文处理的是文本驱动图像编辑中的「对象混合 + 风格融合」联合任务：给定一张源图，同时引入一个新对象（replaced object）、一个混合对象（blend object）和一个目标风格（style），要求输出图像在保持源图几何与背景的同时，将混合对象的形态特征融入替换对象，并施加目标风格的纹理细节。作者指出，现有文本条件扩散编辑器在单一对象替换上表现良好，但当新对象与新风格需要同时引入时缺乏稳健方案（Abstract, Sec. 1）。

此前方法的问题分两层。对象混合层面，CFG-TE（Classifier-Free Guided Text Editing）只支持正/负引导的对象替换，缺少细粒度的形态融合机制（Sec. 3.2）；风格迁移层面，多数方法依赖参考图像而非文本 prompt，且常丢失高频纹理细节（如笔触、颗粒、材质），即使在高分辨率下也如此（Sec. 1）。作者报告，现有方法在同时满足替换精度、混合一致性与风格保真度时存在 trade-off，单一指标的优势往往被互补指标的劣势抵消（Sec. 4.2）。

## 2. 方法

TP-Blend 是 training-free 框架，在 SD-XL 的 DDIM 反演-去噪轨迹上，以 CFG-TE 为基础，额外注入两个 prompt：blend prompt 与 style prompt，二者均设零编辑引导尺度以避免干扰对象替换（Sec. 3.2）。核心由两个互补的 attention 处理器构成。

**CAOF（Cross-Attention Object Fusion）**。第一步，对 multi-head cross-attention 的 H 个头求平均，得到 replaced 与 blend 对象 token 对应的空间注意力图 $a_{\text{replaced}}, a_{\text{blend}}$（Eq. 6）。第二步，用两个独立的百分位阈值 $\tau_{\text{source}}, \tau_{\text{dest}}$ 分别筛选 source 集 $S$（blend 响应强的位置）与 destination 集 $D$（replaced 响应强的位置）（Eq. 7）。第三步，将各头 attention 输出沿特征维拼接为 $O \in \mathbb{R}^{N \times D}$，其中 $D = H \cdot d_k$（SD-XL 中 $D = 640$）（Eq. 8）。第四步，在 $S$ 与 $D$ 之间求解熵正则 OT 问题：

$$\min_{T \geq 0} \sum_{i \in D} \sum_{j \in S} T_{ij} C_{ij} - \gamma H(T) \quad \text{s.t.} \quad \sum_{j \in S} T_{ij} = 1,\ \forall i \in D;\quad \sum_{i \in D} T_{ij} \geq \frac{1}{|S|},\ \forall j \in S$$

其中代价 $C_{ij} = \lambda_{\text{feature}} D_{\text{feature}}(i,j) + \lambda_{\text{spatial}} D_{\text{spatial}}(i,j)$，$D_{\text{feature}}$ 为特征向量余弦距离，$D_{\text{spatial}}$ 为空间坐标欧氏距离（Eq. 10–13）。用 Sinkhorn 算法求解（Eq. 14–15），得到 transport plan $T$。最后按 $T$ 加权混合 destination 位置的特征向量：

$$f'_{d_i} = (1 - w_0) f_{d_i} + w_0 \sum_{s_j \in S} \frac{T_{ij}}{\sum_{s_k \in S} T_{ik}} f_{s_j}$$

其中 $w_0 \in [0,1]$ 控制混合强度（Eq. 9）。作者强调，在完整 $D=640$ 维上做 OT 而非逐头处理，既保留跨头相关性，又将代价矩阵规模从逐头的 $40960 \times 40960$ 降到 $4096 \times 4096$（Sec. 3.3）。

**SASF（Self-Attention Style Fusion）**。在每个 self-attention 层执行两步。第一步 DSIN（Detail-Sensitive Instance Normalization）：先对 replaced 特征做 AdaIN 对齐 style 的通道均值与方差（Eq. 16），再用 1D 高斯核沿 token 维分解低频与高频分量 $F_{\text{LF}} = F * K$，$F_{\text{HF}} = F - F_{\text{LF}}$（Eq. 17），最后注入 style 与 replaced 高频残差之差的一个分数 $\alpha$（Eq. 18）。第二步 Key/Value 替换：将 replaced 区域的 self-attention Key 与 Value 矩阵替换为 style prompt 导出的 Key/Value（Eq. 19）。DSIN 修改的 Query 分支保留，使高频风格线索仍通过 attention score 影响输出（Sec. 3.4）。

## 3. 理论结果

无理论结果。论文未给出任何定理、引理或收敛性/最优性保证。OT 部分直接采用熵正则 OT 的标准 Sinkhorn 求解（Cuturi 2013; Peyré et al. 2019; Genevay et al. 2016），未对 transport plan 的性质或与 attention 的关系做理论分析。

## 4. 实验与数字

**设置**。骨干为 SD-XL；DDIM 反演保证编辑前精确重建；每步执行 TIE-CFG 对象替换、CAOF 混合、SASF 风格注入。Sinkhorn 正则 $\gamma = 0.1$，代价权重 $\lambda_{\text{feature}} = 0.7$，$\lambda_{\text{spatial}} = 0.3$，联合阈值 $\tau_{\text{source}} = \tau_{\text{dest}} \in \{0.6, 0.7\}$（Sec. 4.1）。测试集 4000 样本：40 张 Unsplash 基图 × 20 组 replace-blend 对象组合 × 5 种风格（Sec. 4.1）。

**指标**。CLIP 相似度（原始/替换/混合/风格四个 prompt）、$1 - \text{LPIPS}_O$ 感知保真度，min-max 归一化（$\epsilon = 0.1$）。BOM 为替换、混合、保真三者的调和平均；BOSM 再加入风格相似度的调和平均（Sec. 4.1）。

## 5. 在 OT×扩散地图中的位置

TP-Blend 属于线 B「attention 即 OT 的接口化」在采样期操控传输结构的分支，与 STORM（CVPR 2025）、ASAG（AAAI 2026）并列。它与 STORM 的相似点是都在 cross-attention 上用带空间代价的 OT 重定位特征；区别在于 STORM 是单 prompt 的 attention map 重定位，TP-Blend 是双 prompt（replaced + blend）之间的特征向量传输，且明确在完整多头拼接维度 $D = H \cdot d_k$ 上求解，而非逐头或 head-averaged 标量 attention 上。与 ASAG 的「对抗代价 Sinkhorn 构造负样本」不同，TP-Blend 的 OT 用于正向特征融合，不做 guidance 负分支。

在代价设计上，TP-Blend 的 $C_{ij} = \lambda_{\text{feature}} D_{\text{feature}} + \lambda_{\text{spatial}} D_{\text{spatial}}$ 是「外观 + 空间」的线性组合，对应线 A 中 SCOT 到 GWOT-SC 演化谱系的早期形态——有空间正则但无结构/几何项（GW/FGW）。其边际约束是不对称的：destination 侧严格等于 1，source 侧只要求下界 $1/|S|$（Eq. 12–13），这是一种不平衡 OT 的简化处理，与 UNITE 的自适应质量学习形成对照，但 TP-Blend 未做质量学习，只是用不等式松弛 source 边际。

SASF 部分（DSIN + Key/Value 替换）与 OT 无关，属于风格迁移的统计对齐 + attention 注入路线，对应 OTComp 中「几何引导 OT 传输高频纹理」要解决的问题，但 TP-Blend 用高斯滤波分离高低频后直接做残差注入，没有用 OT 传输纹理。

## 7. 对我们的启发

1. **完整多头维度上的 OT 是一个可复用的设计选择**。TP-Blend 在 $D = H \cdot d_k$（SD-XL 为 640）上做 OT 而非逐头，代价矩阵从 $40960^2$ 降到 $4096^2$，同时保留跨头相关性。这为「OT 注入 attention」类方法提供了一个具体的维度选择依据：在拼接后的完整特征空间做传输，既降低计算量又避免逐头独立匹配的语义割裂。可接入切入点 #1（免训练 batch 级保边缘噪声指派 MPNA）中，作为特征空间构造的参考。

2. **不对称边际约束是处理「对象混合」这类非守恒语义的轻量方案**。Eq. 12–13 的 destination 严格边际 + source 下界边际，本质上是 unbalanced OT 的一个手工简化。这提示我们：在跨域语义不守恒场景（对象增删、部件缺失）中，不必引入完整的 unbalanced OT 质量学习（如 UNITE），用不等式松弛一侧边际即可获得可用的 transport plan。可作为切入点 #2（OT-aware 采样调度）中边际设计的低成本起点。

3. **OT 代价中的空间项权重是控制混合精度的关键旋钮**。TP-Blend 用 $\lambda_{\text{spatial}} = 0.3$ 固定权重，但阈值消融（Fig. 12）显示 source/destination 集合的覆盖率对混合质量影响显著。这提示：在 OT 引导的扩散编辑中，「哪些位置参与传输」比「传输代价怎么算」对最终效果的影响可能更大。可设计实验系统比较集合选择策略（百分位阈值、top-k、显著性 mask）与代价权重的相对贡献，作为分析型论文的切入点。
