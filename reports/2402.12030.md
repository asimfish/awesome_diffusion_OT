# Towards Cross-Tokenizer Distillation: the Universal Logit Distillation Loss for LLMs

> Nicolas Boizard, Kevin El Haddad, Céline Hudelot, Pierre Colombo · arXiv 2024（TMLR 2025 接收） · [arXiv](https://arxiv.org/abs/2402.12030) · 证据级 [R] · 课题 T22 离散数据与文本中的扩散/流与最优传输
> **一句话**：用排序概率向量的 W1 距离做跨词表 logit 蒸馏，作者报告平均比纯文本蒸馏高 2.30 点 F1。

## 1. 问题

本文解决的是知识蒸馏（KD）中一个具体障碍：基于 logit 的蒸馏损失（KL 散度）要求教师模型和学生模型共享同一个词表（vocabulary），否则两个概率分布的支持集不同，KL 中的对数项无定义（Sec. 2.4，Fig. 2）。而现实中的 LLM 家族（LLama、Mistral、Bloomz 等）词表差异很大——作者报告 Bloomz tokenizer 只覆盖 Mistral 词表的 30.03%（Fig. 1）。

此前可行的跨模型蒸馏方法主要是「教师生成文本蒸馏」（teacher-generated text distillation），即只用教师生成的合成文本训练学生，相当于式 (1) 中 λ=0，完全丢弃教师输出的 logit 信息（Sec. 2.3）。作者认为这浪费了教师概率分布中「近零标签」（near-zero labels）所携带的泛化信息（Sec. 3.2）。白盒方法（white-box）需要访问内部特征且假设架构相似，不适用于 API 场景（Sec. 2.3）。因此研究问题是：如何在黑盒框架下构建一个不依赖词表对齐的通用 logit 蒸馏损失。

## 2. 方法

核心思想：用离散 Wasserstein 距离（W1）替代 KL 散度作为蒸馏损失中的分布对齐项。Wasserstein 距离对两个分布的支持集不做任何假设（Sec. 3.1 的 Remark），因此天然适用于词表不同的场景。

**损失函数**（Eq. 4）：

$$L_{\text{ULD}} = \sum_{t=1}^{|x|} \text{CE}(t) + \lambda \times W_1\left(p_{\theta_S}(\cdot|x^S_{<t}),\, q_{\theta_T}(\cdot|x^T_{<t})\right)$$

其中 $|x| = \min(|x^S|, |x^T|)$ 是教师与学生 tokenizer 分词后序列长度的最小值，λ 设为 1.5（Sec. 3.2，附录 B.1 讨论）。

**关键近似**（Sec. 3.3）：朴素 Wasserstein 计算复杂度为 $O(n^3 \log n)$，对 100K 词表不可行。作者引入两个假设将其化简为闭式解：

1. **均匀支持长度**（Uniform Support Length）：通过 padding 使教师和学生分布的支持大小相等，即 $|\Omega_T| = |\Omega_S| = |\Omega|$；
2. **均匀成本**（Uniform Cost）：所有 token 之间的传输成本都设为 1（不建立词表间的语义关系）。

在这两个假设下，W1 距离退化为排序后概率向量的 L1 距离（Eq. 5）：

$$W_1 = \sum_{t=1}^{|x|} \sum_{i=1}^{|\Omega|} \left| p(x^S_{\sigma_S(i)}|x^S_{<t}) - q(x^T_{\sigma_T(i)}|x^T_{<t}) \right|$$

其中 $\sigma_S$ 和 $\sigma_T$ 分别是将学生和教师概率向量按降序排列的置换。复杂度降为 $O(n \log n)$（Sec. 3.3，附录 A.1 有完整推导）。

**训练流程**（Sec. 4.2）：教师模型在推理模式下为五个数据集生成答案；学生模型以 teacher forcing 方式仅训练预测答案；ULD 损失中的教师 logit 由教师模型对同一批数据点前向计算得到；教师权重冻结。

## 3. 理论结果

无理论结果。作者没有给出 ULD 损失的收敛性、泛化界或与 KL 蒸馏关系的任何定理。Eq. 5 的闭式解来自 Peyré et al.（2019）在均匀成本假设下的已知结果，作者在附录 A 中重述了推导，但未提出新的理论贡献。

## 4. 实验与数字

**设置**（Sec. 4.1–4.2）：教师为 LLama 2 7B Chat 和 Mistral 7B Instruct；学生为 OPT-350m、Pythia-160m/410m/1b、Bloomz-560m（均为 decoder），以及 MT0-580m（encoder-decoder）。五个数据集：SQuAD、QED（抽取式 QA，F1）；FairytaleQA、PubMedQA（生成式 QA，BERTScore）；DIALOGSum（摘要，Rouge-Lsum）。基线是教师生成文本蒸馏（Raw Text）。

**教师自身表现**（Table 1）：LLama 在抽取式 QA 平均 F1 为 69.51、生成式 QA 平均 BERTScore 为 36.11、摘要 Rouge-Lsum 为 23.90；Mistral 对应为 64.66、33.47、34.71。作者指出两教师在摘要任务上有 30% 的相对性能差。

**主结果**（Table 2，作者报告）：

作者报告 ULD 在抽取式 QA 上平均比 Raw Text 高 2.30 点 F1；Bloomz-560m 在 QED 上超过其教师 Mistral（55.79 vs 53.01，Table 2 vs Table 1）。摘要任务中 LLama/Mistral 教师间的 30% 性能差在蒸馏后仍然保持（Sec. 5.1）。

**学生规模消融**（Fig. 3，Sec. 5.2）：Pythia 160m/410m/1b 由 LLama 教师蒸馏。作者报告 ULD 在简单任务上对小模型增益更明显，在需要推理的任务（如 FairytaleQA）上需要更大模型才能有效利用教师 logit；Pythia-410m + ULD 在 QED 和 DIALOGSum 上匹配 Pythia-1b + Raw Text 的表现。

**数据量消融**（Fig. 4，Sec. 5.3）：在 25%/50%/75%/100% 数据比例下，ULD 均优于 Raw Text；作者报告「用 50% 数据训练的 ULD 模型超过用全量数据训练的 Raw Text 模型」。每个比例训练 5 次以给出误差范围。

**训练正则化**（Fig. 5，Sec. 5.4）：在 SQuAD 上每 200 步记录验证损失，作者报告 ULD 损失稳定了蒸馏过程、缓解过拟合。同时指出 ULD 模型的 CE 损失高于 Raw Text 模型，但作者解释这是因为 ULD 模型被训练去复现教师 0.92 的置信度而非 1.0，因此校准更好。

**跨架构蒸馏**（Table 3，Sec. 6）：LLama（decoder）→ MT0-580m（encoder-decoder），在 QED 上 ULD 为 56.01 vs Raw Labels 55.63（F1）；PubMedQA 上 30.19 vs 27.56（BERTScore）；DIALOGSum 上 23.92 vs 23.22（Rouge-Lsum）。作者报告生成式任务上 ULD 比 Raw Text 高 2.63 点 BERTScore。

## 5. 在 OT×扩散地图中的位置

本文是「跨 tokenizer OT 蒸馏」这一支线的早期工作，与 MultiLevelOT（arXiv 2502.18961）构成直接前后继关系：ULD 用均匀成本 + 排序闭式解做单层 W1 对齐，MultiLevelOT 则引入 token 嵌入空间的多层 OT 成本矩阵，解决 ULD 中「均匀成本丢弃语义信息」的问题。在课题 T22 的谱系中，本文属于「OT 作为分布对齐损失」的应用层，而非离散扩散/流模型本身的方法贡献。

与课题背景中「任意教师→扩散学生的 OT 蒸馏统一框架」（切入点 #4）的关系：ULD 只处理 AR→AR 或 AR→encoder-decoder 的蒸馏，不涉及扩散学生或 few-step 采样。但它的核心机制——用 W1 替代 KL 以绕过支持集不匹配——正是后续把强 AR 教师蒸馏进 masked 扩散学生时可以直接复用的组件。在推理管线中，本文对应「蒸馏损失设计」环节，与 SDTT/Di4C/DCD 等自蒸馏加速工作互补：后者解决时间步间的分布对齐，本文解决跨词表空间的对齐。

从 OT 理论角度看，ULD 的均匀成本假设实际上放弃了词表空间的几何结构，把 W1 退化为排序概率向量的 L1 距离。这与 Haxholli et al. 用状态相异度作为 ground cost 的离散动态 OT 形成对比：ULD 是「无几何」的极端，后者是「Hamming 几何」的显式建模。两者之间的中间地带（语义嵌入成本）正是 MultiLevelOT 和课题切入点 #2 所占据的位置。

## 6. 局限与批评

**作者承认的**：
1. 均匀成本假设「可能看起来是一个强假设」（Sec. 3.3），作者仅以实验效果作为辩护，未给出理论论证。
2. 小模型在开放生成任务中推理能力有限、更易产生幻觉，本文未对此做深入研究（Broader Impact Statement）。
3. 教师模型中的偏见可能通过蒸馏传递给学生，这是所有 KD 方法的共同风险（Broader Impact Statement）。

**读出来的**：
1. **均匀成本丢弃了全部词表语义**：把 W1 退化为排序概率向量的 L1 距离后，损失只比较概率质量分布的「形状」，完全不关心哪些 token 概率高。这意味着教师对「cat」的高置信度和学生对「dog」的高置信度会被视为完美对齐（只要排序位置相同）。这在跨词表场景下尤其危险，因为两个词表可能对同一概念有不同的 token 切分方式。作者在 Fig. 1 中展示了词表重叠度低的问题，但均匀成本恰恰回避了「如何对齐非重叠 token」这个核心难点。
2. **序列长度截断的语义风险**：$|x| = \min(|x^S|, |x^T|)$（Eq. 4）意味着当教师和学生 tokenizer 对同一句子的分词长度不同时，较长的那个被截断。对于 BPE 类 tokenizer，长度差异往往集中在低频词或子词切分上，截断可能系统性地丢弃教师分布中信息量最大的尾部 token。
3. **基线过弱**：唯一基线是 teacher-generated text（λ=0），没有与任何其他跨词表 logit 蒸馏方法比较（如基于 embedding 投影的方法或 Sinkhorn 正则化 OT）。Sec. 3.3 提到 Bhardwaj et al.（2022）用 Sinkhorn 做 encoder-decoder 分类蒸馏，但未做实验对比。因此「ULD 有效」的结论只能相对于最弱基线成立。
4. **评估指标与蒸馏目标不匹配**：ULD 优化的是排序概率向量的 L1 距离，但评估用的是 F1/BERTScore/Rouge-Lsum。这些指标衡量生成文本质量，与 logit 分布对齐程度之间隔着解码策略（采样/贪心）的鸿沟。作者没有报告困惑度或 logit 层面的校准指标来直接验证蒸馏目标是否达成。

## 7. 对我们的启发

1. **均匀成本是「无几何 OT」的退化极限，可作为消融下界**：在构建跨 tokenizer 蒸馏损失时，ULD 的排序 L1 距离可以作为「完全不使用词表几何」的 baseline。任何引入语义成本（如 embedding 距离、编辑距离）的方法都应该至少超过这个下界，否则说明几何信息在该任务中无增益。这为切入点 #2（语义成本的 minibatch-OT 离散耦合）提供了一个天然的对照实验设计。
2. **W1 替代 KL 的动机可迁移到扩散蒸馏**：ULD 的核心洞察——Wasserstein 距离不要求支持集相同——在离散扩散的 few-step 蒸馏中同样成立。当教师 AR 模型和学生 masked 扩散模型词表不同时，逐 token KL 同样无定义。可以直接把 ULD 的排序 W1 项拼接到 dLLM 类蒸馏损失中，作为跨词表场景的第一版实现，再逐步升级为 MultiLevelOT 式的语义成本。
3. **「排序概率向量 L1」的计算成本极低，适合作为训练中的正则化项**：$O(n \log n)$ 的复杂度意味着它可以作为辅助损失加在任何生成模型的训练中，几乎不增加计算负担。Sec. 5.4 报告的「稳定训练、缓解过拟合」效果提示：即使不追求跨词表蒸馏，这个损失也可能作为通用的分布形状正则化器。值得在扩散 LM 的训练中验证它是否能替代或补充现有的辅助损失。
