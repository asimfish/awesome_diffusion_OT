# TripoSG: High-Fidelity 3D Shape Synthesis using Large-Scale Rectified Flow Models

> Yangguang Li, Zi-Xin Zou, Zexiang Liu et al. · arXiv 2025 · [arXiv](https://arxiv.org/abs/2502.06608) · 证据级 [R] · 课题 T20 3D/点云/几何生成中的 OT 与流
> **一句话**：1.5B/4B rectified flow transformer + SDF-VAE，在 2M 高质量数据上做图生 3D，作者报告 SOTA 保真度与输入对齐。

## 1. 问题

TripoSG 解决单图生成高保真 3D 网格的问题。作者把现有方法分成两类：大规模重建式方法（LRM 及其变体）用网络确定性回归 3D 模型，但多视图输入在重叠区域不一致、遮挡区域产生伪影；扩散式方法在 3D 表示或 VAE 压缩的潜表示上训练，绕开了重建式方法的部分问题，但主流采用 occupancy 表示，需要后处理来减轻混叠伪影，且缺乏细粒度几何细节。此外，vanilla diffusion 架构与采样策略导致生成模型与输入图像之间存在对齐差距。两类方法的共同瓶颈是严重依赖 Objaverse 数据集，而严格的数据过滤常使可用样本减少近一半，限制了数据规模扩展（Sec.1）。

作者提出的核心问题是：生成高保真 3D 模型且与输入条件精确对齐的最优范式是什么（Sec.1）。

## 2. 方法

TripoSG 由三部分组成：rectified flow transformer 生成架构、模型与分辨率扩展策略、SDF-VAE。

**生成架构**：骨干基于 DiT 与 3DShape2VecSet，采用标准 transformer block，并引入 U-ViT 式的长跳跃残差连接。骨干分为 encoder blocks、middle block、decoder blocks，encoder 与 decoder 各 N 个 block（N=10），第 i 个 encoder block 的输出跳跃连接到第 (N−i) 个 decoder block 的输出：

$$Z^{(N-i)}_{DB} = DB^{(N-i)}\left(Z^{(N-i-1)}_{DB}\right) + EB^{(i)}\left(Z^{(i-1)}_{EB}\right), \quad i \in \{0,1,...,N\} \tag{1}$$

隐藏维度 W=2048，每个 block 16 个注意力头，整个 flow 架构约 1.5B 参数（Sec.3.1.1）。图像条件注入：用 CLIP-ViT-L/14 提取全局特征 $I_{global}$，DINOv2-Large 提取局部特征 $I_{local}$，在每个 flow block 内通过两个独立的 cross-attention 同时注入（Eq.4-5）。作者批评 CLAY 的做法——先训 1.5B 文本条件基座模型（256 A800 GPU 15 天），再冻结基座、用 352M 参数做图像条件 cross-attention（8 小时以上）——限制了模型根据图像信息充分更新参数的能力（Sec.3.1.1）。

**Rectified flow 采样**：作者比较了 DDPM、EDM、Rectified Flow 三种轨迹。DDPM 的插值轨迹为 $x_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t}\epsilon$（Eq.7），EDM 为 $x_t = x_0 + \sigma(t)\epsilon$（Eq.8），两者都是曲线轨迹。Rectified Flow 采用线性轨迹：

$$x_t = t x_0 + (1-t)\epsilon \tag{9}$$

作者称线性采样简化网络训练、更高效稳定。训练时采用 SD3 的 logit-normal 采样，增加中间时间步的采样权重：

$$\pi_{\ln}(t; m, s) = \frac{1}{s\sqrt{2\pi}\, t(1-t)} \exp\left(-\frac{(\log(t/(1-t))-m)^2}{2s^2}\right) \tag{10}$$

并引入 SD3 的 resolution-dependent timestep shifting，从基础分辨率 n 的时间步 $t_n$ 重映射到微调分辨率 m 的时间步 $t_m$：

$$t_m = \frac{\sqrt{\frac{m}{n}}\, t_n}{1 + \left(\sqrt{\frac{m}{n}}-1\right) t_n} \tag{11}$$

**扩展策略**：潜分辨率从 2048 提升到 4096，模型从 1.5B 扩展到约 4B，采用 MoE。MoE 替换 FFN 为 N 个并行专家，由 gating 模块按 top-K 概率逐 token 分配，再拼接恢复原长度。采用 DiT-MoE 的共享专家与专家平衡辅助损失；与 DiT-MoE 不同，专家 FFN 沿用基座模型的两层 MLP + GELU 结构，且 MoE 权重从基座模型对应 FFN 初始化。MoE 只应用于 decoder 最后 6 层（深层负责物体特定细节），使用 8 个专家、每 block 激活 top-2 专家并共享 1 个 FFN，总参数从 1.5B 增至约 4B（Sec.3.2）。高分辨率微调时对 Q、K 施加可学习 RMSNorm 以稳定混合精度训练。

**SDF-VAE**：采用 neural SDF（实际为 TSDF）替代 occupancy 表示，理由是 occupancy 有量化误差、混叠伪影与阶梯效应，SDF 几何表达力更强。VAE 损失为：

$$L_{vae} = L_{sdf} + \lambda_{sn}L_{sn} + \lambda_{eik}L_{eik} + \lambda_{kl}L_{kl} \tag{17}$$

$$L_{sdf} = |s-\hat s| + \|s-\hat s\|_2^2 \tag{18}$$

$$L_{sn} = \left(1 - \left\langle \frac{\nabla D(x,f)}{\|\nabla D(x,f)\|}, \hat n \right\rangle\right) \tag{19}$$

$$L_{eik} = \|\nabla D(x,f) - 1\|_2^2 \tag{20}$$

其中 $\hat n$ 是表面法向真值，表面法向损失只施加在表面点上。权重 $\lambda_{sn}=10$，$\lambda_{eik}=0.1$，$\lambda_{kl}=0.001$（Sec.5.1）。VAE 采用 8 层 encoder、16 层 decoder，多分辨率训练 M∈{512, 2048}，权重跨分辨率共享，无位置编码，因此可外推到 4096 tokens 而无需重训（Sec.3.3.3）。与之前只用 2048 或 8192 个表面点作 VAE 输入不同，TripoSG 使用更密的表面点。

**数据系统**：四阶段流水线——评分（约 10K 模型渲染四视角法向图，10 名专业建模师打 1–5 分，训练线性回归评分模型，输入为 CLIP 与 DINOv2 特征拼接）、过滤（大平面底座、动画渲染错误、多物体）、修复与增强（角色模型朝向修正；无纹理模型用 ControlNet++ 生成多视角 RGB 作为条件输入）、场数据生产（UDF 512³ 网格 + Marching Cubes 提取水密网格，阈值 $\tau=3/512$，去除内部结构后采样表面点与法向、体内与近表面随机点）。最终产出 2M 高质量 Image-SDF 对（Sec.4）。

## 4. 实验与数字

**训练配置**：主实验分三阶段渐进训练。第一阶段 1.5B 参数、2M 数据集、潜分辨率 512 tokens、学习率 1e-4、700k 步；第二阶段潜分辨率 2048 tokens、学习率 5e-5、额外 300k 步；第三阶段 MoE 扩展至 4B、潜分辨率 4096 tokens、1M 高质量数据集、学习率 1e-5、100k 步。三阶段 batch size 分别为每 GPU 16、10、8。总训练约 3 周、160 张 A100 GPU（Sec.5.1）。

**消融实验配置**：小数据集 180K（从 Objaverse 过滤）、975M 参数模型。非扩展消融：潜分辨率 512、学习率 1e-4、约 300k 步、32 张 A100 约 3 天。扩展消融：依次在 2048 tokens、4096 tokens、4096 tokens + MoE 上各续训 100k 步，学习率 5e-5、1e-5、1e-5，共约 9 天、32 张 A100（Sec.5.1）。

## 5. 在 OT×扩散地图中的位置

TripoSG 是 rectified flow 在 3D 资产生成领域的大规模工业级落地代表，与 SplatFlow 同属 2025 年确立 RF 为 3D 生成默认主干的工作。在本课题地图中，它对应「生成主干线」的 RF 分支，但**只利用了 RF 的直线概率路径（Eq.9），未涉及任何显式 OT 耦合设计**：噪声-数据配对是独立采样（$x_t = t x_0 + (1-t)\epsilon$，$\epsilon$ 与 $x_0$ 独立），没有 minibatch OT、没有点级置换求解、没有 reflow 拉直。这与 NSOT（ICLR 2025）在点云上系统检验 exact OT 耦合、WFM（ICML 2025）在 Wasserstein 空间上做 FM 形成对照：TripoSG 的「传输性」仅停留在线性插值层面，几何域特有的 exact OT 尚未被利用。

在表示层面，TripoSG 的 VAE 将 SDF 场编码为 latent token set（L×C），再在欧氏潜空间上做 RF——这与 GaussianCube 把非结构化 Gaussians 规整进 voxel 网格喂给扩散骨干的思路平行，都是「先规整表示、再欧氏扩散」的管线。TripoSG 的 SDF-VAE 用 surface normal guidance（Eq.19）与 eikonal 正则（Eq.20）监督梯度域，这属于几何先验注入，与 OT 无直接关系。

TripoSG 对本课题的启示在于：它证明了 RF 线性轨迹 + 大规模数据 + 高潜分辨率在 3D 生成上的可行性，但留下了「耦合质量」这一维度未被探索——如果在其 4096-token 潜空间上引入 minibatch OT 耦合或 reflow，是否能在相同 NFE 下减少轨迹交叉、提升采样质量，是可直接嫁接的切入点。

## 6. 局限与批评

**作者承认的**：
1. 数据依赖：训练数据来自 Objaverse(-XL) 与 ShapeNet 等开源数据集，原始约 10M 中大部分质量参差，需大量预处理；严格过滤使可用样本大幅减少（Sec.1, Sec.4）。
2. 计算成本：主训练 160 A100 GPU 约 3 周，消融也要 32 A100 数天，扩展实验成本高（Sec.5.1）。

**读出来的**：
1. **无定量评测证据**：论文正文在 Sec.5 之后截断，摘要声称 SOTA，但未见与 CLAY、Michelangelo、Craftsman 等的数值对比表、FID/Chamfer/用户研究等指标。作为预印本，结论应视为「作者报告」。
2. **RF 使用停留在朴素形式**：Eq.9 的线性插值中 $\epsilon$ 与 $x_0$ 独立采样，没有利用 rectified flow 的 reflow 步骤来拉直边际耦合，也没有任何 OT 配对。作者称「linear sampling simplifies network training」，但未与 reflow 后的版本对比采样步数-质量曲线。
3. **VAE 外推的边界未验证**：VAE 在 {512, 2048} 上训练、直接外推到 4096 tokens，作者以「无位置编码」为理由，但未报告 4096 分辨率下的重建误差与 2048 的对比数字（Sec.3.2 原文截断，未见）。

## 7. 对我们的启发

1. **在 TripoSG 式潜空间上做 minibatch OT 耦合**：TripoSG 的 RF 训练用独立配对（Eq.9），可直接替换为 batch 级保边缘噪声指派（MPNA）或 minibatch OT-CFM 耦合，在 4096-token 潜表示上检验轨迹交叉率与采样质量的变化。这对应切入点 #1 的免训练变体，且 TripoSG 的潜空间维度（4096×64）远小于图像潜空间，exact Hungarian 求解的可行性更高。
2. **SDF-VAE 的梯度域监督与 OT 度量的互补**：TripoSG 用 surface normal + eikonal 监督几何细节（Eq.17-20），但评测端仍依赖 mesh 提取后的几何度量。可探索在 SDF 潜空间上用 OT 度量（如对 latent token set 做 EMD/Sinkhorn）作为训练或评测信号，替代或补充 Chamfer 类指标。
3. **RF 直线轨迹 + reflow 的 3D 版验证**：TripoSG 选了 RF 但没做 reflow。可在其小规模消融设置（180K 数据、975M 参数）上做一次 reflow 对比，测量 NFE-质量 Pareto 前沿，为「3D 域是否需要 reflow」提供证据——这是图像域已有结论、3D 域缺失的实验。
