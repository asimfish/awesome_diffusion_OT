# Latent Schrödinger Bridge

> 作者：课题清单未提供 · arXiv 2024（预印本）· [arXiv](https://arxiv.org/abs/2411.14863) · 证据级 [R] · 课题 T14 扩散桥 / Schrödinger 桥的图像到图像翻译
> **一句话**：把 SB PF-ODE 速度场拆成源/目标/噪声三个预测子，用预训练 Stable Diffusion 免训练近似；作者报告低 NFE 非配对翻译胜过 SDEdit/DDIB。

⚠ 未读全文，依据摘要。本条目摘要为空，以下仅依据课题清单/课题笔记的一句话贡献；§3/§4 不含任何数字。预印本，结论均为"作者报告"。

## 1. 问题

非配对翻译若用 SB 需要训练 SB 求解器；免训练方法（SDEdit、DDIB）不具 SB/OT 语义或 NFE 高。LSB 想在完全不训练的前提下用预训练文生图模型逼近 SB 的确定性轨迹（依据课题清单转述）。

## 2. 方法

课题清单转述：把 SB 的概率流 ODE 速度场分解为三个预测子——源分布预测、目标分布预测、噪声预测——的线性组合；三者由同一预训练 Stable Diffusion 在不同 prompt 下提供，并对 prompt 做优化以对齐源/目标域；由此得到免训练的近似 SB ODE，用低 NFE 采样。分解的精确公式与近似误差：原文未读，未见。

## 3. 理论结果

原文未读，未见。"速度场可分解为三预测子线性组合"是方法陈述，是否有定理形式未知。

## 4. 实验与数字

- 任务：非配对 I2I；作者报告在低 NFE 下优于 SDEdit 与 DDIB（课题清单转述）。数据集、指标、数字：原文未读，未见。

## 5. 在 OT×扩散地图中的位置

LSB 是 DDIB（2203.08382）路线的免训练升级：DDIB 拼接两条 PF-ODE，LSB 直接在一条 ODE 里组合三个预测子，声称更接近 SB 轨迹且步数更少。它是博客方向一（免重训的轨迹对齐）最"激进"的样本——连域模型都不训、只优化 prompt。与 UNSB/ASBM 相比，它逼近的 SB 的熵正则量与耦合是否成立完全依赖预训练模型的先验，属于课题笔记开放问题 1 的对象。预印本身份意味着结论未经同行评审。

## 6. 局限与批评

我读出来的（基于方法类型）：
