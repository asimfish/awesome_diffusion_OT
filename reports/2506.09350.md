# Autoregressive Adversarial Post-Training for Real-Time Interactive Video Generation

> Shanchuan Lin, Ceyuan Yang, Hao He, et al. · NeurIPS 2025 · [arXiv](https://arxiv.org/abs/2506.09350) · 证据级 [P] · 课题 T19 视频生成与时序一致性中的 OT/流
> **一句话**：把预训练视频扩散模型经对抗后训练改造成 1NFE/帧的自回归生成器，单 H100 达 24fps 736×416 实时流式生成。

## 1. 问题

本文解决交互式视频生成的三个核心挑战：实时吞吐、低交互延迟、长时因果生成（Sec. 1）。现有大规模视频扩散模型生成几秒高清视频需数分钟，无法用于实时交互场景（Abstract）。此前方法各有不足：

- **逐帧扩散**（frame-by-frame）[93, 111] 每帧都要重算上下文，冗余高（Sec. 1）。
- **Diffusion forcing** [7, 108, 40, 23] 引入渐进噪声并行化去噪，但当前最佳模型 CausVid [117] 仍需 4 步去噪，且训练窗口固定（约 5 秒），长视频推理时需重启并重算重叠上下文帧，造成流式应用的等待时间（Sec. 1）。
- **Token 级自回归**（如 VideoPoet [43]）可自然利用 KV cache，但逐 token 解码串行，难以满足高分辨率实时需求（Sec. 1）。

作者的目标是：把预训练 latent video diffusion model 转成每 latent frame 一次前向（1NFE）的因果自回归生成器，流式输出并实时接收用户控制（Abstract）。

## 2. 方法

核心思想：用对抗训练（adversarial training）作为自回归生成的训练范式，分三阶段后训练：**diffusion adaptation → consistency distillation → adversarial training**（Sec. 2.2）。

**架构改造（Sec. 2.1）**：把双向 DiT 换成 block causal attention——text token 只 attend 自己，visual token attend text token 及当前和过去帧的 visual token。模型输入除噪声和条件外，通过 channel concatenation 接收上一自回归步生成的帧（首步用用户提供的帧）。推理时每步复用 KV cache，单次前向生成下一帧。为防注意力计算和 KV cache 无限增长，visual token 最多 attend 过去 $N$ 帧（$N=30$，即 5 秒），同时始终 attend text token 和首帧；多层堆叠使有效感受野远大于窗口（Sec. 2.1, Sec. 3）。

**训练流程（Sec. 2.2）**：

1. **Diffusion adaptation**：加载预训练权重，用扩散目标微调以适应新架构。teacher-forcing：用数据集 ground-truth 帧作为过去帧输入，输出目标平移一帧做 next-frame prediction；噪声 latent 和 timestep $t \sim U(0, T)$ 照常使用，所有帧施加相同噪声水平。
2. **Consistency distillation**：作为对抗训练前的初始化以加速收敛，沿用 APT [49] 的做法；省略 CFG，因为作者发现 CFG 在自回归设置中引入伪影。
3. **Adversarial training**：扩展 APT [49] 到自回归设置。判别器用与生成器相同的因果架构，从 adaptation 后的扩散权重初始化，插入 logit 输出投影层；噪声输入替换为帧输入，随机采样 $t \sim U(0, T)$。判别器为**每一帧**输出 logit（而非整个 clip），实现并行多时长判别。损失用 R3GAN [31] 目标（relativistic loss [36] + 近似 R1/R2 正则化 [73, 65]）。

**Student-forcing（Sec. 2.2）**：teacher-forcing 训练的模型在推理时误差累积严重。student-forcing 中，生成器只用 ground-truth 首帧，后续输入回收自身实际生成结果，与推理行为完全一致；判别器并行评估所有生成帧。作者发现 detach 过去帧输入的梯度图可提升稳定性，梯度通过 KV cache 回流更新所有参数。

**长视频训练（Sec. 2.2）**：数据集中单镜头长视频稀缺（平均镜头时长仅 8 秒）。作者让生成器生成 60 秒长视频，切成 10 秒段给判别器评估，段间保留 1 秒重叠以鼓励段间连续性。判别器在生成段和真实视频上训练，使生成长视频的每一段都拟合数据分布。为省 GPU 内存，生成器一次只生成一段，下一段复用上一段 detach 的 KV cache，每段评估后累积梯度反传。作者指出这之所以可行，是因为对抗训练不需要 ground-truth 目标，判别器无需逐帧显式监督。

**关键公式**：原文未给出编号的数学公式。损失描述为 R3GAN 目标（relativistic loss + R1/R2 正则化），无显式公式呈现。

**推理流程**：首帧由用户提供 → 与 text、condition、noise 一起输入 → 单次前向生成下一帧 → 生成帧回收为输入，配合新 condition 和新 noise 递归生成 → KV cache 避免重算 → sliding window 保证任意长度生成的恒定速度和内存（Fig. 1）。

**消融（Sec. 4）**：

- **训练时长**（Table 5）：10s 训练 → Temporal Quality 85.86 / Frame Quality 57.92；20s → 85.60 / 65.69；60s → 89.79 / 62.16。60s 训练显著优于 10s。
- **Teacher-forcing vs Student-forcing**：teacher-forcing 对抗训练的模型在推理时几帧内内容即严重漂移（Fig. 7）；student-forcing 对缓解误差累积至关重要。作者指出先前工作用加高斯噪声缓解漂移 [93]，但不能从根本上解决分布差距。

## 5. 在 OT×扩散地图中的位置

本文属于 T19 中**对抗系蒸馏线**的延续，直接继承 APT [49]（对抗后训练，一步生成）并将其扩展到自回归场景。与 CausVid [117]（diffusion forcing + 4 步蒸馏）、MAGI-1 [75]（diffusion forcing + 8 步蒸馏）、SkyReel-V2 [9]（diffusion forcing 从头训练）构成直接竞争关系，在速度上全面超越（Table 4）。

在 OT×扩散地图中，本文位于**推理管线环节的「步数压缩」与「流式外推」交叉点**，但不涉及 OT/流公式本身。其 teacher-forcing → student-forcing 的转变对应课题背景中「流式外推的漂移作为累积传输误差」这一开放问题：作者用对抗训练框架内的 student-forcing 消除训练-推理分布差距，而非用 OT 距离显式建模漂移。与 Self-Forcing 的思路（训练时 self-rollout 匹配视频级分布）在动机上一致，但实现路径不同——本文用判别器而非分布匹配损失。

长视频训练中的「分段判别 + 1 秒重叠」策略可视为一种隐式的段间分布连续性约束，但未形式化为传输问题。帧间耦合方面，本文仅用 sliding window + 首帧始终 attend，没有显式的噪声耦合或光流 warp 机制，与 HIWYN/Go-with-the-Flow 的噪声传输线无直接关联。

## 6. 局限与批评

**作者承认的（Sec. 4 Limitations）**：

1. **一致性困难**：模型在保持主体和场景一致性上有困难，源于生成器的 basic sliding window 和判别器的 segment-based discrimination 无法强制长程一致性；作者建议未来用 identity embeddings [54] 或更优架构 [105, 80, 52, 21, 20]。
2. **一步生成缺陷的持久性**：一步生成仍会产生缺陷，且一旦缺陷出现，由于判别器同时强制时序一致性，缺陷会在场景中长时间保留。
3. **训练速度**：长视频训练过程慢。
4. **时长上限**：zero-shot 五分钟生成仍可产出内容但带伪影。

**读出来的**：

1. **Dynamic Degree 显著下降**：120 帧上 AAPT 的 Dynamic Degree 为 42.44，低于 diffusion baseline 的 52.52 和 Hunyuan 的 54.80（Table 1）。这是少步蒸馏中「运动塌缩」的典型表现，作者仅在注释中归因于 CausVid 的 12fps 训练，未对自己的运动幅度下降给出解释。
2. **1440 帧上 I2V Subject/Background 低于 MAGI-1 和 SkyReel-V2**（96.11/97.52 vs 96.90/98.13 和 96.50/98.07，Table 1），作者解释为 MAGI-1 视频大多静止导致 conditioning score 虚高，但这同时说明 AAPT 在长视频首帧条件保持上并非全面领先。
3. **无 OT/流理论贡献**：方法层面完全在对抗训练框架内，未触及 OT 或流匹配的公式改进，对 T19 课题的理论张力（帧间耦合、蒸馏目标几何约束）无直接贡献。

## 7. 对我们的启发

1. **Student-forcing 与 OT 漂移监测的结合**：本文证明 student-forcing 是消除训练-推理分布差距的关键，但未提供漂移的定量监测手段。可接切入点 #5：在 student-forcing 训练中引入在线 OT 距离（如 Sinkhorn 距离）监测滚动 KV 外推的分布漂移，当漂移超过阈值时触发锚定分布再投影正则，给出漂移的 TV/W2 上界。
2. **分段判别可作为 OT 段间耦合的替代品**：本文的「10 秒段 + 1 秒重叠」判别策略隐式约束段间连续性。可将其形式化为段间 latent 分布的 OT 耦合问题：在重叠窗口上求相邻段 latent 块之间的 minibatch-OT 配对，显式优化段间传输代价，替代或补充判别器的隐式约束。
3. **运动塌缩的 OT 诊断**：AAPT 的 Dynamic Degree 从 52.52 降至 42.44（Table 1），是少步蒸馏运动退化的直接证据。可接切入点 #4：用帧间光流幅度分布的 Wasserstein 距离对比 1 步学生与多步教师，建立「运动 OT 谱」作为蒸馏质量的诊断工具，并在 AAPT 这类对抗蒸馏框架中验证 OT 正则项能否缓解运动塌缩。
