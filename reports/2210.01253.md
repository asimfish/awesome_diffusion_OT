# PLOT: Prompt Learning with Optimal Transport for Vision-Language Models

> Guangyi Chen, Weiran Yao, Xiangchen Song, et al. · ICLR 2023 · [arXiv](https://arxiv.org/abs/2210.01253) · 证据级 [P] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：用 Sinkhorn OT 对齐局部视觉特征与多 prompt 集合，防止多 prompt 坍缩，few-shot 识别平均精度超 CoOp。

## 1. 问题

PLOT 解决的是 CLIP 类视觉-语言预训练模型在下游 few-shot 识别任务中的 prompt 学习问题。CoOp（Zhou et al., 2021b）为每个类别学习一个全局 prompt，但作者认为单个 prompt 不足以描述一个类别的多种内在属性与外在上下文关系（Sec. 1, Fig. 1）。直接学习多个 prompt 并分别与同一视觉特征匹配，等价于匹配 prompt 特征的均值与视觉特征，会促使所有 prompt 收敛到同一点，学不到互补特征（Sec. 1）。作者尝试过加约束推开 prompt 之间的距离，但报告「this solution still fails to learn representative and comprehensive prompts」（Sec. 1），原因是把视觉表示当作单一的点，忽略了不同 prompt 可能只关注视觉特征的一个子集。

## 2. 方法

核心思想：把局部视觉特征集合与多个文本 prompt 特征集合分别建模为离散分布，用最优传输距离替代 CoOp 中的单一余弦相似度，实现细粒度的跨模态对齐。

**视觉特征集合**：从 CLIP 视觉编码器的 multi-head attention pooling 层输出中取所有空间位置的特征，得到 $M = H \times W$ 个局部特征 $F = \{f_m\}_{m=1}^M \in \mathbb{R}^{M \times C}$（Sec. 3.3）。文本侧为每个类别 $k$ 初始化 $N$ 个 prompt，经文本编码器得到 $G_k = \{g_n\}_{n=1}^N \in \mathbb{R}^{N \times C}$。

**OT 距离**：离散分布 $U = \sum_m u_m \delta_{f_m}$，$V = \sum_n v_n \delta_{g_n}$，代价矩阵取余弦距离 $C = 1 - F^\top G_k$（Eq. 7）。OT 问题为：

$$d_{OT}(u, v|C) = \min_T \langle T, C \rangle \quad \text{s.t.} \quad T\mathbf{1}_N = u, \; T^\top \mathbf{1}_M = v, \; T \in \mathbb{R}_+^{M \times N} \tag{Eq. 4}$$

加熵正则后用 Sinkhorn 迭代求解（Eq. 5, 6）。

**两阶段优化**：内层固定视觉与文本特征，用 Sinkhorn 算法求 transport plan $T^*$ 和 OT 距离 $d_{OT}(k)$；外层固定 $T^*$，用交叉熵损失反向传播更新 prompt 参数（Sec. 3.3）。预测概率为：

$$p_{OT}(y=k|x) = \frac{\exp((1 - d_{OT}(k))/\tau)}{\sum_{k'} \exp((1 - d_{OT}(k'))/\tau)} \tag{Eq. 8}$$

作者强调整个流程端到端可微，Sinkhorn 迭代的矩阵乘法梯度被 autograd 记录（Sec. 3.3）。

## 4. 实验与数字

**数据集**：11 个视觉识别数据集——Caltech101、DTD、EuroSAT、FGVCAircraft、Flowers102、Food101、ImageNet、OxfordPets、StanfordCars、SUN397、UCF101（Sec. 4.1）。few-shot 设置取 1/2/4/8/16 shots，用原始测试集评估。域泛化用 ImageNet 训练，在 ImageNetV2、ImageNet-Sketch、ImageNet-A、ImageNet-R 上测试。

**主结果**（Fig. 3）：PLOT 在 11 个数据集平均精度上超过 CoOp，提升幅度随 shot 数变化：

| shots | PLOT 相对 CoOp 平均提升 |
|-------|------------------------|
| 1 | +3.03% |
| 2 | +3.45% |
| 4 | +2.13% |
| 8 | +1.38% |
| 16 | +0.61% |

出处：Sec. 4.3 正文。PLOT 在 Food101 和 DTD 上提升较大，在 StanfordCars 上与 CoOp 相当；作者归因于 StanfordCars 的判别特征重合度高，单个全局 prompt 已够用（Sec. 4.3）。

**域泛化**（Table 1，16 shots，N=4）：

| 方法 | Source (ImageNet) | -V2 | -Sketch | -A | -R |
|------|-------------------|-----|---------|-----|-----|
| CLIP + CoOp | 61.91 | 54.26 | 32.47 | 21.78 | 54.21 |
| CLIP + PLOT | 63.01 | 55.11 | 33.00 | 21.86 | 55.61 |

**消融**（Table 2，Caltech101/DTD/Food101）：直接匹配全局视觉特征与多 prompt 的均值（G）提升有限；加 prompt 方差正则（G+V）无一致提升；用不同初始化做集成（G+E）有提升但低于 PLOT；直接用 feature map 替换全局特征（M 或 M+V）在 1-shot 下约掉 20% 精度（Sec. 4.4）。

**prompt 数量分析**（Table 3）：N 从 1 增到 4 时，1-shot 精度在 Caltech101/DTD/Food101 上分别提升 1.36%、2.64%、1.68%；N=8 时提升不一致。默认 N=4，在 Caltech101 上调参后用于其他数据集（Sec. 4.4）。

**Adapter 兼容性**（Table 4）：Tip-Adapter-F + PLOT 在 11 个数据集平均精度上超过 Tip-Adapter-F，16-shot 平均 76.20% vs 75.83%（Sec. 4.4）。

**计算开销**：相对 CoOp 约增加 10% 推理时间和 5% 训练时间（Sec. 4.4）。

**零样本**：作者报告 PLOT 不能提升零样本学习（Sec. 4.4，详细分析在附录，原文截断未见）。

## 5. 在 OT×扩散地图中的位置

PLOT 属于线 B「attention 即 OT 的接口化」的早期工作，但严格说它不涉及 attention 矩阵，而是把 OT 用在 prompt-token 集合与视觉特征集合的对齐上。它和 Sinkformer（AISTATS 2022）共享同一个技术内核：用熵正则 Sinkhorn 替代 softmax 式的逐点匹配，获得带边际约束的全局耦合。PLOT 的贡献在于把这个内核从序列 attention 搬到了 prompt 学习场景，证明了「多 prompt 各自运输到不同视觉特征」可以防止 prompt 坍缩。

在课题地图中，PLOT 是 OTSeg（ECCV 2024）的直接前驱：OTSeg 在多模态解码器里用 MPSA 整体替换 cross-attention 归一化，让多个文本 prompt 各自运输到不同像素语义，PLOT 的「多 prompt + OT 对齐」思想在此被推广到 dense prediction。PLOT 与线 C 的 ICCC 2022 多 prompt OT 引导是同期精神先驱关系。它不涉及扩散模型，与 STORM/ASAG/OTComp 等采样期 OT 干预工作没有直接技术继承，但共享「OT 防止 many-to-one 错配」的动机。

## 6. 局限与批评

作者承认的：
1. 不使用 class-specific context，导致在细粒度分类数据集（如 FGVCAircraft）上表现低于 linear probing（Sec. 4.3）。
2. PLOT 不能提升零样本学习（Sec. 4.4）。
3. StanfordCars 上提升有限，作者归因于该数据集判别特征重合（Sec. 4.3）。

读出来的：
1. 视觉特征集合的边际分布 $u$ 取均匀分布（Sec. 3.3），这意味着所有空间位置被强制等质量运输。对于背景占大比例的图像，背景特征会与前景特征同等参与运输，可能稀释语义信号。论文没有讨论对 $u$ 做显著性调制（对比 SCOT 的做法）。
2. 内层 Sinkhorn 迭代次数未在正文给出（附录可能截断），Eq. 6 的迭代公式中 $u^{(t)}$ 和 $v^{(t)}$ 的更新写法与标准 Sinkhorn 略有出入（标准形式是交替缩放行和列），原文的符号不够清晰。
3. 两阶段优化中外层固定 transport plan 的做法，使得 prompt 的梯度不经过 plan 的重新优化，可能限制了对齐质量；作者声称端到端可微，但实际是交替优化而非联合优化。

## 7. 对我们的启发

1. **边际分布设计是可迁移的切入点**：PLOT 用均匀边际 $u$，而 SCOT 用显著性调制边际。在扩散 attention 的 OT 干预中（如 STORM/ASAG），把均匀边际换成基于去噪 latent 显著性或物体 mask 的边际，可能直接改善「背景特征被强制运输」的问题。对应切入点 #2 的 mass-aware 方向。
2. **「多 prompt 各自运输」可作为防止语义坍缩的通用机制**：在扩散引导中，多个文本 token 的 cross-attention 常出现 many-to-one 错配（多个 query 挤到同一 key）。PLOT 证明 OT 的边际约束可以强制分散运输。这为 ASAG 式采样期 attention 干预提供了一个判别式证据：OT 对齐确实能产生可解释的、分散的 transport plan（Fig. 4 的热力图）。
3. **两阶段交替优化的局限提示我们做联合优化**：PLOT 外层固定 plan 的做法可能次优。在扩散采样期 OT 干预中，plan 和去噪 latent 是交替更新的（每 k 步重算 plan），这天然是 PLOT 两阶段策略的推广。可以显式对比「固定 plan 多步」vs「每步重算 plan」对编辑一致性的影响，作为切入点 #1 的消融。
