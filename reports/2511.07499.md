# Toward the Frontiers of Reliable Diffusion Sampling via Adversarial Sinkhorn Attention Guidance

> Kwanyoung Kim · AAAI 2026 · [arXiv](https://arxiv.org/abs/2511.07499) · 证据级 [P] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：把 self-attention 重释为 OT，用对抗代价的 Sinkhorn 构造"劣化分支"做 guidance，即插即用提升 T2I/IP-Adapter/ControlNet 保真度

## 1. 问题

扩散模型直接采样（naïve sampling）输出质量欠佳。CFG（Ho and Salimans 2022）通过条件/无条件分数之差做加权调整来提升保真度，但需要额外训练，且 guidance scale 过大时输出退化（Sec. 1, p.1）。后续 guidance 方法（PAG、SEG、AutoGuidance 等）的共同策略是构造一个"弱化输出"作为辅助信号，引导主模型走向更好的采样轨迹。但作者指出：这些方法依赖启发式扰动——PAG 用 identity masking 扭曲 attention map，SEG 对 attention 权重做 Gaussian blur，AutoGuidance 依赖一个训练不佳的模型——缺乏理论依据，无法回答"什么是最优扰动"（Sec. 1, p.1–2）。

作者把问题定位在 self-attention 的语义对齐机制上：attention score 代表 pixel 级相似性与交互，现有方法"天真地破坏 attention 机制"，而 ASAG 的目标是用 OT 理论给出一个有原则的、可调的劣化路径构造方式。

## 2. 方法

核心思想：把 self-attention 的相似度矩阵重释为 OT 代价，然后**反转代价方向**——不是最小化 `1 − QK^T`（鼓励语义对齐），而是最小化 `QK^T`（压制 query-key 相似性），用 Sinkhorn 算法求出熵最大化的双随机 attention plan，作为"劣化分支" `˜ϵ_θ(x_t, c)`，再按 CFG 式的外推公式做 guidance。

关键公式：

**（1）guided sampling 的统一形式**（Eq. 4, p.3）：
$$\epsilon'_\theta(x_t, c) = \epsilon_\theta(x_t, c) + s\,(\epsilon_\theta(x_t, c) - \tilde\epsilon_\theta(x_t, c))$$
其中 `s` 是 guidance strength，`˜ϵ_θ` 是"弱化变体"，模拟 undesirable score。CFG 里弱化方式是丢掉条件，PAG 里是注入 identity condition，ASAG 里是用对抗 Sinkhorn attention 替换 self-attention。

**（2）对抗 Sinkhorn attention（ASA）**（Eq. 13, p.4）：
$$\text{ASA}(Q_t, K_t, V_t) = \text{Sinkhorn}(\lambda M^\downarrow_t)\, V_t, \quad M^\downarrow_t = Q_t K_t^\top$$
对比标准 Sinkhorn attention（Eq. 12）用 `M^↑_t = 1 − Q_tK_t^T` 最大化相似性，ASA 用 `M^↓_t = Q_tK_t^T` 最小化相似性。`λ = 1/√d`。

**（3）熵正则 OT 目标**（Eq. 6, p.3）：
$$d^\lambda_M(\mu, \nu) = \min_{P \in U(\mu,\nu)} \langle P, M\rangle - \frac{1}{\lambda}\langle P, \log P\rangle$$

采样流程（Algorithm 2, p.5）：每个 timestep `t` 从 T 到 1，先用 ASA 构造的 `˜ϵ_θ` 按 Eq. 4 修正 `ϵ_θ(x_t, c)`，再按 DDIM 更新规则（Eq. 2）用 Tweedie 估计 `x̂_0(t)`（Eq. 3）递推。ASA 只应用在部分 self-attention 层（受 PAG/SEG 只扰动 attention 子集的启发，Sec. Methods, p.4）。Sinkhorn 迭代用 log-domain 稳定版（Schmitzer 2019），实际只需约 2 次迭代即稳定（Sec. Ablation, p.6）。

## 3. 理论结果

**Theorem 1（Entropy-Maximizing Plan via Adversarial Sinkhorn）**（p.5, 证明见 supplement）：设 `Q_t, K_t ∈ R^{n×d}`，对抗代价 `M^↓_t = Q_tK_t^T`。在熵正则 OT 问题中，当 `λ → 0`（即 `1/λ → ∞`）时，最优 transport plan 收敛到最大熵均匀耦合：
$$\lim_{\lambda \to 0} P^*_t = \frac{1}{n^2} \mathbf{1}\mathbf{1}^\top$$

**Lemma 1（Uniform Plan Maximizes Entropy）**（p.5）：在均匀边际 `µ = ν = (1/n)1` 下，耦合 `P^* = (1/n^2)11^T` 在 transport polytope `U(µ, ν)` 上唯一最大化 Shannon 熵。

**Corollary 1.1**（p.5）：`δ_t := ϵ_θ(x_t, c) − ˜ϵ_θ(x_t, c)` 定义了 score 空间中一个有语义基础的方向——锚定原始 attention、偏离熵最大化对抗轨迹，从而提供有原则的对比式 guidance。

**Remark 1**（p.5）：`λ → 0` 的均匀 plan 是语义破坏的理论极端，但直接使用会导致生成多样性下降和不稳定；ASA 用有限 `λ` 的 Sinkhorn plan，保留双随机结构、可控地增加熵，兼顾稳定性。

理论的性质：这是对 ASA 构造的**极限行为刻画**（λ→0 时退化为均匀耦合），不是对生成质量或收敛性的保证。作者用"Practical Justification"（p.5）明确承认均匀 plan 直接使用会降低多样性，实际方法依赖有限 λ 的折中。

**Guidance scale 分析**（Fig. 6, p.6）：性能随 `s` 增大先升后降，峰值在 `s = 1.5`，过大值导致轻微退化（类似 CFG）。

## 5. 在 OT×扩散地图中的位置

ASAG 属于**线 B（attention 即 OT 的接口化）**与**线 C（采样级 OT 耦合先验）**的交汇点，具体是"采样期操控传输结构"的**反向操作**。

继承关系：
- 直接继承 Sinkformer（Sander et al. 2022）的"softmax attention 是 Sinkhorn 第一轮迭代"结论，以及 OTSeg（Kim, Oh, and Ye 2024）的 Sinkhorn attention 公式（Eq. 10 即 OTSeg 的 MPSA 形式）。
- 在 guidance 框架上继承 PAG（Ahn et al. 2025）和 SEG（Hong 2024）的"扰动 attention 子集构造劣化分支"策略，但把启发式扰动（identity masking / Gaussian blur）替换为 OT 代价反转。
- 与 STORM（CVPR 2025）形成镜像：STORM 用带空间代价的 OT 把 attention map **重定位到目标区域**（正向引导），ASAG 用对抗代价把 attention **推向熵最大**（负向引导）。两者都利用"attention 是熵正则 OT 的单边归一化"这一接口，但方向相反。

理论张力：ASAG 触及的核心问题是"什么是最优的 undesirable path"。它给出的答案是：在 OT 语义下，最优劣化是**熵最大化**（λ→0 的均匀耦合），即完全抹除 query-key 相似性偏好。这为 T16 的"attention plan 偏离最优耦合 ⇒ 语义错乱"提供了一个反向版本——不是偏离导致错乱，而是**主动推向最大熵**作为对比信号。但注意：ASAG 的 Theorem 1 只刻画了 λ→0 的极限，没有建立"劣化程度"与"生成质量提升"之间的定量关系，理论仍是动机性的。

## 6. 局限与批评

**作者承认的**：
1. 均匀 plan `(1/n^2)11^T` 是理论极端，直接使用会降低生成多样性和稳定性（Sec. Practical Justification, p.5；Table 3 中 IS 从 10.54 降到 9.710）。
2. Sinkhorn attention 本身计算昂贵，应用到所有 attention 层开销显著（Sec. Methods, p.4），因此 ASAG 只选择性应用于部分层。
3. 过大 guidance scale 会导致性能退化（Fig. 6, p.6），与 CFG 的饱和/退化行为类似。

**读出来的**：
1. **理论-实践断裂**：Theorem 1 证明的是 λ→0 的极限行为，但实际方法用有限 λ（`1/√d`），且 Table 3 显示均匀 plan 的 FID（92.11）与 ASAG（92.01）几乎相同，差异只在 IS。这意味着论文的核心理论结论（熵最大化）与实际采用的机制（有限 λ 的 Sinkhorn plan）之间的因果链没有被实验直接验证——ASAG 的优势可能来自"双随机归一化 + 代价反转"本身，而非"逼近熵最大"。
2. **缺乏对"劣化分支质量"的直接度量**：没有实验展示 ASA 产生的 attention map 与标准 attention 的差异程度（如熵、互信息、与语义区域的对应关系），也没有验证"劣化分支确实弱化了语义对齐"这一前提。
3. **下游任务只有定性结果**：ControlNet 和 IP-Adapter 的实验仅以 Fig. 4、5 的定性图呈现，没有 FID/CLIPScore 等定量数字，无法判断"显著提升"的幅度。
4. **单作者、单机构**（Samsung Research），实验规模与消融深度相对有限；SD3 上 SEG 因"官方不支持"被省略，削弱了对比完整性。

## 7. 对我们的启发

1. **可接切入点 #2（不平衡/partial OT 的 guidance 化）**：ASAG 的 ASA 用均匀边际 `µ = ν = (1/n)1`，这在跨域语义不守恒（物体增删、部件缺失）时会把质量强行均分。把 UNITE 的自适应质量学习引入 ASA 的边际约束，构造 mass-aware 对抗 Sinkhorn attention，在多物体编辑 benchmark 上测属性泄漏率与编辑成功率，是直接可做的扩展。
2. **可接切入点 #3（"attention plan 偏离最优耦合 ⇒ 语义错乱"的定量理论）**：ASAG 的 Theorem 1 只刻画了 λ→0 极限，没有给出"有限 λ 下 ASA plan 与标准 softmax attention 的偏差"与"生成质量提升"的定量关系。可以尝试在线性化 DiT 假设下，推导熵正则 OT plan 与 softmax attention 的偏差范数作为 attribute mis-binding 概率的上界，用 ASAG 的消融数据（Table 3 的 FID/IS 随代价方向变化）做初步验证。
3. **可接 token 级 OT 一致性 metric（切入点 #5）**：ASAG 的 ASA 提供了一个天然的"劣化 attention"参考分布。可以把编辑前后 cross-attention plan 的（Gromov-）Wasserstein 距离做成编辑一致性度量，并用 ASA 的熵最大化 plan 作为"完全失配"的标定点，与 CLIP-score、LPIPS、人工评分做相关性分析。
