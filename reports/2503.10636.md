# The Curse of Conditions: Analyzing and Improving Optimal Transport for Conditional Flow-Based Generation

> Ho Kei Cheng, Alexander Schwing · ICCV 2025 · [arXiv](https://arxiv.org/abs/2503.10636) · 证据级 [P] · 课题 T08 OT-CFM 与 minibatch OT 耦合
> **一句话**：无条件 minibatch OT 在条件生成中系统性有害（训练先验被条件偏斜），成本矩阵加条件项即修复。

## 1. 问题

Minibatch OT 耦合（Tong et al.、Pooladian et al.）在无条件 FM 中拉直流、降低 NFE，但本文发现它在**条件生成**里一贯地比独立耦合更差（Fig. 1）。机制：OT 配对只看 $\|x_0-x_1\|^2$，不看条件 $c$；配对后 $(x_0,c)$ 变得相关——Fig. 2 的一维例子里，先验左半边总配 $c=0$、右半边总配 $c=1$。训练时模型只见过这种偏斜的 $(x_0,c)$ 组合，测试时却从完整先验 $q(x_0)$ 独立采噪声并任意指定 $c$，遇到从未见过的 $(x_0>0,c=0)$ 组合就失效（Sec. 3.2）。

形式化（Eq.(7)）：对一般的 OT 耦合 $\pi_{\text{ot}}(x_0,x_1,c)$，要得到 $q(x_1|c=c_1)$ 所需的先验是 $\int\pi_{\text{ot}}(x_0,x_1|c=c_1)dx_1=q(x_0|c=c_1)$，测试时不可得；除非 $q(x_0|c)=q(x_0)$，否则条件分布无法被准确复现。此前 LOOM-CFM（Davtyan et al.）把条件生成留作未来工作，等变 FM 只处理特定对称性数据（Sec. 2）。

## 2. 方法

核心思想：在每个条件内部独立做 OT，让 $x_0$ 与 $c$ 保持独立、同时保留 $x_0$ 与 $x_1$ 的 OT 关联。

- 目标联合分布（Eq.(8)）：$\pi_{\text{c2ot}}(x_0,x_1,c):=q(x_0)\,q(c)\,\pi_{\text{ot}}(x_1|x_0,c)$。对任意 $c_1$ 对 $x_1$ 积分得 $q(x_0)$（Eq.(9)），先验不再偏斜。
- 实现（Eq.(10)，Alg. 3）：在 $b\times b$ 匈牙利匹配的成本矩阵上加条件项：$\min_P\|X_0-PX_1\|_2^2+\sum_i f(C_i,[PC]_i)$，$f$ 对称非负且 $f(c,c)=0$；代码上只是 `Cost ← pairwise_dist(X0,X1) + pairwise_dist(C,C)`。
- 离散条件（Eq.(11)）：$f_d(c_1,c_2)=\infty$ 若 $c_1\ne c_2$，否则 0——禁止配对改变条件，等价于每类内部独立解 OT，**精确**采样 Eq.(8)。注意 $PC=C$ 不意味着 $P=I$，同类样本之间仍可交换。
- 连续条件（Eq.(12)）：$f_d$ 会退化为独立耦合（几乎没有两条件相等），改用 $f_c(c_1,c_2)=w\cdot\mathrm{cdist}(c_1,c_2)$（余弦距离）；$w=0$ 回到 OT，$w\to\infty$ 趋于独立耦合，只是 Eq.(8) 的近似。
- 自适应 $w$（Eq.(13)）：定义「潜在 OT 候选比例」$r(w)=\frac1{B^2}\sum_{i,j}\mathbb 1[\|X_{0i}-X_{1j}\|^2+w\,\mathrm{cdist}(c_i,c_j)\le\|X_{0i}-X_{1i}\|^2]$，指数搜索 + 二分搜索使 $r(w)\approx r_{\text{tar}}$；$r_{\text{tar}}$ 对距离尺度不变，跨数据集/分辨率可复用；相邻 batch 的 $w$ 变化 <1%，10 次迭代内收敛。全文取 $r_{\text{tar}}=0.01$。
- 过采样 OT batch（Sec. 3.3.4）：$k$ 个类时有效 OT batch 缩到 $b/k$，故把 OT batch $b$ 与网络 batch $b_n$ 解耦，取 $b\gg b_n$（CIFAR-10 640、ImageNet 6400，$b_n$ 为 256/512）；一个 OT batch 供 $b/b_n$ 次前后向复用，摊销代价 $O(b^2b_n)$；OT 放到 data worker 的 CPU 上并行，8 worker/GPU 时 $b\le6400$ 无挂钟开销。

## 3. 理论结果

无定理编号，但有两条精确推导：(i) Eq.(7) 证明一般 OT 耦合在条件生成中所需先验为 $q(x_0|c)$，即训练–测试先验不匹配的必然性；(ii) Eq.(9) 证明 $\pi_{\text{c2ot}}$ 对任意条件的 $x_0$ 边际都是 $q(x_0)$，且离散条件下 Alg. 3 精确采样该分布。连续条件下的 $f_c$ 只给出「$w$ 两端极限分别为 OT 与独立耦合」的定性说明，没有偏差界。

## 5. 在 OT×扩散地图中的位置

本课题「成本函数设计」路线中最直接的一篇：它不改 OT 求解器、不改 batch 大小，只改成本矩阵，却揭示了 OT-CFM（2302.00482）/ Multisample FM（2304.14772）在条件生成下的系统性失效——这是综合报告 I2「OT 用量是可研究变量」张力三角的第三个顶点（与大 Sinkhorn 2506.05526、NSOT 并列）。LOOM-CFM（2603.15279）App. G 承认的「条件与噪声区域对齐产生采样偏差」正是本文 Eq.(7) 所刻画的现象，两篇同年互补。

与等变 FM（2306.15030）、Metric FM（2405.14780）同属「把先验/结构编码进成本」的谱系，但目标相反：等变/度量成本是让配对**更**贴合数据结构，C²OT 是让配对对条件**不**敏感（保持 $x_0\perp c$）。SD-FM（2509.25519）的条件三角映射扩展是同一问题的半离散版本。Table A3「从配对噪声预测类别」把「先验偏斜」变成可测量，是 T12 环节 ①/② 评估耦合是否引入条件泄漏的现成探针。

对应张力 3「直 vs 最优」的条件版：Table A1 显示 OT 最直但 FID 最差，C²OT 用少量直线度换回正确的条件边际——「直线度」与「边际正确性」被再次拆开。对应推理管线环节 ①（数据管线噪声指派）在条件模型上的修正准则。

## 6. 局限与批评

作者承认：(1) 高维图像上收益比 2D 小得多，猜测是图像数据更纠缠、OT 引起的先验偏斜更弱（Sec. 4.2；Table A3 显示 OT 的类别可预测率随分辨率从 29.7% 降到 20.1%）；(2) 连续条件的 $f_c$ 只是 Eq.(8) 的近似，需要 $r_{\text{tar}}$ 超参；(3) 越接近真 OT 自适应求解器 FID 越差，作者归因于「更准的耦合减少了训练数据变化、类似少了数据增广」（Sec. 4.3.1）；(4) ImageNet-256 只训 64 epoch，与 800 epoch 的报告值不可比。

我读出来的：(1) C²OT 相对 FM 的收益在高维几乎在噪声内：CIFAR-10 自适应 2.904 vs 2.922、Euler-25 5.644 vs 5.640、ImageNet-32 自适应 5.350 vs 5.358、CLIP 完全持平——真正稳健的差距只在 Euler-2/5 与 ImageNet-256 Euler-50/100（3.72 vs 3.89、3.32 vs 3.48）；论文的主要贡献是「诊断 OT 有害」而非「C²OT 大幅优于 FM」；(2) Euler-2 上 OT 仍是 FID 最低（CIFAR 64.4、ImageNet-32 81.3 vs C²OT 102.4），说明先验偏斜在极少步时被「更直」抵消，作者以 CE/CLIP 更差来回应，但没有讨论这种权衡何时值得；(3) 有效 OT batch $b/k$ 的问题在 1000 类 ImageNet 上意味着 6400/1000≈6 个样本/类，此时类内 OT 几乎退化为独立耦合——文本条件下的 $f_c$ 版本实际有效性没有单独量化；(4) 「越接近 OT 多步越差」的解释是猜测，没有实验区分「多样性损失」与「minibatch OT 高维噪声」两种机制。

## 7. 对我们的启发

1. 接 Top-10 #1（MPNA）：推理期 batch 级 (条件, 噪声) 指派必须满足 Eq.(9) 的 $x_0\perp c$ 约束，否则会在训练–推理之外制造新的「推理内先验偏斜」；C²OT 的 $f_d$ 块对角结构给出现成做法——按条件分组后组内 Hungarian，且 Table A3 的类别可预测率可直接作为我们方法的「保边缘性」检验指标。
2. 接课题 §5 问题 3（语义成本的系统消融）：本文只试了余弦距离一种 $f_c$ 与一个 $r_{\text{tar}}$；把 CLIP/DINO 语义成本、latent Mahalanobis 成本放进 Eq.(10) 同框架比较，并用 Eq.(13) 的尺度不变比例做统一超参，是空位明确的一篇。
3. 理论空位：给 $f_c$ 版本写出「$x_0$ 与 $c$ 的互信息 ≤ g(w, r_tar)」型偏斜上界，把 Table A3 的经验量变成定理，接 Top-10 #5 的耦合训练统计率。
