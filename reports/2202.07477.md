# Understanding DDPM Latent Codes Through Optimal Transport

> Valentin Khrulkov, Gleb Ryzhakov, Andrei Chertkov et al. · ICLR 2023 · [arXiv](https://arxiv.org/abs/2202.07477) · 证据级 [P] · 课题 T02 扩散模型与 OT 的理论联系
> **一句话**：猜想 DDPM 的 PF-ODE encoder 映射就是到 $\mathcal N(0,I)$ 的 Monge OT 映射；对多元高斯给出证明，合成分布上传输代价相对误差 $\sim10^{-15}$。

## 1. 问题

DDIM / PF-ODE 给扩散模型一个确定性的可逆 encoder：数据 $\to$ 标准正态的 latent code。它支撑图像反演、编辑、唯一编码和精确似然计算，但这个映射本身的数学性质此前没有人刻画（Sec. 1）。本文问的是：对 VP-SDE（DDPM）的 PF-ODE，$t\to\infty$ 的流映射 $E_{\mu_0}$ 是不是二次代价下 $\mu_0\to\mathcal N(0,I)$ 的 Monge 最优传输映射？

作者的先验直觉来自 Otto calculus：Fokker–Planck 的解曲线是 Wasserstein 空间中的梯度流，相邻两个无穷小时刻的密度之间的 OT 映射恰由 PF-ODE 的流给出，所以整条轨迹是"无穷小最优传输的序列"——这一般不保证复合后是全局 OT 映射，但数值实验显示在目标为 $\mathcal N(0,I)$ 时两者几乎无法区分（Sec. 3）。

## 2. 方法

**设定**：VP-SDE $dx=-\frac12\beta(t)x\,dt+\sqrt{\beta(t)}dw$（Eq.(5)），PF-ODE $dx=-\frac{\beta(t)}2[x+\nabla\log p_t(x)]dt$（Eq.(6)）。换时间变量去掉 $\beta$ 后 Fokker–Planck 为 $\partial_tp=\nabla\cdot(xp)+\nabla^2p$（Eq.(8)），PF-ODE 为 $dx=-[x+\nabla\log p_t(x)]dt$（Eq.(9)）。encoder 映射定义为流的无穷时间极限 $E_{\mu_0}(x):=\lim_{t\to\infty}E_{\mu_0}(t,x)$，满足 $E_{\mu_0\#}\mu_0=\mathcal N(0,I)$（Sec. 2.2、Sec. 3）。

**三条证据**：
1. 玩具例（Sec. 3.1）：$\mu_0=\mathcal N(a,I)$，$\mu_t=\mathcal N(ae^{-t},I)$，PF-ODE 为 $dx/dt=-ae^{-t}$，极限 $E(x)=x-a$，正是 OT 映射。
2. 定理（Sec. 3.3，Theorem 3.1）：一般多元高斯情形，见 §3。
3. 数值（Sec. 3.4）：用 tensor-train（TT）格式的 Fokker–Planck 求解器（Chertkov & Oseledets 2021：Chebyshev 网格、二阶算子分裂、谱微分、TT-cross 插值，App. C）算出 $p_t$，再对从 $p_0$ 采的点云 $X_0$ 用 Runge–Kutta 积分 PF-ODE 得 $X_1$；用 POT 库算 $X_0\to X_1$ 的离散 OT 代价，与"$x_i\mapsto E(x_i)$"这个指派的代价比较，相对误差 $\varepsilon_{rel}(p)=\frac{\mathrm{Cost}(E_p)-\mathrm{Cost}(OT)}{\mathrm{Cost}(OT)}$。测试分布：$d=2,3$ 用最多 5 个 $\exp(-q_1-q_2)$（$q_1$ 二次、$q_2$ 四次多项式）的均匀混合（Eq.(14)），$d=7$ 用秩 2 随机正 TT 函数乘标准高斯（Eq.(15)）；空间域 $[-8,8]^d$，时间 $[0,5]$，每个维度 100 个随机密度。

**图像实验（Sec. 3.5）**：若两个数据分布的 encoder 都是到 $\mathcal N(0,I)$ 的 L2-OT 映射，同一个 latent code 解码出的两张图应在像素空间"平均地"接近，即纹理 / 颜色 / 姿态相似。用 guided-diffusion（LSUN 配置，1000 步）分别在 AFHQ 三类（15000 张，训练 $3\times10^5$ 步）、FFHQ（70k，$10^6$ 步）、MetFaces（1000 张，从 FFHQ 微调 $25\times10^3$ 步）训练 256×256 模型，加条件 ImageNet 256 checkpoint 换类别标签。

## 3. 理论结果

- **Theorem 3.1**（Sec. 3.3，证明 App. B）：$\mu_0=\mathcal N(a(0),\Sigma(0))$，则 $E_{\mu_0}(x)=\Sigma(0)^{-1/2}(x-a(0))$，即 $\mu_0\to\mathcal N(0,I)$ 的 Monge OT 映射。证明：$\Sigma(t)=I+e^{-2t}(\Sigma(0)-I)$、$a(t)=e^{-t}a(0)$，所有 $\Sigma(t)$ 可交换；齐次部分 PF-ODE $dx/dt=-(I-\Sigma^{-1}(t))x$（Eq.(17)）在 $\Sigma(0)$ 的特征基下逐分量解为 $f(\lambda,t)=\sqrt{(e^{-2t}(\lambda-1)+1)/\lambda}\to\lambda^{-1/2}$（Eq.(19)）；非齐次项用常数变易得 $\lim g(\lambda,t)=-\lambda^{-1/2}$（Eq.(21)）。
- **猜想**（Sec. 3.3 Discussion）：Theorem 3.1 的结论"也许近似地"对任意分布（或很大一类分布）成立；作者把精确分析留作未来工作。
- 对反例的回应（Sec. 3.3）：作者知悉 Lavenant & Santambrogio (2022) 的反例，表述为"两个映射在单个点不完全相等"，并称在有限样本、高维情形差异仍极低。
- App. A 澄清：PF-ODE 不是 Benamou–Brenier 问题的解（其轨迹不是直线，Figure 1、Figure 3），本文只声称 $t\to\infty$ 的流映射解 Monge 问题。

每个密度在普通笔记本上约 100 s（Sec. 3.4）。对 Lavenant–Santambrogio 的反例分布跑同一流程，也得到机器精度级差异（Sec. 3.4）。

**图像**：Figure 4 上：AFHQ Dog/Cat/Wild 三个独立模型从同一 code 解码，多数情况下姿态与纹理对应；下：FFHQ/MetFaces 传递性别、纹理、发型、胡须等，模型的噪声伪影也共享。Figure 5：条件 ImageNet（rooster / pizza / crab / corgi）同 code 共享纹理。对照：预训练条件 BigGAN 无此现象，说明纹理对齐是 DDPM 特有而非条件机制导致（Sec. 3.5）。**数值**：AFHQ 每类验证集 500 张，DDIM 反演得 code，在 $\mathbb R^{256\times256\times3}$ 用 POT 算图像与 code 的 OT 矩阵，OT 代价与 ODE 诱导指派的代价"在三种情况下都精确到机器精度"匹配；作者自己指出高维少样本下这一吻合不令人意外（Sec. 3.5）。

## 5. 在 OT×扩散地图中的位置

- **辩论线的起点**（KB §3"辩论爆发"）：本文提出 Conjecture，Lavenant–Santambrogio（`The_flow_map_of_the_Fokker_Planck_equation_does_no`）随即证伪一般情形，且指出障碍是 $D^2u$ 与 $D^2(\log\det D^2u-\frac12|\nabla u|^2)$ 的非交换；Tanana（`1709.06464`）是更早的高斯反例前驱（drift $-Ax$）。三者合成 KB 的结论：逐时刻最优 ≠ 全局最优，但数值上近乎最优。
- **正面结果的边界**：Theorem 3.1 与 Pierret–Galerne（`2405.14250`）Prop. 3 一致（后者给出任意有限区间的高斯闭式解，并指出实践中 $\mathcal N_0$ 初始化使生成流不是 OT 流）；P. Zhang et al.（`2311.03886`）给出"特定条件下有限时间区间上 PF 是 Monge map"的另一类正面结论。
- **应用侧含义**：Sec. 3.5 的"同 code 跨域解码"就是 KB §4 方向二警示的做法——两个域的 encoder 复合当跨域映射；本文说它像素级 L2 对齐，但没有最优性保证。这与 T13 神经 OT 翻译、T14 桥式 I2I 形成对照。
- 本文也是 Chen et al.（`2405.11326`）"轨迹非直但近 OT"讨论的前身（Figure 1 明说高斯情形轨迹也不是直线）。

## 6. 局限与批评

作者承认：
1. 一般情形只有猜想，无证明（Sec. 3.3）；已知存在反例。
2. 像素空间二次代价对视觉数据"似乎次优"，希望构造导出特征级代价的扩散过程（Sec. 5）。
3. AFHQ 数值实验的机器精度吻合在高维少样本下不足为证（Sec. 3.5）。

我读出的：
4. 检验标准太弱：比较的是"$x_i\mapsto E(x_i)$ 这个指派的代价"与"点云间离散 OT 代价"。前者是可行方案，二者相等只说明该指派是有限点集上的最优匹配（等价于采样对的循环单调性），这是比"$E=\nabla\varphi$"弱得多的性质，高维、有限样本下极易满足；它无法探测 $O(\varepsilon)$ 级的非最优性——这正是 Sec. 3.4 对反例分布也得到机器精度的原因。
5. 对反例的描述不准确："在单个点不相等"是误读。Lavenant–Santambrogio 证明的是必要条件（Hessian 交换性）在一点失效，从而 $S_\infty$ 不是凸函数梯度；光滑映射若在一点不同则在一个开邻域上不同，只是幅度可能很小。
6. "$t\to\infty$ 极限"在数值上用 $[0,5]$ 截断（$e^{-5}\approx0.007$），文中未报告截断对结果的影响。
7. 图像实验是定性的；"纹理对齐"与"OT 映射"之间只有启发式联系，任何 L2 意义下近似单调的编码器都会有类似现象。

## 7. 对我们的启发

1. **KB §5 第 1 点（量化 $S_\infty$ 次优度）**：复用本文 TT Fokker–Planck 求解器（App. C）在可控分布族上扫描，但检验量必须换成映射层的 $\int|S_\infty-\nabla u^*|^2d\mu_0$ 或 $DS_\infty$ 的非对称部分范数，而不是本文的指派代价差；Tanana 的 $DS_\infty$ 非对称检验（`1709.06464`）是现成模板。
2. **切入点 #1 保边缘噪声指派（MPNA）**：本文的"同 code 跨域纹理对齐"说明预训练 encoder 已给出一个近单调的噪声指派；保边缘指派方法应以 $E_{\mu_0}$ 为初始化并显式修正其非梯度分量，而非从零学 OT。
3. **代价选择**：作者自己承认像素 L2 代价不合适；做跨域生成时应把 OT 代价放到特征空间，这与 T16 语义对应课题相接。
