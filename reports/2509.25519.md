# Flow Matching with Semidiscrete Couplings

> Alireza Mousavi-Hosseini, Stephen Y. Zhang, Michal Klein, Marco Cuturi · arXiv 2025 · [arXiv](https://arxiv.org/abs/2509.25519) · 证据级 [R] · 课题 T08 OT-CFM 与 minibatch OT 耦合
> **一句话**：用全数据集半离散 OT 势函数替代 minibatch OT 配对，训练时 O(N) MIPS 指派噪声，FID 优于 I-FM 且开销远低于 OT-FM。

## 1. 问题

Flow matching（FM）默认使用独立耦合 $\pi_I = \mu_0 \otimes \mu_1$ 采样噪声-数据对。独立耦合诱导的 ODE 路径曲率高，推理时需要更多 NFE 才能获得可接受的样本质量（Sec. 2, "Straighter flows"）。OT-FM（Pooladian et al., 2023; Tong et al., 2024）用 batch 内 OT 配对替代独立采样，但实践中收益有限。Zhang et al. (2025) 指出原因在于 batch size $n$ 太小：小样本上的最优匹配受维度诅咒影响，无法可靠近似大 $n$ 下的匹配（Sec. 1, "Optimal Transport Flow Matching"）。扩大 $n$ 到约 $10^6$ 需要多 GPU 节点的 Sinkhorn 实现，且 Sinkhorn 的预计算成本按 $O(n^2/\varepsilon^2)$ 增长（Sec. 1, "The Semidiscrete Approach"），其中 $\varepsilon$ 是熵正则参数，而实验表明 $\varepsilon$ 越小、$n$ 越大效果越好——这是一个计算上不可持续的"爆炸性超参数组合"（Sec. 2, "... using pairs sampled from OT couplings"）。

本文要解决的问题是：如何在不依赖 minibatch OT 配对的前提下，获得接近全局 OT 耦合的 FM 训练配对，同时把配对开销降到可忽略。

## 2. 方法

核心思想：目标数据集是有限大小 $N$ 的离散分布 $\nu = \sum_{j=1}^N b_j \delta_{y_j}$，噪声分布 $\mu_0$ 是连续的。因此可以直接求解半离散 OT（SD-OT）问题，得到一个大小为 $N$ 的对偶势向量 $g \in \mathbb{R}^N$。训练时，每个新采样的噪声 $x_0$ 通过最大内积搜索（MIPS）指派给数据点，成本 $O(N)$（Sec. 1, "The Semidiscrete Approach"）。

**关键公式**：

半离散 OT 的半对偶形式（原文 Eq. (Sε)）：
$$\max_{g \in \mathbb{R}^N} F_\varepsilon(g) := \mathbb{E}_{X \sim \mu}[f_{g,\varepsilon}(X)] + \langle b, g \rangle,$$
其中 soft-c 变换（原文 Eq. (2.4)）：
$$f_{g,\varepsilon}(x) = \begin{cases} -\varepsilon \log\left[\sum_{j=1}^N b_j \exp\left(\frac{g_j - c(x, y_j)}{\varepsilon}\right)\right], & \varepsilon > 0 \\ -\max_{j=1}^N [g_j - c(x, y_j)], & \varepsilon = 0. \end{cases}$$

给定势向量 $g$，构造耦合 $\pi_{\varepsilon,g}$（原文 Eq. (3.2)）：
$$d\pi_{\varepsilon,g}(x, y_j) := [s_{\varepsilon,g}(x)]_j \, d\mu(x), \quad s_{\varepsilon,g}(x) := \sigma_{b,\varepsilon}([g_j - c(x, y_j)]_j) \in \Delta_N.$$
该耦合自动满足第一边缘约束（噪声侧），当且仅当第二边缘 $m(g) = [\pi_{\varepsilon,g}(\mathbb{R}^d, y_j)]_j$ 等于 $b$ 时才是 OT 耦合（Sec. 3, "Marginal Estimation for SD Couplings"）。

**算法流程**（Sec. 4, "SD-FM vs. OT-FM vs. I-FM"）：
1. **预计算阶段**：用 SGD 求解 $(S_\varepsilon)$，存储 $g^\star \in \mathbb{R}^N$。成本 $NdK$，其中 $K$ 是 SGD 步数（Table 1）。
2. **FM 训练阶段**：采样噪声 $x_0$，按 $k \sim s_{\varepsilon,g^\star}(x_0)$ 选择数据点 $x_1^{(k)}$。当 $\varepsilon = 0$ 时退化为 $k^\star = \arg\max_k [g_k^\star + \langle x_0, x_1^{(k)} \rangle]$，即精确 MIPS（Sec. 4）。

成本函数采用点积成本 $c(x, y) = -x^\top y$，条件生成时用增广成本 $c((x,z),(x',z')) = c_X(x,x') + \beta c_Z(z,z')$（Eq. (2.3)）。$\varepsilon$ 按参考 batch 的成本矩阵标准差重缩放（Sec. 4）。

## 3. 理论结果

**收敛准则**（Sec. 3, "Convergence Criterion"）：提出用 $\chi^2$ 散度 $\chi^2(m(g) \| b)$ 作为 SD-OT 收敛的监控指标。Fact 1（原文 Eq. (3.4)）给出其期望形式：
$$\chi^2(m(g) \| b) = \iint_{x,x' \in \mathbb{R}^d} \sum_j \frac{1}{b_j} [s_{\varepsilon,g}(x)]_j [s_{\varepsilon,g}(x')]_j \, d\mu(x) d\mu(x') - 1.$$
由此得到无偏估计量 $\hat{\chi}^2$（原文 Eq. (3.5)），用 $B$ 个 i.i.d. 样本在 $O(NB)$ 时间内计算。作者指出 TV 距离作为收敛准则会有偏，因为期望在范数内部，去偏需要与 $N$ 线性增长的样本数（Sec. 3）。

**SGD 收敛定理**（Theorem 2, Sec. 3）：假设 $\varepsilon > 0$ 或 Assumption 1 成立（Assumption 1：$c(x,y) = -x^\top y$，$\delta := \min_{j \neq j'} \|y_j - y_{j'}\| > 0$，$\mu$ 有 Lebesgue 密度，且 $\mu$ 的凸子集最大表面积有界 $C_\mu^{\max}$；当 $\mu = N(0, I_d)$ 时 $C_\mu^{\max} \leq 4d^{1/4}$）。令 $L_\varepsilon := 1/\varepsilon$（$\varepsilon > 0$）或 $L_0 := C_\mu^{\max}/\delta$（$\varepsilon = 0$），常数学习率 $\eta_k = \sqrt{\Delta/(L_\varepsilon K)}$，其中 $\Delta := F_\varepsilon^\star - F_\varepsilon(0)$。则对任意 $\varepsilon \geq 0$：
$$\mathbb{E}[\chi^2(m(g_t) \| b)] \lesssim \frac{1}{\min_j b_j} \sqrt{\frac{L_\varepsilon \Delta}{K}},$$
$$\mathbb{E}[C_\varepsilon(\pi_{\varepsilon,g_t})] - C_\varepsilon^\star \lesssim \left(\|g_\varepsilon^\star\|_2 + \frac{\Delta}{L_\varepsilon}\right)^{1/2} \cdot \left(\frac{L_\varepsilon \Delta}{K}\right)^{1/4}.$$
衰减学习率 $\eta_k = \sqrt{\Delta/(L_\varepsilon k)}$ 将 $1/K$ 替换为 $\log K / K$。该定理覆盖 $\varepsilon = 0$ 情形，这是 Genevay et al. (2016) 未考虑的（Sec. 3, "Convergence Analysis"）。

**广义 Tweedie 公式**（Proposition 3, Sec. 4）：对 SD-OT 耦合 $\pi_{\varepsilon,g}$，设 $X_t = (1-t)X_0 + tX_1$，$v_t(x) := \mathbb{E}[X_1 - X_0 \mid X_t = x]$，$\rho_0 = N(0, I_d)$。则对任意 $\varepsilon \geq 0$：
$$\nabla \log \rho_t(x) = \frac{t v_t(x) - x + (1-t)\delta_\varepsilon}{(1-t)^2},$$
其中 $\delta_\varepsilon = \frac{1}{\varepsilon}\mathbb{E}[-\nabla_{x_0} c(X_0, X_1) + \mathbb{E}[\nabla_{x_0} c(X_0, X_1) \mid X_0] \mid X_t = x]$（$\varepsilon > 0$），且 $\delta_0 = 0$。作者报告 $\|\delta_\varepsilon\| \lesssim e^{-1/\varepsilon}/\varepsilon$，随 $\varepsilon \to 0$ 消失；$\varepsilon \to \infty$ 恢复独立耦合的经典 Tweedie 公式（Sec. 4, "Score Estimation and Guidance"）。

**引导校正**（Proposition 4, informal, Sec. 4）：对两个流模型的速度场 $v_{1,t}, v_{2,t}$，要采样几何混合 $\rho_t^{(\gamma)} = \rho_{1,t}^\gamma \rho_{2,t}^{1-\gamma}/Z_t^{(\gamma)}$，不能只线性组合速度场。需生成 $r$ 条轨迹，按权重 $w^{(\gamma,i)} = \gamma(\gamma-1)\int \frac{1-t}{t}\|v_{1,t} - v_{2,t}\|^2 dt$ 做 softmax 重采样，$r \to \infty$ 时收敛到目标分布。利用 Proposition 3（$\varepsilon = 0$ 或 $\varepsilon = \infty$ 时）可用速度模型计算权重，无需显式 score。

## 4. 实验与数字

**数据集**：ImageNet 32×32（$N = 2.56$M，水平翻转增强，$d = 3072$）、ImageNet 64×64（$d = 12288$）、PetFace 64×64（$N = 1.27$M）、CelebA 64×64（162k 训练图像，超分辨率任务）、ImageNet 256×256 latent space（MeanFlow 实验）。FID 用 Heusel et al. (2017)，曲率用 Lee et al. (2023)，precision/recall 用 Kynkäänniemi et al. (2019)（Sec. 5）。

**FID 结果**（Table 2）：

| 数据集 | 设置 | 方法 | Euler 4 | Euler 8 | Euler 16 | Dopri5 |
|---|---|---|---|---|---|---|
| ImageNet-64 无条件 | PCA 500 | I-FM | - | 79.95 | 37.90 | 19.68 |
| | | SD-FM ε=0 | 45.62 | 23.75 | 15.02 | 8.42 |
| | | SD-FM ε=0.01 | 45.68 | 23.91 | 15.10 | 8.45 |
| | | SD-FM ε=0.1 | 45.90 | 24.05 | 15.35 | 8.58 |
| ImageNet-64 类条件 | PCA 500 | I-FM | - | 34.51 | 12.95 | 7.39 |
| | | SD-FM ε=0 | 26.04 | 12.06 | 7.32 | 3.63 |
| PetFace 无条件 | full d=12k | I-FM | - | 56.53 | 26.85 | 13.38 |
| | | SD-FM ε=0 | 20.54 | 12.77 | 7.50 | 1.26 |
| PetFace 类条件 | full d=12k | I-FM | - | 47.66 | 21.91 | 11.56 |
| | | SD-FM ε=0 | 19.10 | 12.10 | 7.13 | 1.05 |

SD-FM 在所有 Euler 步数下优于 I-FM；Dopri5 下 ImageNet-64 无条件 FID 从 19.68 降到 8.42，PetFace 无条件从 13.38 降到 1.26（Table 2）。ε 的三个取值（0, 0.01, 0.1）之间 FID 差异很小，作者因此推荐 ε=0（Sec. 5, "Limitations and Discussion"）。

**势函数质量与 FID 的关系**（Figure 3）：在 ImageNet-32 上记录 SGD 迭代中 6 个不同 $g$，追踪 $\hat{\chi}^2(m(g)\|b)$。FID 随 $\hat{\chi}^2$ 下降而改善，曲率收缩，收益在 $\hat{\chi}^2 \approx 0.05$ 附近饱和。SGD 收敛耗时约 12 小时（8×H100 GPU 节点）（Sec. 5.1, "FID vs. Potential Quality"）。

**配对时间开销**（Figure 4, Table 1）：SD-FM 的配对开销远小于 OT-FM。OT-FM 在 ImageNet-64 全维度（$d=12288$）大 $n$ 下配对成本超过 10 天，因此未展示（Sec. 5.1, "Class-conditional ImgN and PetFace"）。SD-FM 的配对开销相对于 FM 训练的单对梯度计算时间 $\Theta$ 可忽略（Figure 4 红虚线）。

**CelebA 超分辨率**（Table 3）：4× SR，噪声 σ=0.1 时 SD-FM ε=0.01 的 PSNR 21.41 vs. I-FM 21.17，SSIM 0.69 vs. 0.67；8× SR，σ=0.1 时 PSNR 17.94 vs. 17.52，SSIM 0.52 vs. 0.50。σ=0.2 时 SD-FM 同样优于 I-FM。

**引导校正**（Figure 5）：ImageNet-32 上，γ=2，NFE=4，ε=0。$r=1$ 是无校正的 CFG 基线，$r=0$ 是无引导的条件模型。增大 $r$ 提高 precision（约 0.20 到 0.35）但降低 recall（约 0.175 到 0.10）。

**MeanFlow 一步生成**（Figure 6）：ImageNet-256 latent space，DiT-XL/2 训练 300 epochs，M/2 训练 40 epochs。SD-MF 在 NFE=1,2,4,8 下 FID 均低于 I-MF；NFE=1 时 SD-MF XL-2 的 FID 约 45-50，I-MF XL-2 约 60-65（从图中读出，原文未给精确数值）。

## 5. 在 OT×扩散地图中的位置

本文直接回应 T08 课题的核心张力：minibatch OT 耦合的 batch 大小 $n$ 有限导致偏差，扩大 $n$ 又面临 $O(n^2/\varepsilon^2)$ 的 Sinkhorn 成本。SD-FM 走的是"跨 batch 全局化"路线中的半离散分支：用全数据集一次性求解 SD-OT 对偶势，绕开 batch 级 OT 的统计偏差和计算瓶颈。

与相关工作的关系：
- **继承**：Genevay et al. (2016) 的 SGD 半对偶优化框架（本文将其扩展到 ε=0 并给出收敛分析）；Zhang et al. (2025) 的点积成本、PCA 加速、ε 重缩放方案；Pooladian et al. (2023) 的 FM 训练设置。
- **竞争/替代**：对 OT-FM（Pooladian et al., 2023; Tong et al., 2024）和 LOOM-CFM（Davtyan et al., 2025）构成替代——后者仍需 batch 级 Hungarian 或 Sinkhorn，前者 $O(n^3)$ 每 batch，后者 $O(n^2/\varepsilon^2)$ 预计算。SD-FM 将配对成本降为 $O(N)$ 的 MIPS。
- **扩展**：条件生成部分继承 Kerrigan et al. (2024) 的三角映射框架和增广成本 Eq. (2.3)；引导校正部分可视为 Bradley & Nakkiran (2024) 和 Skreta et al. (2025) 的 flow 版本。

在推理管线中的位置：SD-FM 作用于训练阶段的耦合选择环节，不改变 FM 损失函数形式或推理时的 ODE 积分器。其效果体现在学到的速度场曲率更低，从而在固定步数 Euler 求解器下 FID 更好。

## 6. 局限与批评

**作者承认的**：
1. SD-OT 预计算在 $N$ 达到数十亿时可能成为挑战（虽然仍比 FM 训练便宜）。作者建议用 batching、momentum 或 ε-tempering 缓解（Sec. 5, "Limitations and Discussion"）。
2. ε>0 时对 $N$ 维 softmax 做 categorical sampling 成本高，因此推荐 ε=0 配合 MIPS。近似 MIPS 加速留作未来工作（Sec. 4, "SD-FM vs. OT-FM vs. I-FM"）。
3. 与更复杂 FM 方法（如 Reflow）的交互未评估（Sec. 5, "Limitations and Discussion"）。

**读出来的**：
1. 实验未直接对比 SD-FM 与 Zhang et al. (2025) 的大规模 OT-FM 在相同 FID 水平下的端到端总成本（预计算 + 训练 + 推理）。Figure 4 只比较了配对时间，未给出 OT-FM 在 $n = 2^{19}$ 时的最终 FID 数值。
2. Theorem 2 的 ε=0 情形依赖 Assumption 1 中的 $\delta = \min_{j \neq j'} \|y_j - y_{j'}\| > 0$ 和 $\mu$ 表面积有界。对于高维真实数据（如 ImageNet 的 $d=3072$），$\delta$ 的实际值和 $C_\mu^{\max}$ 的行为未被讨论，定理的实用指导意义有限。
3. 所有实验使用点积成本 $c(x,y) = -x^\top y$。对于像素空间数据，点积成本是否比 $\ell^2$ 成本更合理、以及成本函数选择对结果的敏感性，原文未做消融。

## 7. 对我们的启发

1. **半离散耦合可作为 batch 级方法的免训练替代**：SD-FM 的核心优势在于把"配对"从训练循环中剥离为一次性预计算。对于我们的 T08 课题，这提示一个可操作方向：在资源受限场景下，优先考虑半离散 OT 势函数而非增大 batch size 的 Sinkhorn。具体可接切入点 #2（LOOM 与 semidiscrete 之间的中间地带）：设计内存 $O(K)$ 的在线全局耦合，用聚类级 anchor OT 或流式 semidual 更新，对比 SD-FM 与 LOOM-CFM 的 FID vs. 预计算开销帕累托前沿。

2. **$\hat{\chi}^2$ 收敛准则可作为通用诊断工具**：Fact 1 的无偏 $\chi^2$ 估计量（Eq. (3.5)）不限于 SD-FM，可用于任何需要监控半离散 OT 收敛的场景。Figure 3 显示 $\hat{\chi}^2 \approx 0.05$ 时收益饱和，这给出了一个实用的停止准则。在我们的实验中可以复用此指标来判断势函数质量是否足够。

3. **ε=0 的 MIPS 指派 + 广义 Tweedie 公式为引导校正提供免 score 路径**：Proposition 3 表明 ε=0 时 SD-FM 的速度场可直接用于 score 估计（$\delta_0 = 0$），Proposition 4 的权重公式只需速度场差值。这为 classifier-free guidance 或 autoguidance 的校正提供了不训练额外 score 模型的方案。可接切入点 #3（保耦合蒸馏）：在蒸馏场景中，SD-FM 的直线路径 + 免 score 引导校正可能降低蒸馏时的 NFE 需求。
