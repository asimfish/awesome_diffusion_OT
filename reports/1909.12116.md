# Optimal Transport driven CycleGAN for Unsupervised Learning in Inverse Problems

> Byeongsu Sim, Gyutaek Oh, Jeongsol Kim et al. · SIAM J. Imaging Sciences 2020 · [arXiv](https://arxiv.org/abs/1909.12116) · 证据级 [P] · 课题 T15 医学影像模态转换与 OT/SB/扩散
> **一句话**：从 Kantorovich 对偶推导出 OT-cycleGAN，前向算子已知时砍掉一半生成器，在加速 MRI、SMLM、低剂量 CT 上验证。

## 1. 问题

逆问题 $y = Hx + w$ 中，$H$ 常使问题不适定（Sec. 1）。经典 PLS 方法（Eq. 1.3）每次新测量都要重新求解优化；监督深度学习方法需要配对标签数据，而配对数据在医学影像中难以获取。CycleGAN 是无监督图像翻译的成功方法，但作者指出两个问题：(i) 两对生成器/判别器同时训练困难，一个网络训练不好会导致其他网络不收敛；(ii) 逆问题中前向算子 $H$ 往往已知，但标准 cycleGAN 没有机制把这一物理信息纳入训练（Sec. 2.3）。本文要解决的是：如何从最优传输理论推导 cycleGAN 型架构，并让前向物理知识自动决定架构复杂度。

## 2. 方法

核心思想：把 PLS 成本函数作为 OT 的传输成本，其中正则项是一个以测量 $y$ 为输入、估计未知图像 $x$ 的神经网络 $G_\Theta$：

$$c(x, y; \Theta, H) = \|y - Hx\|_q + \lambda \|G_\Theta(y) - x\|_p \quad \text{(Eq. 3.1)}$$

与 MoDL 的关键区别：MoDL 的 $Q_\Theta(x)$ 是预训练去噪器，输入是重建 $x$；这里的 $G_\Theta(y)$ 输入是测量 $y$，惩罚的是「逆路径不一致性」，且 $G_\Theta$ 不是预训练的，而是由该成本函数训练（Sec. 3.1）。

对 $p=q=1$，定义 OT 原始问题 $K(\Theta, H) = \min_\pi \int c\, d\pi$（Eq. 3.4）。作者用 Kantorovich 对偶（Theorem 2.1）推导出 $K$ 的上下界，得到可计算的代理目标 $D(\Theta, H) = \frac{1}{2}\ell_{cycle}(\Theta, H) + \ell_{OT'}(\Theta, H)$（Eq. 3.5），其中 $\ell_{cycle}$ 是循环一致性损失（Eq. 3.6），$\ell_{OT'}$ 是 W-GAN 型判别器损失（Eq. 3.7）。最终优化问题为：

$$\min_{\Theta, H} \ell_{OT'}(\Theta, H) + \gamma \ell_{cycle}(\Theta, H) \quad \text{(Eq. 3.14)}$$

判别器用 WGAN-GP 实现 1-Lipschitz 约束（Eq. 3.24）。根据前向算子知识的不同，OT-cycleGAN 退化为三种架构（Table 1, Fig. 1）：
- **(b) 线性卷积前向**（$y = h * x$，$h$ 未知）：一个深度生成器 $G_\Theta$ + 一个线性卷积层替代第二个生成器，两个判别器；
- **(c) 前向算子 $H$ 完全已知**：只需一个生成器 + 一个判别器，$\psi_\Xi$ 判别器可省略；
- **(d) 前向算子未知**：两对生成器/判别器，与标准 cycleGAN 架构相同但判别器损失不同。

## 3. 理论结果

**Proposition 3.1**（核心理论结果）：对 $p=q=1$ 的 PLS 成本（Eq. 3.4），定义 $D(\Theta, H)$ 如 Eq. 3.5，则

$$|K(\Theta, H) - D(\Theta, H)| \leq \frac{1}{2}\ell_{cycle}(\Theta, H) \quad \text{(Eq. 3.8)}$$

且当 $G_\Theta$ 是 $H$ 的精确逆（即 $HG_\Theta(y)=y$ 且 $G_\Theta Hx = x$ 对所有 $x, y$）时，误差界为零。证明思路：用 Kantorovich 对偶的两种形式（Eq. 2.3, 2.4），将 $c$-变换中的 $\inf_x$ 替换为 $x = G_\Theta(y)$、$\inf_y$ 替换为 $y = Hx$ 得到上界；用 1-Lipschitz 性（Eq. 3.9, 3.10）得到下界 $\ell_{OT'}$。该命题将原始 OT 问题（需在高维空间上交替优化联合分布 $\pi$）转化为无需显式估计 $\pi$ 的 min-max 问题。

## 4. 实验与数字

三个应用对应三种架构变体（Sec. 4）：

**加速 MRI（Table 1(c) 变体，前向算子已知）**：fastMRI 单线圈膝关节数据，3500 张切片，3000 训练/500 测试，加速因子 4，ACS 区域 4% k-space 线，图像裁剪 320×320。配对信息仅用于测试评估。U-Net 生成器 + PatchGAN 判别器，WGAN-GP，Adam（$\beta_1=0.5, \beta_2=0.9$，lr=0.0001），判别器每生成器更新 5 次，batch size 1，100 epochs。

| 方法 | PSNR (dB) | SSIM |
|---|---|---|
| Input (×4) | 26.81 | 0.6419 |
| Supervised Learning | 27.96 | 0.6419 |
| Conventional CycleGAN | 25.01 | 0.4689 |
| Proposed OT-cycleGAN | 28.17 | 0.6550 |

来源：Table 2。OT-cycleGAN 在 PSNR 上比监督学习高 0.21 dB，比标准 cycleGAN 高 3.16 dB；SSIM 比标准 cycleGAN 高 0.1861。

**单分子定位显微镜 SMLM（Table 1(b) 变体，线性模糊核未知）**：三个真实 SMLM 数据集（α-tubulin 微管），第一个数据集 500 帧 128×128 用于训练，数据增强（翻转）后 1800 帧训练/200 帧验证；第二、三数据集（1000 帧、2000 帧）用于测试。从 128×128 低分辨率重建 256×256 高分辨率图像。生成器为改进 U-Net（最大通道数 300），第二生成器为单个 10×10 卷积层建模 PSF。原文未给出定量指标表，仅 Fig. 8 展示重建结果对比（FALCON、监督学习、标准 cycleGAN、OT-cycleGAN），作者报告 OT-cycleGAN 重建结果优于标准 cycleGAN（Sec. 4.2 文字描述，原文截断，未见具体数值）。

**低剂量 CT（Table 1(d) 变体，前向算子未知）**：原文在 Sec. 4.3 开始处被截断，未见数据集、基线与数值结果。

## 5. 在 OT×扩散地图中的位置

本文是「OT 作为无监督医学逆问题理论骨架」前史阶段的奠基工作。它把 cycleGAN 从启发式架构提升为 Kantorovich 对偶的严格推导结果，核心贡献是建立了「PLS 数据保真 + 深度逆路径惩罚」作为传输成本时，前向算子知识直接决定架构复杂度的原则。这条「把物理前向模型编进传输成本」的路线在后续工作中延续：PESB/PEDB 的投影嵌入桥将前向算子嵌入 Schrödinger bridge 的漂移项，是同一思想在扩散/桥时代的直接继承。本文的 OT 是静态 Kantorovich 形式，没有熵正则、没有时间维度，与 Schrödinger bridge 的随机过程视角形成对照：本文解决「无配对数据下学逆映射」，SB 解决「源分布到目标分布的路径规划」。在推理管线中，本文对应「传输成本设计」环节——成本函数中的 $\|y - Hx\|$ 项是物理先验注入的早期范例，与 LMSB 的「学一个解剖感知度量再训 SB」在哲学上同源（成本函数即先验接口），但本文的前向算子知识是解析给定的，LMSB 的度量是数据驱动学习的。

## 6. 局限与批评

作者承认的：
1. 只处理了 $p=q=1$ 的情形，因为 1-Lipschitz 不等式（Eq. 3.9, 3.10）只在该情形成立；一般 $p, q$ 需要正则化 OT，作者留作未来工作（Sec. 3.4）。
2. Proposition 3.1 给出的是 $K$ 与 $D$ 之间的误差界，$D$ 是 $K$ 的近似而非精确对偶；只有当循环一致性损失为零时二者才相等，而训练中 $\ell_{cycle}$ 只是被约束到 $\epsilon$ 以内（Eq. 3.12）。

读出来的：
1. 加速 MRI 实验中 SSIM 与监督学习完全相同（0.6419），PSNR 仅高 0.21 dB，且输入本身 SSIM 也是 0.6419——SSIM 指标在该设置下区分度极低，结论主要靠 PSNR 支撑。
2. SMLM 实验没有定量指标表，只有视觉对比（Fig. 8），无法判断改进幅度；低剂量 CT 部分在提供的全文截断中未见任何数值。
3. 理论推导中把 $\inf_x$ 替换为 $x = G_\Theta(y)$ 得到的是上界，这个替换的紧致性完全依赖 $G_\Theta$ 接近 $H$ 的逆，训练初期该假设不成立，但作者未讨论这对优化动态的影响。

## 7. 对我们的启发

1. **前向算子已知时砍架构**：本文 Table 1(c) 显示，当 $H$ 完全已知时，$\psi_\Xi$ 判别器在数学上可省略。对医学 SB/扩散桥工作（如 SynthRAD 挑战中的 CBCT→CT），若前向退化算子（如 CBCT 散射模型）可解析表达，可考虑把对应判别器/评分网络从架构中移除，减少训练不稳定源。
2. **成本函数即物理先验接口**：Eq. 3.1 的 $\|y - Hx\|$ 项是把物理前向模型注入无监督学习的直接方式。在扩散桥框架中，这对应在传输成本或漂移项中加入数据保真项，而非仅在采样后做投影——可接课题切入点 #3（任务感知传输成本），把剂量学误差而非像素 MAE 写进成本。
3. **无配对数据下学逆映射的 OT 对偶视角**：Proposition 3.1 的误差界结构（循环一致性损失控制对偶近似误差）提示：在 SB 的无配对训练中，若用对偶/对抗形式近似 OT 成本，循环一致性型约束的紧致性可能同样控制近似质量。这为设计无配对医学 SB 训练目标提供了可迁移的理论模板。
