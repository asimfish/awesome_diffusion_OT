# Edit Flows: Flow Matching with Edit Operations

> Marton Havasi, Brian Karrer, Itai Gat, Ricky T. Q. Chen · NeurIPS 2025 · [arXiv](https://arxiv.org/abs/2506.09018) · 证据级 [P] · 课题 T22 离散数据与文本中的扩散/流与最优传输
> **一句话**：把 CTMC 定义在整条序列空间上，转移=插入/删除/替换，经辅助对齐过程+Bregman 散度损失可训练，原生支持变长生成。

## 1. 问题

非自回归生成模型在图像、视频、音频上已成为标准，但在离散文本/代码生成上仍依赖「固定 token 位置」的因子化表示：现有离散扩散/流模型（如 mask 构造）只能迭代 unmask 或替换 token，**不能插入或删除 token**（Sec. 1）。这带来两个直接后果：

1. **变长序列需要外部处理**。mask 构造训练时靠 padding，但过度 padding 使模型对 padding token 过度自信，推理时依赖半自回归采样绕过（Sec. 2.2, Mask construction 段）。作者指出 LLaDa 等模型需要 heuristic semi-autoregressive sampling（Sec. 1）。
2. **绝对位置编码的刚性**。token-wise 构造要求每个 token 在生成时考虑其绝对位置（如相邻 mask token 的精确数量），而序列数据更自然的建模方式是相对位置（Sec. 4, Relative positions 段）。

作者提出的问题是：能否在**整条序列空间**上定义 CTMC，使转移操作本身是插入、删除、替换，从而原生支持变长生成和位置相对建模？此前 Campbell et al. (2024a) 用 jump diffusion 建模插入，但扩展到删除和替换「非常困难，可以说不可解」（Sec. 4, Non-autoregressive variable length generation 段）。

## 2. 方法

核心思想：状态空间从固定长度 $T^N$ 改为所有长度不超过 $N$ 的序列集合 $X = \bigcup_{n=0}^{N} T^n$。CTMC 的转移只允许三种编辑操作（Sec. 3.1）：

- **插入** $\text{ins}(x, i, a)$：在位置 $i$ 右侧插入 token $a$，式 (10)
- **删除** $\text{del}(x, i)$：删除第 $i$ 个 token，式 (11)
- **替换** $\text{sub}(x, i, a)$：将位置 $i$ 替换为 token $a$，式 (12)

速率参数化（式 13–15）将每种操作分解为「操作总速率 × token 分布」：

$$u^\theta_t(\text{ins}(x,i,a)|x) = \lambda^{\text{ins}}_{t,i}(x)\, Q^{\text{ins}}_{t,i}(a|x)$$

$$u^\theta_t(\text{del}(x,i)|x) = \lambda^{\text{del}}_{t,i}(x)$$

$$u^\theta_t(\text{sub}(x,i,a)|x) = \lambda^{\text{sub}}_{t,i}(x)\, Q^{\text{sub}}_{t,i}(a|x)$$

其中 $\lambda_{t,i} \geq 0$ 是位置 $i$ 处各操作的总速率，$Q$ 是归一化的 token 分布。自转移速率由式 (16) 给出，保证速率条件 (2) 成立。

**训练的关键困难**：直接构造条件速率 (5) 不可行，因为从 $x_0$ 到 $x_1$ 存在多组编辑操作（如多个插入可产生等价序列）。作者引入**辅助对齐过程**解决（Sec. 3.2）：

1. 定义对齐空间 $Z = (T \cup \{\varepsilon\})^N$，其中 $\varepsilon$ 是空白 token，不进入模型输入输出。函数 `frm-blanks` 剥离所有 $\varepsilon$，将 $Z$ 映射到 $X$（多对一）。
2. 给定 $x_0, x_1$，构造对齐序列 $z_0, z_1$（随机 padding 或最优编辑距离对齐）。对齐中的元组 $(a \to b)$ 直接对应编辑操作：$a=\varepsilon$ 是插入，$b=\varepsilon$ 是删除，否则是替换。
3. 在增广空间 $X \times Z$ 上定义条件概率路径（式 20）：$p_t(x, z | z_0, z_1) = p_t(z | z_0, z_1)\, \delta_{\text{frm-blanks}(z)}(x)$，其中 $p_t(z|z_0,z_1)$ 是 token-wise mixture path (8)。对应的条件速率（式 21）只允许单编辑操作转移，与 Edit Flow 的转移 (13)–(15) 完美对应。

**定理 3.1（Flow Matching with Auxiliary Processes）** 是训练的核心理论工具：若 $u_t(x,z|x_t,z_t)$ 生成增广空间上的 $p_t(x,z)$，则边际速率

$$u_t(x|x_t) \triangleq \sum_z \mathbb{E}_{p_t(z_t|x_t)} u_t(x,z|x_t,z_t)$$

生成边际路径 $p_t(x)$；且对任意 Bregman 散度 $D_\phi$，用增广空间上的期望梯度训练等价于用边际速率训练（式 18）。这允许模型自动推断辅助变量 $z$，训练时无需暴露给模型。

最终训练损失（式 23）：

$$L(\theta) = \mathbb{E}_{t, \pi(z_0,z_1), p_t(x_t,z_t|z_0,z_1)} \left[ \sum_{x \neq x_t} u^\theta_t(x|x_t) - \sum_{i=1}^{N} \mathbb{1}[z^i_1 \neq z^i_t] \frac{\dot{\kappa}_t}{1-\kappa_t} \log u^\theta_t(x(z_t, i, z^i_1)|x_t) \right]$$

解释为：最小化所有输出速率之和，同时对使 $x_t$ 更接近 $x_1$ 的编辑操作做加权交叉熵。

**采样**（Sec. 3.3）：从 $X_0 \sim p$ 出发，用一阶近似 (1) 迭代模拟 CTMC；每步以概率 $h\lambda_{t,i}(X_t)$ 独立决定每个插入/删除/替换是否发生，然后同时执行所有编辑操作。

**高级技术**（Sec. 3.3）：CFG 独立应用于 $\lambda$ 和 $Q$；Q 的 temperature/top-p/top-k 锐化；学习反向速率 $\vec{u}^\theta_t$ 实现推理时自校正；局部化编辑操作（localized propagation，Sec. C.1）通过构造局部传播的辅助 CTMC 鼓励相邻编辑操作同时发生。

## 3. 理论结果

**定理 3.1（Flow Matching with Auxiliary Processes）**：设 $u_t(x,z|x_t,z_t)$ 是增广空间 $X \times Z$ 上生成 $p_t(x,z)$ 的速率，则式 (17) 定义的边际速率生成边际路径 $p_t(x)$；且对任意由凸函数 $\phi$ 定义的 Bregman 散度 $D_\phi$，式 (18) 的梯度等式成立。证明在 Appendix B。

该定理的贡献在于：与原始 Flow Matching 推导（Lipman et al., 2024）不同，它允许对**时间依赖的过程**（而非仅时间无关变量）做边际化。作者指出该结果比训练 Edit Flows 更通用，Sec. C.1 展示了另一个应用（局部化传播速率）。

**Lemma B.2**（正文引用）：给出增广空间上条件速率 (21) 的构造，该速率只允许单编辑操作转移。

无其他理论结果（如收敛性、采样复杂度界）。

## 4. 实验与数字

**模型与设置**：Llama 架构 280M 和 1.3B 参数；最大序列长度 1024；cubic scheduler $\kappa_t = t^3$；Edit Flow 用 FlexAttention 处理变长 batch，训练时同等算力下可处理 3× 更多数据（Sec. 5, Architecture 段）。基线：Llama3 Autoregressive（因果注意力）和 Mask DFM（全注意力）。

## 5. 在 OT×扩散地图中的位置

Edit Flows 属于「改状态空间几何」路线：把 CTMC 从固定长度 token 网格搬到**编辑距离几何下的序列空间**。与课题地图的对应关系：

- **继承**：直接建立在 Discrete Flow Matching 框架（Campbell et al. 2024b; Gat et al. 2024）之上，训练目标属于 Bregman 散度族（Holderrieth et al. 的 Generator Matching）。token-wise mixture path (8) 是其特例（替换-only，$\lambda^{\text{ins}} = \lambda^{\text{del}} = 0$）；mask 构造是进一步约束 $\lambda^{\text{sub}}_{t,i}(x)=0$ 当 $x_i \neq m$（Sec. 3.1, Special cases 段）。
- **与 OT 的关联**：编辑距离（Levenshtein）是序列空间上的 ground metric，插入/删除对应质量创生/湮灭，即 unbalanced OT 的离散对应物。但本文**没有显式使用 OT 耦合**——对齐构造是「随机 padding 或最优编辑距离对齐」（Sec. 3.2），最优对齐是编辑距离的副产品，而非训练目标。作者在 Sec. 3.2 末尾指出：即使训练时用最差对齐（删除所有 $x_0$ token、插入所有 $x_1$ token），模型仍偏好最小化编辑次数，这「类似于连续空间 Flow Matching 中观察到的 kinetic energy 最小化」（Shaul et al., 2023）。这是本文与 OT 最实质的连接点：**编辑次数最小化是离散版的 kinetic-optimal 路径偏好**，但作者未将其形式化为 OT 目标。
- **竞争/互补**：与 Haxholli et al. 的 minibatch-OT 离散耦合互补——后者在固定状态空间上用 OT 耦合源-目标分布，本文改变状态空间本身。与 DDOT 的位置级 OT 耦合互补——DDOT 解决灵活长度填充，Edit Flows 直接消除填充需求。与 Campbell et al. (2024a) 的 jump diffusion 是直接前驱，但后者无法扩展到删除和替换。
- **推理管线环节**：Edit Flows 解决的是「前向过程设计」环节——用编辑操作替代 mask/unmask 作为传输机制。它不涉及 few-step 加速或蒸馏。

## 6. 局限与批评

**作者承认的**（Sec. 6）：

1. **预训练配置偏向 AR**：AR 训练时模型看到输入序列内所有可能的条件上下文；Edit Flows 只随机选子集作为条件。若随机子集与评估场景不对齐，学习信号减弱。
2. **文本基准测的是似然而非生成质量**：非自回归模型没有闭式似然，只能用 ELBO 的噪声估计。HellaSwag 等基准不直接评估生成文本质量。

**读出来的**：

1. **对齐构造是启发式的**。训练目标 (23) 依赖 $z_0, z_1$ 的对齐方式，但作者没有系统比较不同对齐策略（随机 padding vs 最优编辑距离）对最终生成质量的影响。Sec. 3.2 只提到「即使最差对齐也能学到非平凡耦合」，但没有给出对齐质量与下游性能的定量关系。
2. **编辑次数最小化只是经验观察，无理论保证**。作者将模型偏好最少编辑类比于连续 FM 的 kinetic energy 最小化，但没有证明 Edit Flows 训练目标在编辑距离成本下有任何最优性。这与课题地图中「离散 kinetic-optimal 路径定理」的开放问题直接对应。
3. **代码生成仍落后于 AR**。Table 3 中最好的 Localized Edit Flow 在 HumanEval Pass@1 上为 14.0，低于 Llama3 AR 的 17.0；MBPP Pass@1 为 14.8，低于 AR 的 25.6。作者在结论中承认「在文本基准和代码生成上略落后于 AR」。
4. **采样步数未报告**。正文没有给出推理时的 NFE（number of function evaluations）或步长 $h$ 的具体数值，无法评估采样效率。原文截断，未见。

## 7. 对我们的启发

1. **把对齐采样替换为编辑距离下的最优（部分）耦合**。当前训练从 $z_0, z_1$ 的对齐构造是启发式的（随机 padding 或最优编辑距离）。可将其替换为 Levenshtein 成本下的 minibatch-OT 耦合，使辅助对齐过程本身成为可微的 OT 模块。这直接对应课题切入点 #3（Edit Flows × unbalanced OT），且可验证训练方差是否降低、期望编辑次数是否逼近编辑距离下界。
2. **编辑次数最小化 → 显式离散 kinetic-optimal 目标**。作者观察到模型偏好最少编辑，但没有形式化。可在 Edit Flows 框架内加一个编辑距离成本的 Kantorovich 正则项（类似 Haxholli et al. 的 minibatch-OT 目标），检验是否进一步降低生成过程中的编辑次数、提升 few-step 质量。这对应切入点 #1 的经验侧。
3. **Edit Flows 的变长能力可服务跨 tokenizer 蒸馏**。Edit Flows 不需要 padding，天然适合作为蒸馏学生：用强 AR 教师（不同词表）的序列分布作为目标，Edit Flow 学生的插入/删除操作可以自适应长度，避免 mask 模型的 padding 过度自信问题。可结合 MultiLevelOT 的跨 tokenizer OT 损失，验证 AR 7B → Edit Flow 1B 的蒸馏效果。
