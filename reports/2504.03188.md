# Pairwise Optimal Transports for Training All-to-All Flow-Based Condition Transfer Model

> Kotaro Ikeda, Masanori Koyama, Jinzhe Zhang et al. · arXiv 2025 · [arXiv](https://arxiv.org/abs/2504.03188) · 证据级 [R] · 课题 T17 风格迁移与域自适应中的 OT×扩散
> **一句话**：作者报告：用带条件惩罚的 minibatch OT 耦合同时学所有条件对之间的 pairwise OT，支持连续条件与非分组数据，在分子属性迁移上超过 COATI-LDM。

## 1. 问题

本文解决 **all-to-all 条件迁移**（condition transfer）问题：给定一族条件分布 $\{P_c \mid c \in \mathcal{C}\}$，对任意条件对 $(c_1, c_2)$ 学习从 $P_{c_1}$ 到 $P_{c_2}$ 的传输映射，且该映射应逼近 pairwise 最优传输（OT）。应用场景包括图像风格迁移和分子属性修改（Sec. 1）。

此前方法的缺口在于数据格式假设。Multimarginal SI [3] 和 Extended Flow Matching (EFM) [21] 都能做 all-to-all 传输，但都要求 **grouped data**：每个条件 $c$ 下要有足够多样本，才能估计 $P_c$ 并计算与其他条件的耦合（Sec. 1, Fig. 1(b)）。当条件变量是连续值时（如分子的连续物理性质），每个条件往往只对应一个观测样本，即 **non-grouped data**；此时每个 $P_c$ 的信息极稀疏，且条件对数量可能无限，逐对应用两分布方法在计算上不可行。作者声称：据其所知，此前没有方法能在一般观测-条件对数据集（含非分组数据）上可扩展地学习 all-to-all 条件迁移模型（Sec. 1）。

## 2. 方法

核心思想：把条件迁移建模为学习一族 $(c_1, c_2)$ 参数化的 ODE 向量场 $v(x, t \mid c_1, c_2)$，其端点耦合由一个新的 minibatch OT 目标函数给出。该目标函数在数据点距离之外，额外惩罚两个 batch 中条件变量的错配，从而在 $\beta \to \infty$ 时迫使耦合只在相近条件之间发生，同时通过有限 $\beta$ 在非分组数据上共享跨条件信息（Sec. 3.1, 3.2）。

训练流程（Algorithm 1）：
1. 从数据集 $D = \{(x^{(i)}, c^{(i)})\}$ 独立抽取两个等大小 batch $B_1, B_2$，各 $N$ 个样本。
2. 求解耦合置换 $\pi^*_\beta$，最小化目标函数（原文 Eq. (11)）：

$$
\sum_{i=1}^{N} \|x_1^{(i)} - x_2^{\pi(i)}\|^2 + \beta \left( \|c_1^{(i)} - c_1^{\pi(i)}\|^2 + \|c_2^{(i)} - c_2^{\pi(i)}\|^2 \right)
$$

3. 用耦合对构造线性路径 $\psi_i(t) = (1-t)x_1^{(i)} + t x_2^{\pi^*_\beta(i)}$，以 $(c_1^{(i)}, c_2^{\pi^*_\beta(i)})$ 为条件，按 FM 损失更新 $v_\theta$（原文 Eq. (10)）：

$$
\mathbb{E}_{\psi, c_1, c_2, t}\left[ \|v(\psi(t), t \mid c_1, c_2) - \dot\psi(t)\|^2 \right]
$$

采样时，给定源样本 $x_{c_1} \sim P_{c_1}$ 和目标条件 $c_2$，从 $t=0$ 到 $t=1$ 前向解 ODE $\dot x_{c_1,c_2}(t) = v(x_{c_1,c_2}(t), t \mid c_1, c_2)$（Sec. 3.1）。

关键设计直觉（Sec. 3.2）：当 $C$ 有限且 $\beta \to \infty$ 时，第二项惩罚迫使置换只在 $c_1^{(i)} = c_1^{\pi(i)}$ 且 $c_2^{(i)} = c_2^{\pi(i)}$ 的索引子集 $U(c_1, c_2)$ 内进行，目标函数退化为对每个条件对 $(c_1, c_2)$ 独立求解标准 OT 成本 $\sum_{i \in U(c_1,c_2)} \|x_1^{(i)} - x_2^{\pi(i)}\|^2$。当 $N$ 增大，每个 $U(c_1,c_2)$ 变大，耦合逼近 $P_{c_1} \to P_{c_2}$ 的真 OT。对连续 $C$，该论证可推广（Sec. 3.3）。

## 3. 理论结果

**Proposition 3.1（非正式）**：设 $\Pi^*_\beta$ 为最小化 Eq. (11) 的耦合 $\pi^*_\beta$ 所定义的 $(X \times C) \times (X \times C)$ 上的联合分布。则对任意序列 $\beta_k \to \infty$，存在样本量 $N_k$ 的递增序列，使得 $\Pi^*_{\beta_k}$ 收敛到 $\Pi^*$，且对几乎每个 $(c_1, c_2)$，条件分布 $\Pi^*(\cdot, \cdot \mid c_1, c_2)$ 达到

$$
\int_{X^2} \|x_1 - x_2\|^2 \, d\Pi^*(x_1, x_2 \mid c_1, c_2) = W_2^2(P_{c_1}, P_{c_2})
$$

（原文 Eq. (12)）。正式证明在 Appendix A，原文正文未展开。作者在 Sec. 3.3 明确说这是「informal」表述，正式结果见附录；附录部分在给定全文截断中未见完整证明细节。

## 4. 实验与数字

**合成数据（Sec. 5.1, Table 1）**：指标为与 ground-truth pairwise OT 的 MSE，误差为标准差，10 次评估运行。

| 设置 | 方法 | MSE from pairwise OT |
|---|---|---|
| Grouped data | Ours ($\pi^*_\beta$) | $(5.81 \pm 2.22) \times 10^{-2}$ |
| Grouped data | Generalized geodesic | $(1.03 \pm 0.04) \times 10^{0}$ |
| Non-grouped data | A2A-FM (Ours) | $(1.51 \pm 0.17) \times 10^{-2}$ |
| Non-grouped data | Partial diffusion | $(6.77 \pm 0.14) \times 10^{-2}$ |
| Non-grouped data | Multimarginal SI | $(4.90 \pm 0.28) \times 10^{-2}$ |

Grouped 设置：3 个条件，每个条件 $10^3$ 样本，$\beta = 10^4$（Fig. 3(a) 说明）。Non-grouped 设置：2D 极坐标象限，$r \in [1,2]$，$\theta \in [0, \pi/2]$ 为连续条件，$P_\theta$ 沿 $r$ 均匀；Multimarginal SI 将 $\theta$ 离散为 $K=5$ 个 bin（Sec. 5.1）。作者报告：partial diffusion 产生近乎随机的耦合；Multimarginal SI 因离散化无法生成目标分布的边缘（Sec. 5.1）。

**QED 分子优化（Sec. 5.2, Table 2）**：任务为把 QED ≤ 0.8 的分子迁移到 QED ≥ 0.9，同时 Tanimoto 相似度 ≥ 0.4。训练集为 500K ZINC22 子集，$X$ 为分子表征的 latent 空间，$C = \mathbb{R}^{32}$ 为 QED embedding 空间。默认最大 oracle calls 为 50000。

| 方法 | Success (%) |
|---|---|
| DESMILES [34] | 76.9 |
| QMO [19] | 92.8 |
| MolMIM [38] | 94.6 |
| COATI-LDM [25] | 95.6 |
| A2A-FM (Ours) | 97.5 |

作者报告 A2A-FM 在默认 oracle calls 下超过 SOTA，且在 Fig. 4 中所有最大 oracle calls 值（25, 100, 500, 1000, 50000）下都取得更高成功率。Sec. 6 提到：加入反称性约束 $v_{c_1,c_2} = -v_{c_2,c_1}$ 后，QED 成功率从 94.6% 提升到 97.5%。

**LogP-TPSA 实验（Sec. 5.2, Table 3）**：从 ZINC22 随机选 1024 个初始分子，目标为同时改变 LogP 和 TPSA 到随机目标值，$C = \mathbb{R}^{32 \times 2}$。指标为 $Pr(c_{err} \le a)$ 对 $Pr(s_{Tani} \le a)$ 曲线的 AUC。

| 方法 | AUC |
|---|---|
| PD+CFG (T=500) | 0.027 |
| PD+CFG (T=300) | 0.450 |
| PD+CFG (T=1000) | 0.060 |
| SI (K=10) | 0.583 |
| OT-CFM | 0.819 |
| A2A-FM (Ours) | 0.990 |

**计算成本（Sec. 5.3）**：Multimarginal SI 需要 $O(K^2)$ 的 pairwise 优化成本，$K$ 为离散 bin 数；A2A-FM 的计算成本只依赖 $|D|$，与 OT-CFM 相同（仅成本函数不同），对固定 $|D|$ 与 $K$ 无关（Table 6, Appendix C，原文截断未见该表具体数字）。

**$\beta$ 选择（Sec. 5.3）**：作者报告启发式 $\beta = N^{1/(2d_c)}$（$d_c$ 为条件维度）在合成非分组数据上有效，且方法在跨越一个数量级的 $\beta$ 范围内稳定（Fig. 7, Appendix C，原文截断未见具体数值）。

## 5. 在 OT×扩散地图中的位置

本文处于 **OT×流匹配的条件迁移** 分支，直接继承 OT-CFM [41] 的 minibatch OT 耦合 + 线性路径 + FM 训练框架，把「源分布固定为 $P_\emptyset$」推广为「任意条件对 $(c_1, c_2)$ 之间的传输」。其理论工具来自 conditional OT (COT) 文献 [9, 28, 4, 20]：COT 用 Eq. (6) 的成本在联合空间 $X \times C$ 上做耦合，保证逐条件收敛到条件 Wasserstein 距离；本文把 COT 的单条件惩罚替换为双条件惩罚（Eq. (11)），从而把「条件生成」（$P_{\emptyset,c} \to P_c$）升级为「条件间迁移」（$P_{c_1} \to P_{c_2}$）。作者明确指出：直接把 COT 的 $c$ 替换为 $(c_1, c_2)$ 会失败，因为模型只会学到 $c_1$ 与 $c_2$ 相近的传输（Sec. 4）。

与同期的 all-to-all 方法相比：Multimarginal SI [3] 用广义测地线原理，EFM [21] 用矩阵场解连续性方程，Meta Flow Matching [6] 用 population embedding——三者都要求 grouped data。A2A-FM 是作者声称的第一个在 non-grouped data 上可扩展的 all-to-all 条件迁移方法（Sec. 1, Sec. 4）。

在课题地图中，本文对应「扩散机制层」的 OT 耦合设计问题，与 OT-CFM、ModFlows（rectified flow 学 OT plan）同属「用 OT 耦合改善流模型训练」的管线环节。它不涉及采样期引导（区别于 SW-Guidance），也不涉及 latent 空间对齐的有限步误差分析（区别于 OT-ALD）。其分子实验与 COATI-LDM [25] 的 partial diffusion 方法直接竞争，属于「条件生成/属性迁移」的应用层。

## 6. 局限与批评

**作者承认的局限**：
1. $\beta$ 与数据集大小的平衡是潜在局限：$\beta$ 过大在非分组数据上无法准确逼近 pairwise OT，$\beta$ 过小导致端点精度下降（Sec. 5.3, Sec. 7）。作者只给出经验启发式 $\beta = N^{1/(2d_c)}$，其理论依据是未来工作。
2. A2A-FM 不强制循环一致性 $T_{c_2 \to c_3} \circ T_{c_1 \to c_2} = T_{c_1 \to c_3}$，因为 OT 一般不满足该性质；而 Multimarginal SI 和 EFM 将循环一致性直接建入模型（Sec. 6）。

**读出来的局限**：
1. Proposition 3.1 是非正式表述，且收敛需要「存在递增样本量序列 $N_k$」——这意味着 $\beta_k$ 和 $N_k$ 的联合调度是理论成立的关键，但正文未给出可操作的调度规则；实际训练用的是固定 $\beta$ 启发式，与理论设定之间的差距未量化。
2. 实验规模有限：合成数据是低维（2D/3 条件）设置；真实数据只有分子任务，没有图像风格迁移或域自适应的实证。Sec. 6 提到 Appendix C 有图像数据集实验，但给定全文截断未见具体数字，无法核实。
3. 反称性约束（$v_{c_1,c_2} = -v_{c_2,c_1}$）在 QED 上带来 2.9 个百分点提升（94.6% → 97.5%），但作者未在 LogP-TPSA 或其他任务上报告该约束的效果，其普适性存疑。

## 7. 对我们的启发

1. **非分组条件迁移的耦合设计可迁移到风格迁移**：Eq. (11) 的双条件惩罚本质是「在 batch 级用条件距离做软分组，再在组内做 OT」。对连续风格条件（如色温、纹理参数）且每条件样本稀疏的场景，这个思路比先离散化再逐组 OT 更自然。可尝试把条件空间 $C$ 换成风格描述子的 embedding，验证 A2A-FM 在连续风格插值任务上是否优于 Multimarginal SI 的离散化方案。
2. **$\beta = N^{1/(2d_c)}$ 的启发式值得在 OT-aware 采样调度中检验**：该速率来自经验测度 Wasserstein 收敛速率 [14]，本质是把「条件维度 $d_c$」纳入耦合惩罚的尺度校准。若把类似的条件惩罚引入扩散采样期的 batch 级 OT 指派（如 SW-Guidance 的参考集匹配），可能需要在 latent 空间重新推导 $d_c$ 的有效维度，这是一个可操作的实验点。
3. **反称性约束作为廉价的循环一致性代理**：A2A-FM 用 $v_{c_1,c_2} = -v_{c_2,c_1}$ 在 QED 上换来 2.9 个百分点提升，成本极低。对保耦合蒸馏或域迁移中的往返一致性要求，这个约束可以作为显式循环一致性损失的轻量替代，值得在风格迁移的往返保真（forward-backward consistency）场景中测试。
