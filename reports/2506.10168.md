# Momentum Multi-Marginal Schrödinger Bridge Matching

> Panagiotis Theodoropoulos, Augustinos D. Saravanos, Evangelos A. Theodorou, Guan-Horng Liu · NeurIPS 2025 · [arXiv](https://arxiv.org/abs/2506.10168) · 证据级 [P] · 课题 T27 多边际 OT 与 Wasserstein 重心的生成应用
> **一句话**：相空间提升+多点条件化随机桥，学习满足多个位置约束的测度值样条；matching 迭代中保持中间边缘不变，解决两两插值丢失长程时序依赖的问题

## 1. 问题

本文解决的是**从稀疏时间快照推断轨迹**的问题：给定 $N+1$ 个时间点上的位置边缘分布 $q(x_0), q(x_1), \dots, q(x_N)$，要学一个随机动力系统，使其在对应时刻的边缘分布匹配这些观测，同时轨迹在时间上平滑、连贯。应用场景包括单细胞测序、气象、经济数据（Sec. 1）。

作者指出现有方法分两类，各有缺陷（Table 1）：
- **局部两两插值类**（simulation-free，可扩展，但丢失全局耦合）：SBIRR（Shen et al., 2024）用逐对 bridge 优化做轨迹推断，无法强制全局轨迹一致性，依赖 informative priors；MMFM（Rohbeck et al., 2024）用确定性三次样条插值加预计算逐段耦合，损害时间连贯性和动力学保真度；MMSFM（Lee et al., 2025）在重叠三元组上优化测度值样条，但仍缺全局耦合且是一阶动力学，轨迹不够平滑（Sec. 1）。
- **全局 mmSB 求解类**（有全局耦合，但不可扩展）：DMSB（Chen et al., 2023a）在相空间用 Bregman 迭代解全局 mmSB 耦合，但需要缓存完整 SDE 轨迹，导致计算瓶颈、误差累积和潜在不稳定；Smooth SB（Hong et al., 2025）用平滑高斯路径作参考动力学，但 belief propagation 阻碍高维扩展（Sec. 1）。

核心矛盾是：**全局耦合与可扩展性不可兼得**。本文的切入点是把这个矛盾用 matching 框架化解——matching 类方法不需要缓存轨迹、不需要数值积分，同时通过迭代保持中间边缘不变。

## 2. 方法

核心思想分三步：**（1）把动力学提升到相空间**（位置 $x_t$ + 速度 $v_t$），使目标函数惩罚加速度而非速度，从而产生平滑低曲率轨迹；**（2）推导多点条件化的 momentum Brownian bridge 的闭式解**，避免数值积分；**（3）用交替 matching 训练**：固定多边际耦合 → 解条件桥 → 匹配参数化 drift → 用新 drift 采样更新耦合，迭代收敛到全局 mmSB。

**相空间 SOC 形式**（Eq. (2)）：设 $m_t = [x_t, v_t]^\top \in \mathbb{R}^{2d}$，动力学为
$$dm_t = A m_t\, dt + u_t\, dt + g\, dW_t, \quad A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, \quad g = \begin{pmatrix} 0 & 0 \\ 0 & \sigma \end{pmatrix},$$
目标是最小化 $\int \mathbb{E}_{p_t}[\|a_t\|^2] dt$，其中 $u_t = [0, a_t]^\top$，约束是位置边缘 $x_n \sim q_n$ 在 $n = 0, 1, \dots, N$ 处匹配。

**多点条件桥的闭式解**（Theorem 3.1 + Prop. 3.2）：对条件桥问题（Eq. (3)–(4)），作者用动态规划原理递归求解，得到每个时间段 $[t_n, t_{n+1})$ 上的最优条件加速度：
$$a^\star_t(m_t \mid \{\bar{x}_{n+1} : t_{n+1} \geq t\}) = C^n_1(t)(x_t - \bar{x}_{n+1}) + C^n_2(t) v_t + C^n_3(t) \sum_{j=n+1}^{N} \lambda_j \bar{x}_j,$$
其中 $C^n_1, C^n_2, C^n_3$ 是每段时间特定的时变系数，$\lambda_j$ 是静态系数。关键性质：**线性组合 $\sum_{j=n+1}^N \lambda_j \bar{x}_j$ 捕捉了当前段对之后所有 pinned points 的依赖**，这是区别于两两插值的核心机制。Remark 3.3 指出，当中间状态代价 $R$ 中 $c \to 0$ 时，约束只要求轨迹在 $t_n$ 到达 $\bar{x}_n$，不预设中间速度 $\bar{v}_n$。

**训练流程**（Alg. 1）：
1. 初始化 $a^\theta_t$，耦合 $q(\{x_n\}) := q(x_0) \otimes q(x_1) \otimes \cdots \otimes q(x_N)$，$v_0 \sim \mathcal{N}(0, I)$；
2. 对每个采样点集 $\{\bar{x}_n\}$，用 Eq. (6) 计算条件加速度，通过 SDE 积分前向/后向传播 $J$ 次（作者报告实验中最多约 10 次迭代，无 backpropagation）来近似中间边缘的速度分布 $\pi_n(v_n \mid x_n)$；
3. 固定条件路径 $p_t$，最小化 variational gap（Eq. (9)）匹配参数化加速度 $a^\theta_t$；
4. 用更新后的 $a^\theta_t$ 通过 Eq. (2) 的 SDE 采样新的 $\{x_n\}$，更新耦合 $q(\{x_n\})$；
5. 重复至收敛。

采样时，条件路径 $p_{t|\{\bar{x}_n\}} = \mathcal{N}(\mu_t, \Sigma_t)$ 的均值和协方差有解析解（Eq. (10)），通过 Cholesky 分解构造 $m_t$。

## 3. 理论结果

**Theorem 3.1（3MBB 的 SOC 表示）**：对 Eq. (3)–(4) 的多边际 momentum 系统，值函数 $V_t(m_t) = \frac{1}{2} m_t^\top P_t^{-1} m_t + m_t^\top P_t^{-1} r_t$ 给出最优控制 $u^\star_t(m_t) = -gg^\top P_t^{-1}(m_t + r_t)$，其中 $P_t, r_t$ 满足 Eq. (5) 的 backward ODEs，中间约束通过 $P_n = (P_{n+}^{-1} + R)^{-1}$ 和 $r_n = P_n(P_{n+}^{-1} r_{n+} - R\bar{m}_n)$ 传播。

**Proposition 3.2（闭式加速度）**：当 $R = \begin{pmatrix} 1/c & 0 \\ 0 & c \end{pmatrix}$ 且 $c \to 0$ 时，3MBB 的解在每个时间段上有闭式表达式 Eq. (6)。

**Proposition 3.4（marginal path 的 drift）**：边际路径 $p_t$ 作为条件桥的混合，满足 FPE 的参数化加速度由 Eq. (8) 给出，匹配目标为 Eq. (9)。

**Theorem 3.5（收敛性）**：在 mild assumptions 下，交替方案（路径插值优化 ↔ 耦合细化）存在不动点解 $P^\star$，满足 $KL(P_i \mid P^\star) \to 0$，且该不动点与唯一的 $P_{\text{mmSB}}$ 重合。作者称这是对 Shi et al., 2023 收敛证明的替代性论证，基于最优控制原理和 KL 散度的单调性（Girsanov 定理）。

## 4. 实验与数字

四个数据集：Lotka-Volterra（LV，合成）、Gulf of Mexico（GoM，洋流）、Beijing Air Quality（PM2.5）、Embryoid Body（EB，单细胞，100 维 PCA）。指标为 Sliced Wasserstein Distance（SWD），EB 额外用 MMD。所有数字来自 Table 2–5，均为 5 seeds 的均值±标准差。

**LV（Table 2）**：9 个边际，偶数索引训练（t0, t2, t4, t6, t8），奇数索引留出验证。3MSBM 在 t1 上 SWD = 0.23±0.02（SBIRR 0.17±0.03 更低），t3 = 0.13±0.01（最低），t5 = 0.15±0.02（Smooth SB 0.11±0.02 更低），t7 = 0.36±0.03（SBIRR 0.48±0.05，MMFM 0.57±0.05，3MSBM 更低），Rest SWD = 0.18±0.02（与 SBIRR 持平，低于 MMFM 0.22±0.01、DMSB 0.43±0.04、Smooth SB 0.23±0.02）。DMSB 在所有指标上明显最差（t5 达 0.98±0.07）。

**GoM（Table 3）**：同样 9 边际、偶数训练。3MSBM 在 t5 = 0.08±0.01、t7 = 0.06±0.01、Rest SWD = 0.05±0.01 上均为最低；t1 = 0.14±0.02（SBIRR 0.15±0.03 接近），t3 = 0.14±0.02（SBIRR 0.11±0.02 更低）。Smooth SB 的 Rest SWD = 0.08±0.01，是第二好的训练边际保持。

**Beijing Air Quality（Table 4）**：13 个时间快照，留出 t2, t5, t8, t11。3MSBM 在 t5 = 9.78±1.58（MMFM 23.94±1.97，DMSB 21.92±1.78）、t8 = 22.23±3.64（MMFM 32.56±2.96，DMSB 35.53±3.82）、t11 = 32.23±3.76（MMFM 39.98±3.59，DMSB 35.75±4.13）、Rest SWD = 21.25±1.63（MMFM 30.25±2.17，DMSB 33.42±2.42）上全面最低；t2 = 17.70±1.93 与 MMFM 17.51±2.41 接近。

**EB（Table 5）**：5 个阶段，训练 t0, t2, t4，验证 t1, t3。3MSBM 在 MMD t1 = 0.18±0.01（SBIRR 0.71±0.08，MMFM 0.37±0.02，DMSB 0.38±0.04）、MMD t3 = 0.14±0.04（SBIRR 0.73±0.06，MMFM 0.35±0.04，DMSB 0.36±0.07）、SWD t1 = 0.48±0.04（SBIRR 0.80±0.06，MMFM 0.59±0.04，DMSB 0.58±0.06）、SWD t3 = 0.38±0.03（SBIRR 0.91±0.05，MMFM 0.76±0.04，DMSB 0.54±0.06）、Rest MMD = 0.11±0.02、Rest SWD = 0.36±0.05 上全面最低。DMSB 训练时间约为 3MSBM 的 2.5 倍（Sec. 4.4）。

**Ablation：pinned points 数量**（Sec. 4.5）：在 GoM 上，从只用最近 1 个 pinned point 增加到多个，性能显著提升，但超过 $K = n+3$ 后收益 plateau。原因：$|\lambda_j|$ 系数随 pinned point 数量指数衰减（Figure 10）。实用上可截断条件策略，只考虑接下来 $k$ 个 pinned points。

**Scalability**（Sec. 4.6）：3MSBM 在所有数据集上 wall-clock time 快于 DMSB，内存占用显著更低（Figures 11, 12）。边际数从 3 增到 5，per-epoch 训练时间从 773s 到 812s，增幅 5.1%（Table 6）。EB-100 上条件桥计算仅占 3.3% 时间，bridge matching 占 96.7%；GoM 上分别为 7.4% 和 92.6%（Table 7）。

## 5. 在 OT×扩散地图中的位置

本文处于 **T27（多边际 OT 与 Wasserstein 重心的生成应用）** 的「多时间边缘生成」支线，与以下工作构成直接对话：

- **继承 DMSB（Chen et al., 2023a）**：同一个 mmSB 问题（Eq. (2) 的相空间 SOC 形式直接来自 Chen et al., 2019 和 DMSB），但把求解方式从 Bregman 迭代/IPF 换成 matching。DMSB 需要缓存完整 SDE 轨迹，3MSBM 用闭式条件桥消除这一步。Table 1 中 3MSBM 是唯一同时满足 simulation-free、平滑轨迹、全局耦合三项的方法。
- **竞争 SBIRR（Shen et al., 2024）与 MMFM（Rohbeck et al., 2024）**：这两者都是 simulation-free 但牺牲全局耦合。3MSBM 的实验在 LV、GoM、EB 上系统性地对比了这两者，在多数留出边际上 SWD 更低。
- **竞争 Smooth SB（Hong et al., 2025）**：同样追求平滑轨迹和全局耦合，但 Smooth SB 不是 simulation-free（Table 1），且 belief propagation 限制高维扩展。实验上 Smooth SB 在 LV t5 和 GoM t3 上略优于 3MSBM，但 3MSBM 在训练边际保持（Rest SWD）上更优。
- **与 MMFM 的样条思路对比**：MMFM 用确定性三次样条插值，平滑是「规定式」的；3MSBM 的平滑来自相空间 SOC 对加速度的惩罚，有控制论依据。这是课题背景中提到的「MMFM 平滑是规定式的，3MSBM 以相空间动量桥给出有控制论依据的平滑」的直接体现。

在推理管线中，3MSBM 占据「多时间边缘 → 全局耦合随机桥 → 参数化 drift」的环节。它没有触及 barycenter 融合或模型融合，也没有涉及 OT 势函数的引导式推理。

## 6. 局限与批评

**作者承认的**：
1. **高维图像空间未探索**：Sec. 5 明确写「its effectiveness in densely sampled high-dimensional image spaces, such as those encountered in video interpolation, remains unexplored」。所有实验的最高维度是 EB 的 100 维 PCA 特征空间，没有原始图像级实验。
2. **初始速度分布未知**：$v_0 \sim \xi_0(v)$ 在实践中未知，作者用 $\mathcal{N}(0, I)$ 初始化并通过 Langevin-like 迭代传播近似（Sec. 3.3），这是一个近似步骤，原文未给出该近似的误差界。

**读出来的**：
1. **Theorem 3.5 的「mild assumptions」未具体化**：收敛性证明声称基于 KL 单调性和最优控制原理，但正文没有列出具体假设条件，也没有给出收敛速率。与 DMSB 的 IPF 收敛性相比，matching 交替方案的收敛性在理论上更弱。
2. **实验对比的公平性存疑**：Table 2 中 LV 数据集上 3MSBM 在 t1 上不如 SBIRR（0.23 vs 0.17），t5 上不如 Smooth SB（0.15 vs 0.11），但摘要和 Sec. 4.1 的措辞是「outperforms the baseline models」「lowest deviation from most left-out marginals」——「most」这个限定词掩盖了并非全面占优的事实。GoM 的 t3 上 SBIRR 也略优（0.11 vs 0.14）。
3. **速度边缘的评估缺失**：所有实验指标（SWD、MMD）都只评估位置边缘 $q(x_n)$ 的匹配，没有评估速度边缘 $\xi(v_n)$ 或轨迹的动力学保真度。相空间提升的核心卖点是平滑轨迹，但「平滑」在定量指标中没有直接体现（Figure 5、6 的视觉对比是定性的）。

## 7. 对我们的启发

1. **可接切入点 #2（OT 势即插即用引导）**：3MSBM 的闭式条件加速度 Eq. (6) 中，线性组合 $\sum_{j=n+1}^N \lambda_j \bar{x}_j$ 本质上是「未来 pinned points 对当前段的势场贡献」。这个结构可以改写为对预训练 FM/扩散模型的 inference-time guidance：给定少量中间域样本，用 Eq. (6) 的系数构造一个中间边缘约束势，注入 probability-flow ODE，使采样轨迹无须重训地经过中间分布。3MSBM 的 $\lambda_j$ 指数衰减（Figure 10）提示截断势是可行的，这直接对应课题背景中「现有 guidance 均为终端条件式，没有中间边缘约束式 guidance」的空白。
2. **可接切入点 #4（结构化 MMOT 作为多模态联合生成的训练目标）**：3MSBM 的 Eq. (6) 闭式桥只对线性相空间系统成立。如果把多模态联合生成建模为树形 MMOT 耦合 + 相空间桥，可以利用树代价的结构化可解性（Altschuler–Boix-Adserà 判据）把 3MSBM 的条件桥推广到多模态设置。关键问题是：树形耦合下 Eq. (6) 的 $\lambda_j$ 系数是否仍有闭式解或可高效近似。
3. **训练边际保持作为评估维度**：3MSBM 的「Rest SWD」指标（训练边际的保持程度）是一个值得借鉴的评估维度。在 barycentric merging 或 OT 引导的工作中，可以加入类似的「约束保持度」指标，衡量生成过程是否在中间步骤真正经过了目标分布，而非只在终端匹配。
