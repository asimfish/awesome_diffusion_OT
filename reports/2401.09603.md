# Rethinking FID: Towards a Better Evaluation Metric for Image Generation

> Sadeep Jayasumana, Srikumar Ramalingam, Andreas Veit et al. · CVPR Highlight 2024 · [arXiv](https://arxiv.org/abs/2401.09603) · 证据级 [P] · 课题 T30 端侧部署、benchmark 与顶会趋势
> **一句话**：FID 的正态假设、Inception 特征和样本效率都有问题；作者提出 CLIP 嵌入 + Gaussian RBF 核 MMD 的 CMMD 替代。

## 1. 问题

文本到图像（T2I）模型的评估依赖自动化指标，其中 FID 是事实标准。FID 计算真实图像与生成图像的 Inception-v3 特征分布之间的 Fréchet 距离（即 Wasserstein-2 距离），但作者指出它在现代 T2I 场景下有三类缺陷（Sec. 1, Sec. 3）：

1. **Inception 特征表达能力弱**：Inception-v3 在约 100 万张 ImageNet 图像、1000 类上训练，每张图通常只有一个显著物体（Sec. 4）；而现代 T2I 模型生成的图像内容多样、prompt 复杂，Inception 特征难以表示这些内容。
2. **正态假设不成立**：FID 的闭式解（Eq. 2）严格依赖两个分布都是多元正态（Sec. 3.1）。作者用三种统计检验（Mardia 偏度、Mardia 峰度、Henze-Zirkler）对 COCO 30K 的 Inception 嵌入做检验，p 值均为机器精度下的 0.0，强烈拒绝正态假设（Sec. 3.3, Appendix A）。作者同时指出 CLIP 嵌入也不满足正态假设，但 CMMD 不依赖该假设（Sec. 3.3）。
3. **样本效率差**：FID 需要估计 2048×2048 协方差矩阵（约 400 万个条目），小样本下估计误差大；且 FID 是有偏估计量，偏差依赖被评估的模型（Sec. 3.1, Sec. 6.3，引用 [5]）。

此前工作 [5] 提出无偏版本 FID∞，[19] 指出低层图像处理操作（压缩、resize）会显著影响 FID 并建议抗锯齿 resize。作者指出 FID∞ 继承正态假设缺陷，抗锯齿 resize 也不能解决本文揭示的问题（Sec. 2, Sec. 3.2）。

## 2. 方法

CMMD（CLIP-MMD）定义为参考（真实）图像集与生成图像集的 CLIP 嵌入之间的平方 MMD 距离，使用 Gaussian RBF 核（Sec. 4）。

**关键公式**：

MMD 距离定义（原文 Eq. 3）：
$$\text{dist}^2_{\text{MMD}}(P, Q) := \mathbb{E}_{x,x'}[k(x,x')] + \mathbb{E}_{y,y'}[k(y,y')] - 2\mathbb{E}_{x,y}[k(x,y)]$$

其中 $x, x'$ 独立采样自 $P$，$y, y'$ 独立采样自 $Q$。对特征核 $k$，MMD 是度量（Sec. 4，引用 [8, 11]）。

无偏估计量（原文 Eq. 4）：
$$\widehat{\text{dist}}^2_{\text{MMD}}(X, Y) = \frac{1}{m(m-1)}\sum_{i=1}^{m}\sum_{j\neq i} k(x_i, x_j) + \frac{1}{n(n-1)}\sum_{i=1}^{n}\sum_{j\neq i} k(y_i, y_j) - \frac{2}{mn}\sum_{i=1}^{m}\sum_{j=1}^{n} k(x_i, y_j)$$

**具体设置**（Sec. 4）：
- 核：Gaussian RBF $k(x,y) = \exp(-\|x-y\|^2 / 2\sigma^2)$，带宽固定 $\sigma = 10$。作者报告带宽对总体趋势影响不显著，但固定以保持数值一致。
- CLIP 模型：公开的 ViT-L/14@336px，是作者所称最大且性能最好的 CLIP 模型。
- 数值缩放：MMD 平方值上界为 2，作者将 Eq. 4 的值乘以 1000 以便阅读。
- 在 T2I 评估中 $m = n$，因为生成图像与共享相同 prompt 的真实图像对比。

**算法流程**：对参考集和生成集分别提取 CLIP 嵌入 → 按 Eq. 4 计算平方 MMD → 乘以 1000 得到 CMMD 值。

## 3. 理论结果

无新定理。作者引用的理论性质（Sec. 4）：
- MMD 对特征核是度量（引用 [8, 11]）。
- Eq. 4 是 $\text{dist}^2_{\text{MMD}}(P,Q)$ 的无偏估计量。
- Gaussian RBF 核是特征核。
- 对比：FID 是有偏估计量，偏差依赖被评估模型（引用 [5]）。

## 4. 实验与数字

**数据集**：COCO 30K 作为参考真实图像集（Sec. 6）；PartiPrompts（1633 个 prompt）用于人评（Sec. 5）。

**人评实验**（Sec. 5, Table 3）：对比 Model-A（完整 Muse，24 步 base + 8 步 super-resolution）与 Model-B（早停 Muse，20 步 base + 3 步 super-resolution）。同一随机种子保证内容与 prompt 对齐一致，3 名独立评分者，每对图像由 3 人评分，2 人以上偏好即判胜。

| 指标 | Model-A（完整） | Model-B（早停） |
|---|---|---|
| FID | 21.40 | 18.42 |
| FID∞ | 20.16 | 17.19 |
| CMMD | 0.721 | 0.951 |
| 人评偏好 | 92.5% | 6.9% |

人评中 0.6% 为无差异。FID 和 FID∞ 都认为 Model-B 更好（数值更低），与人评矛盾；CMMD 与人评一致（Table 3）。

**迭代改进单调性**（Sec. 6.1, Fig. 4, Fig. 6）：
- Muse 迭代：CMMD 随 refinement iteration 单调下降（从约 1.100 降至约 0.600），FID 和 FID∞ 反而上升（从约 16 升至约 22），错误地指示质量退化（Fig. 4）。
- Stable Diffusion 1.4 最后 5 步（第 96–100 步）：CMMD 单调下降（约 0.85 降至约 0.65），FID 在最后两步上升（约 21.0 升至约 26.0），行为不一致（Fig. 6）。

**失真实验**（Sec. 6.2, Fig. 1, Fig. 5, Fig. 7）：对 Muse 生成图像在 VQGAN latent 空间以概率 $p$ 随机替换 token 再重建。随 $p$ 增大，CMMD 单调上升（失真加重），FID 在前几个失真级别反而下降。具体数值：未失真 FID 21.40 / CMMD 0.721；$p=0.2$ 时 FID 18.02 / CMMD 1.190（Fig. 5）。对 COCO 30K 自身做渐进失真，FID 同样在前几个级别改善（Fig. 1）。

**样本效率**（Sec. 6.3, Fig. 8）：在 COCO 30K 上随机采样不同大小子集评估 Stable Diffusion。作者报告 FID 需要超过 20,000 张图像才能可靠估计，CMMD 在小图像集上即给出稳定估计。Fig. 8 显示 FID 在 5000–30000 样本区间相对值波动约 100%–350%，CMMD 相对值稳定在约 100% 附近。

**计算成本**（Sec. 6.4, Table 4）：$n=30,000$，$d=2048$，TPUv4 + JAX：

| 操作 | 时间 |
|---|---|
| Fréchet 距离 | 7007.59 ± 231 ms |
| MMD 距离 | 71.42 ± 0.67 ms |
| Inception 推理（batch 32） | 2.076 ± 0.15 ms |
| CLIP 推理（batch 32） | 1.955 ± 0.14 ms |

FD 时间取作者 JAX 实现与 [19]、[5] 公开 PyTorch/numpy 实现中的最优值。MMD 渐近复杂度 $O(n^2 d)$，但只涉及矩阵乘法，易并行（Sec. 6.4）。

**合成实验**（Sec. 3.2, Table 2）：参考分布为原点处 2D 各向同性高斯，第二分布为四个等权高斯混合，均值随 $\lambda$ 远离原点但整体均值与协方差保持不变（$\tau_\lambda^2 = \sigma^2 - \lambda^2/2$）。FD 和 FD∞ 始终为 0.0；MMD 从 0.0 单调增至 244.9（Table 2 最后一行，$\lambda$ 增大方向）。

## 5. 在 OT×扩散地图中的位置

本文处于评测线，与 OT 的关系是间接但实质性的：FID 本质是 Inception 特征上两个高斯拟合之间的 Wasserstein-2 距离（原文 Eq. 1 即 OT 耦合定义，Eq. 2 是高斯情形闭式解）。作者攻击的不是 OT 距离本身，而是「用高斯闭式解近似任意分布间 W2」这一做法——即 Bures-Wasserstein 近似在非正态特征上的失效。

在课题地图中：
- **继承**：Chong & Forsyth [5]（FID 有偏性、FID∞）、Parmar et al. [19]（resize 对 FID 的影响）、Heusel et al. [13]（FID 原始提出）、Bińkowski et al. [2]（KID，用 rational quadratic 核的平方 MMD，但仍基于 Inception 特征）。
- **竞争/替代**：CMMD 直接挑战 FID 作为 T2I 主指标的地位；与 KID 同属 MMD 家族，但换用 CLIP 特征。与 FD-DINOv2（后续工作，用 DINOv2 特征）构成「换特征 + 换距离」的评测改进路线。
- **对课题的意义**：本课题背景指出「FID 对少步模型系统性不公平」——本文提供了机制层面的解释：少步模型输出分布更集中、模式收缩，偏离正态更严重，高斯闭式解误差更大。这直接支撑开放问题 #4（Sinkhorn/OT 系评测指标对少步模型的公平性）的动机。

## 6. 局限与批评

**作者承认的**：
- CLIP 嵌入也不满足正态假设（Sec. 3.3 明确说明），因此 CMMD 不适用于任何需要正态假设的距离计算。
- 带宽 $\sigma=10$ 的选择是经验性的，作者只报告「带宽对总体趋势影响不显著」，未给系统性消融（Sec. 4）。

**读出来的**：
- 人评实验只用了 Muse 一个模型家族（Model-A vs Model-B），且只测了 3 名评分者、1633 个 prompt。CMMD 与人评一致性的证据来自单一模型对，泛化到其他模型家族（如扩散模型、自回归模型）的人评相关性未在本文验证。
- CMMD 的绝对数值依赖 CLIP 模型版本和带宽 $\sigma$，跨论文比较 CMMD 值时需要固定这些设置；作者固定了 $\sigma=10$ 和 ViT-L/14@336px，但社区若不统一采用，数值不可比。
- 样本效率实验（Fig. 8）只展示了 Stable Diffusion 一个模型在 COCO 30K 上的结果，未展示多模型、多数据集下的样本效率曲线。
- 失真实验只用了 VQGAN latent 空间的 token 替换这一种失真类型；对高斯噪声、模糊等低层失真，作者承认 FID 能正确捕捉（Sec. 6.2 引用 [13]），CMMD 在这些失真上的表现未做对比。

## 7. 对我们的启发

1. **端侧少步 benchmark 的指标选择**：本课题开放问题 #2 提出建「端侧少步生成」标准 benchmark。本文的直接启示是：在 NFE≤4 区间，FID 的正态假设错得更离谱（少步模型输出分布更集中），CMMD 或 FD-DINOv2 应作为分布级主指标，FID 降级为参考。benchmark 协议中应固定 CLIP 模型版本与 $\sigma$，否则 CMMD 数值不可跨论文比较。
2. **评测指标本身可作为端侧部署的快速筛选工具**：CMMD 的样本效率（Fig. 8 显示小样本即稳定）意味着端侧模型迭代时可以用少量生成图像快速评估，降低真机评测前的筛选成本。对「量化+少步」的复合误差研究（开放问题 #1），CMMD 比 FID 更适合作为质量退化量的度量，因为量化噪声造成的分布偏移不一定是均值/协方差层面的。
3. **Sinkhorn/OT 系指标的定位**：本文证明了「高斯闭式 W2」在非正态特征上失效，但未否定 OT 距离本身。开放问题 #4 用 entropic OT（Sinkhorn divergence）在 DINOv2/CLIP 特征上做分布距离，正是填补「不用高斯假设的 OT 距离」这一空白。CMMD 可作为该研究的基线之一，重点对比 Sinkhorn 与 MMD 在少步模型上的样本效率与人评相关性差异。
