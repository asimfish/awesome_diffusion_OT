# Accelerating Sinkhorn Algorithm with Sparse Newton Iterations

> Xun Tang, Michael Shavlovsky, Holakou Rahmanian et al. · ICLR 2024 · [arXiv](https://arxiv.org/abs/2401.12253) · 证据级 [P] · 课题 T29 高性能 OT 求解器与训练基础设施
> **一句话**：Sinkhorn 一阶缩放后接 Hessian 稀疏化的 Newton 迭代，超线性收敛，每迭代 O(n²)。

## 1. 问题

熵正则化最优传输（Eq.(1)）的标准求解器是 Sinkhorn 算法，它只做矩阵行列缩放，每迭代 O(n²)，但收敛慢。作者指出：Sinkhorn 虽满足指数收敛（Franklin & Lorenz, 1989; Carlier, 2022），但其可证明的指数速率常数往往太接近 1，实际表现更像多项式收敛（Sec. 2）；在早期阶段，达到次优间隙 ϵ 的迭代复杂度上界是 O(poly(ϵ⁻¹))（Sec. 1）。

此前已有 Sinkhorn-Newton 方法（Brauer et al., 2017）用 Newton 法联合优化对偶变量，可获超指数收敛，但单个 Newton 步解稠密 Hessian 线性系统要 O(n³)，违背了近线性时间的目标（Sec. 1）。作者把问题表述为：是否存在一个算法，迭代复杂度像 Newton 法，而每迭代复杂度像 Sinkhorn 的 O(n²)？

## 2. 方法

核心思想：把 Sinkhorn 算法看作对 Lyapunov 势函数 f(x,y)（Eq.(2)）的交替坐标上升（Eq.(3)），然后在一阶缩放阶段之后切换到稀疏化的 Newton 阶段。关键观察是 Hessian 矩阵近似稀疏，因此可以截断小元素后用稀疏线性系统求解器（共轭梯度）得到近似 Newton 方向。

Hessian 的显式形式（Eq.(4)）：

$$\nabla^2 f(x,y) = \eta \begin{pmatrix} \operatorname{diag}(P\mathbf{1}) & P \\ P^\top & \operatorname{diag}(P^\top \mathbf{1}) \end{pmatrix}$$

其中 $P = \exp(\eta(-C + x\mathbf{1}^\top + \mathbf{1}y^\top) - 1)$。

算法 1（SNS）分两阶段：
1. **Sinkhorn 阶段**：跑 N₁ 步标准行列缩放（warm start，同时让 P 接近稀疏）。
2. **Newton 阶段**：跑 N₂ 步。每步先对 ∇²f(z) 做阈值截断（小于 ρ 的元素置零，或动态取第 ⌈λn²⌉ 大元素保证目标稀疏度 λ），再用共轭梯度解稀疏线性系统 $M\Delta z = -\nabla f(z)$，最后做线搜索更新 $z \leftarrow z + \alpha \Delta z$。

复杂度：共轭梯度每次左乘 M 的代价是 O(τ(M)n²)，其中 τ(M) 是稀疏度（Definition 1）。设目标稀疏度 λ = O(1/n)，则每 Newton 迭代 O(λn³) = O(n²)（Sec. 4）。数值实验中唯一解情形取 λ = 2/n，非唯一解情形取 λ = 15/n（Sec. 6）。

## 3. 理论结果

**Theorem 1（Sinkhorn 阶段后的近似稀疏性）**：设 ∥r∥₁ = ∥c∥₁ = 1，Δ 为顶点最优性间隙（Definition 2）。存在常数 q, t₁，使得当 η > (1+2 log n)/Δ 且 t > t₁ 时，

$$\operatorname{dist}(F, P_{t,\eta}) \le 6n^2 \exp(-\eta\Delta) + \frac{\sqrt{q}}{\sqrt{t}}$$

因此 P_{t,η} 是 (λ*, ε_{t,η})-稀疏的，其中 λ* = τ(F)，ε_{t,η} = 6n² exp(−ηΔ) + √q/√t。进而 Hessian 在 N₁ 步 Sinkhorn 后是 (λ*/2 + 1/(2n), 2ε_{N₁,η})-稀疏的。若原 OT 问题有唯一解（对 cost 矩阵 C 是 generic 的，非唯一解集合 Lebesgue 测度为零），则 λ* ≤ 2/n；若 r = c = (1/n)1，则 λ* = 1/n。

**Theorem 2（Newton 阶段内的近似稀疏性）**：设 z_k 是第 k 个 Newton 步的对偶变量，ε_k 是次优间隙。在相同条件下，对 ε_k < 1，P_k 是 (λ*, ζ_k)-稀疏的，其中 ζ_k = 6n² exp(−ηΔ) + √q (ε_k)^{1/4}。作者指出若 ε_k 超指数下降，则 ε_k^{1/4} 项变得无关紧要。

**Theorem 3（非唯一解情形的稀疏性）**：若 cost 矩阵满足「cij + c_{i'j'} = c_{i'j} + c_{ij'} 当且仅当 i = i' 或 j = j'」，则 τ(F) ≤ (1+o(1))/√n。证明用二分图上的极值组合工具。

## 4. 实验与数字

设置：2021 Macbook Pro，Apple M1 Pro 芯片；熵正则参数 η = 1200（作者称这是有挑战性的设置）；共轭梯度解线性系统。三个测试用例：随机线性指派（n = 500，C 元素 iid Unif([0,1])，r = c = (1/n)1）、MNIST 图像间 OT（28×28 像素网格，cost 为 ∥x−y∥₂）、MNIST 图像间 OT（cost 为 ∥x−y∥₁，已知有非唯一解）。

关键数字：Random 用例 SNS 总迭代 29 vs Sinkhorn 56,199（约 1,938 倍减少），总时间 0.34s vs 233.36s（约 686 倍加速）；MNIST L2 迭代 53 vs 2,041，时间 2.33s vs 18.84s；MNIST L1 迭代 777 vs 5,748，时间 12.22s vs 45.75s。所有数字来自 Table 1。

非唯一解情形（MNIST L1）需要 N₁ = 700 步 Sinkhorn 预热和 λ = 15/n 的目标稀疏度才能收敛到 ground truth（Sec. 6）。作者明确说「无法证明猜想的超指数收敛，但 Newton 阶段的低迭代数提供了强的数值支持」（Sec. 6 末）。

## 5. 在 OT×扩散地图中的位置

本工作属于「更强的迭代算法」方向（课题背景中的方向 ii），与 cuRegOT（二阶方法 GPU 化）同族，是 Sinkhorn-Newton（Brauer et al., 2017）的稀疏化改进。它解决的问题是 Sinkhorn 在高精度区间收敛慢的瓶颈，与 ProgOT（ε 退火分治）、PDOT/cuPDLP（一阶 LP 求解器复兴）构成竞争关系：SNS 用二阶方法在固定 ε 下拿超线性收敛，ProgOT 用退火调和快与准，PDOT 在 GPU 上做 matrix-free 精确 OT。

在扩散/流匹配训练管线中，batch 内 OT 配对通常用中小 batch 和中等精度，Sinkhorn 本身开销不大（Immiscible Diffusion 报告 22.8ms 量级）。SNS 的直接适用场景是**需要高精度 OT 解**的环节——例如需要精确 Monge 配对而非近似熵正则解、或小 ε 难例（η 大）的情形。作者在 Sec. 7 明确提到未来方向包括与硬件并行加速结合，这与 FlashSinkhorn/FastSinkhorn 的 kernel 级 IO 工程正交：SNS 减少迭代数，IO-aware 实现减少每迭代的常数和显存，两者可叠加。

## 6. 局限与批评

作者承认的：
1. 无法证明猜想的超指数收敛，只有数值支持（Sec. 6 末、Sec. 7）。
2. 非唯一解情形需要更多 Sinkhorn 预热（N₁ = 700 vs 20）和更宽松的目标稀疏度（λ = 15/n vs 2/n），且 Theorem 3 的条件（cost 矩阵的严格四点和性质）在一般非唯一解问题上未必成立（Sec. 6、Theorem 3）。
3. 稀疏化只用简单阈值截断，更复杂的稀疏近似技术留作未来工作（Sec. 7）。

读出来的：
1. 实验规模小：n = 500（Random）和 n = 784（MNIST），没有展示 n 更大时 λ = 2/n 的稀疏度选择是否仍然有效，也没有与 GPU 上的 Sinkhorn 实现对比（实验在 M1 Pro 笔记本上跑）。
2. 所有实验固定 η = 1200。Theorem 1 的稀疏性保证要求 η > (1+2 log n)/Δ，但 η 太大时 Sinkhorn 阶段本身会极慢（MNIST L1 用了 700 步预热），SNS 的总时间优势依赖 Newton 阶段能弥补预热成本，这一权衡没有被系统扫过。
3. 共轭梯度的迭代次数和收敛判据未报告，O(n²) 的每迭代复杂度是渐近的，实际常数（稀疏矩阵存储、CG 内循环）在表 1 中体现为 Newton 阶段单迭代时间远高于 Sinkhorn 单迭代（如 Random：0.22s/9 步 vs 0.12s/20 步）。

## 7. 对我们的启发

1. **高精度 OT 配对的加速选项**：如果扩散训练中需要精确 batch 内配对（而非熵正则近似），SNS 提供了一条在 CPU/单卡上把迭代数从数万压到数十的路线。但要注意 η 的选择：η = 1200 是作者为展示加速而选的难例设置，实际扩散训练中常用的 η 远小于此，SNS 的优势幅度需要重新评估。
2. **与 IO-aware Sinkhorn 的叠加**：SNS 的 Newton 阶段核心操作是稀疏 Hessian 的共轭梯度，其矩阵-向量积涉及 P 的稀疏近似。如果 P 的稀疏模式稳定，可以预计算稀疏索引并用 GPU 稀疏核加速，这与 FlashSinkhorn 的 online-LSE 路线互补——一个减迭代数，一个减每迭代常数。可作为切入点 #1（IO-aware 推广）的扩展方向。
3. **非唯一解是实际风险**：MNIST L1 用例显示非唯一解时 SNS 需要 35 倍预热迭代和 7.5 倍稀疏度目标。扩散训练中 cost 常用平方欧氏距离（严格凸，唯一解），但若改用其他 cost（如 cosine 或学习到的 cost），非唯一解风险上升，SNS 的鲁棒性需要验证。这对接切入点 #1 中「非欧 cost」的推广场景。
