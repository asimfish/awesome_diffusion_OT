# LAST: Bridging Vision-Language and Action Manifolds via Gromov-Wasserstein Alignment

> Huaihai Lyu, Chaofan Chen, Yuheng Ji, et al. · ICML 2026 · [arXiv](https://arxiv.org/abs/2606.11221) · 证据级 [A] · 课题 T26 Gromov-Wasserstein 与跨空间生成对齐
> **一句话**：LAST 用 Lie 代数线性化 + 协方差白化重构动作空间，使 VLA 在 LIBERO 上平均成功率 95.8%。

## 1. 问题

VLA 模型把机器人动作当作 token 处理，希望继承 Transformer 的 scaling law，但视觉-语言（VL）语义空间与机器人动作物理流形之间存在结构性异质：语义空间在归一化余弦几何下近似线性且各向同性，而动作流形位于 SE(3) 上，非欧氏且各向异性（Sec. 1）。作者把这种不匹配分解为两个 gap：

- **几何不匹配**：标准回归用欧氏残差 $\|\vec{ox}-\vec{oc}\|_2^2$ 度量原型偏差，隐含假设动作空间是凸向量空间、加法更新可行（$\vec{ox}\approx\vec{oc}+\vec{cx}$）。但机器人动作在 Lie 群 SE(3) 上，对欧氏加法不封闭，欧氏残差和线性混合会产生几何无效的旋转（Sec. 1）。
- **统计不匹配**：VLM 嵌入经对比学习训练、在 $\ell_2$ 归一化特征上用余弦相似度比较，鼓励局部各向同性的超球面几何；而动作模式沿动力学约束方向强各向异性。用各向同性 VL 度量检索动作邻居会跨椭圆短轴选到假邻居、沿主轴漏掉真邻居，破坏局部度量一致性（Sec. 1）。

作者认为直接回归 $\Phi: X\to Y$ 是 ill-posed 的（Sec. 3.2），此前 tokenizer 方法——简单 binning（Kim et al., 2024）、结构化 VQ（Lee et al., 2024）、频域变换 FAST（Pertsch et al., 2025）——要么忽略 SE(3) 非线性、要么假设各向同性、要么引入 Gibbs ringing 等非物理伪影（Sec. 2.1）。

## 2. 方法

核心思想：不显式优化 GW 目标，而是用 GW 视角指导设计一个 tokenizer，使动作空间的域内关系几何与 VL 语义空间的域内几何结构兼容（Sec. 3.2）。LAST 分两阶段：

**阶段一：Global Topological Linearization（全局拓扑线性化）**

1. **Lie 代数线性化**（Eq. 8）：把原始轨迹 $a=\{P_t\}_{t=1}^T\in SE(3)^T$ 映射到切空间。对每帧计算相对起始帧 $P_1$ 的运动并取对数：
$$\xi_t = \log(P_1^{-1}\cdot P_t)^{\vee}$$
其中 $(\cdot)^{\vee}$ 把 se(3) 矩阵代数同构映射到 $\mathbb{R}^6$。堆叠得到 $\xi=[\xi_1,\dots,\xi_T]^\top$，把弯曲流形变成线性向量空间，使后续线性操作保持几何有效性。

2. **B 样条时间抽象**（Eq. 9）：用 ridge 回归求解固定长度的控制点 $z\in\mathbb{R}^{T_c\times 6}$：
$$z = \arg\min_{z'} \|\Phi z'-\xi\|_F^2 + \lambda\|z'\|_F^2 = (\Phi^\top\Phi+\lambda I)^{-1}\Phi^\top\xi$$
其中 $\Phi\in\mathbb{R}^{T\times T_c}$ 是均匀 B 样条基矩阵，$T_c$ 是固定潜在 horizon。这把变长轨迹统一为固定长度表示。

**阶段二：Local Metric Discretization（局部度量离散化）**

1. **粗粒度 schema 选择**（Eq. 10）：用 Layer-1 codebook $C^{(1)}=\{c^{(1)}_k\}_{k=1}^K$ 对 $z$ 做软分配：
$$p_k(z) = \frac{\exp(-\|z-c^{(1)}_k\|^2/\tau)}{\sum_{j=1}^K \exp(-\|z-c^{(1)}_j\|^2/\tau)}$$
粗重构 $\hat{z}^{(1)}=\sum_k p_k(z)c^{(1)}_k$ 是所选邻域的 barycenter。

2. **软统计建模**（Eq. 11–12）：残差 $r=z-\hat{z}^{(1)}$ 在各局部 chart 内强各向异性。用软分配插值局部协方差，得到软白化矩阵：
$$\Sigma_{\text{soft}}(z) = \sum_{k=1}^K p_k(z)\left[(z-c^{(1)}_k)(z-c^{(1)}_k)^\top + \epsilon I\right], \quad W_{\text{soft}}(z) = \Sigma_{\text{soft}}(z)^{-1/2}$$

3. **白化残差量化**（Eq. 13–15）：把残差投影到矫正后的局部坐标系 $\tilde{r}=W_{\text{soft}}(z)\cdot(z-\hat{z}^{(1)})$，在该坐标系中 $\tilde{r}\approx\mathcal{N}(0,I)$，Layer-2 codebook 在标准 VQ 下学习（Eq. 14），最终重构为：
$$\hat{z} = \hat{z}^{(1)} + \Sigma_{\text{soft}}(z)^{1/2}\cdot c^{(2)}_{q_2}$$

**VLA 训练**（Sec. 3.3.3）：Stage 1 预训练 tokenizer，目标 $L_{\text{tok}}=L_{\text{rec}}+\lambda_1 L_{\text{com}}$（Eq. 16–17）；Stage 2 冻结 tokenizer，VLA 双头训练——AR 头预测离散 token（$L_{\text{dis}}$，Eq. 18），扩散头（DiT）在隐藏状态 $h$ 条件下对白化 Lie 代数动作做迭代去噪（$L_{\text{con}}$，Eq. 19），总目标 $L_{\text{vla}}=L_{\text{dis}}+\lambda_2 L_{\text{con}}$。

## 3. 理论结果

论文给出两个引理（Sec. 3.2.1），均为构造性论证，非统计收敛率或最优性保证：

- **Lemma 3.1（Local Closure via Discrete Action Intents）**：假设多簇动作分布为高斯混合 $P(a|s)=\sum_k \omega_k(s)\mathcal{N}(a;\mu_k,\Sigma_k)$，引入离散意图变量 $z$ 后得到局部闭合分解 $P(a|s)=\sum_k P(a|z=k,s)P(z=k|s)$，把全局传输计划分解为局部计划混合 $\Phi\approx\sum_k\Phi_k$，每个 $\Phi_k$ 把语义簇 $X_k$ 映射到测地凸的动作 chart $Y_k$。证明基于链式法则分解与条件分布近似为高斯（Eq. 3–5）。

- **Lemma 3.2（Statistical Alignment via Whitened Isomorphism）**：在局部 chart $z_k$ 内应用白化变换 $\psi_k(a)=\Sigma_k^{-1/2}(a-\mu_k)$，有效度量张量变为 $\tilde{G}_Y=(\Sigma_k^{1/2})^\top G_Y(\Sigma_k^{1/2})=I$（Eq. 6），Hessian 条件数坍缩到 $\kappa(J_\Phi)\approx 1$，满足 Bi-Lipschitz 条件且常数 $C\approx 1$（Eq. 7）。证明基于 Hessian 条件数 $\kappa(H)\approx\lambda_{\max}(\Sigma_k)/\lambda_{\min}(\Sigma_k)\gg 1$ 在白化后变为单位阵的论证。

另有 Lemma A.1、A.2（形式化两种 failure mode）和 Lemma A.4（局部 chart 内运动合成近似可加）在附录中，正文未给出完整陈述。

## 4. 实验与数字

**实现**：真实世界实验用 3B 参数纯自回归 Transformer（Qwen2.5 配置）；LIBERO/SimplerEnv/真实世界 action horizon 分别为 8/16/30 帧；tokenizer 预训练 5 epochs，$T_c=16$，codebook 大小 $K=1024$，$\lambda_1=0.5$；VLA 微调 5 epochs，batch size 256，8×A800，$\lambda_2=10$（Sec. 4.1）。

## 5. 在 OT×扩散地图中的位置

LAST 属于「生成对齐线」中把 GW 视角前置到模型设计的一支，与 MIRROR（[R]）并列：不事后求 GW 耦合，而是重构动作空间使其与语义空间度量兼容。它继承 Alvarez-Melis–Jaakkola（EMNLP 2018）「嵌入空间可被 GW 无监督对齐」的观察，但把对齐从「事后耦合」推进到「训练前空间重构」。

与 GENOT（NeurIPS 2024）的关系是互补而非竞争：GENOT 用流匹配参数化 entropic GW 耦合的条件分布，解决跨空间随机映射的可外推采样；LAST 不学习耦合，而是通过 Lie 代数线性化 + 白化把动作流形改造成与 VL 嵌入统计兼容的空间，使下游 VLA 的回归/扩散头面对的是近似各向同性的局部 chart。两者共享「GW 对齐需要先解决度量异质性」的前提，但 LAST 的 GW 是设计原则而非训练目标。

在推理管线中，LAST 占据「动作 tokenization」环节：它把连续 SE(3) 轨迹压缩为离散 token + 白化残差，下游 VLA 的 AR 头做拓扑选择（对应 GW 中的局部 chart 指派）、DiT 扩散头做度量细化（对应局部 chart 内的连续传输）。这对应课题背景中「GW 视角前置到模型设计」的切入点，与 Blind Match（CVPR 2025）的「预训练表征结构上可对齐」形成上下游关系：Blind Match 验证对齐可行性，LAST 提供使对齐可行的动作空间构造。

## 6. 局限与批评

**作者承认的**（Impact Statement）：
1. **白化复杂度**：Local Metric Discretization 估计 per-schema 协方差成本 $O(Kd^3)$（$K$ 为 codebook 大小，$d$ 为残差维度），在本文规模（$K=1024, d=6$）可忽略；高自由度具身（如多指灵巧手）可能需要低秩或 shrinkage 估计器避免欠采样协方差模式的不稳定。
2. **局部近似有效性**：SE(3) 对数映射在 cut locus 附近（旋转接近 $\pi$）单射性退化。在 ≥30 Hz 采样下帧间残差保持在 injectivity radius 内，线性化基本无畸变；稀疏采样或剧烈旋转轨迹可能需要 multi-chart 覆盖或递归线性化。

**读出来的**：
1. **GW 视角是定性的**：论文没有显式计算任何 GW 距离或耦合，Lemma 3.1/3.2 的「GW alignment」停留在「使域内几何兼容」的论证层面，没有给出对齐质量的定量度量（如 GW 畸变值）或与显式 GW 求解器的对比。Table 1–5 的所有指标都是下游任务成功率或重建误差，无法直接验证「GW 对齐」本身是否达成。
2. **理论结果弱**：两个引理都是构造性论证，假设高斯混合、局部凸性等强条件，没有样本复杂度、收敛率或最优性保证；Lemma A.1/A.2 在正文中未给出完整陈述，无法评估其形式化强度。
3. **基线选择**：LIBERO 上最强的对比是 π0 系列，但 LAST 的 3B 参数 Qwen2.5 配置与 π0 的架构差异未被控制；「LAST-Continuous 超过 π0 0.9 个百分点」的边际（94.1% vs 95.8%）在无方差/多次运行报告的情况下难以判断显著性。

## 7. 对我们的启发

1. **「空间重构替代事后耦合」可作为 GW 生成对齐的低成本路径**：LAST 表明，与其在训练中显式求解 GW 耦合（O(n³) 且不可微），不如在数据预处理阶段用几何先验（Lie 代数 + 白化）把源空间改造成与目标空间度量兼容。这对应课题切入点 #2 的变体：在扩散潜空间缝合中，可以先对两个冻结模型的潜变量做类似的局部白化/线性化预处理，再学轻量映射，可能比直接学 GW plan 更稳定。
2. **离散 schema + 连续残差的双层分解是「拓扑选择 + 度量细化」的实例**：LAST 的 AR 头选 chart、扩散头做 chart 内连续传输，与 GW 的「局部低畸变耦合混合」结构同构。这提示在跨模态生成中可以把「模式选择」和「模式内生成」分离训练，降低单次优化的非凸性——可接切入点 #1（跨维 Gromov-Schrödinger bridge）中「先选模式再桥接」的设计。
3. **白化作为 OT 对齐的预处理有直接迁移价值**：Lemma 3.2 的论证（白化使 Hessian 条件数坍缩到 1）不限于机器人动作，任何各向异性数据空间在进入 GW/FGW 求解器前做局部白化都可能改善条件数。这对应课题背景中「GW 求解器对度量条件敏感」的痛点，可作为 GW-at-Scale 或 GENOT 类方法的廉价预处理步骤。
