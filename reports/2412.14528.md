# Multi-Level Optimal Transport for Universal Cross-Tokenizer Knowledge Distillation on Language Models

> Xiao Cui, Mo Zhu, Yulei Qin, et al. · AAAI (Oral) 2025 · [arXiv](https://arxiv.org/abs/2412.14528) · 证据级 [P] · 课题 T22 离散数据与文本中的扩散/流与最优传输
> **一句话**：用 token 级 + 序列级双层 OT 对齐不同词表的 logit 分布，实现任意教师→学生的跨 tokenizer LLM 蒸馏。

## 1. 问题

这篇论文解决的是跨 tokenizer 知识蒸馏（cross-tokenizer knowledge distillation, CTKD）问题：教师模型和学生模型使用不同的 tokenizer（即不同词表），导致输出 logit 的维度不一致，无法直接套用 KL 散度、RKL、JS 散度等传统蒸馏损失。传统 KD 方法要求教师和学生的 logit 维度一一对应，这强制二者使用相同 tokenizer，限制了跨模型家族蒸馏的灵活性（Sec. Introduction）。

此前仅有的两个 CTKD 尝试各有缺陷。ULD（Boizard et al. 2024）用 token 级 OT 对齐单个 token 的分布，但只考虑单个 token 内部信息，忽略全局上下文；其 zero padding 策略引入噪声，且限制了成本矩阵只能取单一形式。DSKD（Zhang et al. 2024b）用可学习投影器把隐状态双向映射到对方空间，但变换后的分布精度低，且仍假设严格的 token-by-token 对应（Sec. Introduction）。作者指出，不同 tokenizer 对长词的切分方式不同，token 顺序错位是实际存在的，刚性 token 对应假设不成立。

## 2. 方法

核心思想：在 token 级和序列级两个层次上用 OT 距离度量教师和学生 logit 分布的差异，消除对维度对应和 token 逐位对应的依赖。总损失为（Eq. 21）：

$$L = \sum_{t=1}^{T} L_{CE}(y(t), s(t)) + \alpha(L_{HAD} + \beta L_{SL} + \gamma L_{SD})$$

其中 $L_{HAD}$ 是 holistic absolute difference loss，$L_{SL}$ 是 sequential logarithmic loss，$L_{SD}$ 是 Sinkhorn distance loss。

**Token 级：Holistic Absolute Difference Loss。** 先对序列内所有 token 的 logit 求和并降序排序，得到序列级排序 $t^{SR}$；学生 logit 通过置换矩阵 $Q^*$ 匹配教师排序（Eq. 10-11）。然后做 top-k 截断（Eq. 12），使双方支持集大小一致且不含零值。截断后，绝对差成本矩阵 $C^{tok}_{ij}(t) = |t_i(t) - s_j(t)|$ 下的 OT 最优传输矩阵退化为单位阵 $P^{HAD}$，损失为（Eq. 14）：

$$L_{HAD} = \sum_{t=1}^{T}\sum_{i=1}^{k} |t^{SR,Tr}_i(t) - s^{SR,Tr}_i(t)|$$

**Token 级：Sequential Logarithmic Loss。** 用对数形式成本 $C^{tok}_{ij}(t) = -t_i(t)\log s_j(t)$，在 top-k 截断保证无零值的前提下，最优传输矩阵同样退化为 $P^{HAD}$，损失为（Eq. 16）：

$$L_{SL} = -\sum_{t=1}^{T}\sum_{i=1}^{k} t^k_i(t)\log s^k_i(t)$$

**序列级：Sinkhorn Distance Loss。** 用 token 间 OT 距离构造序列级成本矩阵 $C^{seq}_{ij} = \sum_{l=1}^{k}\sum_{q=1}^{k} P^{HAD}_{lq}|t^k_l(i) - s^k_q(j)|$（Sec. Methods, Sinkhorn Distance Loss）。然后用熵正则化的 Sinkhorn 距离近似 Wasserstein 距离：构造高斯核 $K_0 = \exp(-C/\lambda)$（Eq. 18），迭代做行列归一化（Eq. 19），$N$ 次迭代后得到 $P_\lambda = K_N$，损失为（Eq. 20）：

$$L_{SD} = \langle P_\lambda, C\rangle = \sum_{i=1}^{T}\sum_{j=1}^{T} K^N_{i,j}C_{i,j}$$

训练流程：教师和学生分别对输入 $x$ 做 softmax 温度缩放得到 $t \in \mathbb{R}^{T\times m}$ 和 $s \in \mathbb{R}^{T\times n}$（Eq. 1）；计算上述三个 OT 损失与 CE 损失的加权和；无标签蒸馏场景下用教师生成文本替代 ground-truth。超参数：$\alpha=0.15$，$\beta=0.1$，$\gamma=0.1$，$\tau_{SL}=1$，$\tau_{SD}=2$，$\lambda=0.1$，$N=20$，$k=50$（Sec. Implementation details）。

## 3. 理论结果

无理论结果。论文没有给出定理、引理或收敛性保证。作者通过重构 ULD 的 OT 问题（Eq. 2-6）说明 ULD 的 token 级 Wasserstein 距离等价于排序后 logit 的绝对差之和，并据此论证可以设计不同成本矩阵并扩展到多级 OT，但这是推导而非理论保证。

## 5. 在 OT×扩散地图中的位置

这篇论文属于 OT 在离散文本分布对齐中的应用，不涉及扩散模型或流匹配。它对应课题背景中「蒸馏即分布对齐」谱系的一个分支：跨 tokenizer 的 AR→AR 蒸馏。与课题中提到的 dLLM 加速蒸馏（SDTT/Di4C/DCD，同模型自蒸馏）和跨 tokenizer OT 蒸馏（MultiLevelOT，AR→AR）是并列关系。

在 OT 方法论上，MultiLevelOT 继承了两条线：一是 ULD 的 token 级 OT 跨词表对齐思路，作者通过重构 ULD 的 OT 问题（Eq. 2-6）揭示其等价于排序后绝对差，并在此基础上做扩展；二是 SinKD（Cui et al. 2024b,a）的 Sinkhorn 距离蒸馏，作者将其从同词表场景迁移到跨词表场景的序列级对齐。与 DSKD 的隐空间投影路线形成竞争关系，作者明确批评其「dual-space projection lacks semantic interpretability」（Sec. Related Work）。

对课题的启示在于：MultiLevelOT 展示了在离散 token 分布上，OT 成本矩阵的设计（绝对差 vs 对数似然差）和层级选择（token 级 vs 序列级）是可控的工程自由度。这为课题开放问题 #4「任意教师→扩散学生的 OT 蒸馏统一框架」提供了现成的跨词表对齐损失组件——将 MultiLevelOT 的双层 OT 损失从 AR 学生替换为 masked 扩散学生，即可拼接出跨 tokenizer 的扩散蒸馏方案。但需注意 MultiLevelOT 的序列级 Sinkhorn 是在 logit 空间而非序列分布空间上做的，与扩散模型中的序列分布对齐（如 CDLM 的后验桥一致性）在对象上有本质区别。

## 6. 局限与批评

**作者承认的**：
1. 超参数未做充分调优——「Although further tuning may enhance performance, we maintain a consistent set of hyper-parameters across all tasks to underscore the robustness of our approach」（Sec. Implementation details）。这意味着报告的数字可能低于该方法的上限。
2. 排除 DSKD 作为基线的原因是「it introduces additional modules whose increased learnable parameters may cause unfair comparison」（Sec. Baselines），这回避了与带额外参数方法的直接对比。

**读出来的**：
1. 序列级 Sinkhorn 距离的 ground cost 用的是 token 级 OT 距离（$C^{seq}_{ij}$），而 token 级 OT 本身依赖序列级排序和 top-k 截断。这意味着序列级对齐的质量受限于 token 级排序的正确性，两个层次的误差可能耦合。论文没有分析这种耦合对最终性能的影响。
2. top-k 截断（$k=50$）是一个强假设：它假设教师和学生 logit 的前 50 维在语义上可对齐。对于词表差异极大的 tokenizer 对（如多语言 vs 单语言），前 50 维可能对应完全不同的语义空间，排序对齐的合理性存疑。论文只在英文任务上验证，未涉及跨语言场景。
3. 计算开销未报告。序列级 Sinkhorn 需要 $T\times T$ 的核矩阵和 $N=20$ 次迭代，对长序列（如 DIALOGSum 的对话摘要）可能有不可忽略的在线蒸馏成本。论文没有给出训练时间或显存对比。

## 7. 对我们的启发

1. **可接切入点 #4（任意教师→扩散学生的 OT 蒸馏统一框架）**：MultiLevelOT 的 token 级 HAD/SL 损失只依赖 logit 排序和截断，不依赖学生模型类型。将 AR 教师（不同词表）的 logit 与 masked 扩散学生的 logit 用同样的双层 OT 损失对齐，同时保留扩散学生的 few-step 采样能力，是一个可直接验证的实验闭环。关键改动是扩散学生的 logit 来自去噪步骤而非单步自回归输出，需要处理时间步维度的对齐。
2. **成本矩阵设计可作为离散 OT 的语义 ground cost 参考**：MultiLevelOT 用绝对差和对数似然差两种成本矩阵捕获 logit 分布的不同几何特征，这与课题中「语义成本的 minibatch-OT 离散耦合」（切入点 #2）的思路相通。可以借鉴其对数成本形式，在冻结嵌入空间中用语义距离构造离散扩散的 ground cost，替代 Hamming 距离。
3. **序列级 Sinkhorn 的熵正则化参数 $\lambda$ 和迭代数 $N$ 的敏感性结论可迁移**：Table 7 显示 $N=20$ 后饱和，Table 8 显示 $k=50$ 最优。这提示在扩散模型的序列分布对齐损失中，Sinkhorn 迭代数和截断阈值同样存在饱和点，可作为超参数搜索的初始参考范围。
