# A dynamical formulation of multi-marginal optimal transport

> Brendan Pass, Yair Shenfeld · arXiv 2025 · [arXiv](https://arxiv.org/abs/2509.22494) · 证据级 [R] · 课题 T27 多边际 OT 与 Wasserstein 重心的生成应用
> **一句话**：把 MMOT 静态问题写成耦合流的动力学问题，凸优化可解并给出 quasi-Monge 解。

## 1. 问题

本文解决多边际最优传输（MMOT）缺少动力学形式的问题。两边际 OT 有 Benamou-Brenier 动力学形式（Eq. 1.3–1.4）：把静态 Monge 问题（Eq. 1.2）改写为边缘流 $(\rho, u)$ 满足连续性方程的最小化问题，再经变量替换 $m := \rho u$ 变成凸优化（Eq. 1.9）。但 MMOT 的静态问题（Eq. 1.10）涉及 $k \ge 2$ 个边缘，没有天然的"时间箭头"——两边际情形是从 $\mu_1$ 流向 $\mu_2$，多边际情形没有这种方向性（Sec. 1.2）。此前只有特殊情形或不同视角的工作（[CK18, ABLVE24]，原文引用，未见细节）。

此外，Benamou-Brenier 形式只适用于形如 $L(x_1, x_2) = c(x_2 - x_1)$ 且 $c$ 凸的代价函数（Eq. 1.12）。本文的动力学形式覆盖更广的代价族，包括半凸代价（Remark 1.8 / Corollary 2.5）。

## 2. 方法

核心思想：不流边缘，流**耦合**。构造一个从源测度 $p$ 出发、在 $t=1$ 时刻边缘匹配 $\mu_1, \dots, \mu_k$ 的耦合流 $(\pi, v)$，最小化沿流路径的代价积分。关键公式：

**动力学 MMOT 问题**（Theorem 1.6 / Definition 2.2）：

$$\min_{\pi, v} \int_0^1 \int_{\Omega^k} L(v(t, x)) \, d\pi(t, x) \, dt$$

约束为连续性方程 $\partial_t \pi + \nabla(\pi v) = 0$，$\pi(0, \cdot) = p$，且 $\pi(1, \cdot)$ 的边缘为 $\mu_1, \dots, \mu_k$（Eq. 1.16–1.17）。

**凸化变量替换**：令 $m := \pi v$，得凸优化问题（Eq. 1.31）：

$$\min_{\pi, m} \int_0^1 \int_{\Omega^k} L\left(\frac{dm(t,x)}{d\pi(t,x)}\right) d\pi(t,x) \, dt$$

约束 $\partial_t \pi + \nabla m = 0$，$\pi(0, \cdot) = p$，$\pi(1, \cdot)$ 边缘为 $\mu_1, \dots, \mu_k$。当 $L$ 凸时目标函数凸（Lemma 2.6），约束线性，故整体为凸优化。

**源测度与代价的匹配**（Corollary 2.4）：三种情形保证等价性成立：
- (i) $p = \delta_0$，$L$ 凸；
- (ii) $L$ 平移不变（$L(x_1 - \xi, \dots, x_k - \xi) = L(x_1, \dots, x_k)$），$p = \mathrm{Law}(\xi, \dots, \xi)$，$\xi \sim \nu$；
- (iii) $L(x) = \tilde{L}(\mathrm{Proj}_E(x))$，$\mathrm{supp}(p) \subseteq E^\perp$。

**半凸代价**（Corollary 2.5）：当 $p = \delta_0$ 且 $L$ 为 $\alpha$-半凸时，静态问题等价于在动力学目标中加 $\frac{\alpha}{2}|v|^2$ 项再减去仅依赖边缘的常数项 $\frac{\alpha}{2}\sum_{l=1}^k \int_\Omega |x_l|^2 d\mu_l(x)$（Eq. 2.13）。

**quasi-Monge 解的提取**：从最优流 $v_{\mathrm{opt}}$ 解 ODE $\partial_t \Phi_{\mathrm{opt}}(t,x) = v_{\mathrm{opt}}(\Phi_{\mathrm{opt}}(t,x))$，$\Phi_{\mathrm{opt}}(0,x) = x$，则 $\Phi_{\mathrm{opt}}(1, \cdot)_\sharp p = \pi_{\mathrm{opt}}(1, \cdot)$ 是静态 MMOT 的最优耦合（Eq. 1.35–1.37）。数值上不直接解 ODE（因 $v_{\mathrm{opt}}$ 正则性低），而是从 $\pi_{\mathrm{opt}}(1, \cdot)$ 取条件期望估计传输映射（Sec. 4.3.1）。

**对偶形式**（Theorem 1.10 / Theorem 3.2）：动力学 MMOT 的对偶为

$$\sup_{\lambda, \lambda_1, \dots, \lambda_k} \left\{ \sum_{l=1}^k \int_\Omega \lambda_l(x_l) d\mu_l(x_l) - \int_{\Omega^k} \lambda(0, x) dp(x) \right\}$$

约束 $\partial_t \lambda(t,x) + L^*(\nabla \lambda(t,x)) \le 0$（Hamilton-Jacobi 不等式）和 $\sum_{l=1}^k \lambda_l(x_l) \le \lambda(1, x)$（Eq. 1.41–1.43）。

## 3. 理论结果

**Theorem 2.3（主定理）**：设 $\Omega \subseteq \mathbb{R}^d$ 紧凸，$p$ 为 $\Omega^k$ 上概率测度，$L: \mathbb{R}^{kd} \to \mathbb{R}$ 凸且 $p$-平移不变（Eq. 2.7）。则

$$\min_{\gamma \in \Pi(\mu_1, \dots, \mu_k)} \Gamma(\gamma) = \min_{(\pi, m) \in \mathcal{C}(p, \mu_1, \dots, \mu_k)} \mathcal{B}(\pi, m),$$

且两侧最小值均可达。进一步：(1) 静态最优耦合 $\gamma_{\mathrm{opt}}$ 诱导一个动力学最优流，满足 $\pi_{\mathrm{opt}}(1, \cdot) = \gamma_{\mathrm{opt}}$；(2) 动力学最优流的 $\pi_{\mathrm{opt}}(1, \cdot)$ 是静态最优耦合。

**Corollary 2.4**：三种源测度-代价匹配情形（见 §2）下等价性成立。

**Corollary 2.5**：$p = \delta_0$ 时半凸代价的等价性（Eq. 2.13）。

**Theorem 3.2（对偶）**：在 $L$ 连续可微、$\lim_{\beta \uparrow +\infty} \frac{1}{\beta} \int_{\mathbb{R}^{kd}} L(\beta x) dp(x) = 0$、$L$ 凸且 $p$-平移不变的条件下，动力学 MMOT 的对偶如 Eq. 1.41–1.43 所示。原文注明该定理不讨论 sup 的取得到（Remark 3.3）。

**Lemma 2.6**：$L$ 凸则透视函数 $(\pi, m) \mapsto L(m/\pi)\pi$ 凸，故 $\mathcal{B}(\pi, m)$ 凸。

**Lemma 2.8**：凸代价下动力学代价在概率核卷积下不增（Eq. 2.22），这是证明中正则化步骤的关键。

**Proposition 2.10**：对任意 $(\pi, m) \in \mathcal{C}(p, \mu_1, \dots, \mu_k)$，存在概率测度 $P$ 集中在满足 ODE（Eq. 2.25）的轨迹对上，且 $\pi(t, \cdot)$ 是 $\Phi(t, x)$ 在 $P$ 下的边缘（Eq. 2.26）。这用 Ambrosio 的概率表示处理向量场正则性不足的问题。

**Proposition 2.11**：给定 $q_a, q_b$ 和耦合 $q_{ab}$，沿线性插值 $X(t, y^a, y^b) = (1-t)y^a + t y^b$ 构造的 $\pi(t, \cdot)$ 和条件期望向量场 $v(t, x) = \int (y^b - y^a) dq^{t,x}_{ab}(y^a, y^b)$ 满足连续性方程（Eq. 2.30–2.33）。

## 5. 在 OT×扩散地图中的位置

本文填补了 MMOT 理论中"动力学形式"的空白，对应课题背景中"MMOT 理论线"的 Pass–Shenfeld 动力学化（DMMOT [R]）。与 Benamou-Brenier（[BB00]）的关系是**推广而非竞争**：两边际情形下本文的形式覆盖 Benamou-Brenier 不覆盖的代价（如 $p = \delta_0$ 时任意凸代价，Corollary 2.4(i)），但代价是流的是 $kd$ 维耦合空间而非 $d$ 维边缘空间，计算代价更高。

与课题中其他工作的关系：
- **继承**：Agueh–Carlier (2011) 的 barycenter 即特殊 MMOT；Pass (2015) 的 MMOT Monge 解结构；Friesecke–Vögler [FV18] 的 quasi-Monge 概念（本文将其从离散、全同边缘推广到连续、不同边缘，Sec. 1.3）。
- **互补**：Altschuler–Boix-Adserà 的复杂度结果（固定维数多项式可解、对维度指数依赖不可去除）解释了为何需要利用结构；本文的动力学形式是一种"利用结构"的方式，但并未绕开维度灾难——耦合流在 $\Omega^k$ 上，维度随 $k$ 线性增长。
- **潜在衔接**：课题背景中提到的 TreeDSB、MMFM、OTP-FM 等生成应用线均依赖 MMOT 或 barycenter 的某种可解形式。本文的凸优化形式为这些方法提供了另一种可能的数值管线，但原文未做生成实验，也未与这些工作对比。

在推理管线中的位置：本文属于"静态 MMOT → 可解形式"的理论层，不直接涉及扩散或 FM 的采样/训练。其 quasi-Monge 解的概念（Eq. 1.32–1.33）与 barycenter 的"共同源测度"视角一致，但本文的源测度 $p$ 是 $\Omega^k$ 上的（如对角测度 $\mathrm{Law}(\xi, \dots, \xi)$），而非 barycenter 本身的测度。

## 6. 局限与批评

**作者承认的**：
1. 数值上不能直接解 ODE（Eq. 1.35）构造 quasi-Monge 解，因为 $v_{\mathrm{opt}}$ 正则性低，ODE 可能无经典解（Sec. 1.3）；改用条件期望估计传输映射。
2. Theorem 3.2 不讨论对偶 sup 的取得到（Remark 3.3）。
3. 对偶定理需要额外的正则性和可积性假设（脚注 4）。

**读出来的**：
1. **维度问题未解决**：动力学问题定义在 $\Omega^k \subseteq \mathbb{R}^{kd}$ 上，流是 $kd$ 维的。对于 $k$ 个边缘、每个 $d$ 维，状态空间维度是 $kd$，比两边际 Benamou-Brenier 的 $d$ 维高 $k$ 倍。原文未讨论离散化后的网格规模或计算复杂度，也未与静态 MMOT 的 LP 求解器对比计算成本。对于生成建模中常见的 $d \ge 2$、$k \ge 3$ 设置，这可能是实际障碍。
2. **数值验证极弱**：仅 1 维、3 边缘、二次代价一个例子，无定量误差、无基线对比、无高维实验。proximal splitting 的收敛性、步长选择、离散化误差均未报告（原文截断，未见）。
3. **源测度 $p$ 的选择依赖代价结构**：Corollary 2.4 的三种情形覆盖了常见代价，但一般凸代价只能用 $p = \delta_0$（情形 (i)），此时源测度是点质量，流的初始条件退化（Remark 2.13 显示 $v(t,x) = x/t$ 在 $t \downarrow 0$ 发散）。这对数值离散化的稳定性可能不利。
4. **quasi-Monge 解的存在性依赖非原子源测度**：Sec. 1.3 中从 $\gamma_{\mathrm{opt}}$ 构造 quasi-Monge 解需要 $\nu$ 非原子（引用 [Pra07, Theorem A]）。当 $p = \delta_0$ 时源测度是原子的，此时 quasi-Monge 解的构造路径不直接适用（原文未明确讨论这一点）。

## 7. 对我们的启发

1. **凸优化管线可作为 MMOT 生成应用的备选求解器**：本文的 Eq. 1.31 是凸优化，可用 proximal splitting 求解。对于课题中"多时间边缘生成"或"多条件融合"场景，如果代价是平移不变的（如二次代价 Eq. 1.28），可以考虑用此形式替代 Sinkhorn 类熵正则方法，避免熵偏差。但需先解决 $kd$ 维状态空间的离散化成本问题——可尝试用神经网络参数化 $\pi$ 和 $m$（如 Neural OT 的做法），而非网格离散。
2. **quasi-Monge 解与 barycenter 的"共同源"视角可对接模型融合**：Eq. 1.32–1.33 的 quasi-Monge 解用一个源测度 $\nu$ 同时推到 $k$ 个边缘，这与逐层 barycenter 融合（OTFusion 线）的"对齐+平均"思路同构。本文的动力学形式提供了一个连续时间的目标，可能用于设计"保耦合蒸馏"的训练损失：让 $k$ 个网络的输出分布沿耦合流演化，而非独立插值。
3. **半凸代价的动力学形式（Corollary 2.5）可能适用于非凸生成损失**：Eq. 2.13 把半凸代价的静态 MMOT 转化为凸目标加常数项。如果生成建模中的某些非凸损失可写成半凸 MMOT 代价，这个形式提供了凸化的可能。但需注意 $\alpha$ 项要求代价的"非凸程度"有界，且常数项依赖边缘的二阶矩。
4. **对偶形式（Theorem 3.2）的 Hamilton-Jacobi 约束可衔接 OT 势引导**：Eq. 1.42 的 $\partial_t \lambda + L^*(\nabla \lambda) \le 0$ 与 OTP-FM 的势函数框架形式相似。如果能把多边缘的势约束写成对预训练 FM/扩散模型的 inference-time guidance，可能实现"中间边缘约束"式引导（课题切入点 #2）。但本文的对偶是耦合空间上的，需先降维到边缘空间才可操作。
