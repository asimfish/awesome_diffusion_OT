# Towards a mathematical theory for consistency training in diffusion models

> Gen Li, Zhihan Huang, Yuting Wei · AISTATS (PMLR v258) 2025 · [arXiv](https://arxiv.org/abs/2402.07802) · 证据级 [P] · 课题 T10 一致性模型与少步蒸馏的 OT 视角
> **一句话**：证明一致性训练步数超过 O(d^{5/2}/ε) 即可使一步采样在 W1 意义下 ε-接近目标分布。

## 1. 问题

扩散模型采样需要在反向过程中反复评估神经网络，计算开销高，限制实时应用。一致性模型（consistency models, Song et al., 2023）通过训练一个函数，把扩散轨迹上任意时刻的点直接映射回数据分布的起点，使采样阶段只需一次网络评估（Sec. 1）。尽管一致性模型在 CIFAR-10、ImageNet 64×64、LSUN 256×256 及视频生成等任务上取得经验成功（Sec. 1），其理论理解仍然缺失——此前没有工作给出一致性训练采样保真度的非渐近刻画。

本文聚焦「训练阶段的一致性训练」（consistency training），即不依赖预训练扩散模型，直接从数据递归学习一组一致性函数 {f_t}_{1≤t≤T}，最终用 f_T(X_T)（X_T ~ N(0, I_d)）一步生成样本。核心问题是：训练步数 T 需要多大，才能保证 f_T(X_T) 与目标分布 X_1 在 Wasserstein 距离意义下足够接近。

## 2. 方法

作者考虑离散时间前向过程（Eq. (5)）：

$$X_t = \sqrt{1-\beta_t}X_{t-1} + \sqrt{\beta_t}W_t, \quad W_t \sim N(0, I_d)$$

记 α_t = ∏_{k=1}^t (1−β_k)，则 X_t = √α_t X_0 + √(1−α_t) W^t（Eq. (7)）。一致性训练从 f_1(x) ≡ x 出发，对每个 t = 2, ..., T 递归最小化（Eq. (14)）：

$$f_t \approx \arg\min_{f \in \mathcal{F}} \mathbb{E}\left[\left\|f(\sqrt{\alpha_t}X_0 + \sqrt{1-\alpha_t}Z) - f_{t-1}(\sqrt{\alpha_{t-1}}X_0 + \sqrt{1-\alpha_{t-1}}Z)\right\|_2^2\right]$$

其中 Z ~ N(0, I_d)，X_0 ~ p_data。采样阶段从 X_T ~ N(0, I_d) 出发，输出 f_T(X_T)。

分析的关键是概率流 ODE 的两时间 flow map Φ_{t→k}（Eq. (16)–(17)）：它满足 Φ_{t→k}(X_t) 与 X_k 同分布，且 Φ_t = Φ_{t→1}。证明的核心递归关系（Eq. (34)）刻画误差 ξ_t(x) = f_t(x) − Φ_t(x) 如何沿轨迹传播：

$$\xi_t(x_t) = \mathbb{E}[\xi_{t-1}(X_{t-1}) | X_t = x_t] + (f_t(x_t) - f_t^{\mathcal{F}}(x_t)) + (f_t^{\mathcal{F}}(x_t) - f_t^{\star}(x_t)) + \frac{\partial \Phi_{t-1}}{\partial x}(\varphi_t(x_t))\left(\mathbb{E}[X_{t-1}|X_t=x_t] - \varphi_t(x_t)\right) + \text{高阶项}$$

学习率调度采用 Li et al. (2023) 的构造（Eq. (23)）：β_1 = 1/T^{c_0}，β_t = (c_1 log T / T) · min{β_1(1 + c_1 log T / T)^t, 1}。

## 3. 理论结果

**定理 1（主结果）**：设学习率按 Eq. (23) 选取，目标分布满足有界支撑条件 P(‖X_0‖_2 ≤ T^{c_R}) = 1（Eq. (22)）。在假设 1（Φ_{t→k} 为 L_f-Lipschitz，Eq. (19)）和假设 2（训练误差 ε 与函数类逼近误差 ε_F 分别由 Eq. (20a)–(20b) 控制）下，有（Eq. (24)）：

$$W_1(f_T(X_T), X_1) < C_1 \frac{L_f^3 d^{5/2} \log^5 T}{T} + \varepsilon + \varepsilon_F$$

其中 C_1 > 0 为普适常数，X_T ~ N(0, I_d)。

**推论**：要使 W_1(f_T(X_T), X_1) ≤ 2(ε + ε_F)，训练步数 T 超过 rO(L_f^3 d^{5/2}/(ε + ε_F)) 即可（Eq. (25)）。当函数类 F 容量足够大、ε_F = 0 时，所需步数约为 L_f^3 d^{5/2}/ε 的量级。

**假设细节**：假设 1 要求任意两时刻间的 flow map Φ_{t→k} 是 L_f-Lipschitz 的；假设 2 将训练误差分解为两部分——估计误差 ε（学到的 f_t 与函数类内最优 f_t^F 的差距）和逼近误差 ε_F（f_t^F 与条件期望最优解 f_t^⋆ 的差距）。作者明确说明，他们采用「分而治之」策略，将训练阶段与采样阶段解耦，只量化采样保真度，假设训练阶段的优化/估计误差较小（Sec. 3.1）。

**与已有扩散理论的关系**：作者指出，此前关于扩散模型 Wasserstein 收敛的结果常对 score 函数光滑性参数有指数依赖（如 Benton et al., 2023b; Tang & Zhao, 2024），源于 Grönwall 不等式的直接使用；本文结果不直接可比，因为光滑性假设施加在前向轨迹随机变量之间的映射上，而非 score 函数上（Sec. 3.2）。

## 5. 在 OT×扩散地图中的位置

本文属于课题 T10 中「一致性线（轨迹压缩）」的**理论层**工作，与 FMM（TMLR 2025）的理论统一框架直接相关：FMM 证明 CM/CTM/PD 的 Lagrangian/Eulerian 损失控制教师-学生 W2 距离，而本文给出的是**免教师、从零训练**的一致性训练在 W1 度量下的离散化步数下界。两者互补——FMM 处理蒸馏场景（有预训练教师），本文处理训练场景（无教师，直接学 flow map）。

在课题背景的 OT 视角三层结构中，本文落在 **(a) 理论层**：它不引入 OT 损失或 OT 耦合，而是用 Wasserstein 距离作为**评估度量**，刻画一致性训练步数与采样质量之间的定量关系。其核心对象 Φ_{t→k} 正是 PF-ODE 的两时间 flow map，与 FMM 的 Lagrangian 视角一致。

与课题背景中「开放问题 2」直接相关：该问题提出「更低曲率的耦合能否把 Li 等人的 O(d^{5/2}/ε) 离散化步数上界中的维度依赖降下来」。本文的 d^{5/2} 依赖来自对 flow map 导数与 score 函数二阶矩的逐项控制（Lemma 3–5），其中 d^{3/2} 来自 T1 项（Eq. (46)），d^{5/2} 来自 T2 项（Eq. (52)）。若用 OT 耦合替换独立高斯耦合（即 Eq. (14) 中 X_0 与 Z 的配对方式），可能改变 X_{t-1} 与 φ_t(X_t) 之间的条件期望结构，从而影响 T1 项的界——这是课题背景中提出的可操作切入点。

本文作者在 Sec. 5 明确提到分析框架「可能适用于其他生成与蒸馏模型，如 Salimans & Ho (2022) 的渐进蒸馏」，这指向 FMM 所统一的 Progressive Distillation 分支。

## 6. 局限与批评

**作者承认的局限**：
1. 维度依赖 d^{5/2} 与 Lipschitz 常数依赖 L_f^3 是否最优未知，能否建立匹配下界是开放问题（Sec. 5）。
2. 理论将训练阶段与采样阶段解耦，假设优化/估计误差 ε、ε_F 较小，未给出端到端（end-to-end）结果（Sec. 5）。
3. 目标分布的有界支撑假设（Eq. (22)）是简化处理，作者称可替换为尾部概率假设，但未给出具体形式（Sec. 3.1）。

**读出来的局限**：
1. 假设 1 要求所有两时间 flow map Φ_{t→k} 全局 L_f-Lipschitz，且最终界对 L_f 是三次依赖。对于真实数据分布，PF-ODE 的 flow map 在低密度区域可能不满足全局 Lipschitz 条件，该假设的验证本身是困难的。
2. 学习率调度（Eq. (23)）是专为证明设计的构造，β_1 = 1/T^{c_0} 意味着第一步几乎不加噪，与实践中一致性训练常用的调度（如 Song et al., 2023 的 EDM 风格调度）差异较大，理论界对实际调度的指导意义有限。
3. 定理只保证 W1 距离，未涉及 W2 或更细的分布差异度量；且界中 log^5 T 因子在 T 较大时不可忽略。

## 7. 对我们的启发

1. **维度依赖的改进空间**：本文 d^{5/2} 依赖的分解（T1 项 d^{3/2} + T2 项 d^{5/2}）为课题背景开放问题 2 提供了具体攻击点。若在 Eq. (14) 的训练目标中用 minibatch Sinkhorn 耦合替换 X_0 与 Z 的独立采样配对，T1 项中 E[X_{t-1}|X_t] − φ_t(X_t) 的条件期望结构会改变，可能降低 d^{3/2} 因子。可先在高斯混合模型上数值验证耦合方式对 T1 项经验界的影响。
2. **W1 作为一致性模型的评测协议补充**：课题背景开放问题 4 提出以教师样本云为参照的 sliced-W2/W2 指标。本文用 W1 度量 f_T(X_T) 与 X_1 的距离，提示在少步蒸馏评测中可同时报告 W1(teacher, student) 与 W2(teacher, student)，因为 W1 对分布尾部差异更敏感，可能暴露 FID 无法区分的「忠实蒸馏 vs 分布漂移」问题。
3. **flow map Lipschitz 常数作为蒸馏难度的先验指标**：本文界对 L_f 三次依赖，说明 flow map 的 Lipschitz 常数是少步蒸馏质量的关键瓶颈。可在实际蒸馏前，用教师 ODE 轨迹的有限差分估计 L_f，作为选择蒸馏步数或耦合策略的先验依据——这与课题背景中「PF-ODE 映射一般并非 OT 映射」的讨论衔接：选择更直的映射（更小 L_f）可能同时改善理论界与经验少步外推稳定性。
