# Spatial Transport Optimization by Repositioning Attention Map for Training-Free Text-to-Image Synthesis

> Woojung Han, Yeonkyung Lee, Chanyoung Kim et al. · CVPR 2025 · [arXiv](https://arxiv.org/abs/2503.22168) · 证据级 [P] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：STORM 用带空间代价的 OT 在早期去噪步重定位 cross-attention map，免训练纠正物体错位，同时改善缺失与属性错配。

## 1. 问题

本文处理 diffusion-based text-to-image（T2I）生成中的三类文本-图像对齐失败：missing objects（物体缺失）、mismatched attributes（属性错配）、mislocated objects（物体错位）。作者指出，前两类已有较多 training-free 方法处理（如 Attend-and-Excite [6]、Divide-and-Bind [23]、CONFORM [25]），但第三类「物体空间位置与文本提示不符」仍相对未被探索（Sec. 1）。

作者给出的关键观察是：Stable Diffusion（SD）对空间提示词不敏感——同一 seed 下仅改变位置关系词（"to the left of" / "to the right of" / "above" / "below"），SD 生成几乎相同的图像（Fig. 2）。现有解决错位的方法多依赖固定空间模板或预定义 layout（如 Layout Guidance [7]、ZestGuide [8]、Wu et al. [41]），这些方法需要额外输入（layout/segmentation），且只能固定物体在图像中的绝对位置（如「far-left corner」），无法表达「一个物体在另一个物体左侧」这类相对位置关系（Sec. 1）。本文目标是在不依赖模板、不增加额外输入、不改模型权重的条件下，让 T2I 模型按文本中的相对空间关系生成物体。

## 2. 方法

核心思想：把每个 text token 的 cross-attention map 视为一个概率分布，用 Optimal Transport（OT）在早期去噪步把这些分布「运输」到符合文本空间关系的位置。整个框架叫 STORM（Spatial Transport Optimization by Repositioning Attention Map），其优化模块叫 Spatial Transport Optimization（STO）。

**三种 attention map 角色**（Sec. 4.1）：
- source distribution：要移动的物体的 attention map（如 Fig. 4 中蓝色区域）；
- reference distribution：作为参照的另一个物体的 attention map（红色区域）；
- target distribution：source 应该去的位置，是一个基于 reference 质心 $(j_{\text{ref}}, i_{\text{ref}})$ 定义的任意分布，只用于引导方向，不施加直接强影响。

**ST Cost 函数**（Sec. 4.2.2，Eq. (2)–(3)）。对每个空间位置 $(i,j)$，定义四个方向的 $\delta$ 值：$\delta^{\leftarrow}_{ij}=j_{\text{ref}}-j$，$\delta^{\rightarrow}_{ij}=j-j_{\text{ref}}$，$\delta^{\uparrow}_{ij}=i_{\text{ref}}-i$，$\delta^{\downarrow}_{ij}=i-i_{\text{ref}}$。按文本指定的方向，把其中一个方向标记为 desired（$\delta^{\text{des}}$），相反方向标记为 restricted（$\delta^{\text{res}}$）。方向代价为：

$$\Delta_{ij}(\delta_{ij}^{\text{des}}, \delta_{ij}^{\text{res}}) = \frac{1}{\omega(\delta_{ij}^{\text{des}}+\epsilon)} \mathbbm{1}_{\subplus}[\delta_{ij}^{\text{des}}] + \omega(\delta_{ij}^{\text{res}}+\epsilon)\mathbbm{1}_{\subplus}[\delta_{ij}^{\text{res}}]$$

其中 $\omega(\cdot)>1$ 是随 timestep 变化的渐进自适应权重，$\epsilon$ 是稳定因子，$\mathbbm{1}_{\subplus}$ 是正部指示函数。最终 ST Cost 把 reference attention map $A_{ij}$ 直接嵌入，给 reference 占据的区域赋高代价以防止重叠：

$$C_{ij} = A_{ij}\,\Delta_{ij}(\delta_{ij}^{\text{des}}, \delta_{ij}^{\text{res}})$$

**Transport plan**（Sec. 4.2.3）：用 Sinkhorn 算法解熵正则 OT（Eq. (1)），对 source 和 target 分布的边际约束做双向迭代，得到 transport plan $P$。

**更新过程**（Sec. 4.4）：在每个 timestep 计算 OT loss $\mathcal{L}$，对 latent 做梯度更新 $z'_t \leftarrow z_t - \alpha_t \nabla_{z_t}\mathcal{L}$，再做 forward pass 得到 $z_{t-1}$。优化在指定 timestep 集合 $\{5,10,15,20\}$ 上迭代进行，$t=25$ 停止（Sec. 5 Implementation Details）。

**无空间提示的扩展**（Sec. 4.3）：(i) 物体级优化——文本无空间关系时随机放置 target distribution，cost 简化为 $C_{ij}=A_{ij}\otimes \mathbf{1}_N$，只防重叠；(ii) 属性匹配优化——物体与其属性的 attention map 应一致，用标准 OT cost（对应位置间 Euclidean distance）量化差异。

## 3. 理论结果

无理论结果。论文没有给出定理、引理或收敛性/最优性保证。OT 的使用是算法层面的：Sinkhorn 算法提供可微、可扩展的 transport plan 计算（Sec. 3），但作者没有证明 STO 的 transport plan 在何种意义下最优，也没有给出梯度更新收敛性的分析。

## 4. 实验与数字

**实现设置**（Sec. 5）：SD v1.4 和 v2.1，denoising timestep 50，guidance scale 7.5，Gaussian filter（kernel 3，std 0.5）平滑 cross-attention map，优化 timestep $\{5,10,15,20\}$，$t=25$ 停止，硬件 NVIDIA RTX A6000 Ada。

**VISOR 基准**（Table 1，SD 1.4 基座）：

| 方法 | OA (%) | VISOR uncond (%) | VISOR cond (%) | VISOR4 (%) |
|---|---|---|---|---|
| SD 1.4 | 29.86 | 18.81 | 62.98 | 1.63 |
| Attend-and-Excite | 42.07 | 25.75 | 61.21 | 0.08 |
| Divide-and-Bind† | 46.03 | 31.62 | 68.70 | 5.30 |
| INITNO† | 60.40 | 35.18 | 58.24 | 6.72 |
| CONFORM† | 60.73 | 38.48 | 62.33 | 9.52 |
| **Ours (SD 1.4)** | **61.01** | **57.58** | **94.39** | **25.70** |

SD 2.1 基座下：Ours OA 62.55，VISOR uncond 59.35，VISOR cond 94.88，VISOR4 25.42；对比 SPRIGHT（OA 60.68，VISOR4 16.15）和 REVISION（OA 48.26，VISOR4 19.53）。VISOR4 表示四个 seed 结果中四个都空间正确的比例（Table 1 注）。

**T2I-CompBench**（Table 2，SD 1.4 基座）：Attribute Binding Color 从 SD 的 0.3765 提升到 0.6458；Shape 从 0.3576 到 0.5983；Texture 从 0.4156 到 0.7539；Spatial 从 0.1246 到 0.1613。SD 2.1 基座下 Ours 四项分别为 0.6777 / 0.6226 / 0.7884 / 0.1981，对比 Attend-and-Excite 的 0.6400 / 0.4517 / 0.5963 / 0.1455。

**User study**（Table 3，30 名参与者，10 个 custom prompts）：Ours 在 Spatial Correctness 上 35.92%，对比 SD 11.81%、CONFORM 12.91%、INITNO 13.15%、Attend-and-Excite 13.20%、Divide-and-Bind 13.01%；Overall Fidelity 22.65%，对比 SD 15.02%、CONFORM 14.14%。

**Ablation：timestep 范围**（Table 4）：STO 从 19–24 开始（A1）OA 46.62、VISOR4 7.82；13–24（A2）OA 55.65、VISOR4 13.81；7–24（A3）OA 59.85、VISOR4 19.31；1–24（A4，即 Ours）OA 61.01、VISOR4 25.70。越早应用 STO，空间准确率越高。

**Ablation：cost 函数**（Table 5）：Manhattan（B0）OA 27.32；Euclidean（B1）OA 47.48；B0+B1（B2）OA 46.60；ST cost 去掉 overlap prevention（B3）OA 31.38、VISOR cond 88.53；完整 ST Cost（B4）OA 61.01、VISOR cond 94.39。overlap prevention 对 OA 关键，对 VISOR 影响小。

## 5. 在 OT×扩散地图中的位置

STORM 属于**线 B（attention 即 OT 的接口化）** 与**线 C（采样级 OT 耦合先验）** 的交汇点，具体是「采样期操控 attention 传输结构」这一 2025 年起的升级形态。它与 Sinkformer（softmax attention 是熵正则 OT 的单边化）共享「attention map 即分布」的视角，但 STORM 不替换归一化，而是在去噪过程中用 OT 的 transport plan 对 attention map 施加空间重定位的梯度引导。

在 OT×扩散地图中，STORM 的位置是：**把 OT 的代价函数设计从「外观相似度」转向「空间方向约束」**。判别式对应线（SCOT → GWOT-SC → Shape-of-You）的代价演化主线是纯外观 → 不平衡质量 → 关键点/掩码 → 几何结构（GW/FGW）→ 3D 先验；STORM 提供的是另一类代价先验：由文本空间关系词直接构造的方向性代价（desired/restricted direction + reference 占据区域惩罚）。这与 ASAG（对抗代价的 Sinkhorn 构造劣化 attention）形成互补——ASAG 用 OT 构造负样本，STORM 用 OT 构造正样本的空间约束。

STORM 的「早期去噪步最有效」发现（Table 4）与课题背景中提到的「早期步建立整体结构、后期步细化细节」的扩散动力学一致，为切入点 #2（OT-aware 采样调度）提供了具体证据：空间约束应在 $t$ 较大时施加，且 STORM 报告「先解决错位可自然解决缺失」（Fig. 8 底行），这给出了一个任务优先级排序的经验规律。

## 6. 局限与批评

**作者承认的**：
1. CLIP score 的可靠性受其「bag-of-words」特性限制（Sec. 5，引用 [43] 与 [6]），因此作者补充了 TIFA 和 user study，但 CLIP 指标本身仍是弱证据。
2. 方法针对 SD v1.4 / v2.1 的 UNet cross-attention 设计，使用 $16\times16$ attention map（Sec. 3），对 DiT 架构或其他分辨率层的适用性未讨论。

**读出来的**：
1. **VISOR cond 的基线不可比风险**：Table 1 中 Layout Guidance 和 REVISION 的 VISOR cond 高达 95.95% / 97.69%，高于 Ours 的 94.39%，但这两者需要额外 layout 输入（Extra Input ✓）。作者用「fair comparison」的加粗/下划线规则把 Ours 标为最好，但 cond 指标上 Ours 并非数值最高。这削弱了「surpasses existing methods」的绝对表述。
2. **ST Cost 的 $\omega(\cdot)$ 渐进权重未给出具体形式**：Eq. (2) 中 $\omega(\cdot)>1$ 是「progressive adaptive weight that controls the alignment importance across timesteps」，但正文没有给出 $\omega$ 的函数形式或消融，细节推到 Supplementary Materials（原文截断，未见）。这使方法的核心调度机制不可复现。
3. **target distribution 是「任意分布」**（Sec. 4.2.1），其构造细节同样推到 Supplementary Materials。target 的选择直接影响 transport plan 的边际约束，但正文未给出定义，读者无法判断结果对 target 选择的敏感性。
4. **VISOR4 绝对值仍然很低**：Ours 的 VISOR4 为 25.70%（SD 1.4），意味着四个 seed 全部空间正确的比例约四分之一。这提示方法在 seed 鲁棒性上仍有较大缺口，作者用「increase in VISOR4 demonstrates reliability」的表述偏乐观。

## 7. 对我们的启发

1. **可接切入点 #2（OT-aware 采样调度）**：STORM 的 Table 4 是「空间约束应在早期去噪步施加」的直接实验证据。可以把这一发现推广为通用的 OT 引导调度策略：在扩散采样中，将 OT 结构约束（空间、对应、质量守恒）集中在早期步，后期步释放给细节细化，并在 SDXL/DiT 架构上验证该调度是否跨架构成立。
2. **可接切入点 #1（免训练 batch 级保边缘噪声指派 MPNA）**：STORM 的「先解决错位可自然解决缺失」（Fig. 8 底行）提示任务之间存在优先级依赖。若把 MPNA 的 batch 级噪声指派与 STORM 式空间代价结合，可以在早期步同时约束「哪个噪声对应哪个物体」和「物体之间的相对位置」，可能同时降低 missing 和 mislocated 两类错误。
3. **代价函数设计的可迁移性**：STORM 的 ST Cost 本质是把文本空间关系词编译成方向性代价 + reference 占据惩罚。这个「文本关系 → 代价函数」的编译思路可以迁移到判别式对应线（线 A）：在 GWOT-SC / Shape-of-You 的代价中加入由文本或 3D 先验导出的方向约束，替代或补充手工几何项。但需注意 STORM 的 $\omega(\cdot)$ 和 target distribution 未公开细节，复现前需先补全这两处。
