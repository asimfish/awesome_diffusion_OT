# Flexible-length Text Infilling for Discrete Diffusion Models

> Andrew Zhang, Anushka Sivakumar, Chiawei Tang, et al. · EMNLP main 2025 · [arXiv](https://arxiv.org/abs/2506.13579) · 证据级 [P] · 课题 T22 离散数据与文本中的扩散/流与最优传输
> **一句话**：DDOT 用 sample-level OT 位置耦合让离散扩散同时去噪 token 值与位置，首次实现无 ground-truth 位置数据的灵活长度/位置文本填充。

## 1. 问题

离散扩散模型（如 SEDD）相比自回归模型有双向上下文、并行生成、灵活提示等优势，但存在一个关键限制：**token 位置在生成过程中固定**，无法改变 prompt token 之间的距离，因此没有 ground-truth 位置数据时无法做灵活长度或灵活位置的文本填充（Sec. 1）。此前方法（如 POINTER、CBART、AutoTemplate）要么依赖顺序 token 预测和多次前向传播，要么需要重新生成整个序列而非仅插入 token，浪费计算（Sec. 2.1）。本文要解决的是：给定任意位置的 prompt token（关键词），在保持其相对顺序的前提下，生成长度和位置均可变的填充文本。

## 2. 方法

DDOT 的核心思想是**同时扩散 token 值和 token 位置**，并用 sample-level OT 耦合保持相对顺序、缩小排列搜索空间。

**Token 值扩散**沿用 SEDD 的 masked diffusion 框架（Sec. 3, Eq. 1–2）。序列被划分为三个不相交子集：prompt（$x_p$，全程 clamp 到 ground-truth，仅作条件）、response（$x_r$，真实待填充 token，走 masked 前向过程）、pad（$x_{pad}$，占位符 [PAD]，维持固定长度 $L$）（Sec. 4.1）。

**位置扩散**：位置向量 $z_t \in \mathbb{R}^L$，终端噪声 $z_T \sim U(-1,1)^L$，ground-truth 位置为均匀间隔、缩放到真实长度的向量（Eq. 3）。位置路径为直线插值 $z_t = (1-t)z_0 + t z_T$（Eq. 4），pad 位置保持静止（Eq. 5）（Sec. 4.2）。

**Sample-level OT 耦合**（Sec. 4.3）是方法核心。在 prompt 集合和 response 集合内**分别**求解 OT 匹配：
- Prompt OT（balanced，Eq. 6）：$\ell_p$ 个 ground-truth prompt 位置与 $\ell_p$ 个采样位置做一一匹配，最小化总位移。1D 凸成本下等价于排序后按索引配对，$O(\ell_p \log \ell_p)$。
- Response OT（unbalanced，Eq. 7）：$\ell_r$ 个 response 位置注入到 $L-\ell_p$ 个非 prompt 位置池中，每个槽最多用一次，未分配槽成为 pad。用 Needleman-Wunsch 全局对齐动态规划求解，$O(\ell_r(L-\ell_p))$ 时间、$O(L-\ell_p)$ 内存。

OT 耦合保证集合内轨迹不交叉（$z_t^{S,(i)} \le z_t^{S,(j)}$ 对所有 $t$），即 prompt 和 response 各自保持相对顺序，但允许 prompt–response 之间的跨集合交叉，从而支持灵活填充（Sec. 4.3, 性质 a–c）。

**训练目标**（Sec. 4.4）：位置损失为 MSE，监督直线路径方向 $v_\theta(z_t, x_t, t) - (z_0 - \tilde z_T)$（Eq. 9）；token 损失为 SEDD score-entropy 目标 $L_{tok}$（Eq. 2）；总损失 $L = L_{tok} + \lambda L_{pos}$，$\lambda=10$（Eq. 10）。训练流程见 Algorithm 1。

**推理**：默认 DDOT-R 随机采样 $z_T$；DDOT-U 将终端位置放在均匀网格上（Eq. 11），避免随机聚类导致的 pad 溢出。采样时位置用 Euler 步更新，prompt 保持 clamp，pad 保持静止（Sec. 4.4）。

**实现**：在 SEDD 的 Diffusion Transformer 基础上加两个模块——可学习 type embedding（区分 prompt/response）和一个线性位置头（Sec. 4.6）。位置信息通过 Rotary Position Embeddings 注入，$z_t$ 从 $[-1,1]$ 缩放到上下文长度 1024。

## 3. 理论结果

无理论结果。论文未给出定理或引理；OT 匹配的最优性来自 1D 凸成本下排序配对和动态规划的标准结论（Sec. 4.3），但未形式化为命题。

## 4. 实验与数字

**数据集**：One-Billion-Word、Yelp（关键词到句子生成，1–6 个关键词）；CodeParrot 的 Python 子集。掩码方式包括 random masking 和 block masking（连续 span，长度 0 到 $L/2$，One-Billion-Word/Yelp 为 32，CodeParrot 为 512）（Sec. 5.1）。

**模型规模**：small（90M 非嵌入参数）和 medium（320M 非嵌入参数）；DDOT-medium 与 CBART（406M）和 AutoTemplate-base（220M）同量级（Sec. 5.1）。

**基线**：AR 模型（GBS、InstructGPT、AutoTemplate-small/base/large）；NAR 模型（SeqBF、CGMH、POINTER、CBART）；扩散基线 LC（Left Context，prompt 全部拼在左侧）和 PoP（Position Prediction，先预测位置再走固定位置 SEDD）（Sec. 5.1）。

**主结果（Table 2，block 数据集，0–32 prompt tokens）**：

| 模型 | OW-Block B2/B4 | OW-Block SR | Yelp-Block B2/B4 | Yelp-Block SR | CodeParrot-Block B2/B4 | CodeParrot-Block SR |
|---|---|---|---|---|---|---|
| LC | 55.1/47.9 | 54.7 | 59.1/51.7 | 60.3 | 51.0/49.4 | 16.9 |
| PoP | 59.2/50.0 | 58.6 | 64.9/48.6 | 67.1 | 29.4/13.3 | 0.34 |
| DDOT-R | 62.2/57.1 | 99.7 | 62.5/57.3 | 99.8 | 47.2/41.1 | 1.01 |
| DDOT-U | **63.7/58.4** | **100.** | **64.9/59.5** | **100.** | **53.7/51.0** | **10.8** |

DDOT-U 在 One-Billion-Word-Block 和 Yelp-Block 上所有指标均超过两个扩散基线；SR 从 LC/PoP 的 54.7–67.1 提升到 99.7–100（Table 2）。CodeParrot-Block 上 DDOT-U 的 SR 为 10.8，远高于 PoP 的 0.34，但仍低。

**短序列结果（Table 3，1–6 prompt tokens，random 数据集）**：DDOT-U 在 One-Billion-Word-Random 上 B2/B4 = 16.3/5.2，SR = 100；Yelp-Random 上 B2/B4 = 21.2/7.9，SR = 100。与 SOTA NAR 模型 CBART（OW-Random B2/B4 = 15.6/6.6，SR = 100）和 AutoTemplate-large（OW-Random B2/B4 = 18.9/8.1，SR = 100）相比，DDOT 在部分指标上落后，但 SR 达到 100（Table 3）。作者指出 random 设置过度依赖 1–6 个随机间隔 token 的不现实任务（Sec. 5.2）。

**OT 消融（Table 4，small 模型）**：去掉 OT 耦合后，One-Billion-Word 上 B2 从 15.7 降到 13.2，N2 从 3.2 降到 1.60；Yelp 上 B2 从 18.6 降到 16.39，N2 从 3.13 降到 2.05（Table 4）。

**采样步数（Table 5，One-Billion-Word）**：DDOT-U 在 2 步时 B2 = 59.4，64 步时 B2 = 63.7；LC 在 2 步时 B2 = 38.3，64 步时 55.1；PoP 在 2 步时 B2 = 45.4，64 步时 59.2。DDOT-U 在相同步数下 BLEU 均高于两个基线，且 wall-clock 时间（2 步 0.44 s/batch，64 步 12.0 s/batch）快于 LC（2 步 0.71，64 步 22.9）并与 PoP 相当（2 步 0.53，64 步 12.0）（Table 5）。

**效率**：OT 计算在 Intel Xeon 8462Y+ 64 核上处理 FineWeb-Edu 的 100 亿 token 子集耗时 16 分 11 秒；带缓存时 1000 训练步（batch 256，L40 GPU）耗时 4 分 30 秒，不带缓存 4 分 27 秒，差异可忽略（Sec. 5.3）。

## 5. 在 OT×扩散地图中的位置

DDOT 位于「离散扩散 × OT」的第三阶段，但切入点是**位置维度的 sample-level OT**，而非 token 值维度的 minibatch OT。它与以下工作形成关系：

- **继承 SEDD**（Lou et al., 2024）：token 值扩散完全沿用 SEDD 的 score-entropy 框架和 masked CTMC 前向过程（Sec. 3）。DDOT 是 SEDD 的架构扩展，不是替代。
- **继承连续域 OT 耦合思想**：明确引用 Tong et al. (2024) 的 minibatch OT coupling 术语，以及 Rectified Flow（Liu et al., 2023）和 Stochastic Interpolants（Albergo & Vanden-Eijnden, 2023）的直线路径思想（Sec. 2.3）。但 DDOT 的耦合是**序列内**（sample-level）的，作用于位置而非数据点之间的 minibatch 配对，粒度不同。
- **与 Haxholli et al. 的离散动态 OT 互补**：后者在 token 值状态空间上做源-目标分布的 minibatch OT 耦合以拉直路径；DDOT 在位置空间上做序列内 OT 以约束排列。两者解决的是离散扩散中不同维度的「传输成本」问题。
- **与 Edit Flows 的编辑距离几何形成对照**：Edit Flows 通过插入/删除/替换操作隐式采用编辑距离几何来处理变长序列；DDOT 通过固定长度 $L$ + pad 槽 + 位置扩散来处理变长填充，几何上是 $[-1,1]$ 上的 1D 位移成本。

在推理管线中，DDOT 对应「前向耦合设计」环节：它用 OT 约束前向位置路径，使反向去噪的监督信号更稳定。这不同于连续 FM 中用 OT 拉直 ODE 轨迹的动机——离散扩散路径本质随机，DDOT 的 OT 不拉直 token 值路径，而是**约束位置路径的排列空间**。

## 6. 局限与批评

**作者承认的**：
1. 扩散 backbone 仍落后于 AR backbone；DDOT 与 AutoTemplate 的差距同样存在（Limitations）。
2. 扩散模型无法使用 KV cache 存储历史激活，推理效率受限（Limitations）。

**读出来的**：
1. **CodeParrot 上 SR 极低**：DDOT-U 在 CodeParrot-Block 上 SR 仅 10.8，CodeParrot-Random 上 11.2（Table 2），说明方法在代码数据上几乎无法保持 prompt 顺序。作者未解释这一失败，也未讨论代码场景下位置扩散为何失效。
2. **短序列 benchmark 上并未全面超越**：Table 3 中 DDOT-U 在 One-Billion-Word-Random 的 B2/B4（16.3/5.2）低于 CBART（15.6/6.6 的 B4 更高）和 AutoTemplate-large（18.9/8.1），作者用「random 设置不现实」来解释，但这削弱了「on par with SOTA NAR」的表述力度。
3. **固定长度 $L$ 的上限约束**：DDOT 仍需要预设最大长度 $L$，填充长度通过 pad 槽的分配隐式决定，并非真正无界的变长生成。论文未讨论 $L$ 的选择对结果的影响。
4. **OT 耦合的 ground-truth 依赖**：训练时 response 的 ground-truth 位置 $z_0^r$ 是已知的（Eq. 3 需要真实长度 $\ell$），因此「无 ground-truth 位置数据」仅指推理时不需要，训练时仍需完整序列的位置信息。这与摘要中「without access to ground-truth positional data」的表述存在张力。

## 7. 对我们的启发

1. **位置 OT 耦合可迁移到其他离散扩散任务**：DDOT 的 prompt/response 分集 OT 匹配（Eq. 6–7）是一个轻量、$O(L)$ 内存的模块，可嵌入任何 masked diffusion 模型。可尝试将其用于代码补全、表格填充、多模态布局生成等需要灵活位置的任务，验证 SR 在非自然语言数据上的提升是否可复现。
2. **1D 排序配对是离散 OT 的免训练特例**：DDOT 利用 1D 凸成本下 OT 等价于排序配对，避免了 dense cost matrix。这提示在序列位置、时间步调度等 1D 结构上，OT 耦合可以以极低计算成本实现。可探索将同样的排序配对思想用于 token 值维度的 minibatch OT（Haxholli et al. 路线），用嵌入空间的 1D 投影近似语义成本。
3. **DDOT-U 的均匀网格初始化是「免训练保边缘」的简单实例**：均匀网格（Eq. 11）避免了随机采样的聚类问题，实质是对终端位置分布做了一种确定性规整。这与课题背景中「免训练 batch 级保边缘噪声指派」的思路相通——可进一步研究终端位置分布的最优设计（如低差异序列、按 prompt 密度自适应网格），以及它如何影响 pad 溢出率和 SR。
4. **SR 作为硬约束指标值得引入扩散 LM 评估**：DDOT 用 SR（prompt 相对顺序保持率）作为核心指标，直接度量 OT 耦合的排列保持效果。在评估其他离散扩散模型的顺序保持能力时，SR 比 BLEU 更直接地反映位置耦合的质量，可作为标准指标加入。
