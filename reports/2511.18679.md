# Neural Geometry Image-Based Representations with Optimal Transport (OT)

> Xiang Gao, Yuanpeng Liu, Xinmu Wang et al. · arXiv 2025 · [arXiv](https://arxiv.org/abs/2511.18679) · 证据级 [R] · 课题 T20 3D/点云/几何生成中的 OT 与流
> **一句话**：用 Ricci flow 共形参数化 + OT 面积校正构造保面积 geometry image，低分辨率 mipmap 经单趟 CNN 超分重建网格，CR=64 时 CD/HD 优于 NCS 等基线。

## 1. 问题

论文处理的是稠密 3D 表面网格的紧凑存储与高效重建。网格表示因几何精度、拓扑一致性和 GPU 渲染管线兼容性而在 VR/AR、游戏、CAD、医学影像、有限元分析等场景中不可替代（Sec. 1），但大规模 3D 数据集（如 Objaverse-XL）中动辄数百万顶点和三角形的网格带来显著存储开销，并阻碍实时渲染、流式传输与交互。

现有神经网格压缩方法（NGLOD、NCS、Neural Subdivision、NPM）采用 encoder–decoder 架构，把粗网格或隐式特征存为紧凑表示，再通过多个 decoder 网络逐级细化。作者指出这类方法有两个根本局限（Sec. 1）：第一，恢复稠密表面需要多次 decoder 前向传播，推理耗时；第二，LoD 通过逐级 decoder 阶段实现，每一级都要单独解码，实时 LoD 控制不现实。此外，这些方法学到的表示往往不是网格，下游渲染/仿真前还要转换回 mesh 格式，增加额外开销。

作者的关键观察是：geometry image 把不规则网格变成规则图像网格，从而可以直接套用图像超分/复原框架；但传统 geometry image 构造存在采样失衡——平坦区域过采样、特征丰富区域欠采样（Sec. 2.1），这阻碍了 mipmap 化 LoD 在 3D 表面网格上的直接推广。本文用 OT 解决这个采样失衡问题。

## 2. 方法

整体管线分三步（Fig. 3）：(1) 用 Optimal Mass Transport（OMT）构造保面积 geometry image；(2) 一个 geometry image 超分网络在单趟前向中把低分辨率 mipmap 输入（position map + normal map）上采样到全分辨率；(3) 重建后的 geometry image 做层级 mipmap，在 GPU 上实现连续 LoD。

**第一步：共形初始化。** 对 genus-zero 单边界网格，用离散 Ricci flow（[27]）做共形参数化。四个边界顶点固定到正方形四角，目标曲率赋为 $\pi/4$，其余为零。共形因子 $u$ 通过最小化 Ricci 能量得到：

$$E(u) = \int_{u_0}^{u} \sum_i (\bar{K}_i - K_i)\, du_i \tag{Eq.1}$$

其中 $K_i$、$\bar{K}_i$ 分别是当前和目标高斯曲率。用 Newton 法求解，梯度为 $(\bar{K}_i - K_i)^T$，Hessian 对角元为 $-\sum_j w_{ij}$，非对角元为 $w_{ij}$（Eq. 2）。共形映射保角但不保面积，导致平坦区域过采样、弯曲区域欠采样。

**第二步：OT 面积校正。** 目标是找测度保持映射 $T: \Omega \to P$，最小化

$$\int_{\Omega} \|x - T(x)\|^2 \mu(x)\, dx \tag{Eq.3}$$

由 Brenier 定理，解是凸势能 $u_h$ 的梯度，$h = (h_1, \dots, h_k)$ 为高度向量。对应变分能量为

$$E(h) = \int_{\Omega} u_h(x)\mu(x)\, dx - \sum_{i=1}^{k} \nu_i h_i \tag{Eq.4}$$

梯度与 Hessian 为

$$\nabla E(h) = (w_1(h) - \nu_1, \dots, w_k(h) - \nu_k)^T \tag{Eq.5}$$

$$\frac{\partial^2 E}{\partial h_i \partial h_j} = \begin{cases} \frac{1}{\|p_j - p_i\|} \int_{e_{ij}} \mu, & e_{ij} = W_i \cap W_j \cap \Omega \\ 0, & \text{otherwise} \end{cases} \tag{Eq.6}$$

$E(h)$ 严格凸，Newton 法收敛到唯一极小点 $h_0$，诱导的梯度映射 $\nabla u_{h_0}$ 给出最终保面积参数化。总映射写作 $\psi^{-1} \circ \phi$，$\phi$ 为共形初始化，$\psi$ 为 OT 校正。Algorithm 1 给出了完整的保面积参数化流程，包括 power diagram、power Delaunay 三角化、cell 面积计算，以及处理空 cell 的 line search 回退。

**第三步：神经超分网络。** 输入是一对低分辨率 mipmap geometry image（position image 与 normal image 做 cross-attention）。两条独立卷积分支分别处理 position 和 normal，cross-attention 把 normal 特征融合进 position 流；融合特征经 residual blocks 和 pixel shuffle 层逐级上采样，最后卷积输出高分辨率结果。另加一条从双线性上采样输入的 skip connection 保留低频信息（Sec. 4.2）。训练损失为 $\ell_1$ 与 MS-SSIM 的加权组合：

$$\mathcal{L}_{\text{recon}} = \eta_1 \mathcal{L}_{\ell_1} + \eta_2 \mathcal{L}_{\text{struct}} \tag{Eq.10}$$

其中 $\eta_1 = \eta_2 = 0.5$，Adam 优化器，学习率 $5 \times 10^{-5}$（Sec. 3.2.1）。geometry image 以 16-bit RGB PNG 存储 $(x, y, z)$ 坐标，分辨率 $1024 \times 1024$，边界像素用最近边界外推保证接缝连续性（Sec. 3.2.2）。

## 3. 理论结果

无独立的理论定理或引理。论文引用了 Brenier 定理（[2]）作为 OT 解的存在性与梯度映射形式的依据，并指出 $E(h)$ 严格凸从而 Newton 法收敛到唯一极小点（Sec. 3.1），但这是对已有变分 OT 理论（[18]）的直接应用，不是本文新证明的结果。

## 4. 实验与数字

数据集为 Thingi10k（[61]），评测指标为 Chamfer Distance（CD，$\times 10^{-4}$）、Hausdorff Distance（HD，$\times 10^{-2}$）和压缩比 CR（定义为存储图像大小与 $1024 \times 1024$ geometry image 之比，越大压缩越高，Sec. 4.1）。

**参数化方法对比（Table 1）：**

| 方法 | CD $\downarrow$ | HD $\downarrow$ | 保面积 | 保角 |
|---|---|---|---|---|
| Uniform [53] | 11.9534 | 19.8963 | ✗ | ✗ |
| Harmonic [11] | 12.1267 | 19.4869 | ✗ | ✗ |
| Ricci Flow [27] | 13.5256 | 20.5909 | ✗ | ✓ |
| Authalic [10] | 13.0667 | 20.2105 | ✗ | ✗（原文标 Mixed ✓） |
| Ours w/ OT | **1.5476** | **18.1094** | ✓ | ✗ |

OT 方法 CD 比次优的 Uniform 低约 8.7 倍（11.9534 vs 1.5476），HD 略优（18.1094 vs 19.4869）。

**与非网格神经表示对比（Table 2，CR=64）：**

| 方法 | 表示 | CD $\downarrow$ | HD $\downarrow$ | 单趟 | 多趟 | Decoder-Free LoD |
|---|---|---|---|---|---|---|
| ACORN [38] | Neural Octree SDF | 1.300 | 4.693 | ✗ | ✓ | ✗ |

| Ours | Neural Geometry Images | **0.059** | **1.482** | ✓ | ✗ | ✓ |

**消融：不同 mipmap 分辨率（Table 4）：**

| 存储分辨率 | CR | CD $\downarrow$ | HD $\downarrow$ |
|---|---|---|---|

## 5. 在 OT×扩散地图中的位置

本文属于「资产/表示线」中 UV/纹理参数化分支的延伸，与 Dominitz & Tannenbaum（2010）的保面积 OT 贴图一脉相承，但把「参数化畸变校正」重新包装为神经压缩与重建问题。它不涉及扩散模型或 flow matching，OT 的用法是**静态测度保持映射**（Brenier 势能 + power diagram），不是生成模型中的动态传输或耦合学习。

在课题地图中的位置：它对应「表示层面」——把非结构化网格参数规整成规则图像网格，与 GaussianCube 把无序 Gaussians 规整进 voxel 网格的思路同构，但规整对象是网格顶点而非 Gaussian 参数集。它不解决损失度量问题（CD/EMD 谱系），也不解决噪声-数据耦合问题（NSOT/WFM 线），而是为下游神经处理提供一个规范 UV 域。

与课题背景中「OT geometry image 上的潜空间扩散」切入点直接相关：本文的保面积 OT 参数化目前只用于压缩/LoD，尚未在 geometry image 上跑 latent diffusion 或 flow matching。本文的 uniform sampling 性质（消除极区过采样、平坦区欠采样）恰好是切入点的前提条件。

## 6. 局限与批评

**作者承认的（Sec. 4.7）：** 方法可能在网格边界处产生接缝，需要后处理消除，但后处理有额外成本。全文仅此一条明确局限。

**读出来的：**

1. **评测对象单一且规模不明。** 所有实验基于 Thingi10k，但论文未报告测试网格数量、类别分布或统计显著性。Table 2/3 的对比数字是单个实例还是均值，原文未说明；Fig. 6/7 的视觉对比各只展示一个模型。作为 [R] 预印本，结论的泛化性证据不足。

2. **Table 4 与 Table 2 的 CD 数值存在内部不一致。** Table 4 中 CR=64 时 CD=0.009，而 Table 2 中 Ours 在 CR=64 时 CD=0.059，相差约 6.5 倍。原文未解释这一差异，削弱了数字的可信度。

3. **OT 构造的适用范围受限。** 方法要求 genus-zero 单边界网格（Sec. 3.1 共形初始化），对高亏格或多边界网格需要切割成多个 chart，而论文未讨论多 chart 情况下的接缝处理与 OT 全局一致性。这限制了在真实 CAD/扫描网格上的直接适用性。

4. **与 NCS 的对比优势幅度小。** Table 2 中 Ours 的 CD=0.059 vs NCS 的 0.083，HD=1.482 vs 1.538，优势在 $10^{-4}$/ $10^{-2}$ 量级上都很小。作者声称的「state-of-the-art」在数值上成立，但实际视觉差异可能有限。

## 7. 对我们的启发

1. **把保面积 OT 参数化作为 3D 生成的规范 UV 域（接切入点 #5）。** 本文证明 OT 校正后的 geometry image 在 $1024 \times 1024$ 分辨率下 CD 低至 $1.5 \times 10^{-4}$ 量级（Table 1），且 uniform sampling 消除了平坦/特征区域的采样失衡。这为在 geometry image 上跑 latent diffusion/FM 提供了干净的输入域：均匀采样意味着扩散模型不需要处理极区过采样带来的密度偏置，OT 对齐的 UV 域也便于多视角纹理烘焙的接缝对齐。可操作的第一步：在 ShapeNet 子集上复现本文的 OMT 参数化，验证 UV 域上的点密度均匀性，然后训练一个 geometry image 的 latent diffusion 做无条件网格生成。

2. **「单趟重建 + mipmap LoD」的存储-精度 trade-off 曲线可作为 3D 生成模型输出的后处理压缩模块。** Table 4 给出了从 CR=4（CD=0.002）到 CR=1024（CD=0.264）的完整曲线，说明该方法可以在几乎无损（CR=4）到高压缩（CR=1024）之间连续调节。对于扩散模型生成的网格，可以先用本文方法参数化，再按目标存储预算选 mipmap 级别，避免重新训练生成模型。

3. **OT 面积校正与神经超分的解耦设计值得借鉴。** 本文把「几何规整」（OT 参数化，无学习）与「分辨率恢复」（CNN 超分，有学习）完全解耦，OT 部分保证测度保持的数学性质，网络部分只做图像域超分。这种解耦避免了端到端训练中 OT 求解不可微或数值不稳定的问题。对于我们的 OT×扩散课题，类似的思路是：用离线 OT 预计算耦合（如 NSOT 的 superset 预计算），训练时只继承配对，不把 OT 求解器放进计算图。
