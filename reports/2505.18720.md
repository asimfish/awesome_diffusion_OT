# Optimal Transport-Based Token Weighting scheme for Enhanced Preference Optimization

> Meng Li, Guangda Huzhang, Haibo Zhang, et al. · ACL main 2025 · [arXiv](https://arxiv.org/abs/2505.18720) · 证据级 [P] · 课题 T22 离散数据与文本中的扩散/流与最优传输
> **一句话**：用 unbalanced OT 在 chosen/rejected 回复间算语义对齐权重，重加权 DPO 的 token 级损失，统一 SimPO/SamPO 等为特例

## 1. 问题

DPO 的 reward difference $\Delta r$ 在 token 级分解后，每个 token 的 log-likelihood ratio 以权重 1 等权贡献（Eq. 4）。作者指出这导致「不相关或噪声 token 不成比例地影响 DPO 损失」（Abstract），模型可能学到捷径而非真正遵循指令。图 1 给出示例：与问题无关的 token 主导了 reward，而「Cat likes to eat fish」这类关键内容未被强调。

已有方法（SimPO、SamPO、LDDPO）只处理 chosen 与 rejected 回复因长度不同导致的总 token 权重不平衡（length bias），采用启发式权重方案缩小总权重差 $\delta = \sum_i \omega_i^c - \sum_j \omega_j^r$（Sec. 2.2）。作者认为这些方法「无法区分与指令遵循相关的重要 token，因为缺乏监督信号」（Sec. 1）。APO 尝试用外部 LLM 改写无关部分以构造最小对比对，但「严重依赖外部 reviser」（Sec. 1）。本文要解决的问题是：在无额外监督信号的前提下，为 DPO 的 token 级损失设计一个能识别语义重要 token 的加权方案。

## 2. 方法

核心思想：chosen 与 rejected 回复中语义相似、结构角色相近的 token 对更可能携带与问题相关的共享信息（类似多数投票原理，Sec. 2.3），应被赋予更高权重；语义不相关的 token 对降权。用 unbalanced optimal transport 在 chosen 与 rejected 的 token 分布之间求最优传输计划，以传输计划的行/列边际作为 token 权重。

关键公式：

**Token 级加权分解**（Eq. 5）：
$$\Delta r = \sum_{i=1}^{|y_c|} \omega_i^c q_i^c - \sum_{j=1}^{|y_r|} \omega_j^r q_j^r$$
其中 $q_i^* = \log \frac{\pi_\theta(y_i^*|x, y_{<i}^*)}{\pi_{ref}(y_i^*|x, y_{<i}^*)}$。DPO 是 $\omega_i = 1$ 的特例；SimPO 取 $\omega_i = 1/|y|$；SamPO 对较长回复随机下采样；LDDPO 对超出 $m = \min(|y_c|, |y_r|)$ 的部分赋权重 $\alpha \in [0,1]$（Tab. 1）。

**Pair 级分解**（Eq. 6–7）：
$$\Delta r = \sum_i \sum_j \Gamma_{i,j}(q_i^c - q_j^r), \quad \omega_i^c = \sum_j \Gamma_{i,j}, \quad \omega_j^r = \sum_i \Gamma_{i,j}$$

**Unbalanced OT 目标**（Eq. 9）：
$$\Gamma^* = \arg\min_\Gamma \sum_{i,j} \Gamma_{i,j} M_{i,j} + \epsilon_1 \Omega(\Gamma) + \epsilon_2 \left( \text{KL}(\Gamma \mathbf{1}, \mathbf{1}_{|y_c|}) + \text{KL}(\Gamma^T \mathbf{1}, \mathbf{1}_{|y_r|}) \right)$$
其中 $M_{ij} = \|h_i^c - h_j^r\|_2$，$h_t^*$ 是模型最后一层 hidden state（Sec. 2.3）；$\Omega(\Gamma) = \sum_{i,j} \Gamma_{i,j} \log \Gamma_{i,j}$ 是熵正则项；两个 KL 项让边际分布接近 DPO 的均匀权重，允许受控偏离。作者明确说明标准 OT 假设两边总质量相等，与 chosen/rejected 长度不等的设置不兼容，因此采用 unbalanced OT（Sec. 2.3）。

**权重归一化**（Eq. 10）：
$$\omega_c^* = \frac{\Gamma \mathbf{1}}{|\Gamma|} \tau, \quad \omega_r^* = \frac{\Gamma^T \mathbf{1}}{|\Gamma|} \tau$$
其中 $\tau = \min(|y_c|, |y_r|)$，$|\Gamma|$ 是传输计划总权重。最终损失为 $L = -\mathbb{E}_{(x,y_c,y_r)\sim D}[\log \sigma(\beta \Delta\hat{r})]$（Eq. 12），$\Delta\hat{r}$ 用 $\omega_c^*, \omega_r^*$ 加权（Eq. 11）。

训练流程：从模型最后一层提取 chosen/rejected 每个 token 的 hidden state → 构造欧氏距离成本矩阵 $M$ → 解 Eq. 9 的 unbalanced OT 问题 → 按 Eq. 10 归一化得到 token 权重 → 代入 Eq. 11–12 计算加权 DPO 损失。

## 4. 实验与数字

**主实验设置**（Sec. 3）：Llama-3-8B-Instruct 与 Llama-3.2-3B-Instruct 在 UltraFeedback 和 HelpSteer2 上做 on-policy 优化；Qwen-2.5-3B 在 TL;DR 上做 offline 摘要。评估用 AlpacaEval2（805 题，GPT-4-Turbo 判分），报告 win rate、length-controlled win rate、平均长度。

**AlpacaEval2 主结果**（Tab. 2）：

| 设置 | 指标 | DPO | 最佳基线 | OTPO |
|---|---|---|---|---|
| Llama-3-8B + UltraFeedback | LC WR (%) | 48.14 | 52.17 (SamPO) | **53.37** |
| Llama-3-8B + HelpSteer2 | LC WR (%) | 27.91 | 28.55 (LDDPO) | **29.64** |
| Llama-3.2-3B + UltraFeedback | LC WR (%) | 26.02 | 26.56 (LDDPO) | **26.97** |
| Llama-3.2-3B + HelpSteer2 | LC WR (%) | 19.99 | 20.29 (LDDPO) | **20.50** |

作者报告：OTPO 在 4 个设置中的 length-controlled win rate 全部最高，相对 DPO 提升 2.6% 到 10.9%，相对其他基线提升 1.0% 到 3.8%（Sec. 4.1）。win rate 在 4 个设置中的 3 个最高，相对最佳基线最多提升 3.5%。OTPO 在 Llama-3-8B + UltraFeedback 的 naive win rate 为 47.58%，低于 DPO 的 51.52%，但平均长度从 2168 降到 1791 tokens；作者将此归因于 LLM judge 偏好冗长回复的偏差（Sec. 4.1，引用 Zheng et al., 2023）。

**摘要任务**（Fig. 4）：TL;DR 上 OTPO win rate 为 71.9%，最佳基线 SamPO 为 63.3%，DPO 为 54.7%，SimPO 为 55.5%，LDDPO 为 44.4%。OTPO 相对最佳基线 SamPO 高出 8.6 个百分点（Sec. 4.1）。

**消融**（Tab. 3，Llama-3-8B + UltraFeedback）：
- 用 uniform 权重替换 OT：LC WR 52.60，WR 46.36，长度 1796；OTPO 为 53.37 / 47.58 / 1791。
- 用 cosine similarity 权重替换 OT：LC WR 53.28，WR 46.09，长度 1757。
- 归一化消融：无归一化 LC WR 26.38（「不到最佳 LC WR 的一半」，Sec. 4.2.2）；mean 归一化 52.79；max 归一化 49.85；按各自长度归一化（Length）48.51。

**人类评估**（Tab. 4）：50 题，Llama-3-8B-Instruct + UltraFeedback。Expert 1 给 OTPO win rate 0.62（DPO 0.46，SimPO 0.56，SamPO 0.48，LDDPO 0.56）；Expert 2 给 OTPO 0.64（DPO 0.50，SimPO 0.54，SamPO 0.46，LDDPO 0.48）。两位专家标注相关性为 0.37（Sec. 4.3）。

**效率**（Sec. 5）：OT 步骤时间复杂度 $O(n^2)$，对比 transformer 前向的 $O(ln^2d + lnd^2)$；内存 $O(l^2)$，对比 transformer 的 $O(l(n^2 + nd^2))$。作者称「可忽略」「minor」。训练时间（Fig. 6）：OTPO 单次运行时间略高于 DPO，但总时间（含超参调优）低于 SimPO，因为 SimPO 对 $\beta, \gamma$ 敏感需要大量调优。

## 5. 在 OT×扩散地图中的位置

本文属于 T22 中「OT 作为序列/文本分布对齐工具」的支线，但**不涉及扩散或流生成模型**。它把 unbalanced OT 用作 chosen/rejected 两个 token 序列之间的软对齐模块，输出 token 级重要性权重，再注入 DPO 损失。与课题地图的关系：

- **继承**：直接继承 DPO 谱系（Rafailov et al., 2024b）的 reward reparameterization，以及 SimPO/SamPO/LDDPO 的 token 加权思路。OT 工具层面继承 WGAN（Arjovsky et al., 2017）的欧氏成本矩阵构造与熵正则 OT 传统。
- **与 AOT 的关系**：AOT（Melnyk et al., 2024）用 OT 在 unpaired preference 数据上做分布支配，本文在 paired 数据的 token 级做对齐，两者是 OT 在偏好优化中的不同粒度应用（Sec. 6 提及 AOT 为「distributional dominance」路线）。
- **对课题的启示**：本文的 unbalanced OT 边际松弛（Eq. 9 的 KL 项）与课题开放问题 #3「Edit Flows × unbalanced OT」共享同一数学工具——插入/删除对应质量创生/湮灭，而本文的 KL 边际松弛正是 unbalanced OT 的标准形式。但本文的 ground cost 是 hidden state 欧氏距离，不是编辑距离；若把成本换成 Levenshtein 距离，可把「语义对齐」换成「编辑对齐」，直接对接 Edit Flows 的序列空间 CTMC。
- **理论张力**：本文没有触及离散动态 OT 或传输成本下界，只是把 OT 当作可微的软匹配层。它对应课题地图中「OT 作为统一语言」的应用侧，而非「重新定义离散动态 OT」的理论侧。

## 6. 局限与批评

**作者承认的**（Limitations 节）：
1. 只做了 off-policy 和单轮 on-policy 设置，未探索 iterative on-policy，后者「可能带来更大的指令遵循提升」。
2. 模型规模较小（3B–8B），「可扩展性与泛化性到数百亿参数模型仍有待验证」。
3. 评估依赖 GPT-4 判分，可能引入偏差。
4. 训练数据主要为英文，未验证非英语数据上的效果。

**读出来的**：
1. **成本矩阵的语义有效性未独立验证**。$M_{ij} = \|h_i^c - h_j^r\|_2$ 用的是「模型最后一层 hidden state」（Sec. 2.3），但该 hidden state 来自正在被优化的策略模型 $\pi_\theta$，训练过程中会变化。作者没有讨论权重随训练动态变化的稳定性，也没有对比冻结的 reference model 表示或外部 embedding。消融中的 cosine similarity 版本（Tab. 3）与 OTPO 差距很小（LC WR 53.28 vs 53.37），说明 OT 的精细 pair 对齐相对简化相似度方案的增益有限。
2. **「共享 token 更重要」的假设在 chosen/rejected 语义分歧大时可能失效**。作者以 on-policy 设置下同一策略生成回复、共享部分更可能相关为理由（Sec. 2.3），但 HelpSteer2 和 UltraFeedback 的 chosen/rejected 是 ArmoRM 打分后选出的最高/最低分回复，两者可能系统性不同（如一个拒绝回答、一个正常回答），此时「共享 token」未必是正确答案的关键部分。
3. **$\tau = \min(|y_c|, |y_r|)$ 的选择缺乏原则性论证**。作者说这是「大多数时候足以包含更简洁的相关信息表示」（Sec. 2.3），但消融显示 mean/max/length 归一化都更差（Tab. 3），min 的选择更像经验调参而非理论推导。梯度范数图（Fig. 5）只展示了波动趋势，没有量化指标。

## 7. 对我们的启发

1. **把 unbalanced OT 的边际松弛换成编辑距离成本，对接 Edit Flows**。本文 Eq. 9 的框架已经具备 unbalanced OT 的完整形式（熵正则 + KL 边际松弛），只需把 $M_{ij} = \|h_i^c - h_j^r\|_2$ 换成 token 级 Levenshtein 成本或状态相异度，就能得到「编辑距离成本下的离散 OT 软对齐」。这直接对应课题开放问题 #3：在 Edit Flows 的插入/删除/替换 CTMC 中，用该耦合替换辅助对齐采样，可检验训练方差是否降低、期望编辑次数是否逼近编辑距离下界。本文的代码框架（POT 求解 + 权重注入）可复用。
2. **OT 权重作为「免训练 batch 级噪声指派」的现成模块**。本文证明在偏好优化中，OT 传输计划的边际可以稳定地作为 token 重要性权重，且无归一化时梯度范数剧烈波动（Fig. 5）。这提示：在扩散 LM 的 batch 级 minibatch-OT 耦合中，传输计划的行/列边际同样可以作为「哪些 token 位置更该被对齐」的软掩码，无需额外训练。可尝试把 OTPO 的权重注入 masked diffusion 的加权交叉熵损失，验证困惑度-采样步数前沿是否改善。
3. **成本矩阵的动态性是一个可操作的消融维度**。本文用正在优化的 $\pi_\theta$ 的 hidden state 构造成本，但没有对比冻结表示。在扩散/流模型的 OT 蒸馏场景中，教师与学生的表示空间不同（跨 tokenizer 蒸馏尤其如此），成本矩阵应该用哪一方的表示、是否随训练更新，是直接影响耦合质量的关键选择。可设计实验：固定教师表示 vs 固定学生表示 vs 联合更新，观察 few-step 生成质量与训练稳定性的差异。
