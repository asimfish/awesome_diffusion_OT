# Bridge-SR: Schrödinger Bridge for Efficient SR

> Chang Li, Zehua Chen, Fan Bao, Jun Zhu · ICASSP 2025 · [arXiv](https://arxiv.org/abs/2501.07897) · 证据级 [P] · 课题 T23 语音与音频中的流匹配与 Schrödinger 桥
> **一句话**：波形域 any-to-48kHz 语音超分，低分辨率波形作先验的可解 SB，1.7M 参数 4 步胜过 8 步条件扩散。

## 1. 问题

语音超分（speech SR）要从低采样率波形重建高采样率波形。已有方法分布在时域、时频域和压缩空间：时频域方法依赖 STFT 等信号处理变换，压缩空间方法需要额外的压缩网络，可能引入级联误差（Sec. I）；时域方法中，基于扩散模型的 NU-Wave、NU-Wave2、UDM+ 取得了较好质量，但它们走的是「噪声到数据」的采样轨迹——从无信息的高斯噪声出发生成高分辨率波形，既没有直接利用低分辨率观测中已有的强先验信息，采样效率也受限（Sec. I）。

作者的核心判断是：低分辨率波形本身对高分辨率目标具有内在信息量，把它当作先验端、把高分辨率波形当作数据端，用可解 Schrödinger Bridge（SB）建立「数据到数据」的生成过程，可以同时改善合成质量与推理速度（Abstract, Sec. I）。

## 2. 方法

**可解 SB 框架。** 训练时，低分辨率波形 $x_{LR}$ 由高分辨率波形 $x_{HR}$ 经过随机选择设置的信号处理滤波器（低通滤波）得到。前向 SDE 定义在 $x_0 = x_{HR} \sim p_{prior}$ 与 $x_T = x_{LR} \sim p_{data}$ 之间：

$$dx_t = f(x_t, t)\,dt + g(t)\,dw_t \tag{1}$$

SB 问题在边界约束下最小化路径测度与参考路径测度的 KL 散度（Eq. 2）。在 Gaussian smoothing 假设下（$p_0 = \mathcal{N}(x_{HR}, \epsilon_0^2 I)$，$p_T = \mathcal{N}(x_{LR}, \epsilon_T^2 I)$，$\epsilon_0 \to 0$），有闭式解，边际分布为：

$$p_t = \Psi_t \hat\Psi_t = \mathcal{N}\left(\frac{\alpha_t \bar\sigma_t^2}{\sigma_1^2} x_0 + \frac{\bar\alpha_t \sigma_t^2}{\sigma_1^2} x_T,\; \frac{\alpha_t^2 \bar\sigma_t^2 \sigma_t^2}{\sigma_1^2} I\right) \tag{6}$$

训练时直接从 $p_t$ 采样 $x_t$，用网络预测 $x_0$：

$$\mathcal{L}_{bridge} = \mathbb{E}_{x_T \sim p_{prior},\, x_0 \sim p_{data},\, t}\left[\|x_\theta(x_t, t, x_T) - x_0\|_2^2\right] \tag{7}$$

**噪声调度。** 作者比较了 Bridge-TTS 提出的 Bridge-VP、Bridge-SVP、Bridge-gmax、Bridge-gconst 四种调度。Bridge-gmax 与 Bridge-gconst 无线性漂移（$f(t)=0$），因此 $\alpha(t)=1$，数据插值系数恒为 1，意味着低频分量在整个 SDE 轨迹中保持不变（Sec. II-B, Fig. 2）；而 Bridge-VP / Bridge-SVP 在轨迹中不保持低频一致性。两者都采用线性 $g^2(t) = (1-t)\beta_0 + t\beta_1$；Bridge-gconst 对称（$\beta_0 = \beta_1$，峰值在 $t_p/T = 1/2$），Bridge-gmax 非对称（$\beta_0 \to 0$，$t_p/T \approx 1/\sqrt{2}$），后者把更多采样步分配给高频信息生成，在 SR 任务上优于 gconst（Sec. II-B）。

**数据缩放。** 高频分量能量低，直接预测 $x_0$ 导致训练损失值过小、优化困难。作者对 $x_0$ 和 $x_T$ 同时施加缩放因子 $s = 1/\sqrt{\mathrm{Var}(x_{LR} - x_{HR})}$，把低分辨率与高分辨率波形之间的方差控制为 1（Sec. II-B）。实验中 $s = 12$（Sec. III-A）。

**辅助损失。** 在 bridge loss 训练后，增加一个独立微调阶段，优化每个时间步估计 $\hat x_0 = x_\theta(x_t, t, x_T)$ 与 $x_0$ 之间的感知加权多尺度 STFT 幅度损失 $\mathcal{L}_{mag}$（遵循 [32]）与多尺度 anti-wrapping 相位损失 $\mathcal{L}_{phase}$（遵循 [33]）：

$$\mathcal{L}_{aux} = \lambda_{mag}\sum_{r=1}^{M}\mathcal{L}^{(r)}_{mag}(\hat x_0, x_0) + \lambda_{phase}\sum_{r=1}^{M}\mathcal{L}^{(r)}_{phase}(\hat x_0, x_0) \tag{8}$$

最终微调损失为 $\mathcal{L}_{final} = \mathcal{L}_{bridge} + \mathcal{L}_{aux}$（Sec. II-C）。

**训练与采样配置。** 训练 1M 步仅用 bridge loss，再微调 70,000 步加入辅助损失；窗口长度 32768（48kHz 下 0.682 秒），batch size 16，学习率 $5\times10^{-5}$；噪声调度 $g^2_{min} = 8\times10^{-7}$，$g^2_{max} = 8\times10^{-2}$；辅助损失权重 $\lambda_{mag} = 4\times10^{-6}$，$\lambda_{phase} = 5\times10^{-6}$（Sec. III-A）。50 步与 8 步采样用一阶 PF-ODE 采样器、线性推理调度（$t_{min}=10^{-5}$ 到 $t_{max}=1$）；4 步用二阶 SDE 采样器，$t \in \{8\times10^{-2}, 5\times10^{-1}, 1\}$；2 步与 1 步用一阶 PF-ODE，$t \in \{3\times10^{-2}, 9\times10^{-1}, 1\}$ 与 $t \in \{4\times10^{-2}, 1\}$（Sec. III-C）。采样器来自 Bridge-TTS [22]。

## 3. 理论结果

无理论结果。本文直接采用 Bridge-TTS [22] 中 Gaussian smoothing 假设下的可解 SB 闭式解（Eq. 5–6），未提出新的定理或保证。

## 4. 实验与数字

**数据集与基线。** VCTK 基准数据集，108 位英语说话人约 400 句，48kHz 录音（Sec. III-A）。训练时低分辨率输入从 6kHz 到 48kHz 均匀采样，实现 any-to-48kHz（Sec. III-A）。基线：AudioSR、NVSR、mdctGAN、NU-Wave2、UDM+（Sec. III-B）。评价指标：全频带 LSD、低频带 LSD-LF、高频带 LSD-HF（均 ↓ 越好）、SI-SNR（↑ 越好）（Sec. III-B）。

## 5. 在 OT×扩散地图中的位置

本文是 Bridge-TTS [22]（arXiv:2312.03491）在语音超分任务上的直接迁移：沿用其可解 SB 闭式解、bridge loss、噪声调度族（Bridge-VP/SVP/gmax/gconst）与采样器，把「文本编码器输出 → mel」的配对桥换成「低分辨率波形 → 高分辨率波形」的配对桥。与 NVIDIA SB-SE 系列（arXiv:2407.16074，语音增强）同属「配对边界可解 SB 在语音修复任务」的扩展线，但任务从去噪/去混响切换到带宽扩展。在推理管线环节上，它对应「条件→数据」甚至「数据→数据」的先验错配问题：用观测端结构信息替代高斯噪声作为桥的起点，从而在少步采样区间获得比条件扩散更优的质量-步数权衡。与 UDM+（无条件扩散 + 推理期低频约束注入）形成对照：UDM+ 在推理时注入约束，Bridge-SR 在训练时就把低分辨率波形作为边界分布。

## 6. 局限与批评

作者承认的局限：无明确「limitations」小节。从实验设置可读出：训练与评估仅在 VCTK 单数据集上进行，未见跨数据集或跨说话人泛化测试（Sec. III-A）；any-to-48kHz 的训练范围是 6–48kHz，低于 6kHz 的输入未见覆盖（Sec. III-A）。

读出来的局限：其一，24kHz 输入下 SI-SNR 未超过 NU-Wave2（29.17 vs 30.21，Table I），说明在高输入采样率、低分辨率与高分辨率差异较小的场景，数据到数据桥的波形级信噪比优势不成立；其二，1 步采样质量明显退化（LSD 1.029，Table II），少步区间（1–2 步）仍不实用；其三，缩放因子 $s=12$ 是固定值，未报告其对不同输入采样率的敏感性；其四，辅助损失微调阶段（70,000 步）与主训练（1M 步）分离，增加了训练流程复杂度，且未报告仅用辅助损失从头训练的结果。

## 7. 对我们的启发

1. **噪声调度选择可作为任务相关的先验信息分配机制。** Bridge-gmax 的非对称调度（$\beta_0 \to 0$，$t_p/T \approx 1/\sqrt{2}$）把更多采样步分配给高频生成，在 SR 上优于对称 gconst；这提示在 OT×扩散知识库中，可以把「噪声调度的峰值位置」形式化为「轨迹曲率/信息密度分布」的函数，与课题切入点 #2（OT-aware 采样调度）直接对接——在语音增强、带宽扩展等任务上，先验端与数据端的频谱差异结构可能预测最优 $t_p$。

2. **数据缩放是波形域桥模型的关键工程细节。** 高频分量能量低导致 bridge loss 数值过小、优化失效，缩放因子 $s = 1/\sqrt{\mathrm{Var}(x_{LR}-x_{HR})}$ 把两端差异方差归一化到 1，消融显示去掉缩放后 SI-SNR 从 25.04 掉到 22.18（Table II）。这提示在波形域做任何数据到数据生成（SB 或 FM）时，应先检查边界分布差异的方差尺度；可推广为按频带加权的缩放策略。

3. **少步采样器与推理时间步选择值得系统化。** 作者在 4 步用二阶 SDE 采样器、时间步 $\{8\times10^{-2}, 5\times10^{-1}, 1\}$，2 步与 1 步用一阶 PF-ODE 且时间步靠后（$\{3\times10^{-2}, 9\times10^{-1}, 1\}$ 与 $\{4\times10^{-2}, 1\}$），这些选择来自 grid search（Sec. III-C）。这为课题切入点 #2 提供了一个具体实验对象：把 grid search 替换为基于轨迹曲率或 kinetic optimal path 的时间步分配，在 Bridge-SR 的 4 步设置上验证免重训调度是否匹配或超过手工调度。
