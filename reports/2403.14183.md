# OTSeg: Multi-prompt Sinkhorn Attention for Zero-Shot Semantic Segmentation

> Kwanyoung Kim, Yujin Oh, Jong Chul Ye · ECCV 2024 · [arXiv](https://arxiv.org/abs/2403.14183) · 证据级 [P] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：用 Sinkhorn 替换跨注意力归一化，让多个文本 prompt 各自对齐不同像素语义，ZS3 三基准 SOTA。

## 1. 问题

零样本语义分割（ZS3）利用 CLIP 的预训练图文知识做像素级分类，但 CLIP 是图像-文本对对比学习训练的，其知识并未针对像素级稠密对齐优化。直接微调 CLIP 做像素预测时，多个文本 prompt 与图像像素之间是「被动对齐」：所有 prompt 驱动的像素预测彼此趋同（cohered），没有发挥多 prompt 各自捕捉不同语义特征的潜力（Fig. 1(a)）。

此前方法要么用单 prompt 或简单 prompt ensemble，要么用正交约束（如 MVP-SEG+ 的 OCL）强制 prompt 差异化，但都缺乏一个全局匹配机制来约束「哪个 prompt 对应哪些像素」。Sinkformer 在单模态 self-attention 中把 SoftMax 换成 Sinkhorn 得到双随机注意力，但只限于单模态（M 像素 → M 像素），没有覆盖多模态的 cross-attention（M 像素 → N 文本 prompt）场景。

## 2. 方法

核心思想：把 cross-attention 的 SoftMax 归一化替换为熵正则最优传输的 Sinkhorn 算子，使多个文本 prompt 与像素之间的匹配成为带边际约束的全局耦合，而非逐 query 独立的局部贪心匹配。

**MPS（Multi-Prompts Sinkhorn）**：给定像素嵌入 $h_{img} \in \mathbb{R}^{M \times D}$ 与文本嵌入 $\tilde{h}_{txt} \in \mathbb{R}^{KN \times D}$（K 个类别名 × N 个 prompt），先算余弦相似度得分图 $S = \tilde{h}_{txt} h_{img}^{\top}$（Eq. 8），再以 $C := 1 - S$ 为代价矩阵求熵正则 OT 计划：

$$T^* = \text{diag}(a^t)\exp(-C/\epsilon)\text{diag}(b^t) \quad \text{(Eq. 4)}$$

边际约束为均匀分布 $\mu = 1_M/M$、$\nu = 1_N/N$（Algorithm 1）。精炼得分图为 $S^* = \mathcal{M}(T^* \odot S)$，其中 $\mathcal{M}$ 把 $RHW \times KN$ 重塑为 $RHW \times K \times N$ 后沿 N 维求和（Eq. 9-10）。MPS 只含矩阵乘法和指数运算，全程可微。

**MPSA（Multi-Prompts Sinkhorn Attention）**：将 MPS 嵌入 Transformer 解码器的 cross-attention 位置，替换 SoftMax：

$$\text{MPSA}(Q, K, V) = \text{MPS}(QK^{\top})V \quad \text{(Eq. 13)}$$

其中 $Q \in \mathbb{R}^{KN \times D}$ 来自文本嵌入，$K, V \in \mathbb{R}^{M \times D}$ 来自像素嵌入。解码器由三层 cross-attention Transformer 组成，每层的 multi-head attention 被 MPSA 替换。语义 mask 由中间层 MPS 输出经 Sigmoid 得到（Eq. 14），再上采样到原图分辨率（Eq. 15）。

**推理集成**：最终输出 $Y^* = \lambda Y + (1-\lambda)\tilde{Y}$（Eq. 17），其中 $Y$ 是解码器输出，$\tilde{Y}$ 是 MPS 精炼得分图的上采样，$\lambda = 0.5$。仅用解码器输出称为 OTSeg，集成后称为 OTSeg+。

训练损失：focal loss + dice loss，权重 $\lambda_{focal}=20$、$\lambda_{dice}=1$（Eq. 18, Appendix B）。图像编码器用 VPT 微调，文本编码器冻结。prompt 数 N=6（VOC 2012）、N=8（PASCAL Context 和 COCO-Stuff164K）。

## 3. 理论结果

无理论结果。论文没有给出任何定理、引理或收敛性/最优性保证。Sinkhorn 的熵正则 OT 公式（Eq. 3-4）和 Sinkformer 的「首轮迭代等价于 SoftMax」观察均引自前人工作（Cuturi 2013；Sander et al. 2022），本文未做新的理论分析。

## 4. 实验与数字

**数据集**：VOC 2012、PASCAL Context、COCO-Stuff164K。评估指标为 seen/unseen 类的 mIoU 及调和均值 hIoU。骨干为 CLIP ViT-B/16，8 张 A100，batch size 16。

**主结果（Table 1）**：

| 设置 | 数据集 | OTSeg hIoU | OTSeg+ hIoU | 此前 SOTA hIoU |
|---|---|---|---|---|
| Inductive | VOC 2012 | 84.5 | **87.1** | 84.3 (ZegCLIP) |
| Inductive | PASCAL Context | 54.8 | **57.7** | 49.9 (ZegCLIP) |
| Inductive | COCO-Stuff164K | 41.4 | **41.5** | 40.8 (ZegCLIP) |
| Transductive | VOC 2012 | 94.2 | **94.4** | 91.1 (ZegCLIP) |
| Transductive | PASCAL Context | 59.3 | **59.8** | 55.6 (ZegCLIP) |
| Transductive | COCO-Stuff164K | 49.5 | **49.8** | 48.5 (ZegCLIP) |

Inductive VOC 2012 上 OTSeg+ 的 mIoU(U)=81.6、mIoU(S)=93.3（Table 1）。PASCAL Context inductive 上 OTSeg+ 的 mIoU(U)=60.4、mIoU(S)=55.2（Table 1）。

**跨数据集（Table 2）**：COCO-156 → ADE20K 上 OTSeg+ 达 19.6（inductive）/ 21.1（transductive），ZegCLIP 为 19.0 / 21.1；COCO-156 → PASCAL Context 上 OTSeg+ 达 49.1 / 53.4，ZegCLIP 为 41.2 / 45.8。

**效率（Table 3）**：OTSeg 参数量 13.8M，与 ZegCLIP 相同；GFLOPS 61.9（ZegCLIP 61.1，+1.2%）；FPS 23.6（ZegCLIP 25.6，-7.8%）；比 Zsseg（4.2 FPS）和 ZegFormer（6.8 FPS）快 4-5 倍。

**消融（Table 4）**：仅用解码器输出（MPSA 路径）在 inductive VOC 2012 上 hIoU=84.5，仅用精炼得分图（MPS 路径）hIoU=81.8，集成后 87.1。两条路径单独都超过 ZegCLIP 的 84.3。

**组件分析（Table 5）**：VOC 2012 上 N=6 最优（hIoU 87.1），N=4 为 84.1，N=8 为 86.1；PASCAL Context 上 N=8 最优（57.7）。MPSA 对比 cross-attention：VOC 2012 上 87.1 vs 84.3（+3% hIoU），PASCAL Context 上 57.7 vs 50.3（+7% hIoU）。naive 多 prompt cross-attention 在 VOC 2012 上反而降到 77.6。

## 5. 在 OT×扩散地图中的位置

OTSeg 是「attention 即 OT 接口化」这条线（线 B）的关键节点，直接继承 Sinkformer（AISTATS 2022）的「SoftMax → Sinkhorn」替换策略，将其从单模态 self-attention 推广到多模态 cross-attention。与 PLOT（ICLR 2023）同属「OT 对齐 prompt-token 集合」方向，但 PLOT 做 few-shot 图像级分类的 prompt 学习，OTSeg 做像素级稠密分割，且把 Sinkhorn 嵌入 Transformer 解码器内部而非仅做外部对齐损失。

在本课题 T16 的框架中，OTSeg 的贡献是验证了「双随机耦合」在判别式语义对应中的价值：SoftMax attention 是单边归一化（每行独立 softmax），Sinkhorn 的双边归一化强制了质量守恒，使 N 个 prompt 的「语义预算」被全局分配，避免多个 prompt 挤到同一批像素上。这与 SCOT 用 OT 解决 many-to-one 错配的动机一致，但作用在 prompt-像素匹配而非图像间匹配。

OTSeg 不涉及扩散模型或生成式引导，与 STORM/ASAG/OTComp 等采样期 attention 干预工作无直接技术继承关系，但它为「attention plan 偏离最优耦合 ⇒ 语义错乱」这一理论张力提供了判别式侧的实证：Table 5(b) 显示 naive cross-attention 在 VOC 2012 上比 MPSA 低 3% hIoU，且多 prompt 直接堆叠反而有害（77.6 vs 84.3），说明缺乏全局约束的局部贪心匹配确实导致 prompt 语义坍缩。

## 6. 局限与批评

**作者承认的**：
1. 每个 prompt 得分图的「真实语义含义」未被完全捕捉——框架没有考虑语义含义与视觉特征之间的显式关联（Sec. 6）。
2. 模块尚未应用到 open-vocabulary、instance 或 panoptic segmentation（Sec. 6）。

**读出来的**：
1. 边际分布设为均匀分布（$\mu = 1_M/M$、$\nu = 1_N/N$，Algorithm 1），这意味着每个 prompt 被强制分配到相同数量的像素。当不同 prompt 对应的语义区域面积差异很大时（如「背景」prompt 对应大面积、「物体」prompt 对应小面积），均匀边际会强制错配。论文没有讨论非均匀边际或质量学习。
2. 效率提升有限：GFLOPS 增加 1.2%、FPS 下降 7.8%（Table 3），Sinkhorn 迭代的额外计算成本在实时场景下不可忽略，且论文未报告 Sinkhorn 迭代次数 $t_{max}$ 的敏感性分析。
3. COCO-Stuff164K 上提升幅度很小（inductive hIoU 41.5 vs 40.8，+0.7；transductive 49.8 vs 48.5，+1.3），说明在类别多、场景复杂的 stuff 分割上，均匀边际的 MPS 优势被稀释。

## 7. 对我们的启发

1. **非均匀边际的 MPS 变体**：把 Algorithm 1 中的均匀 $\nu = 1_N/N$ 替换为可学习的 prompt 质量向量（接 UNITE 的自适应质量学习思路），让 prompt 按语义区域大小自适应分配像素预算。在 ZS3 的 stuff 类别（COCO-Stuff164K）上验证是否能突破当前 +0.7 hIoU 的瓶颈。这直接对应开放问题 #2 的判别式侧版本。
2. **「attention plan 偏离最优耦合」的定量度量**：OTSeg 的 Table 5(b) 已经给出 naive cross-attention vs MPSA 的性能差，但缺少中间度量——可以计算 cross-attention 矩阵与 Sinkhorn plan 之间的（Gromov-）Wasserstein 距离，验证该距离是否与 hIoU 下降单调相关。这为开放问题 #3 提供判别式侧的实证基础，也可反哺扩散模型中 ASAG 式干预的理论动机。
3. **MPSA 作为扩散 cross-attention 的替换插件**：OTSeg 证明 MPSA 在文本 prompt → 像素的匹配上优于 SoftMax cross-attention。扩散模型的 cross-attention 同样是文本 token → 图像 patch 的匹配，且已知存在属性泄漏和 many-to-one 错配问题。可以尝试在 SD/DiT 的 cross-attention 层用 MPSA 替换 SoftMax（training-free 或轻量微调），观察多 token 语义坍缩是否缓解。这是线 B 从判别式分割向生成式扩散的自然延伸，与 STORM/ASAG 的采样期干预互补。
