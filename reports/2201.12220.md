# Neural Optimal Transport

> Alexander Korotin, Daniil Selikhanovych, Evgeny Burnaev · ICLR 2023 (Spotlight) · [arXiv](https://arxiv.org/abs/2201.12220) · 证据级 [P] · 课题 T13 神经 OT 映射与无配对图像翻译
> **一句话**：把 weak OT 对偶写成 $\sup_f\inf_T$ 鞍点，用带噪声输入的网络 $T(x,z)$ 学随机 plan；证明 NN 是 plan 的万能逼近器；unpaired 翻译 FID 与 CycleGAN 系相当或更好。

## 1. 问题
此前可扩展的神经 OT 求解器（W2GN、OTM、Fan et al.）都只针对强 cost、且只学确定性 OT map $T$——而 Kantorovich 最优 plan 可能本质上是随机的，确定 map 根本不存在（Sec. 1, Sec. 3）。能学随机 plan 的方法（Daniels et al. 2021）走熵正则 + score model + Langevin，学与采样都极慢且 plan 有偏（Sec. 1）。ICNN 路线理论漂亮但大规模不实用；熵正则路线 plan 有偏、难采样（Sec. 3）。

unpaired 翻译端，CycleGAN/UNIT 靠多个网络与多项损失，vanilla CycleGAN 学的是任意翻译 map，无法保证保留颜色等属性，需要额外损失（Sec. 5.2）；一对多翻译更难，简单加噪声输入会「conditional collapse」，AugCycleGAN/MUNIT 目标复杂（Sec. 5.3）。

## 2. 方法
核心思想：weak OT 的 C-transform 内层是对分布 $\mu\in\mathcal P(Y)$ 的 inf，把 $\mu$ 表示成噪声 $S$ 经映射 $t$ 的推前 $t\sharp S$（noise outsourcing），再用 Rockafellar 交换定理把逐点 inf 提到函数级，就得到一个只含两个网络的 maximin。

- **Weak OT**（Gozlan et al. 2017）：$\mathrm{Cost}(P,Q)=\inf_{\pi\in\Pi(P,Q)}\int_XC(x,\pi(\cdot|x))dP(x)$（Eq.(3)），cost 作用在条件分布上。实验用 $\gamma$-weak 二次 cost $C(x,\mu)=\int\tfrac12\|x-y\|^2d\mu(y)-\tfrac\gamma2\mathrm{Var}(\mu)$（Eq.(4)），$\gamma\le1$ 时下有界且对 $\mu$ 凸。对偶 $\mathrm{Cost}=\sup_f\int f^C dP+\int f dQ$（Eq.(5)），$f^C(x)=\inf_\mu\{C(x,\mu)-\int fd\mu\}$（Eq.(6)）。
- **Lemma 2–3 + Corollary 1**：$f^C(x)=\inf_t\{C(x,t\sharp S)-\int f(t(z))dS(z)\}$（Eq.(8)），积分后交换 inf 与积分得
$$\mathrm{Cost}(P,Q)=\sup_f\inf_T\mathcal L(f,T),\quad\mathcal L=\int_Yf\,dQ+\int_X\Big[C\big(x,T(x,\cdot)\sharp S\big)-\int_Zf(T(x,z))dS(z)\Big]dP(x)\quad\text{(Eq.(14)–(15))}$$
$T:X\times Z\to Y$ 是「随机 map」，$z\sim S$（高斯噪声）。
- **Algorithm 1**：$f_\omega$ 用 $\tfrac1{|X|}\sum_x\tfrac1{|Z_x|}\sum_zf(T(x,z))-\tfrac1{|Y|}\sum_yf(y)$ 做一步上升；$T_\theta$ 用 $\hat C(x,T(x,Z_x))-\tfrac1{|Z_x|}\sum_zf(T(x,z))$ 做 $K_T$ 步下降（$K_T=10$）。强 cost 用 $|Z|=1$ 的 MC 估计（Eq.(18)）；$\gamma$-weak 需 $|Z|\ge2$ 估计修正批方差（Eq.(19)，实验 $|Z_x|=4$）。
- **与 GAN 的区别**（Sec. 4.3）：这是 $\sup_f\inf_T$ 而非 WGAN 的 $\inf_T\sup_f$——生成器是内层解、对抗于位势；一般 $\inf\sup\neq\sup\inf$（作者举 $\sin(x+y)$ 例）；$T$ 每步更新多次；$f$ 不需要 Lipschitz 约束。
- **conditional collapse**（Sec. 5.1）：强 cost（$\gamma=0$）下 $T(x,z)$ 自动变得与 $z$ 无关，因为 Eq.(7) 的 arg inf 可取退化分布；$\gamma>0$ 时 $-\tfrac\gamma2\mathrm{Var}$ 项奖励条件方差，随机性得以保留。训练时 $\gamma$ 从 0 线性升到目标值（$2/3$ 或 1）用 25K 步（Appendix E「Dynamic weak cost」）。
- 架构：$f$ 用 WGAN-QC 的 ResNet，$T$ 用 UNet，噪声 $z$ 作为第 4 个输入通道（RGBZ），轴向 $\sigma=0.1$；Adam lr $10^{-4}$，batch 64，约 40K 次 $f$ 更新收敛（Appendix E）。

## 3. 理论结果
- **Lemma 1**：$\mu$ 无原子则存在可测 $t$ 使 $t\sharp\mu=\nu$（任意维度）。
- **Lemma 4**（最优 map 解 maximin）：对任一对偶最大化子 $f^*$ 与任一实现某最优 plan 的随机 map $T^*$，$T^*\in\arg\inf_T\mathcal L(f^*,T)$（Eq.(16)）。作者明确指出 arg inf 集可能还含非 OT 的随机函数（Sec. 4.1）。
- **Lemma 5**（Appendix F）：若 $C(x,\mu)$ 对 $\mu$ 严格凸且最优 $f^*$ 存在，则 $\arg\inf_T\mathcal L(f^*,T)$ 中所有元素都是随机 OT map。实验用的强/$\gamma$-weak 二次 cost 都**不是**严格凸的，因此保证不适用（Appendix F 末）。
- **Theorem 1**（万能逼近）：$X,Z$ 紧、$Q$ 二阶矩有限，对任意（不必最优）随机 map $T$ 与 $\epsilon>0$，存在非仿射连续激活的网络 $T_\theta$ 使 $\|T_\theta-T\|^2_{L^2(P\times S)}\le\epsilon$ 且 $W_2^2((T_\theta)\sharp(P\times S),Q)\le\epsilon$（Eq.(20)），证明依赖 Kidger & Lyons 稠密性 + W2GN Lemma A.2；作者提醒这样的网络「可能高度不规则、难学」（Sec. 4.4）。

## 4. 实验与数字
数据：anime faces、CelebA、shoes、Amazon handbags、LSUN church、MIT outdoor，50K–500K 张，90/10 训练/测试，所有结果均为测试图（Sec. 5）。硬件：确定 map 单张 V100 16GB 训 1–3 天，随机 map 用 4×V100（Appendix E）。

| 任务（测试 FID↓） | 一对一：DiscoGAN / CycleGAN / **NOT** | 一对多：AugCycleGAN / MUNIT / **NOT** | 来源 |
|---|---|---|---|
| Handbags→shoes 64×64 | 22.42 / 16.00 / **13.77** | 18.84±0.11 / 15.76±0.11 / **13.44±0.12** | Appendix D, Table 1 |
| CelebA male→female 64×64 | 35.64 / 17.74 / **13.23** | 12.94±0.08 / 17.07±0.11 / **11.96±0.07** | Table 1 |
| Outdoor→church 128×128 | 75.36 / 46.39 / **25.5** | 51.42±0.12 / 31.42±0.16 / **25.97±0.14** | Table 1 |

- 域相近时各法 FID 相当，域相远（outdoor→church）时 NOT 明显领先（Appendix D「Discussion」）。基线用官方/社区实现与原论文超参。
- 超参与规模（Table 2，64×64）：NOT 目标函数超参 0 个（一对一）/ 1 个 $\gamma$（一对多），2 个网络共 32.6M（$T$ 9.7M + $f$ 22.9M；128px 为 42.1M）；CycleGAN 2 个超参、4 网 28.2M；MUNIT 3 个超参、4 网 46.6M；AugCycleGAN 2 超参、6 网 7.0M。
- $\gamma$ 的方差–相似度权衡（Appendix A, Fig. 7，handbags→shoes 64px）：$\gamma=0$ 无多样性（collapse）；$\gamma=1/3,2/3$ 多样性上升且保留输入风格；$\gamma=1$ 多样性很高但许多样本不再保留风格。仅定性。
- 玩具实验（Appendix B–C）：$\gamma=1$ 时 $C(x,\mu)=\tfrac12\|x-\int yd\mu\|^2$（Eq.(21)），Gozlan & Juillet 定理给出条件均值 $\int yd\pi^*(y|x)=\nabla\psi(x)$（凸、1-Lipschitz）作为可核对的真值；与 POT `ot.weak` 离散解对比，学得的平均 map 与 $\nabla\psi$ 接近，传输 cost 接近最优值。仅图形，无表格数字。
- 定性（Sec. 5.2, Fig. 5）：L2 最优性使翻译保留颜色/纹理（shoes↔handbags）、发型头型（celeba→anime）、地面天空（outdoor→church）。

## 5. 在 OT×扩散地图中的位置
- 它是 Korotin 系的「统一框架」节点：强 cost + 确定 $T$ 时退化为 W2 benchmark（2106.01954）中的 MM:R、OTM（2110.02999）的 Q-embedded cost 版本与 Fan et al.（2106.03812）的一般 cost 版本（Sec. 4.3「Dual OT solvers」）。后续 Kernel NOT（2205.15269）直接针对本文的 $\gamma$-weak cost 证明 fake solution 存在并换 kernel cost；General Cost Functionals（2205.15403）与 Extremal（2301.12874）在同一算法骨架上改 cost；ENOT（2403.03777）、DIOTM（2410.03783）、OTP（ICML 2025）则针对本文承认的「arg inf 含非最优解 / 训练波动发散」问题给出修复。
- 与 UOT 支线的界线：Appendix G 指出 unbalanced OT 是无约束问题、$\min_T\max_f$ 形式，与本文「硬约束的 $\max_f\min_T$」本质不同——这正是 UOTM（2305.14777）后来走的另一条路。
- 对综合报告：正文提到 DDIB（Su et al. 2023）用扩散模型做翻译并联系 Schrödinger bridge（Sec. 5.2），即 T14 的多步桥路线；NOT 是它的「一步静态 plan」对照。$\gamma$-weak cost 通过条件方差显式控制一对多多样性，是 T13 中「多样性–保真」张力（KB 开放问题 #5）的源头。

## 6. 局限与批评
作者承认：
1. 鞍点问题 Eq.(14) 的解 $(f^*,T^*)$ 中并非所有 $T^*$ 都是随机 OT map；强 cost 下表现为 conditional collapse；「研究鞍点与 arg inf 集」留作未来工作（Sec. 6「Limitations」）。
2. 训练有时在鞍点附近震荡或发散，$\gamma$-weak 情形当 $P$ 比 $Q$ 分散得少或 $\gamma$ 大时更不稳定（Appendix E「Stability」）。
3. 学到的 OT map 未必适合所有 unpaired 任务，需设计任务专用 cost（Sec. 6）。
4. Theorem 1 的逼近网络可能高度不规则（Sec. 4.4）。

我读出的：
1. Lemma 5 的保证只对严格凸 cost 成立，而全部实验用的二次/$\gamma$-weak 二次 cost 都不严格凸——理论与实验之间有明确缺口，作者自己在 Appendix F 末承认。Kernel NOT 随即证明 $\gamma$-weak cost 确实有 fake solution。
2. 一对多的多样性只有 Fig. 7 的定性展示，没有 LPIPS 类多样性指标，也没有输入保真度量（如 L2/LPIPS 到输入），「$\gamma$ 控制多样性」是视觉结论。
3. FID 比较中基线是 2017–2018 的方法，作者主动排除 StarGAN v2、COCO-FUNIT 等更新方法（Appendix D「Methods」）；且 NOT 的位势网络 22.9M 比 CycleGAN 判别器大一个量级，规模不对等。
4. 随机 map 需 4×V100 训数天，$|Z_x|=4$ 使成本约为确定 map 的 4 倍，可扩展性宣称有前提。

## 7. 对我们的启发
1. Top-10 #1（保边缘噪声指派）：Eq.(14) 的 $\sup_f\inf_T$ 是学「噪声→数据随机耦合」的通用配方；把 $C$ 换成扩散/FM 轨迹的直线度代价（如条件速度方差），就能训练一个显式的随机指派 $T(x,z)$ 而非固定 mini-batch OT。
2. Top-10 #3（保耦合蒸馏）：$\gamma$-weak cost 的 $-\tfrac\gamma2\mathrm{Var}$ 项是「防止一对多蒸馏 collapse」的最小改动——蒸馏学生若对同一条件输出退化为单点，可用该项作多样性正则并以 $\gamma$ 单参调节。
3. Appendix B 的「$\gamma=1$ 时条件均值必为凸函数梯度」是唯一可检验的 weak OT 真值，为 KB 开放问题 #2（weak/UOT 新基准）提供了低成本的构造起点。
