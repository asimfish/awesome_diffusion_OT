# E2 TTS: Embarrassingly Easy Fully Non-Autoregressive Zero-Shot TTS

> Sefik Emre Eskimez, Xiaofei Wang, Manthan Thakker et al. · IEEE SLT 2024 · [arXiv](https://arxiv.org/abs/2406.18009) · 证据级 [P] · 课题 T23 语音与音频中的流匹配与 Schrödinger 桥
> **一句话**：字符序列补 filler token 对齐 mel 长度后直接 FM infilling，砍掉时长模型/G2P/单调对齐，仍达人类级自然度。

## 1. 问题

零样本 TTS 要在给定短音频 prompt 的条件下，为任意文本生成自然语音。此前两条路线各有代价：基于神经编解码语言模型的 AR 方法（VALL-E、VALL-E 2）需要顺序采样，推理延迟高，且要精心挑选文本/音频 tokenizer，长序列还需 AR+NAR 混合、多尺度 Transformer、grouped code modeling 等技巧（Sec. 1）；基于扩散或流匹配的完全 NAR 方法（NaturalSpeech 2/3、Voicebox、Matcha-TTS）虽然可并行推理，但都依赖某种「文本—音频对齐」机制——帧级音素对齐、单调对齐搜索（MAS）加独立时长模型，或 E3 TTS 那种需要精心设计 U-Net 的交叉注意力（Sec. 1）。作者的核心发现是：这些对齐组件对高质量零样本 TTS 并非必要，有时甚至损害自然度（Sec. 1 脚注 1 的表述是 "sometimes even harmful to naturalness"）。

## 2. 方法

E2 TTS 只保留两个模块：基于流匹配的 mel 谱生成器 + 声码器（Sec. 2）。文本输入被转成字符序列，尾部追加特殊 filler token $\langle F\rangle$ 使序列长度等于 mel 帧数 $T$：

$$\hat{y} = (c_1, c_2, \ldots, c_M, \underbrace{\langle F\rangle, \ldots, \langle F\rangle}_{(T-M)\ \text{times}}) \tag{Eq.(1)}$$

训练目标是语音 infilling 任务：学习分布 $P(m \odot \hat{s} \mid (1-m)\odot \hat{s}, \hat{y})$，其中 $m \in \{0,1\}^{D\times T}$ 是二值时间掩码，$\odot$ 是 Hadamard 积（Sec. 2.1）。生成器用条件流匹配训练，目标为：

$$L_{\text{CFM}}(\theta) = \mathbb{E}_{t, q(x_1), p_t(x|x_1)} \| u_t(x|x_1) - v_t(x;\theta) \|^2 \tag{Eq.(3)}$$

采用 OT 路径：$p_t(x|x_1) = \mathcal{N}(x \mid t x_1, (1-(1-\sigma_{\min})t)^2 I)$，$u_t(x|x_1) = (x_1 - (1-\sigma_{\min})x)/(1-(1-\sigma_{\min})t)$（Sec. 2.3）。推理时用 ODE solver 从初始分布 $p_0$ 生成 log mel 特征。

推理时（Sec. 2.2），给定音频 prompt $s^{\text{aud}}$ 及其转录 $y^{\text{aud}}$、文本 prompt $y^{\text{text}}$，构造扩展字符序列：

$$\hat{y}' = (c'_1, \ldots, c'_{M^{\text{aud}}}, c''_1, \ldots, c''_{M^{\text{text}}}, \underbrace{\langle F\rangle, \ldots, \langle F\rangle}_{T\ \text{times}}) \tag{Eq.(2)}$$

其中 $T = T^{\text{aud}} + T^{\text{gen}} - M^{\text{aud}} - M^{\text{text}}$，保证 $\hat{y}'$ 长度等于 $T^{\text{aud}} + T^{\text{gen}}$。生成器学习 $P(\tilde{s} \mid [\hat{s}^{\text{aud}}; z^{\text{gen}}], \hat{y}')$，$z^{\text{gen}}$ 是 $D \times T^{\text{gen}}$ 的全零矩阵。目标时长 $T^{\text{gen}}$ 可任意指定。

骨干网络沿用 Voicebox 音频模型的架构（vanilla Transformer + U-Net 风格 skip connection），仅把帧级音素序列替换为 $\hat{y}$（Sec. 2.3）。两个扩展：X1 在推理时去掉音频 prompt 的转录（训练时用 Montreal Forced Aligner 确定词边界，保证掩码不切断单词，Sec. 2.5.1）；X2 在训练时以 15% 概率把词替换为括号内 CMU 音素序列，推理时可直接指定生词发音（Sec. 2.5.2）。

## 4. 实验与数字

**数据**：Libriheavy（50,000 小时，6,736 说话人，保留大小写与标点）为主；另有 200,000 小时专有数据做扩展实验（Sec. 3.1）。评估用 LibriSpeech-PC test-clean，过滤到 4–10 秒，共 1,132 样本、39 说话人；音频 prompt 取同说话人随机样本最后 3 秒（Sec. 3.3）。

**模型配置**：Transformer 24 层、16 注意力头、嵌入维度 1024、线性层维度 4096、字符词表 399、总参数 335M；100 维 log mel，帧移 10.7 ms，24 kHz；BigVGAN 声码器；训练掩码长度随机取 mel 长度的 70%–100%；CFG 条件丢弃概率 20%；800,000 步，有效 batch 307,200 音频帧，峰值学习率 $7.5\times10^{-5}$，前 20,000 步 warm-up；丢弃超过 4,000 帧的样本（Sec. 3.2）。推理用 CFG 强度 1.0、midpoint ODE solver、NFE=32（Sec. 3.4）。

**主结果**（Table 1，客观指标）：

| 模型 | 数据（小时） | 初始化 | WER↓ | SIM-o↑ |
|---|---|---|---|---|
| Ground Truth | — | — | 2.0 | 0.695 |
| VALL-E | LL (60K) | Random | 4.9 | 0.500 |
| NaturalSpeech 3 | LL (60K) | Random | 2.6 | 0.632 |
| Voicebox† | LL (60K) | Random | 2.1 | 0.658 |
| Voicebox† | LH (50K) | Random | 2.2 | 0.667 |
| Voicebox† | LH (50K) | Pretrain | 2.2 | 0.695 |
| E2 TTS (P1) | LH (50K) | Random | 2.0 | 0.675 |
| E2 TTS (P2) | LH (50K) | Pretrain | **1.9** | **0.708** |
| E2 TTS (P3) | PP (200K) | Random | **1.9** | 0.707 |

P2 的 WER 1.9% 与 SIM-o 0.708 均优于 Ground Truth 的 2.0 / 0.695（Table 1）。

**主观结果**（Table 2）：P2 的 CMOS 为 -0.05，作者按 NaturalSpeech 3 与 Seed-TTS 的标准判定为「与 ground truth 不可区分」；评估中 E2 TTS 在 33% 样本上被判定优于 ground truth，33% 劣于，其余持平（Sec. 3.4 脚注 7）。SMOS 方面所有模型都超过 ground truth（作者解释为 LibriSpeech 说话人在书中用不同声音配不同角色，导致 ground truth 自身 SMOS 低，Sec. 3.4 脚注 8）。

**扩展结果**：X1（无需音频 prompt 转录）在预训练初始化下 WER 2.0 / SIM-o 0.705，与基础版 1.9 / 0.708 接近（Table 3）。X2 在 50% 词替换为音素序列时 WER 仅从 2.0 升到 2.1，SIM-o 基本不变（Table 4）。

**行为分析**：训练进度上，Voicebox 因帧级音素对齐在 10% 训练点就有好 WER，E2 TTS 收敛慢得多，但最终 WER 更好（Fig. 4，Sec. 3.6.1）。音频 prompt 长度从 4 秒到 10 秒，WER 无明显模式，SIM-o 随 prompt 变长显著提升（Fig. 5，Sec. 3.6.2）。语速从 0.7 到 1.3，WER 仅温和上升，SIM-o 保持高位（Fig. 6，Sec. 3.6.3）。

## 5. 在 OT×扩散地图中的位置

E2 TTS 是「FM + masked infilling」范式（Voicebox 确立）的极简化分支：保留 Voicebox 的语音 infilling 预训练任务与 OT-CFM 路径，但把帧级音素序列换成字符 + filler token，从而把 G2P、音素对齐器、时长模型全部吸收进单个流匹配 Transformer（Sec. 2.4 明确说这是「G2P + 时长模型 + Voicebox 音频模型的联合建模」）。它继承 Voicebox 的 OT 条件路径（Eq.(3) 中的 $p_t(x|x_1) = \mathcal{N}(x|tx_1, \ldots)$ 就是 Lipman 条件 OT 路径），但不在 OT 理论层面做新贡献——OT 在这里只是训练用的路径选择。在课题地图上，它直接催生 F5-TTS（解决 E2 收敛慢/鲁棒性问题，加 Sway Sampling），并与 Matcha-TTS 形成对照：Matcha 用 MAS + 独立时长模型，E2 证明这些都可以删。它属于「结构极简化」主线，不是 SB 路线，也没有少步化贡献（推理仍用 32 NFE）。

## 6. 局限与批评

作者承认的：E2 TTS 收敛显著慢于 Voicebox——Voicebox 在 10% 训练点就有好 WER，E2 TTS 需要多得多的训练（Sec. 3.6.1，Fig. 4）。X1 扩展在随机初始化下 SIM-o 从 0.675 降到 0.664，有轻微损失（Table 3）。

读出来的：第一，推理仍用 32 NFE 的 midpoint ODE solver（Sec. 3.4），没有做少步化，RTF 优势只来自 NAR 并行而非采样步数压缩；第二，目标时长 $T^{\text{gen}}$ 在推理时需外部指定，论文用 Voicebox 式回归时长模型做公平对比（Sec. 3.2），但基础框架本身不含时长预测，实际部署时要么用户手定、要么另接模型，这削弱了「砍掉时长模型」的纯度；第三，评估集只有 39 说话人、1,132 样本（Sec. 3.3），且全部来自 LibriSpeech 朗读语音，对自发语音、多语种、噪声 prompt 的泛化未验证；第四，200,000 小时专有数据的扩展实验（P3）不可复现，且 P3 相比 P2 没有带来 WER 或 SIM-o 的进一步提升（Table 1），「scalability」的证据强度有限。

## 7. 对我们的启发

1. **filler token 对齐是「免对齐」的干净实现，可作为 OT 耦合消融的载体**：E2 用字符 + filler 把文本长度强制对齐到 mel 帧数，训练时 $(x_0, x_1)$ 仍是独立采样。在 E2/Matcha 规模上做 minibatch-OT 耦合消融（课题切入点 #4），可以直接观察：当文本侧已经用 filler 对齐后，batch 内 OT 耦合是否还有增益。E2 的极简结构让这个消融的混杂因素最少。

2. **收敛慢是「删对齐」的代价，Sway Sampling 类免重训调度可能正好补这个短板**：E2 在 10% 训练点 WER 远差于 Voicebox（Fig. 4），说明早期训练阶段模型在同时学 G2P、时长、声学。F5-TTS 的 Sway Sampling 把推理步密度向高曲率区倾斜，不改训练。可以测试：对 E2 这种「联合建模」模型，sway 系数是否需要更大，或者按训练进度自适应调整推理步分配。

3. **X2 的音素括号机制是「输入表示灵活性」的最小侵入示范**：训练时 15% 概率替换词为括号音素序列，推理时即可指定生词发音，WER 几乎不降（Table 4）。这提示：在 FM 语音生成中，输入表示的语义由字符本身决定，模型不需要显式的 tokenizer 切换。对多语种或代码切换场景，可以沿用同一机制做「表示级数据增强」，而不改模型结构。
