# Wukong's 72 Transformations: High-fidelity Textured 3D Morphing via Flow Models

> Minghao Yin, Yukang Cao, Kai Han et al. · arXiv 2025 · [arXiv](https://arxiv.org/abs/2511.22425) · 证据级 [R] · 课题 T27 多边际 OT 与 Wasserstein 重心的生成应用
> **一句话**：在预训练 3D flow transformer 的条件 token 空间解 free-support barycenter，training-free 实现带纹理 3D 形变，FID 4.01 优于 3DRM 6.36。

## 1. 问题

本文解决 **textured 3D morphing**：给定一对 source 和 target prompt（图像或文本），生成从源到目标的平滑 3D 形状与纹理过渡序列。此前方法主要依赖手工 correspondence matching 和 deformation trajectory estimation（Sec. 1），受限于大规模成对 3D 数据稀缺，泛化到 unseen data 时输出不理想；且多数方法只处理 untextured mesh，带纹理的 3D morphing 基本未被探索（Sec. 1）。直接训练 feed-forward 网络建模两物体间过渡也不可行，因为基于现有大规模 3D 数据（如 Objaverse-XL）构造 paired 3D data 在技术和经济上都困难（Sec. 1）。

作者选择 training-free 路线：借用预训练 flow-based 3D 生成器（Trellis）的先验，不训练任何新参数。核心挑战是：没有大规模连续 shape/texture 过渡的 3D 数据可供监督，如何在 latent condition 空间设计插值，使生成器输出平滑且语义一致的中间态。

## 2. 方法

整体框架（Fig. 2）：用 DINOv2 编码图像 prompt、CLIP 编码文本 prompt，得到条件 token 集合；把 token 视为经验分布，在 token 空间解 free-support Wasserstein barycenter 得到插值条件 $Z_\alpha$；将 $Z_\alpha$ 送入预训练 Trellis 的几何流模型 $\Phi_{geo}$ 和纹理流模型 $\Phi_{tex}$，解码为 mesh。

**形状插值（Sec. 3.3）**：把 source 和 target 的条件 token 建模为离散分布 $\mu_1=\sum_i a_i\delta_{x_i}$、$\mu_2=\sum_j b_j\delta_{y_j}$，权重 $a_i=b_j=1/n$（Eq. 8）。中间步 $\alpha$ 的插值条件通过 free-support Wasserstein barycenter 问题求得：

$$Z_\alpha = \arg\min_Z \left[(1-\beta)\,W_2^2(\mu_1,\nu) + \beta\,W_2^2(\mu_2,\nu)\right],\quad \beta=\alpha/(J+1) \tag{Eq. 9}$$

其中 $\nu=\sum_k c_k\delta_{z_k}$ 是带可学习支撑点 $\{z_k\}$ 的目标插值分布，$c_k=1/n$。求解用 `ot.lp.free_support_barycenter`（von Lindheim 2023），最大迭代 100，收敛阈值 $10^{-5}$（Sec. 4 Implementation details）。

**顺序初始化（Sec. 3.3）**：naïve 线性初始化 $z_{k,init}=(1-\beta)x_k+\beta y_k$ 在几何距离远或语义分歧大的条件之间会导致不连续插值。作者改为用上一步的优化解初始化当前步：

$$z^{(\alpha)}_{k,init} = \begin{cases} x_k, & \alpha=0 \\ z^{(\alpha-1)}_k, & \text{otherwise} \end{cases} \tag{Eq. 10}$$

**纹理控制（Sec. 3.4）**：默认纹理 morphing 直接用 barycenter token $Z_\alpha$ 作为 $\Phi_{tex}$ 的条件。texture controlled 模式引入相似度引导的选择性插值：对每个 barycenter 点 $z_k$，找其最近 source token $x_i$ 和 target token $y_j$，计算余弦相似度 $sim=\cos(x_i,y_j)$，然后：

$$\tilde{z}_k = \begin{cases} z_k, & 1-sim > \tau \\ x_i, & \text{otherwise} \end{cases} \tag{Eq. 11}$$

$\tau\in[0,1]$ 是用户可调的相似度阈值，控制 source 纹理保留程度。

**生成器**：Trellis 的 rectified flow transformer，结构流和纹理流各 25 采样步，CFG 强度 3，各含 21 个 cross-attention block，在每个 cross-attention 层前对 condition token 做插值（Sec. 4）。$J=6$，单次生成约 30 秒（A100）。

## 3. 理论结果

无理论结果。论文没有给出任何定理、引理或收敛性/误差界证明。方法动机是 flow 模型的确定性（中间态非随机）与 barycenter 的几何平均性质，但「barycenter token 经 $\Phi$ 映射后是否接近输出分布的 barycenter」这一交换性问题未被理论刻画。

## 5. 在 OT×扩散地图中的位置

本文是 **barycenter 融合/插值线** 在 3D 生成上的一个代表性应用，与课题背景中「Wukong (2025 [R]) 在预训练 flow transformer 条件 token 上 training-free 解 free-support barycenter 做 3D 形变」的定位一致。

具体关系：
- **继承**：free-support barycenter 求解器直接采用 von Lindheim (2023) 的 `ot.lp.free_support_barycenter`；生成 backbone 继承 Trellis（Xiang et al. 2024）的 rectified flow transformer 与 SLAT 表示；2D morphing 的「插值条件 token」思路受 DiffMorpher（Zhang et al. 2024a）启发，但把线性插值替换为 OT barycenter（Sec. 2 Related work）。
- **竞争**：与 3DRM（Yang et al. 2025）直接竞争——3DRM 用 3D diffusion prior 做 textured 3D morphing，但作者批评其「主要关注参数融合，对 latent condition 插值关注较少」（Sec. 2）；与 MorphFlow（Tsai et al. 2022）等 correspondence-based 方法竞争。
- **理论张力**：本文触及但未解决课题背景中开放问题 #3——「预训练确定性流映射 $\Phi$ 与条件空间 barycentric 插值何时可交换」。作者在条件 token 空间求 barycenter，再经 $\Phi$ 映射到 3D 输出，但没有任何理论保证 $\Phi(\mathrm{bary}(c_i))$ 接近输出分布的 barycenter。这正好是课题背景指出的可证空白。
- **管线环节**：属于「inference-time 条件插值」而非「训练目标」或「模型融合」。与 OTP-FM 的势引导、Wasserstein Flow Matching 的测地线生成不同，本文没有把 OT 作为训练或采样动力学的约束，只在条件空间做一次性几何平均。

## 6. 局限与批评

**作者承认的**：
1. 默认 textured morphing「严格将纹理演化与结构过渡耦合」，缺乏灵活性，因此才需要额外的 texture controlled 模式（Sec. 3.4）。
2. 线性初始化失败的原因是「忽视 token 分布结构，常导致 barycenter 优化收敛到不稳定或不真实插值」（Sec. 3.3），即方法对初始化敏感。

**读出来的**：
1. **无理论保证**：全文没有定理或命题。barycenter 在条件 token 空间求解，但生成器 $\Phi$ 是非线性 flow transformer，barycenter 的几何平均性质经过 $\Phi$ 后是否保持完全未知。实验数字（Table 1）只能说明经验上有效，不能说明「barycenter 插值」本身比精心调参的线性插值有原理性优势——消融中「w/o r-i」的 FID 12.52 仍远好于 Linear 14.73，但两者都远差于完整方法，说明递归初始化贡献了大部分增益，barycenter 本身的独立贡献未被隔离。
2. **评估集不透明**：沿用 3DRM 的输入对，但原文未报告评估对数量、类别分布、是否与 3DRM 完全一致。STP-GPT 和 SEP-GPT 达到 1.00 满分，这种饱和值提示指标区分度或评估协议可能有问题（例如 GPT 评分对自身输出过拟合），原文未讨论。
3. **计算成本**：每个中间步都要解一次 free-support barycenter（最大 100 次迭代），单次生成约 30 秒（Sec. 4），完整 $J=6$ 的 7 帧序列约 3.5 分钟，且递归初始化使各步串行依赖，无法并行。对交互式应用偏慢。
4. **τ 的选择无原则**：相似度阈值 $\tau$ 是用户手工调节的，论文没有给出自动选择机制或对 $\tau$ 的敏感性定量分析（只有 Fig. 6 的定性展示）。

## 7. 对我们的启发

1. **可证空白：$\Phi$ 与 barycenter 的交换性误差界**（对应课题切入点 #3）。本文在条件空间求 barycenter 再经 flow transformer 映射，但没有任何理论刻画。可做：假设 $\Phi$ 是 $L$-Lipschitz 的确定性流映射，证明 $\|\Phi(\mathrm{bary}(c_i)) - \mathrm{bary}(\Phi(c_i))\|$ 的上界依赖 $L$ 与条件分布的 spread；若 $\Phi$ 来自 rectified flow，其 Lipschitz 常数可用训练时的速度场正则性估计。这能把本文的工程配方升级为有保证的方法。
2. **递归初始化的本质是沿 barycenter 轨迹的 continuation**。这提示一个更一般的设计：不逐点独立解 barycenter，而是把整条 barycenter 轨迹作为测地线参数化，用上一步解作为 warm start 的 path-following 算法。可对比不同 continuation 步长对收敛速度和插值质量的影响，并研究是否能用更少的优化迭代达到同等 FID——直接降低本文 30 秒/帧的成本。
3. **纹理控制的相似度阈值机制可推广为「语义对齐的局部 OT 插值」**。当前 $\tau$ 是全局标量，Eq. 11 的 if-else 是硬阈值。可改为：对每个 token 用 $sim$ 作为局部插值权重 $\tilde{z}_k = (1-w(sim))z_k + w(sim)x_i$，$w$ 是光滑递减函数；或把「保留 source 高频细节」形式化为一个带语义对齐正则的 unbalanced OT 问题。这能消除硬阈值的不连续，并给出 $\tau$ 的自动标定。
4. **评估协议警示**：STP-GPT/SEP-GPT 达到 1.00 满分，说明 GPT-based 指标在 3D morphing 上可能缺乏区分度。若我们要在类似任务上做 benchmark，应避免单一依赖 GPT 评分，加入几何层面的定量指标（如 Chamfer distance 沿轨迹的平滑度、纹理映射的局部等距性）。
