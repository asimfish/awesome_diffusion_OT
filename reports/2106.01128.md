# Linear-Time Gromov Wasserstein Distances using Low Rank Couplings and Costs

> Meyer Scetbon, Gabriel Peyré, Marco Cuturi · ICML 2022 · [arXiv](https://arxiv.org/abs/2106.01128) · 证据级 [P] · 课题 T26 Gromov-Wasserstein 与跨空间生成对齐
> **一句话**：低秩耦合 + 低秩代价分解把 GW 从 O(n³) 降到 O(n²) 乃至 O(n)，单细胞对齐上快几个数量级。

## 1. 问题

Gromov-Wasserstein（GW）距离用于对齐两个不可比空间中的点云，通过寻找一个低畸变、保几何的赋值矩阵。GW 是非凸的二次 OT 推广，NP-hard（Sec. 1）。实际中常用 entropic GW（Peyré et al., 2016）近似求解，其复杂度为 O(n³)（n 为样本数），这构成规模化瓶颈。

此前加速 GW 的路线主要有两类（Sec. 1）：(i) 求解 GW 能量的代理问题，如单变量嵌入（Mémoli, 2011; Sato et al., 2020）、sliced 机制（Vayer et al., 2019）、树度量（Le et al., 2021）；(ii) 通过量化（Chowdhury et al., 2021）或递归聚类（Xu et al., 2019a; Blumberg et al., 2020）缩小问题规模。作者指出，据其所知，此前无人尝试加速 GW 内部的 Sinkhorn 迭代。本文的目标是直接对 GW 本身降复杂度，而非改换代理目标。

## 2. 方法

核心思想分三层递进：

**第一层：低秩代价分解（§3）。** 若两个代价矩阵 A ∈ R^{n×n}、B ∈ R^{m×m} 有低秩分解 A = A₁A₂ᵀ、B = B₁B₂ᵀ（d ≪ n, d′ ≪ m），则 entropic GW 中每次外迭代的代价更新 C = −4APB 可从 O(n²m + nm²) 降到 O(nm(d+d′) + dd′(n+m))，目标函数 QA,B(P) 的评估也降为 O(nmd + mdd′)。平方欧氏距离矩阵天然满足此假设：若 A = [‖xᵢ−xⱼ‖²₂]，则 A = z1ᵀ + 1zᵀ − 2XᵀX，其中 z = (X⊙²)ᵀ1_d，可写成秩 d+2 的分解（Sec. 3）。对一般距离矩阵，可用 Bakshi & Woodruff (2018)、Indyk et al. (2019) 的线性时间低秩近似，以概率至少 0.99 满足 ‖A − A₁A₂ᵀ‖²_F ≤ ‖A − A_d‖²_F + τ‖A‖²_F（Sec. 3）。这一层把 entropic GW 从 O(n³) 降到 O(n²)，对应 Algo. 2（Quad Ent）。

**第二层：低秩耦合约束（§4）。** 不假设代价矩阵低秩，而是把耦合 P 限制为非负秩 ≤ r 的集合：

Π_{a,b}(r) := { P ∈ R^{n×m}_+, ∃g ∈ Δ*_r s.t. P = Q diag(1/g)Rᵀ, Q ∈ Π_{a,g}, R ∈ Π_{b,g} }

低秩 GW 问题（式 5）为 min_{(Q,R,g)∈C(a,b,r)} Q_{A,B}(Q diag(1/g)Rᵀ)。用广义 KL 散度下的镜像下降（MD）求解，每步做 Dykstra 投影（式 6）。初始化用 Mémoli (2011) 第一下界在低秩设置下的适配版本（Prop. 1），即对一维平方欧氏代价 ˜C 求解低秩 OT，成本 O((n+m)r)。整体每迭代 O((n²+m²)r)，对应 Algo. 3（LR）。

**第三层：双重低秩（§5）。** 同时假设代价低秩 + 耦合低秩。Algo. 3 中仅剩的二次操作——Line 2 的 ˜x = A⊙²a、˜y = B⊙²b，以及 Line 7/8/16/17 的 C₁ = −AQ diag(1/g)、C₂ = RᵀB——全部线性化。A⊙² 的分解利用 ⟨u,v⟩² = ⟨uuᵀ, vvᵀ⟩，把 A⊙² 写成 ˜A₁˜A₂ᵀ，其中行向量经 ψ(u) = vec(uuᵀ) 展平到 R^{d²}，代价 O(nd²)（需 d² ≪ n）。C₁、C₂ 的更新替换为 C₁ ← −A₁A₂ᵀQ diag(1/g) 和 C₂ ← RᵀB₂B₁ᵀ。最终每迭代复杂度 O(nr(r+d) + mr(r+d′))，时间和内存均为线性，对应 Lin LR。

关键公式（原文编号）：

- GW 能量（式 3）：Q_{A,B}(P) = ⟨A⊙²a, a⟩ + ⟨B⊙²b, b⟩ − 2⟨APB, P⟩
- 低秩 GW 问题（式 5）：min_{(Q,R,g)∈C(a,b,r)} Q_{A,B}(Q diag(1/g)Rᵀ)
- MD 收敛准则（§4）：Δ_α(ξ,γ) := (1/γ²)(KL(ξ, G_α(ξ,γ)) + KL(G_α(ξ,γ), ξ))

## 3. 理论结果

**Prop. 1（§4）**：设 ˜x = A⊙²a ∈ Rⁿ，˜y = B⊙²b ∈ Rᵐ，˜C = (|√˜xᵢ − √˜yⱼ|²)_{i,j}。则对所有 r ≥ 1，GW-LR(r)_α((a,A),(b,B)) ≥ LOT(r)_α(˜C, a, b)，其中 LOT 是低秩 OT 问题。这为初始化提供了下界依据。

**Prop. 2（§4）**：设 1/r ≥ α > 0，N ≥ 1，L_α := 27(‖A‖₂‖B‖₂/α⁴)。取常数步长 γ = 1/(2L_α) 于 MD 方案（式 6）。记 D₀ := Q_{A,B}(Q₀ diag(1/g₀)R₀ᵀ) − GW-LR(r)_α((a,A),(b,B)) 为初始值与最优值的间隙，则

min_{1≤k≤N} Δ_α((Q_k, R_k, g_k), γ) ≤ 4L_αD₀/N

即 MD 方案在 N 次迭代内达到 O(1/N) 阶的平稳收敛。作者指出，由于 α 足够小时 GW-LR(r)_α = GW-LR(r)，该命题表明算法到达问题（5）的平稳点。收敛准则 Δ_α 强于 Ghadimi et al. (2013) 的广义投影梯度准则（§4）。

## 4. 实验与数字

实验在 MacBook Pro 2019 上运行，代码公开于 github.com/meyerscetbon/LinearGromov。所有合成实验重复 10 次取误差棒。比较对象：LR（Algo. 3，二次）、Lin LR（§5，线性）、Ent（Peyré et al. 2016 的三次实现）、Quad Ent（本文 Algo. 2，二次）、MREC（Blumberg et al., 2020）。

**Dykstra 迭代数不依赖 n**（Fig. 3）：对 10/15 维各向异性高斯混合，n = m = 100 到 5000，Dykstra 达到精度 δ = 1e−3 的迭代数不受样本量显著影响；外循环通常 ≤ 25 次收敛。

**合成低秩问题**（Fig. 5–7）：n = m = 5000，10 或 30 个各向异性高斯簇，10-D 与 15-D。欧氏距离下，LR 用 r = n/100 即获得与 Ent 相似的 GW loss，速度快几个数量级（Fig. 5）。平方欧氏距离下 Lin LR 与 Quad Ent 结论相同（Fig. 6–7，Fig. 7 为 n = m = 10000，5 或 20 簇）。

**大规模实验**（Fig. 8）：n = m = 1e5，单位正方形 2-D 采样，平方欧氏代价。此规模只有 Lin LR 可计算；GW loss 随 r 从 5 增到 500 而下降。

**单细胞基因组数据**（Fig. 4）：SNAREseq 数据集 n = m = 1047，R¹⁹；Splatter 数据集 n = m = 5000，R⁵⁰⁰。代价为 k-NN 图上的最短路径距离。LR 在 r = n/100 时达到与 Ent 相似的 GW loss，速度快几个数量级。FOSCTTM 指标上 LR、Ent、MREC 对齐性能相似，LR 对 r 的选择稳健。

**BRAIN 数据集**（Fig. 10）：n = 34079（基因表达）与 m = 27906（DNA 区域可及性），PCA 降到 50 维，平方欧氏距离。Lin LR 的匹配准确率一致优于 MREC（MREC 的 ε 取 1、0.01、0.0001 三个值），且对 rank r 稳健。

**超参数敏感性**（Fig. 9, Fig. 12）：γ 在 {100, 500, 1000} 内对时间-loss 权衡影响轻微；α 结论类似。其余实验固定 γ = 100，α = 10⁻¹⁰。

**rank 效应**（§6）：n = m = 5000，10 和 20 个簇的高斯混合，GW loss 随 r 增大而下降，直到 r = 20（数据中最大簇数）后饱和。

## 5. 在 OT×扩散地图中的位置

本文是 GW 计算线从「entropic 三次」到「可扩展」的关键转折点。它直接继承 Scetbon et al. (2021) 的低秩 OT 耦合约束，将其插入 GW 的镜像下降管线；同时利用距离矩阵的低秩结构（平方欧氏距离天然低秩）把代价更新线性化。与 Peyré et al. (2016) 的 entropic GW 是竞争关系——本文在相同 GW 目标上以低秩约束替代熵正则，实验显示 GW loss 相当但速度快几个数量级。与 MREC（Blumberg et al., 2020）的递归聚类路线是并行竞争，本文在 BRAIN 上准确率更高。

在课题 T26 的脉络中，本文是 moscot/OTT-JAX 规模化 GW 的算法基石：低秩耦合约束使 GW 在百万级细胞 atlas 上可算。它对应「计算线」的早期阶段，后续被 SDP 认证（NeurIPS 2024）和 CNT lifted 线性内存求解器（ICML 2026）在可认证性与可微性两个方向上超越，但其低秩耦合思想仍是当前最实用的规模化方案。对生成对齐线（GENOT、Wasserstein Flow Matching）而言，本文提供的是底层 GW 求解器，而非生成模型本身；GENOT 类方法若需在更大规模上估计 entropic GW 耦合，可直接受益于本文的线性时间近似。

## 6. 局限与批评

**作者承认的局限**（§6 Discussion）：
1. 步长 γ 的设置「在大多数实验中不成问题，但在困难情形下可能需要一些调参」以获得更快运行。
2. 达到线性时间的两个假设：距离矩阵的秩 d、d′ 必须被 n、m 支配（即数据内在维度远小于样本量）；耦合秩 r 必须足够小且能捕获输入测度的配置。作者称这些约束「在我们所知的大多数相关实验设置中成立」。

**读出来的局限**：
1. 低秩耦合约束改变了优化问题的可行域——作者明确说「我们的目标不再是逼近最优耦合，而是在众多低 GW 代价的解中促进低秩解」（§6 Discussion）。这意味着 Lin LR 找到的是 GW-LR(r) 的平稳点，而非原 GW 问题的平稳点；当真实最优耦合本身不是低秩时，存在不可消除的近似误差，且该误差没有理论刻画。
2. 对一般距离矩阵的低秩近似依赖 Bakshi & Woodruff (2018) 和 Indyk et al. (2019) 的算法，其保证是 Frobenius 范数意义下的相对误差（概率 ≥ 0.99），但本文实验中的单细胞数据用最短路径距离，作者自己承认「无法直接线性时间获得低秩分解」，因此只用 LR 而非 Lin LR（§6）。这说明线性时间声明在非欧氏、需先构图的应用中不成立。
3. Prop. 2 的步长 γ = 1/(2L_α) 依赖 L_α = 27(‖A‖₂‖B‖₂/α⁴)，α 是 g 的下界。α 取 10⁻¹⁰ 时 L_α 极大，理论步长极小；实验用 γ = 100 与理论步长差距巨大，理论保证与实际设置脱节。

## 7. 对我们的启发

1. **低秩耦合作为 GW 求解的默认加速器**：在需要批量估计 GW 耦合的生成对齐管线（如 GENOT 类方法的耦合先验估计）中，可优先用 Lin LR 或 LR 替代 entropic GW，尤其在样本量超过 1e4 时。注意：若代价矩阵是平方欧氏距离，直接走线性路径；若是图最短路径距离，只能走二次 LR 路径。
2. **rank r 的选择可对接聚类结构**：实验显示 GW loss 随 r 增大直到数据簇数后饱和（§6）。在单细胞跨组学对齐中，可先用聚类数或先验细胞类型数设定 r，避免盲目调参。这对医学 SB 或跨模态对齐中的耦合秩选择有直接参考价值。
3. **低秩分解的代价矩阵可复用**：平方欧氏距离的秩 d+2 分解（§3）是解析的，不需要额外计算。在扩散模型潜空间对齐（如不同分辨率扩散模型的潜变量缝合）中，若潜空间距离用平方欧氏度量，可直接套用本文的线性时间 GW 求解器，无需训练额外网络。
