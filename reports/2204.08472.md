# Simultaneous Multiple-Prompt Guided Generation Using Differentiable Optimal Transport

> Yingtao Tian, Marco Cuturi, David Ha · ICCC 2022 · [arXiv](https://arxiv.org/abs/2204.08472) · 证据级 [P] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：用可微 Sinkhorn OT 替换多 prompt 引导中的均值距离损失，缓解生成图像向 prompt 均值塌缩的问题。

## 1. 问题

本文处理的是文本引导图像生成中的一个具体缺陷：当用户提供多个文本 prompt 时，现有管线（以 VQGAN+CLIP 为代表）先把所有 prompt 嵌入取平均得到一个合成 prompt 向量，再把生成图像中随机采样的 patch 与这个合成 prompt 的距离取平均作为损失。作者指出，这种对「均值」的双重依赖会导致 mode collapse——整张图像被拉向所有 prompt 的平均语义，失去多 prompt 本应带来的空间多样性（Sec. Introduction, p.1-2）。

作者给出两个具体机制：其一，均值损失让所有 patch 被均匀地推向所有 prompt 的混合方向，无法对不同 patch 做差异化处理；其二，在 CLIP 嵌入空间做向量算术（取平均）隐含假设了欧氏空间，但 CLIP 是用 cosine 距离训练的，均值 prompt 向量可能落在没有对应语义的嵌入区域，引入不可控的冗余语义（Sec. Methodology, p.4）。论文的定位是 computational creativity 场景下的生成工具改进，不是提出新的生成模型。

## 2. 方法

核心思想：把「patch 集合」和「prompt 集合」看作两个离散概率分布，用熵正则最优传输（Sinkhorn）求它们之间的最优匹配，以 OT 损失替代均值距离损失。

**基线损失**（Eq. 1）：给定 $n$ 个 patch 编码 $u_i = E_I(x_i)$ 和 $m$ 个 prompt 编码 $v_j = E_T(t_j)$，均值损失为

$$F(z) = \text{Mean}_D(z) = \frac{1}{mn}\sum_{1\le i\le n, 1\le j\le m} D(u_i, v_j)$$

**提出的 OT 损失**（Eq. 5）：

$$F = L_\epsilon(a, b, [D(u_i, v_j)]_{i,j})$$

其中 $a_i = 1/n$，$b_j = 1/m$ 为均匀边际，代价矩阵 $C_{i,j} = D(u_i, v_j)$ 由 pairwise 距离填充。$L_\epsilon$ 是熵正则 Kantorovich 问题：

$$L_\epsilon(a,b,C) = \min_{P\in U(a,b)} \langle C, P\rangle - \epsilon H(P)$$

约束集 $U(a,b) = \{P \in \mathbb{R}^{n\times m}_+ : \sum_j P_{i,j}=a_i,\ \sum_i P_{i,j}=b_j\}$（Sec. Background, p.3）。

**梯度流**：作者用 Danskin 定理（envelope theorem）对 $L_\epsilon$ 关于 $C$ 求导，得到 $\partial L_\epsilon/\partial u_i$ 存在且处处有界（Eq. 4），然后通过链式法则回传到 latent 变量 $z$（Eq. 6）：

$$\nabla_z F = \left(\sum_{1\le i\le n} \frac{\partial L_\epsilon}{\partial u_i}\frac{\partial u_i}{\partial x_i}\frac{\partial x_i}{\partial x}\right)\frac{\partial x}{\partial z}$$

更新规则为 $z \leftarrow z - \gamma \nabla_z F$。实现上使用 OTT-JAX 的 Sinkhorn 求解器，保证可微性（Sec. Background, p.3-4）。

**分析工具**：作者定义 pushforward 映射 $\phi(u_i) = [D(u_i, v_1), \dots, D(u_i, v_m)]$，将 patch 嵌入空间的梯度推前到「cost plane」（$m$ 维距离空间），得到 $w_i = d\phi(\partial L_\epsilon/\partial u_i)$（Eq. 7）。$w_i$ 的第 $j$ 个分量表示该 patch 被推向第 $j$ 个 prompt 的梯度分量，用于可视化不同 patch 被不同 prompt 差异化引导的程度（Sec. Experiments, p.5）。

## 3. 理论结果

无定理或形式化保证。论文只引用了两个已知的 OT 性质作为方法动机：熵正则 OT 可用 Sinkhorn 算法高效求解（Cuturi 2013）；OTT-JAX 实现下 $L_\epsilon$ 对 $u_i$ 的梯度存在且处处有界（Eq. 4，原文标注为来自 OTT-JAX 的可微性，非本文证明）。作者在 Sec. Methodology 中给出三条定性论证（OT 对不同 patch 差异化处理、OT 不做嵌入空间算术、OT 对距离定义不可知），但均未形式化为命题或定理。

## 4. 实验与数字

实验设置：预训练 VQGAN（Imagenet 或 WikiArt 数据集），CLIP 编码器，$N=64$ 个随机采样 patch，1000 次 latent 更新迭代（Sec. Experiments, p.5-6）。对比基线为 Eq. 1 的均值损失，其余配置完全相同。

**两 prompt 实验**（prompts: "Walt Disney World." 与 "a daytime picture of Tokyo."）：

| 指标 | OT 方法 | Mean 基线 |
|---|---|---|
| 64 个 cutouts 中更接近 Prompt 0 的数量 | 36 | 49 |
| 64 个 cutouts 中更接近 Prompt 1 的数量 | 28 | 15 |

来源：Fig. 3(c)(d)。作者据此报告 OT 的 patch 分布更平衡（36/28 vs 49/15），且 OT 生成的 patch 中接近 "Walt Disney World." 的多为特写、接近 "daytime picture of Tokyo." 的多为远景（Sec. Experiments, p.6）。

**梯度方向可视化**（Fig. 4）：在 cost plane 上，OT 方法的 patch 梯度箭头呈「扇形发散」，不同 patch 被推向不同 prompt 的混合比例；基线方法的梯度方向均匀一致，不区分 prompt（Sec. Experiments, p.6）。

**六 prompt 实验**（Fig. 5）：使用 WikiArt 训练的 VQGAN，6 个 prompt 涵盖 Impressionism/Romanticism/Realism 三种风格与不同画家。作者报告 OT 方法能将多个 prompt 的风格与物体组合到同一画布上（Sec. Experiments, p.6-7）。Fig. 6 显示 3-prompt 和 6-prompt 设置下 cost plane 上的梯度发散行为仍然保持。

**定量比较的局限**：论文没有报告任何数值化的生成质量指标（如 FID、CLIP score、人工评分）。作者在 Sec. Experiments 开头明确说明「由于 text-to-image synthesis 的创造性本质，没有像分类准确率那样的标准衡量尺度」（p.5）。「quantitatively」在摘要中的含义指向 Fig. 3 的 cutout 计数和 Fig. 4/6 的梯度可视化，而非标准 benchmark 指标。

## 5. 在 OT×扩散地图中的位置

本文是课题 T16 中「生成式引导」路径的早期先驱，对应线 C 的起点。它第一次把可微 OT 耦合直接作为生成引导损失，用于 patch↔prompt 的跨域语义对应，时间上早于扩散模型成为主流的 OT 引导工作。

与后续工作的关系：
- **被 OTCS（NeurIPS 2023）在方法论上升级**：本文的 OT 是「当前生成图像 patch ↔ 文本 prompt」之间的匹配，边际是均匀分布；OTCS 把 OT 耦合用于非配对数据上的条件分数模型训练，处理的是「源分布 ↔ 目标分布」的传输，且给出了生成过程实现 OT 数据传输的理论界。本文没有理论保证。
- **与 ASAG（AAAI 2026）共享「OT 作为 attention/匹配结构的替代」动机**：本文替换的是 VQGAN-CLIP 管线的均值聚合，ASAG 替换的是扩散模型 cross-attention 的 softmax 归一化。两者都针对「局部贪心/均值聚合导致语义塌缩」这一共同根源，但接口不同。
- **与 Sinkformer（AISTATS 2022）同期**：Sinkformer 形式化了 softmax attention 与熵正则 OT 的关系，本文则是在生成引导损失层面直接使用 Sinkhorn，两者独立但共享「Sinkhorn 可微」这一技术基础。
- **方法上的正交性声明**：作者明确说该方法只改变 (patch, prompt) 距离的重组方式，与生成模型选择正交，是 mean 操作的 drop-in replacement（Sec. Introduction, p.2）。这一「正交插件」定位与后来 STORM、ASAG 等 training-free 采样期干预的思路一致，但本文作用于 VQGAN latent 优化而非扩散去噪过程。

在推理管线中，本文对应「引导损失设计」环节：用全局质量守恒匹配替代逐点独立聚合，是 OT 边际约束在生成引导中的最早落地之一。

## 6. 局限与批评

**作者承认的**：
1. 只验证了 VQGAN 一种生成模型，未来工作需扩展到 diffusion models 等其他生成范式（Sec. Conclusion, p.7）。
2. patch 采样只用随机采样，未探索 OT 与自适应采样的结合（Sec. Conclusion, p.7）。

**读出来的**：
1. **无标准定量评估**：论文声称「quantitatively better」，但唯一的数值是 Fig. 3 的 cutout 计数（36/28 vs 49/15），这是单次生成结果，无多次运行的均值/方差，无统计检验，无标准生成质量指标。摘要中的「quantitatively」证据强度很弱。
2. **均匀边际假设过强**：$a_i = 1/n$ 和 $b_j = 1/m$ 强制每个 patch 和每个 prompt 的质量相等。当用户希望某个 prompt 主导画面（如「背景」vs「主体」）时，均匀边际会强制所有 prompt 获得相同的 patch 分配，这本身就是一种不合理的先验。论文没有讨论非均匀边际或 unbalanced OT 的可能性。
3. **计算成本未报告**：Sinkhorn 迭代在每次 latent 更新中都要运行，但论文没有报告与均值基线相比的额外计算开销或运行时间。
4. **评估依赖主观观察**：Fig. 2 的「better diversity」、Fig. 5 的「composing instructions」均为作者主观判断，没有用户研究或人工评分协议。

## 7. 对我们的启发

1. **「均值聚合 → OT 匹配」的替换逻辑可迁移到扩散 attention 引导**：本文证明在 VQGAN-CLIP 管线中，把 patch-prompt 距离的均值重组换成 OT 耦合即可缓解语义塌缩。对应到扩散模型，cross-attention 的 softmax 归一化同样是「每个 query 独立做加权平均」，可考虑用 Sinkhorn 双随机归一化替换（接 Sinkformer/OTSeg 的接口化思路），在采样期做 training-free 干预。这与切入点 #2（ASAG 式 attention 干预）直接相关。
2. **均匀边际是本文的隐含弱点，也是可改进点**：本文用 $1/n$ 和 $1/m$ 的均匀边际，强制每个 prompt 获得等量 patch 质量。在多物体编辑场景中，用户对不同 prompt 的「语义预算」通常不同（主体 vs 背景）。可引入非均匀边际或 unbalanced OT，让 prompt 权重由用户指定或自适应学习，对应课题背景中 UNITE 的自适应质量学习思路。
3. **cost plane 可视化是廉价的诊断工具**：Eq. 7 的 pushforward 梯度可视化（Fig. 4/6）能直观显示不同 patch 被推向不同 prompt 的「混合比例」，成本低、无需额外训练。可将其改造为扩散模型 cross-attention plan 的诊断工具：把 attention 行向量推前到 prompt 距离空间，观察是否存在「所有 query 被推向同一 prompt」的塌缩模式，作为 OT 干预效果的定性验证手段。
