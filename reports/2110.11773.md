# Sinkformers: Transformers with Doubly Stochastic Attention

> Michael E. Sander, Pierre Ablin, Mathieu Blondel, Gabriel Peyré · AISTATS 2022 · [arXiv](https://arxiv.org/abs/2110.11773) · 证据级 [P] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：把 softmax attention 换成 Sinkhorn 双随机归一化，attention 可解释为 Wasserstein 梯度流，实验精度小幅提升。

## 1. 问题

Transformer 的自注意力机制对交互矩阵 $C$（其中 $C_{i,j} = (W_Q x_i)^\top W_K x_j$）做 SoftMax 归一化，得到行随机矩阵 $K_1$：每行和为 1，但列和不受约束（Sec. 1, Eq.(1)）。这意味着每个 query 独立地在所有 key 上分配注意力质量，没有全局约束来保证不同 query 之间的「语义预算」守恒。

作者观察到：在多个训练任务中，经典 Transformer 的注意力矩阵随训练 epoch 增加，列和逐渐趋近于 1，即行随机矩阵在训练过程中自发地接近双随机矩阵（Sec. 3, Figure 2）。这提示双随机性可以作为一个信息先验显式施加。此前用 Sinkhorn 做注意力归一化的工作要么用于排序网络（Tay et al., 2020）、要么用于 LSTM 编码器-解码器且用 Frank-Wolfe 求解（Niculae et al., 2018），没有人在 Transformer 自注意力上做 Sinkhorn 归一化并给出理论分析（Sec. 2）。

## 2. 方法

核心做法：把注意力模块中的 SoftMax 替换为 Sinkhorn 算法的输出。给定 $K_0 = \exp(C)$，Sinkhorn 迭代交替做行归一化和列归一化：

$$K_{l+1} = \begin{cases} N_R(K_l) & l \text{ 为偶数} \\ N_C(K_l) & l \text{ 为奇数} \end{cases} \tag{Eq.(3)}$$

其中 $(N_R(K))_{i,j} = K_{i,j} / \sum_l K_{i,l}$，$(N_C(K))_{i,j} = K_{i,j} / \sum_l K_{l,j}$。极限 $K_\infty = \text{Sinkhorn}(C)$ 是双随机矩阵。Sinkformer 的注意力更新为：

$$x_i \leftarrow x_i + \sum_{j=1}^n K^\infty_{i,j} W_V x_j \tag{Eq.(4)}$$

关键性质：Sinkhorn 的第 1 次迭代恰好等于 SoftMax，因此 Sinkformer 以 Transformer 为特例，迭代次数 $l$ 作为插值参数（Sec. 1, Sec. 3）。实际实现中通常用 3 到 5 次迭代即可近似收敛到双随机矩阵，训练时间与普通 Transformer 相当（Sec. 3）。Sinkhorn 全程可微，可直接用自动微分反传；若迭代次数成为内存瓶颈，可用隐函数定理计算 Jacobian（Sec. 3）。

另一个重要性质是代价函数的不变性：若代价加上可分离项 $\tilde{C}_{i,j} = C_{i,j} + f_i + g_j$，则 $\text{Sinkhorn}(C) = \text{Sinkhorn}(\tilde{C})$（Proposition 1）。因此可以用 $L_2$ 代价 $\tilde{C}_{i,j} = -\frac{1}{2}\|W_Q x_i - W_K x_j\|^2$ 替代内积代价而不改变 $K_\infty$。

## 3. 理论结果

**Proposition 2（PDE 对应）**：在对称性假设 $W_K^\top W_Q = W_Q^\top W_K = -W_V$（Assumption 1）下，定义能量泛函 $F_0(\mu) = \frac{1}{2}\int k_0 \, d(\mu \otimes \mu)$ 和 $F_\infty(\mu) = -\frac{1}{2}\int k_\infty \log(k_\infty / k_0) \, d(\mu \otimes \mu)$。则 $k_0$ 和 $k_\infty$ 分别生成 Wasserstein 梯度流 $T_\mu^0 = -\nabla_W F_0(\mu)$ 和 $T_\mu^\infty = -\nabla_W F_\infty(\mu)$；而 SoftMax 核 $k_1$ 生成的向量场是 $T_\mu^1 = -\nabla[\log(\int k_0(\cdot, x') d\mu(x'))]$，不是 Wasserstein 梯度（Sec. 4）。

**Proposition 3（SoftMax 非梯度流）**：$T_\mu^1$ 不是 Wasserstein 梯度，证明基于其缺乏对称性（Sec. 4）。这意味着 Sinkformer 可以解释为 argmin 层，而 Transformer 不能。

**Theorem 1（Sinkformer 的热扩散极限）**：设 $\mu$ 支撑在紧集上且有密度 $\rho \in C^3(\mathbb{R}^d)$，满足 Assumption 1 且 $W_K^\top W_Q$ 半正定。对带宽 $\varepsilon$ 缩放后的 Sinkhorn 核 $k_\varepsilon^\infty = \text{Sinkhorn}(c/\varepsilon)$，当 $\varepsilon \to 0$ 时，修正后的向量场 $\bar{T}_{\mu,\varepsilon}^\infty \to -\nabla\rho / \rho$（$L^2$ 范数），对应的 PDE 退化为热方程：

$$\partial_t \rho = \Delta \rho \tag{Eq.(6)}$$

**Proposition 4（Transformer 的非线性非局部 PDE）**：在同样极限下，使用 $L_2$ 代价的 SoftMax 注意力（$W_Q, W_K$ 可逆）对应的 PDE 是：

$$\partial_t \rho = \text{div}\left(W_Q^\top W_K^{-1} \frac{\nabla\rho}{\rho}(W_K^{-1} W_Q \cdot) \rho\right) \tag{Eq.(7)}$$

该方程关于 $\rho$ 非线性，且是非局部的——密度在 $x$ 处的演化依赖于 $W_K^{-1} W_Q x$ 处的密度值（Sec. 5）。作者指出，Sinkformer PDE 的线性局部性与 Transformer PDE 的非线性非局部性在去掉 $W_Q^\top W_K = -W_V$ 假设后仍然成立（Sec. 5）。

## 4. 实验与数字

实验覆盖 3D 形状分类、情感分析、机器翻译、图像分类四类任务，均使用 PyTorch 和 Nvidia Tesla V100 GPU（Sec. 6）。

**ModelNet 40 分类**（Table 1，4 次运行）：

| 模型 | Best | Median | Mean | Worst |
|---|---|---|---|---|
| Set Transformer | 87.8% | 86.3% | 85.8% | 84.7% |
| Set Sinkformer | 89.1% | 88.4% | 88.3% | 88.1% |
| Point Cloud Transformer | 93.2% | 92.5% | 92.5% | 92.3% |
| Point Cloud Sinkformer | 93.1% | 92.8% | 92.7% | 92.5% |

Set Sinkformer 用 21 次 Sinkhorn 迭代达到 89.1% 最佳精度，比 Set Transformer 的 87.8% 高 1.3 个百分点（Sec. 6.1）。Sinkhorn 迭代次数增加会提高精度（Figure 3）。Point Cloud 版本上 Sinkformer 的 best 精度 93.1% 略低于 Transformer 的 93.2%，但 median 精度 92.8% 高于 92.5%（Table 1）。

**IMDb 情感分析**：Sinkhorn 在 3 次迭代内完美收敛到双随机矩阵；训练时间每 epoch 为 Transformer 4m02s vs Sinkformer 4m22s（Sec. 6.2）。学习曲线显示 Sinkformer 精度更高（Figure 4），但原文未给出具体最终精度数字。

**IWSLT'14 德英机器翻译**（Table 2，6 次运行中位数 BLEU）：Transformer 训练 30 epoch 得 34.43；用训练好的 Transformer 权重直接评估 Sinkformer 得 33.81（标记 ⋆）；学习率除以 10 再训练 5 epoch 后，Transformer 得 34.68，Sinkformer 得 34.73。训练时间每 epoch 为 Transformer 2m48s vs Sinkformer 2m52s（Sec. 6.3）。Sinkhorn 只插入 encoder，因为 decoder 的因果 mask 阻止了直接应用（Sec. 6.3）。

**ViT 图像分类**：cats vs dogs 二分类任务上，median 测试精度 Transformer 79.0% vs Sinkformer 79.5%；最大测试精度 Transformer 80.0% vs Sinkformer 80.5%（5 次运行，Sec. 6.4）。训练时间每 epoch 为 Transformer 3m20s vs Sinkformer 3m25s。在 MNIST 上，单层单头自注意力模块（无前馈网络）的测试精度随 patch size 减小，Sinkformer 与 Transformer 的差距拉大（Figure 6）；patch size 为 1 时 Sinkformer 约 94%+，Transformer 约 92%+（Figure 6 读值，原文未给精确数字）。

## 5. 在 OT×扩散地图中的位置

这篇论文是「attention 即 OT」接口化的奠基工作，位于线 B 的起点。它形式化了 softmax attention 与熵正则 OT 的关系：SoftMax 是 Sinkhorn 的第 1 次迭代，即单边归一化的熵正则 OT 耦合；Sinkhorn 完整迭代给出双边归一化的 OT plan。这个「attention ≈ 熵正则 OT」的对应关系是后续所有 attention-OT 工作的理论接口。

与课题内其他工作的关系：
- **继承**：PLOT（ICLR 2023）把 OT 对齐搬到 prompt-token 集合层面，直接受益于 Sinkformer 建立的 attention-OT 对应；OTSeg（ECCV 2024）的 MPSA 模块本质上是把 Sinkformer 的双随机归一化推广到多模态解码器的 cross-attention。
- **被取代/升级**：STORM（CVPR 2025）和 ASAG（AAAI 2026）不再替换归一化，而是在采样期用带空间/对抗代价的 OT 操控 attention 的传输结构，属于「接口升级」。
- **理论张力**：Sinkformer 的 Theorem 1 证明双随机 attention 在无穷样本极限下退化为热扩散（线性、局部），而 softmax attention 退化为非线性非局部 PDE（Proposition 4）。这个「双随机 ⇒ 平滑扩散」的理论结论，与 GWOT-SC（BMVC 2025）发现 SD 特征 ensemble 的作用是提供空间平滑性形成呼应——双随机归一化本身就是一种空间平滑先验。

在推理管线中，这篇论文对应的是「attention 归一化层」这一环节：它证明把单边归一化换成双边归一化，等价于在 attention 层注入一个熵正则 OT 先验，且该先验有明确的变分解释（Wasserstein 梯度流）。

## 6. 局限与批评

**作者承认的**：
1. 机器翻译任务上，Sinkformer 的 BLEU 提升极小（34.68 vs 34.73，Table 2），且直接用训练好的 Transformer 权重评估 Sinkformer 反而下降（33.81 vs 34.43）。作者将此归因于 decoder 的因果 mask 阻止了 Sinkhorn 的完整应用，只在 encoder 插入（Sec. 6.3）。
2. Point Cloud Transformer 上 Sinkformer 的 best 精度 93.1% 低于 Transformer 的 93.2%（Table 1），提升主要体现在 median 和 worst 上。

**读出来的**：
1. 理论结果严重依赖 Assumption 1（$W_K^\top W_Q = W_Q^\top W_K = -W_V$），这是一个很强的对称性约束。作者在附录中声称去掉 $W_Q^\top W_K = -W_V$ 后 PDE 的线性/非线性对比仍然成立，但 Proposition 2 的 Wasserstein 梯度流解释在去掉该假设后是否成立，原文未给出完整论证（Sec. 4-5）。
2. 实验规模偏小：IMDb 和 cats vs dogs 都是小型任务，ViT 实验只用了单层单头或小规模设置，没有在 ImageNet 级别验证。精度提升幅度（0.5-1.3 个百分点）在统计显著性上未做检验。
3. Sinkhorn 迭代次数是超参数，且作者只考虑奇数次迭代以保持行随机性（Sec. 6.1），这意味着实际使用的矩阵并非完全双随机，而是「更接近双随机」的行随机矩阵。理论分析针对的是 $K_\infty$，实验用的是有限迭代的 $K_l$，两者之间存在 gap。

## 7. 对我们的启发

1. **双随机归一化作为免训练的 attention 平滑先验**：Sinkformer 证明把 softmax 换成 Sinkhorn 不需要改网络结构、不需要额外训练目标，就能给 attention 注入全局质量守恒约束。在扩散模型的 cross-attention 上，这可以作为一种 training-free 的干预手段：对去噪过程中的 attention map 做 Sinkhorn 双随机化，强制不同 query token 的语义预算守恒，可能缓解 many-to-one 错配。可接切入点 #1 的免训练方向，在 SDEdit 管线上测试属性泄漏率。

2. **Sinkhorn 迭代次数作为插值旋钮**：Sinkformer 用迭代次数 $l$ 在「Transformer（$l=1$）」和「完全双随机（$l=\infty$）」之间连续插值。这提供了一个可调节的「OT 先验强度」参数。在扩散采样中，可以在早期去噪步用较大的 $l$（强全局约束），后期用较小的 $l$（保留局部细节），对应切入点 #2 的 OT-aware 采样调度思想。

3. **代价不变性（Proposition 1）的实用价值**：Sinkhorn 输出对代价的可分离项不敏感，意味着可以用 $L_2$ 代价替代内积代价而不改变 attention plan。这为在扩散 attention 中设计空间代价（如 STORM 的空间距离代价）提供了理论依据：只要代价差异是可分离的，Sinkhorn plan 不变，可以放心地把几何先验编码进代价函数而不破坏 OT 结构。
