# Shape-of-You: Fused Gromov-Wasserstein Optimal Transport for Semantic Correspondence in-the-Wild

> Im et al. · CVPR 2026 · [arXiv](https://arxiv.org/abs/2603.11618) · 证据级 [P] · 课题 T16 OT 代价先验引导的跨域语义对应
> **一句话**：用 3D 几何结构做 FGW 伪标签，anchor 线性化降计算，SPair-71k 达 67.9% PCK@0.1

## 1. 问题

本文解决 in-the-wild 语义对应（semantic correspondence）任务：在无显式几何标注（相机位姿、3D 模型、视角）的条件下，为同一类别不同实例建立像素级对齐。此前无标注方法依赖 2D 基础模型（DINO、Stable Diffusion）特征，通过最近邻（NN）匹配生成伪标签来训练适配器（如 ASIC [8]、DistillDIFT [7]）。作者指出 NN 匹配有两个根本缺陷（Sec. 1）：第一，它在特征空间中局部操作，忽略全局信息，无法验证整幅图像上匹配的几何一致性；第二，2D 模型仅用外观线索训练，无法反映真实 3D 几何结构。这导致「语义上合理但几何上错误」的对应，在对称结构或重复特征处产生歧义，训练噪声降低性能。

## 2. 方法

核心思想：把伪标签生成重新表述为 Fused Gromov-Wasserstein（FGW）最优传输问题，联合优化特征间相似性（Wasserstein 项）与实例内几何结构一致性（GW 项）。几何结构由 3D 基础模型 VGGT [33] 从 2D 图像提升到 3D 点云获得，而非在 2D 特征空间中定义。

**伪标签生成流程（Sec. 3，两阶段）：**

1. **语义 UOT 初始化（t=0）**：用 SAM [11] 分割实例区域，提取 patch 的语义特征（DINOv2 + SD）与 3D 坐标（VGGT + 双线性插值）。计算语义代价 $C^{\text{sem}}_{ij} = 1 - S_{ij}$（$S_{ij}$ 为 patch 特征的余弦相似度）。用不平衡 OT（UOT，Eq. (3)）求解初始传输计划 $\pi^{(0)}$，以处理遮挡和非重叠区域。

2. **Anchor 线性化 FGW 精化（t>0）**：原始 GW 目标（Eq. (5)）是 $\pi$ 的二次型，非凸且 NP-hard。作者用 anchor 传输计划 $\hat{\pi}$ 替换其中一个二次项（$\pi_{i'j'}$），将其线性化。每轮迭代从 $\pi^{(t-1)}$ 中选 $K=64$ 个高置信度 anchor 对，选择标准是匹配空间与 3D 几何的双重循环一致性（cycle-consistency），3D 循环误差低于阈值 $\delta$ 才保留。线性化后的几何代价为：

$$\mathcal{L}_{\mathrm{GW}}(\pi) \approx \sum_{i,j} \pi_{ij} \left( \frac{1}{K}\sum_{(a_A,a_B) \in \mathcal{A}^{(t)}} \big| D^{A}_{i,a_A} - D^{B}_{j,a_B} \big| \right) \tag{Eq. (6)}$$

其中 $D^A_{ik} = \|v^A_i - v^A_k\|_2$ 是 3D 坐标的实例内成对距离。融合代价为 $C^{\text{total}} = (1-\alpha)\tilde{C}^{\text{sem}} + \alpha \tilde{C}^{\text{geo}}$（Eq. (7)），$\alpha=0.3$，两者先归一化。用 $C^{\text{total}}$ 重新求解 UOT（Eq. (8)）得到 $\pi^{(t)}$，迭代 $T$ 轮。

**训练管线（Sec. 4）：**

- 用 $\pi^{(T)}$ 训练轻量精化网络 $f_\theta$（架构同 [40]），输入为 DINOv2 + SD 多尺度特征。
- 训练前用 relaxed cycle consistency [5] 过滤伪标签，保留 top-k 候选构造多热目标 $\pi^{\text{hard}}$。
- **软目标损失**：将 $\pi^{\text{hard}}$ 与网络当前特征求出的 OT 计划 $\pi^{\text{curr}}$ 混合（Eq. (9)），$\pi^{\text{soft}} = (1-\beta)\pi^{\text{hard}} + \beta\pi^{\text{curr}}$，$\beta=0.5$。$\pi^{\text{curr}}$ 计算时停止梯度。损失为对称软监督对比损失（Eq. (10)）。
- **稠密对应损失**：soft-argmax 预测目标位置，加高斯噪声正则（Eq. (11)）。
- 总损失 $L_{\text{total}} = L_{\text{soft}} + L_{\text{dense}}$。

推理时丢弃迭代优化管线，仅用训练好的网络做 NN 匹配 + soft-argmax。

## 3. 理论结果

无理论结果。作者明确指出完整 FGW 目标是非凸二次规划，NP-hard（Sec. 3，引用 [32]），标准求解器只能保证收敛到局部驻点。本文的 anchor 线性化是计算近似，不提供收敛性保证或误差界。

## 5. 在 OT×扩散地图中的位置

本文是判别式语义对应线（线 A）的最新节点，直接继承 SCOT（语义对应即 OT）→ GWOT-SC（GW 结构项 + DINOv2 特征）的代价设计演化，把 GW 结构项从 2D 特征空间搬到 3D 几何空间，并用 FGW 显式融合外观与结构代价。与 GWOT-SC 的关系是「继承并替换结构空间」：GWOT-SC 用 SD 特征的空间平滑性做结构项，本文用 VGGT 的 3D 点云距离做结构项，并引入 anchor 线性化解决 GW 二次型计算问题。与 UNITE 的关系是「共享 UOT 工具」：UNITE 用不平衡 OT 处理跨域质量不守恒，本文用 UOT 处理遮挡/部分可见。与 KPG-RL 的关系是「先验注入的另一种形态」：KPG-RL 用 keypoint mask 约束 plan 可行域，本文用 3D 结构代价约束 plan 的几何一致性。

在 OT×扩散地图中，本文占据「判别式对应的代价设计」环节，尚未进入扩散采样/训练管线。其 FGW plan 是概率性软对应，天然适合作为切入点 #1（FGW 对应闭环进扩散采样）的 correspondence 一致性损失来源。其 soft-target loss 中「网络当前 OT plan 与几何 guide 动态混合」的思路，与切入点 #3（attention plan 偏离最优耦合的定量理论）有概念呼应：两者都隐含「网络自身的传输结构需要被外部几何先验校正」的假设，但本文未给出理论刻画。

## 6. 局限与批评

**作者承认的（Sec. 6 Limitations）：**
1. 依赖 3D 基础模型，VGGT 在平坦重建或透明表面上可能失败。
2. 严重几何歧义（如中距离视角下的对称汽车部件）可导致 anchor 匹配错误。
3. soft target 有时会过度平滑几何信号。

**读出来的：**
1. **anchor 线性化无误差界**：Eq. (6) 用 $K=64$ 个 anchor 的均匀分布 $\hat{\pi}$ 替换 GW 二次项，但未分析该近似与真实 GW 目标的偏差。当 anchor 分布偏离真实匹配结构时（如对称部件场景），线性化代价可能系统性误导 plan。作者在 Limitations 中承认的对称部件失败正是此问题的表现。
2. **伪标签质量上限受 SAM 分割约束**：PCKlabel 指标只在 SAM mask 内的 ground-truth 对上评估（Sec. 5.1），这意味着 SAM 分割错误直接排除在评估之外，实际部署中的分割失败影响未量化。
3. **baseline 比较的公平性依赖重评估**：DistillDIFT 和 DINOv2+SD 被作者重评估（† 标记），原始论文的数字不可直接对比。DINOv2+SD 是作者自己建立的零样本基线，不是已发表方法的原始报告数字。

## 7. 对我们的启发

1. **FGW plan 作为扩散编辑的 correspondence 先验（接切入点 #1）**：本文的 $\pi^{(T)}$ 是概率性软对应，且已在 3D 几何空间中验证一致性。可直接将其作为 SDEdit/FlowEdit 编辑管线中「源图 ↔ 当前去噪 latent」的 correspondence 一致性损失权重，每 $k$ 步用扩散特征重算 FGW plan 做梯度引导。与 P2P/MasaCtrl 的 attention 注入基线对比时，本文的 3D 结构项可专门针对对称/重复纹理场景（本文已证明 2D 方法在此失败）。
2. **anchor 线性化是「免训练 batch 级 OT 干预」的低成本模板（接切入点 #2）**：本文证明 $K=64$ 个 anchor 足以近似 GW 结构代价。在扩散采样期的 attention 干预中，可以用类似策略：从当前 attention map 中选高置信度 anchor 对，线性化结构代价后做轻量 UOT 重分配，避免每步求解完整 GW。这比 ASAG 的对抗代价 Sinkhorn 更轻，适合多物体编辑场景的实时干预。
3. **soft-target 动态混合是「保耦合蒸馏」的现成配方（接切入点 #3）**：Eq. (9) 的 $\pi^{\text{soft}} = (1-\beta)\pi^{\text{hard}} + \beta\pi^{\text{curr}}$ 提供了一个「外部几何 guide 与网络自身判断」的混合模板。在把判别式对应网络蒸馏进扩散模型（或反过来）时，可以用同样的动态混合策略防止学生网络被教师 plan 中的噪声过度约束。本文 Table 4 显示 soft target loss 单独贡献 +0.4%p（67.5 vs 67.1），说明该机制有效但增益有限，蒸馏场景中可能需要更大的 $\beta$ 调度。
