# Expected Batch Optimal Transport Plans and Consequences for Flow Matching

> Samuel Boïté, Julie Delon, Kimia Nadjahi · arXiv 2026 · [arXiv](https://arxiv.org/abs/2605.12174) · 证据级 [R] · 课题 T08 OT-CFM 与 minibatch OT 耦合
> **一句话**：作者报告：期望 batch OT 耦合 π̄_k 在半离散情形以 O(k^{-1/2})（紧支撑 O(k^{-1})）收敛成本偏差、以 O(k^{-1/4}) 收敛 plan，其 FM 速度场良定；增大 batch 主要改善低 NFE 采样。

## 1. 问题

Flow matching（FM）的训练目标依赖 source 分布 μ 与 target 分布 ν 之间的一个耦合 π。独立耦合 μ⊗ν 实现简单，但导致推理时数值积分步数（NFE）高；精确 OT plan π⋆ 在原理上可给出直线路径、一步积分即可，但高维下不可解。Minibatch OT 是折中：在每个大小为 k 的随机 batch 内解 OT，用匹配后的样本对训练 FM（Pooladian et al., 2023a; Tong et al., 2024）。

但 minibatch OT 作为替代方案，其总体层面的行为未被精确刻画。具体缺口有三：第一，minibatch OT 相对精确 OT 的偏差——无论是传输成本还是 plan 本身——没有被定量给出；第二，minibatch OT 诱导的速度场是否定义良定的流（well-posed flow）不清楚，因为一个耦合不一定是可整流的（rectifiable）（Hertrich et al., 2025）；第三，近期 benchmark 提示 minibatch OT-FM 的收益可能只在远大于常规训练 batch 的 OT batch 上才出现（Zhang et al., 2025），而 semidiscrete OT 也能改善 FM（Mousavi-Hosseini et al., 2025），因此「训练时增大 OT batch」与「推理时增大 NFE」之间的实际权衡不明确。

## 2. 方法

核心对象是**期望 batch OT plan** π̄_k：先从 μ⊗k ⊗ ν⊗k 中抽取随机 batch (X_k, Y_k)，在经验测度 μ̂_k 与 ν̂_k 之间解 OT 得到经验 plan π̂_k，再从中均匀随机选一个匹配对，其分布即为 π̄_k（Definition 3.1）。该构造在完全离散情形退化为 Fatras et al. (2021b) 的平均 minibatch 传输矩阵，也与 Pooladian et al. (2023a) 的 marginalized minibatch coupling q^{(k)} 一致。π̄_k ∈ Π(μ, ν)，且 π̄_1 = μ⊗ν（Section A.1.3）。

关键公式：

- 成本恒等式（Proposition 3.2）：
$$\int_{\mathbb{R}^d\times\mathbb{R}^d} \|x-y\|^2\, d\bar{\pi}_k(x,y) = \mathbb{E}[W_2^2(\hat{\mu}_k, \hat{\nu}_k)].$$

- FM 速度场的后验表示（Lemma 4.1，Gaussian-to-discrete 情形）：
$$u_t^{\pi}(x) = \frac{m_t^{\pi}(x) - x}{1-t}, \quad m_t^{\pi}(x) = \mathbb{E}_{\pi}[X_1 \mid X_t = x] = \sum_{j=1}^{M} v_j\, P_{(X_0,X_1)\sim\pi}(X_1 = v_j \mid X_t = x),$$
其中后验权重由
$$P(X_1 = v_j \mid X_t = x) = \frac{f_{\pi}\!\left(\frac{x - t v_j}{1-t}, v_j\right)}{\sum_{\ell=1}^{M} f_{\pi}\!\left(\frac{x - t v_\ell}{1-t}, v_\ell\right)}$$
给出（式 (2)–(3)）。

- Euler 积分误差（式 (4)）：对 n 个均匀时间步 t_j = j/n，
$$f_{j+1,n}^{\pi} = \left(\mathrm{id} + \frac{1}{n} u_{t_j}^{\pi}\right) \circ f_{j,n}^{\pi}, \quad E_{n,k} = \mathbb{E}_{X_0\sim\mu}\left[\|f_n^{\bar{\pi}_k}(X_0) - \phi^{\bar{\pi}_k}(X_0)\|\right].$$

图像实验流程：对 CIFAR-10 与 SVHN，ν 取归一化到 [−1,1]^{3072} 的 flattened 图像上的均匀经验测度；固定优化 minibatch 大小，仅变化 OT batch size k ∈ {1, 2, 4, …, 8192}；每个 k 训练一个独立 flow 模型，用精确 OT 耦合（batch 内 Hungarian）训练；采样用显式 Euler，按指定 NFE 生成，以 FID 评估；每个 k 报告 6 个训练种子的 FID（Section 4.5）。

## 3. 理论结果

**成本偏差的收敛与速率（Proposition 3.3）**：

1. 序列 (E[W_2^2(μ̂_k, ν̂_k)])_{k∈N*} 非增；若 μ, ν ∈ P_q(R^d)（q > 2），则 lim_{k→∞} E[W_2^2(μ̂_k, ν̂_k)] = W_2^2(μ, ν)。
2. 若 μ 紧支撑、ν 为有限支撑上的均匀分布、且对偶 OT 问题有唯一非退化解，则 E[W_2^2(μ̂_k, ν̂_k)] − W_2^2(μ, ν) = O(k^{-1})。
3. 若 μ ∈ P_q(R^d)（q > 4）且 ν 为有限支撑均匀分布，则偏差为 O(k^{-1/2})。

作者强调：由于 semidiscrete 结构，这些速率避开了完全离散情形中出现的对维度 d 的指数依赖（Fournier and Guillin, 2015）。O(k^{-1/2}) 来自 Hundrieser et al. (2024) 的 semidiscrete 估计；更快的 O(k^{-1}) 利用了带符号期望（signed expectation）与 semidiscrete 对偶目标在极大值附近的局部二次曲率（Del Barrio et al., 2024）加经验过程界。

**Plan 的收敛与速率（Proposition 3.4）**：设 μ 对 Lebesgue 测度绝对连续（保证 π⋆ 唯一）。则 π̄_k 弱收敛到 π⋆。此外：

1. 对任意 k ≥ 1，
$$W_2^2(\bar{\pi}_k, \pi^\star) \geq \frac{1}{2}\left((\mathbb{E}[W_2^2(\hat{\mu}_k, \hat{\nu}_k)])^{1/2} - W_2(\mu, \nu)\right)^2.$$
2. 若 μ = N(0, I_d) 且 ν 为有限集上的均匀分布，则存在 A_ν > 0 使
$$W_2^2(\bar{\pi}_k, \pi^\star) \leq A_\nu\left(\mathbb{E}[W_2^2(\hat{\mu}_k, \hat{\nu}_k)] - W_2^2(\mu, \nu)\right)^{1/2} = O(k^{-1/4}).$$

作者还证明：对任意 π ∈ Π(μ, ν)，不存在用成本偏差控制 W_2^2(π, π⋆) 的通用模量（Section A.5.4），即 plan 收敛需要额外假设。

**FM 良定性（Proposition 4.2，Gaussian-to-discrete 情形）**：对任意 k ∈ N*，π̄_k 是可整流的：

1. 对任意紧集 K ⊆ R^d，(t, x) ∈ [0,1) × K ↦ u_t^{π̄_k}(x) 联合连续；对任意 τ ∈ (0,1)，在 x 上局部 Lipschitz，且对 t ∈ [0, τ] 一致。
2. ODE ẋ(t) = u_t^{π̄_k}(x(t)), x(0) = x_0 在 [0,1) 上有唯一解，记为 t ↦ φ_t^{π̄_k}(x_0)；对任意 t ∈ [0,1)，x_0 ↦ φ_t^{π̄_k}(x_0) 连续，且 (φ_t^{π̄_k})_♯ μ = ρ_t^{π̄_k}。
3. 存在 Borel 映射 φ^{π̄_k} : R^d → {v_1, …, v_M}，使 φ^{π̄_k}(x_0) = lim_{t↑1} φ_t^{π̄_k}(x_0) 对 μ-a.e. x_0 成立，且 (φ^{π̄_k})_♯ μ = ν。

作者称这是 minibatch OT 耦合在 FM 中的首个 rectifiability 结果。

**NFE 与 batch size 的渐近比较（Proposition 4.3，两原子模型）**：设 μ = N(0,1)，ν = Unif{−1, 1}。则
$$\log E_{n,1} \sim -\frac{2\pi}{\sqrt{3}} n^{2/3} \quad (n\to\infty), \qquad \log E_{1,k} \sim -\frac{1}{2}\log k \quad (k\to\infty).$$
即增大 Euler 步数 n 使积分误差以 exp(−c n^{2/3}) 衰减，而增大 OT batch size k 只给出 k^{-1/2} 型衰减。

## 4. 实验与数字

**数值收敛速率（Section 3.4, Figure 2）**：μ = N(0, I_d)，ν 为从 [−1,1]^d 均匀抽取后固定的 M 个原子，d ∈ {10, 1000}，M ∈ {5, 10, 50}。观测到成本偏差按 O(k^{-1}) 衰减，快于 Theorem 3.3 的 O(k^{-1/2}) 界；E_{(X,Y)∼π̄_k}[‖Y − T⋆(X)‖^2]（W_2^2(π̄_k, π⋆) 的上界）按 O(k^{-1/2}) 衰减。作者指出有限样本区间比渐近区间慢，且实验提示 O(k^{-1}) 成本速率可能在 μ 为 Gaussian（无界支撑）时仍成立。

**后验集中（Section 4.3, Figure 4）**：Gaussian-to-discrete，M = 100 个原子。E[max_i P(X_1 = v_i | X_t)] 随 k 增大而增大（d = 20 固定）；k = 1 时随维度 d 增大而增大。后者此前被 Bertrand et al. (2025) 观测到，本文在 Section B.3 给出定量陈述。

**Euler 误差（Section 4.4, Figures 5–6）**：两原子模型中，将 NFE 从 25 降到 10 需要把 k 从 1 增到 90 才能补偿（Figure 5）。在 d = 20、M = 100 的 Gaussian-to-discrete 设置中，数值积分误差与 n 的 1/n 标度、与 k 的 1/√k 标度一致（Figure 6）；误差在小 k 处非单调。

## 5. 在 OT×扩散地图中的位置

本文直接继承并补全 Pooladian et al. (2023a)（Multisample FM）与 Fatras et al. (2021b)（minibatch OT 平均传输矩阵）的路线：把 minibatch OT 耦合从训练启发式提升为有总体定义的 π̄_k，并给出其大 batch 一致性、成本偏差速率、plan 收敛速率与 FM 良定性。在 OT-CFM 与 minibatch OT 耦合（T08）课题中，它正面回应了「batch 有限时期望 batch 耦合 π_k 边缘正确但并非真 OT plan，偏差受维度诅咒支配且不随训练消失」这一核心张力：本文证明在半离散情形偏差以 O(k^{-1/2})（紧支撑 O(k^{-1})）消失，且给出 plan 的 O(k^{-1/4}) 收敛速率，是首个针对该偏差的定量理论。

与 Zhang et al. (2025)（大 Sinkhorn 耦合）和 Mousavi-Hosseini et al. (2025)（semidiscrete 耦合 FM）的关系：本文用精确 batch OT（Hungarian）而非熵正则 Sinkhorn，且明确将 k 与 NFE 解耦扫描；Zhang et al. 研究的是远大于常规训练 batch 的 entropic OT 耦合，本文则覆盖 k 从 1 到 8192 的精确 OT。在推理管线环节上，本文的 Proposition 4.3 与 Figure 5–7 直接量化「训练时 OT batch size」与「推理时 NFE」之间的不对称：增大 k 主要改善低 NFE 采样，高 NFE 下收益消失甚至反转。这为「扩大 n（大规模 Sinkhorn）」与「跨 batch 全局化（半离散 OT）」两条修正路线提供了成本-收益的定量参照。

## 6. 局限与批评

**作者承认的**：

1. 多数定量结果限于 semidiscrete 情形（μ 绝对连续、ν 有限离散），更一般的 source-target 配置的收敛速率与结构性质未给出（Section 5, Limitations）。
2. 理论分析针对耦合诱导的**真实速度场**，而实际 FM 依赖神经网络学到的近似速度场；正则性、rectifiability 与低 NFE 收益如何迁移到 learned velocity 是未解决的下一步（Section 5）。
3. NFE 与 batch size 的理论比较仅在一维两原子模型、Euler 方法下得到；一般 En,k 的界与其他数值格式未解决（Section 5）。

**读出来的**：

1. 图像实验的 FID 改善幅度在低 NFE 下存在，但原文未给出 FID 的精确数值表，且 SVHN 上高 NFE 时大 k 反而轻微恶化——这说明「增大 k」并非单调收益，实际部署需要按 NFE 预算调参。
2. Proposition 3.4(2) 的 plan 收敛速率 O(k^{-1/4}) 依赖 μ = N(0, I_d) 这一强假设；作者自己的数值实验（Figure 2 右）显示上界按 O(k^{-1/2}) 衰减，暗示理论速率可能可改进，但当前证明未覆盖。
3. 精确 batch OT 在 k = 8192 时训练开销增加 55%（Table 2），而 FID 收益集中在低 NFE 区间；若推理预算本身充足，这笔训练开销的性价比存疑。作者未与 entropic/sliced 等更便宜的 batch 耦合做对比（Section 4.5 明确留作未来工作）。

## 7. 对我们的启发

1. **OT batch size 的收益有明确的 NFE 条件**：本文 Figure 7 与 Proposition 4.3 表明，增大 k 只在低 NFE 区间（CIFAR-10 上 NFE=10，SVHN 上 NFE=5–10）有实质 FID 改善，高 NFE 下收益消失甚至反转。若我们的推理管线固定用低 NFE（如医学 SB 的快速采样场景），可优先考虑增大 OT batch；若 NFE 预算充足，训练开销的投入应转向其他方向。这直接支持「OT-aware 采样调度」类切入点的设计：按目标 NFE 决定是否启用大 batch OT 训练。
2. **π̄_k 的 rectifiability 为 batch 级耦合蒸馏提供理论依据**：Proposition 4.2 证明 π̄_k 诱导的速度场在 [0,1) 上局部 Lipschitz、生成唯一流、且终端映射存在。这意味着用 π̄_k 训练出的目标速度场本身是良定的 ODE 场，可以作为蒸馏的教师信号——保耦合蒸馏（切入点 #3）可以放心使用 batch OT 耦合作为教师，而不必担心教师场本身不可积分。
3. **成本偏差的 O(k^{-1}) 紧支撑速率提示：对 target 做紧支撑化处理可能加速收敛**：Proposition 3.3(2) 的 O(k^{-1}) 比一般矩条件下的 O(k^{-1/2}) 快一倍，且数值实验（Figure 2 左）显示 Gaussian 源也呈现 O(k^{-1})。若我们的 target 数据本身有界（如图像像素归一化到 [−1,1]），则 batch OT 的成本偏差可能实际按 O(k^{-1}) 衰减，这比理论保证的 O(k^{-1/2}) 更乐观，可用于指导 batch size 的选择。
