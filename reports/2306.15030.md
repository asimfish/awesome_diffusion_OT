# Equivariant flow matching

> Leon Klein et al. · NeurIPS 2023 · [arXiv](https://arxiv.org/abs/2306.15030) · 证据级 [P] · 课题 T08 OT-CFM 与 minibatch OT 耦合
> **一句话**：把 batch OT 的欧氏成本换成旋转+置换对齐后的不变成本，让等变 CNF 在小 batch 下逼近 OT 路径。

## 1. 问题

本文要解决的是：在训练等变连续归一化流（CNF）时，用 OT flow matching 的 minibatch 近似无法得到接近最优传输（OT）的直线积分路径，因为目标分布具有高度对称性。

具体来说，OT flow matching 在每个 batch 内解离散 OT 问题，用欧氏平方距离 $c(x_0,x_1)=\|x_0-x_1\|_2^2$ 作为成本（Eq.(12)）。当目标分布是置换不变（$S(N)$）和旋转不变（$O(D)$）的 Boltzmann 分布时，两个样本在欧氏距离下可能很远，但在某个置换或旋转对齐后其实很近。作者指出：置换数量随可交换粒子数按 $N!$ 增长，而 batch 内样本对组合数只按 batch size 平方增长，因此「即使对于小系统，任何 target-prior 样本对 $(x_0,x_1)$ 恰好共享同一置换的可能性都很低」（Sec.4）。结果是 minibatch OT 配对质量差，训练出的向量场高度弯曲（Figure 1d），推理需要更多积分步数。作者报告，在 LJ55 上 OT flow matching 的训练对平均 batch 传输成本约为 equivariant OT flow matching 的 10 倍（Figure 2b），积分路径长度约为 2 倍（Figure 2a,c）。

此前方法不够的原因：likelihood-based 训练 CNF 需要反复积分 ODE 并计算 Jacobian 迹，计算昂贵（Sec.3.3）；OT flow matching 虽然 simulation-free，但其欧氏成本没有利用目标能量的对称性，导致有限 batch 下 OT 近似很差。

## 2. 方法

核心思想：把 OT flow matching 的 batch 内成本函数从欧氏平方距离换成群对齐后的最小平方距离，即

$$\tilde c(x_0,x_1)=\min_{g\in G}\|x_0-\rho(g)x_1\|_2^2 \tag{Eq.(13)}$$

其中 $G$ 是目标分布的对称群。对本文关注的 $O(D)$ 旋转/反射与 $S(N)$ 置换，精确成本为

$$\tilde c(x_0,x_1)=\min_{r\in O(D),\,s\in S(N)}\|x_0-\rho(rs)x_1\|_2^2 \tag{Eq.(15)}$$

由于对所有旋转×置换组合求最小在计算上不可行，作者用顺序搜索近似：先用 Hungarian 算法求最优置换 $\tilde s$，再用 Kabsch 算法求最优旋转 $r$：

$$\tilde c(x_0,x_1)=\min_{r\in SO(D)}\|x_0-\rho(r\tilde s)x_1\|_2^2,\quad \tilde s=\arg\min_{s\in S(N)}\|x_0-\rho(s)x_1\|_2^2 \tag{Eq.(16)}$$

训练流程（Sec.4）：对每个 batch，先采样 prior 和 target 样本；对成本矩阵 $M$ 的每个元素，先用 Hungarian 算法算最优置换，再用 Kabsch 算法做旋转对齐；然后按修改后的成本矩阵解离散 OT 问题；用 OT 解给出的配对 $(x_0,x_1)$ 作为条件变量 $z$，按 Eq.(10)-(11) 的 OT 条件路径训练，即 $u_t(x|z)=x_1-x_0$，$p_t(x|z)=\mathcal N(x\mid t x_1+(1-t)x_0,\sigma^2)$。作者称此损失为 Equivariant OT flow matching。

向量场架构（Sec.5）：$O(D)$- 和 $S(N)$-等变图神经网络，类似 [18] 所用、源自 [54]。更新规则见 Eq.(17)-(20)，其中 Eq.(18) 的坐标更新在同类粒子下保持几何中心，否则在最后一层后减去几何中心。配合 mean-free 高斯先验，push-forward 分布保持 $O(D)$- 和 $S(N)$-不变。

## 3. 理论结果

有一个定理（Theorem 1，Sec.4），假设 $G$ 是紧群、以等距作用在欧氏空间上，$T$ 是 $G$-不变测度 $\nu_1,\nu_2$ 之间以成本 $c$ 的 OT 映射。结论三条：

1. $T$ 是 $G$-等变的，对应 OT plan $\pi(\nu_1,\nu_2)$ 是 $G$-不变的；
2. 对所有 $(x,T(x))$ 和 $y\in G\cdot T(x)$，有 $c(x,T(x))=\int_G c(g\cdot x,g\cdot T(x))\,d\mu(g)=\min_{g\in G}c(x,g\cdot y)$（Eq.(14)）；
3. $T$ 也是成本 $\tilde c$ 下的 OT 映射。

作者据此论证：目标 OT 映射 $T$ 是 $G$-等变的，所以用 $G$-等变流模型学习是自然的；且 $\tilde c$ 对齐样本对的方式与 $G$-等变 OT 映射 $T$ 下的对齐方式一致。推导在 Appendix B.1。注意：该定理没有给出 minibatch 近似误差或有限 batch 下的收敛保证，也没有对 Eq.(16) 顺序近似与 Eq.(15) 精确成本的差距给出理论刻画。

## 4. 实验与数字

四个数据集：DW4（4 粒子双阱）、LJ13（13 粒子 Lennard-Jones）、LJ55（55 粒子 Lennard-Jones 簇）、alanine dipeptide（丙氨酸二肽，Cartesian 坐标，GFN2-xTB 半经验力场）。三个训练目标对比：likelihood-based、OT flow matching、equivariant OT flow matching。所有实验用 mean-free 高斯先验（Sec.6）。误差为三次运行（Table 1 注）。

**Table 1 关键数字**（NLL↓ / ESS↑ / path length↓）：

| 数据集 | 训练目标 | NLL | ESS | Path length |
|---|---|---|---|---|
| DW4 | Likelihood | 1.72±0.01 | 86.87±0.19% | 3.11±0.04 |
| DW4 | OT FM | 1.70±0.02 | 92.37±0.89% | 2.94±0.02 |
| DW4 | Equivariant OT FM | 1.68±0.01 | 88.71±0.40% | 2.92±0.01 |
| LJ13 | Likelihood | −15.83±0.07 | 39.78±6.19% | 5.08±0.22 |
| LJ13 | OT FM | −16.09±0.03 | 54.36±5.43% | 2.84±0.01 |
| LJ13 | Equivariant OT FM | −16.07±0.02 | 57.98±2.19% | 2.15±0.01 |
| LJ55 | OT FM | −88.45±0.04 | 3.74±1.06% | 7.53±0.02 |
| LJ55 | Equivariant OT FM | −89.27±0.04 | 4.42±0.35% | 3.52±0.01 |
| Alanine dipeptide | OT FM | −107.54±0.03 | 1.41±0.04% | 10.19±0.03 |
| Alanine dipeptide | Equivariant OT FM | −106.78±0.02 | 0.69±0.05% | 9.46±0.01 |

关键观察：

- **LJ13**：equivariant OT FM 的 path length 2.15，明显低于 OT FM 的 2.84 和 likelihood 的 5.08（Table 1）；ESS 57.98% 高于 OT FM 的 54.36%（Table 1）。
- **LJ55**：equivariant OT FM 的 path length 3.52，约为 OT FM 7.53 的一半（Table 1）；ESS 4.42% vs 3.74%（Table 1）。作者报告 equivariant OT FM 可用固定步长 rk4 积分器、约 20 步采样，相对 OT FM 有 3 倍加速（Figure 2e，Sec.6.2）。
- **DW4**：equivariant OT FM 的 ESS 88.71% 低于 OT FM 的 92.37%，path length 2.92 略低于 2.94（Table 1）。作者在贡献 2 中明确承认「我们提出的方法在较大高对称系统上最有效，而在较小系统上有时结果不如 OT flow matching」（Sec.1）。
- **Alanine dipeptide**：equivariant OT FM 的 ESS 0.69% 低于 OT FM 的 1.41%，NLL −106.78 也略差于 −107.54（Table 1）；但 path length 9.46 短于 10.19（Table 1）。作者在 Sec.6.3 说「OT flow matching 在 ESS 和 NLL 上优于 equivariant OT flow matching」，并说明自由能估计实验用的是 OT flow matching loss，因为它在 alanine dipeptide 上表现略好。

**自由能差（Table 2）**：alanine dipeptide 最慢转变（φ 二面角）的无量纲自由能差 $\Delta F/k_BT$：MD 5.31，relaxed MD 5.00，umbrella sampling 4.10±0.26（五次运行），Boltzmann generator 4.10±0.08（五次运行）。作者报告 BG 估计与 umbrella sampling 参考解一致，而 MD 和 relaxed MD 高估了自由能差（Sec.6.3）。

**训练数据**：alanine dipeptide 训练集由两步生成：先用 Amber ff99SBildn 力场跑 1 ms MD，再随机选 $10^5$ 个态用 GFN2-xTB 力场各弛豫 100 fs（Sec.6.3）。作者称这是有偏训练集，通过 reweighting 得到渐近无偏样本（Figure 3e，Appendix B.3）。

## 5. 在 OT×扩散地图中的位置

本文是 T08「OT-CFM 与 minibatch OT 耦合」中**成本函数设计线**的开端工作。它直接继承 Tong et al. 的 OT-CFM（arXiv:2302.00482，本文引用 [22]）的 minibatch OT 配对框架，但把成本从欧氏距离换成群对齐不变成本，针对的是「batch 大小 $n$ 有限时，期望 batch 耦合 $\pi_k$ 并非真 OT plan」这一核心张力。与同期工作 Song et al.（arXiv 未在本文给出，引用 [23]）几乎提出相同目标，作者在贡献 1 中明确标注为 concurrent work。

在课题地图中的位置：它不修正 minibatch OT 的统计偏差（那是 LOOM-CFM、半离散 OT 等后续工作的方向），也不扩大 batch size（那是大规模 Sinkhorn 的方向），而是通过改变成本函数让「小 batch 内的局部 OT」在对称群轨道意义下更接近全局 OT。这对应课题背景中五条修正路线中的「成本函数设计」线。其理论贡献（Theorem 1）给出的是等变 OT 映射与不变成本的关系，属于对称性条件下的 OT 结构性质，不是 minibatch 偏差的收敛速率理论。

与后续工作的关系：本文的等变成本思想可被看作「任务感知成本」的一个特例——对称群是物理系统给定的先验。C²OT 的条件感知成本、Metric FM 的黎曼成本是同一设计空间的其他实例。本文没有解决 batch 偏差本身，LJ55 上 equivariant OT FM 的 ESS 仍只有 4.42%（Table 1），说明有限 batch 的耦合质量仍是瓶颈。

## 6. 局限与批评

作者承认的：

1. **未做迁移性实验**：Sec.8 明确说「我们没有进行实验来证明方法的可迁移性」，架构和损失函数「可能」可用于训练可迁移模型，留给未来工作。
2. **Hungarian 算法 $O(N^3)$ 复杂度**：Sec.8 指出 Eq.(15) 的近似包含 Hungarian 算法，计算复杂度 $O(N^3)$，建议用近似 Hungarian 的启发式替代。
3. **小系统上不如 OT FM**：贡献 2 和 Sec.6.1 承认，在 DW4 上 equivariant OT FM 的 ESS 低于 OT FM（88.71% vs 92.37%，Table 1）；alanine dipeptide 上 ESS 和 NLL 也略差（Table 1）。

我读出的：

1. **Eq.(16) 是顺序近似，不是 Eq.(15) 的精确解**：先固定置换再优化旋转，不能保证找到旋转×置换联合最小。作者在 Appendix A.9 测试了其他近似策略，报告结果无显著变化，但正文没有给出顺序近似与精确解之间差距的任何定量刻画。
2. **Theorem 1 与实验之间的鸿沟**：定理假设 $G$ 是紧群、以等距作用，且 $T$ 是精确 OT 映射；但实验中的 $G$ 包含置换群 $S(N)$（有限群，紧）和 $O(D)$（紧），条件满足。然而定理没有说明 minibatch 近似下用 $\tilde c$ 解离散 OT 会以什么速率逼近全局 OT，也没有解释为什么 alanine dipeptide 上 equivariant OT FM 反而更差。
3. **alanine dipeptide 的对称性处理是人为截断的**：Sec.6.3 说五个 backbone 原子被视为可区分「以便分析」，这意味着置换对称性在该实验中被部分移除，equivariant OT FM 的优势被削弱，但作者没有讨论这一设计选择对结论的影响。

## 7. 对我们的启发

1. **成本函数设计可作为独立于 batch 大小的杠杆**：本文证明在对称系统中，仅改成本函数就能把 LJ55 的 path length 从 7.53 降到 3.52（Table 1），且推理加速 3 倍（Figure 2e）。这提示在 T08 的「成本函数设计」线上，除了条件感知（C²OT）和黎曼度量（Metric FM），还可以系统探索「先验对称性/不变性注入成本」的通用配方。可操作方向：对任意已知目标对称群 $G$，在 batch OT 前用群对齐预处理样本对，成本几乎为零地改善小 batch 耦合质量。
2. **等变成本与 minibatch 偏差的交互值得定量研究**：本文报告 equivariant OT FM 在 LJ55 上 ESS 仅 4.42%（Table 1），说明即使成本对齐了对称性，有限 batch 的耦合偏差仍然严重。这正好接课题切入点 #1：能否证明「群对齐成本下，minibatch OT 耦合的偏差随 batch size 的衰减速率」？本文的 Theorem 1 提供了等变 OT 映射的结构，但缺一个从 minibatch 离散 OT 到全局 OT 的收敛界。
3. **顺序近似（Hungarian→Kabsch）的误差传播可被形式化**：Eq.(16) 先置换后旋转，是一个两阶段贪心。若把置换和旋转的联合对齐写成一个小型 assignment-on-manifold 问题，可以研究顺序解与联合解的 gap 上界，以及这个 gap 如何影响学到的向量场曲率。这比本文 Appendix A.9 的「试了其他策略、结果差不多」更有理论价值。
4. **对医学/分子 SB 的迁移**：本文的等变成本不依赖 CNF 架构，可直接用于等变扩散模型或 Schrödinger bridge 的 minibatch 耦合。若目标系统有已知对称群（如分子构象的 SE(3)），在 SB 训练中把 batch 内配对成本换成群对齐成本，可能在不增加 batch size 的情况下缩短桥路径、减少 NFE。这与课题切入点 #7（医学 SB）的关联在于：医学影像中的刚性变换对称性（平移/旋转/缩放）可以用类似 Kabsch 对齐的方式注入耦合成本。
