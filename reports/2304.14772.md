# Multisample Flow Matching: Straightening Flows with Minibatch Couplings

> Aram-Alexandre Pooladian, Heli Ben-Hamu, Carles Domingo-Enrich et al. · ICML 2023 · [arXiv](https://arxiv.org/abs/2304.14772) · 证据级 [P] · 课题 T08 OT-CFM 与 minibatch OT 耦合
> **一句话**：把 FM 的独立耦合换成 batch 内 OT/稳定匹配耦合，ImageNet 上同 FID 省 30–60% NFE，训练开销 <4%。

## 1. 问题

Flow Matching 的条件路径对单个数据点是 OT 直线，但边际路径离噪声→数据的 OT 路径很远（Sec. 1）。根源是噪声与数据独立采样：无穷多条穿过同一 $(t,x)$ 的条件直线方向互相冲突，导致 (i) 梯度方差即使在收敛点也不为零，(ii) 学到的边际速度场弯曲、少步 Euler 采样质量差，(iii) 学到的 $x_0\mapsto\psi_1(x_0)$ 传输代价远离 $W_2^2$（Sec. 3）。

此前想把 OT 塞进 CNF 的路线要么走 min-max（WGAN、ICNN、Albergo & Vanden-Eijnden 2023），要么训练时模拟 ODE（RNODE、Rectified Flow 的 reflow）；而直接用 batch OT 解训静态映射（Genevay 2018、Fatras 2019 等）只能拟合出重心投影，边际不保（Sec. 5.1）。作者要的是：simulation-free、非对抗、且严格保边际地利用 batch OT 解。

## 2. 方法

核心思想：训练只需从联合分布 $q(x_0,x_1)$ 采样，不需要其密度；任何满足边际约束 Eq.(13) 的联合分布都能用，所以通过「采样过程」隐式定义一个更好的耦合。

- Joint CFM 目标（Eq.(15)）：$\mathcal{L}_{\text{JCFM}}=\mathbb{E}_{t,q(x_0,x_1)}\|v_t(x_t;\theta)-u_t(x_t|x_1)\|^2$，$x_t=(1-t)x_0+tx_1$，$u_t(x_t|x_1)=x_1-x_0$；$q=q_0q_1$ 时退化为原 CFM Eq.(7)。
- 多样本构造（Sec. 4）：(1) 各采 $k$ 个 $x_0^{(i)}\sim q_0$、$x_1^{(j)}\sim q_1$；(2) 由样本算一个双随机矩阵 $\pi(i,j)$；(3) 从 $q^k(x_0,x_1)=\frac1k\sum_{i,j}\delta_{x_0^{(i)}}\delta_{x_1^{(j)}}\pi(i,j)$ 采样。对 step 1 取期望即得隐式 $q(x_0,x_1)$。
- 四种耦合：**BatchOT**——POT 精确解 $k\times k$ 二次代价 OT，得置换矩阵，$O(k^3)$；**BatchEOT**——Sinkhorn，$\tilde O(k^2/\varepsilon)$，$\varepsilon\to0$ 回到 BatchOT、$\varepsilon\to\infty$ 回到独立耦合；**Stable**——Gale–Shapley 稳定匹配，只用相对排序，$O(k^2\log k)$；**Heuristic**——按循环单调性改造的 Gale–Shapley（App. A.2）。CondOT（原 FM）对应均匀耦合 $\pi(i,j)=1/k$（Sec. 4.1）。
- 直线度度量（Eq.(18)(19)）：$S=\mathbb{E}_{t,q_0}\big[\|u_t(\psi_t(x_0))\|^2-\|\psi_1(x_0)-x_0\|^2\big]\ge0$，当且仅当轨迹为直线时为零。
- 工程细节：耦合只在单 GPU 的 batch 内解（ImageNet-32 每卡 256、ImageNet-64 每卡 50），跨 GPU 做耦合「无明显收益且略差」（App. E.1）。

## 3. 理论结果

- **Lemma 3.1 / Lemma 4.1**：任意满足 Eq.(13) 的 $q$，Joint CFM 的最优速度场把 $q_0$ 输运到 $q_1$；多样本三步构造得到的 $q$ 边际恰为 $q_0,q_1$。这是「batch OT 解可用于生成建模且保边际」的关键——静态映射做不到（Sec. 5.1）。
- **Lemma 3.2**（Eq.(16)(17)）：固定 $(t,x)$ 的梯度总方差 $\sigma^2_{t,x}\le\|\nabla_\theta v_t(x;\theta)\|^2\,\mathbb{E}_{p_t(x_1|x)}\|u_t(x)-u_t(x|x_1)\|^2$，故 $\mathbb{E}_{t,p_t}[\sigma^2_{t,x}]\le\max_{t,x}\|\nabla_\theta v_t\|^2\cdot\mathcal{L}_{\text{JCFM}}$：Joint CFM 的最优值是梯度方差的代理上界；独立耦合下该值不可能为零。
- **Theorem 4.2**（App. D 完整版 Theorem D.2/D.4）：BatchOT 下 $k\to\infty$ 时 (i) 最优 Joint CFM 值 → 0，(ii) 直线度 $S\to0$，(iii) 传输代价 $\mathbb{E}_{q_0}\|\psi_1(x_0)-x_0\|^2\to W_2^2(q_0,q_1)$。假设：(A1) $q_0,q_1$ 有界支撑；(A2) $q_0$ 有密度且二次代价 OT map 连续（Caffarelli 正则性给出充分条件 A2'）；(A3) 经验 plan $q^k$ a.s. 弱收敛到 $q$——对 BatchOT 由 Proposition D.1 保证。
- **Proposition D.7**：任意保边际 $q$，学到的流的传输代价 $\le\mathbb{E}_q\|x_1-x_0\|^2$（等价于 Rectified Flow 的 Theorem 3.5）。
- **Theorem D.8**：BatchOT 下该上界 $\mathbb{E}_{q^{(k)}}\|x_1-x_0\|^2$ 关于 $k$ 单调不增——「大 batch 不会更差」的弱保证，但没有速率。

## 5. 在 OT×扩散地图中的位置

与 Tong 等 OT-CFM（2302.00482）同期独立：那边给的是任意 source + SB 变体 + 工程库，这边给的是耦合族的完整理论（保边际引理、方差界、$k\to\infty$ 三重收敛、单调性），两篇合起来构成本课题的奠基层。它显式继承并回应 Fatras 等 minibatch Wasserstein（1910.04091）与 BoMb-OT（2102.05912）——那些工作在静态映射层面修正 batch 偏差，而本文用 neural ODE 的动态参数化直接绕过「不保边际」问题（Sec. 5.1）。

后续：LOOM-CFM（2603.15279）与 SD-FM（2509.25519）解决「$k$ 受限于单卡 batch」的瓶颈；Zhang 等（2506.05526）用 $n\approx10^6$ 的 Sinkhorn 实证 Theorem 4.2 的渐近区间；Boïté 等（2605.12174）给出 Theorem 4.2 缺失的速率与半离散情形的精确刻画；C²OT（2503.10636）指出该框架在条件生成下的失效。Stable coupling 这条廉价替代线基本无人接续。

对应综合报告张力 3「直 vs 最优」：Prop D.7 与 Theorem D.8 说明学到的流至少不比 batch 耦合更贵，但只有 $k\to\infty$ 才触及最优——直线度（$S$）和最优性（传输代价）在本文是两个分别度量的量。对应推理管线环节 ①，且 Table 3 的 consistency 指标是 T12 「同噪声不同 NFE 输出一致性」的最早量化。

## 6. 局限与批评

作者承认：(1) Theorem 4.2 只有渐近性，无 $k$ 的速率（Sec. 4.2）；(2) 跨 GPU 扩大耦合 batch 未见收益（App. E.1）；(3) FID 不反映单样本路径变化，故另设 consistency 指标（Sec. 6.2）。

我读出来的：(1) ImageNet 结果的 FID 收益很小甚至倒挂——ImageNet-32 上 BatchEOT 6.14、Stable 5.79 都差于 CondOT 5.04，只有 BatchOT 4.68 更好；ImageNet-64 上 BatchOT 12.37 与 CondOT 13.93 差 1.6，而 NLL 全部持平（Table 6）。真正稳定的收益只在低 NFE 区间（Table 1/2）；(2) 实际耦合 batch 只有 $k=256$（ImageNet-32）和 $k=50$（ImageNet-64），$\mathrm{Var}(u_t)$ 只从 594 降到 507、1880 降到 1733（约 8–15%），说明在这个 $k$ 下离 Theorem 4.2 的渐近区很远，与「跨 GPU 无收益」的观察一起，正是后来 Zhang 等（2506.05526）质疑的小 batch 现象；(3) Stable 耦合不依赖代价函数却与 BatchOT 打平，暗示高维小 batch 下 OT 解的「最优性」本身贡献有限，但文中未深究；(4) 「未知代价」实验（Table 4）用的是合成高斯混合，未接任何真实偏好数据。

## 7. 对我们的启发

1. 接 Top-10 #1（MPNA）：Lemma 4.1 的三步构造就是「保边缘 batch 指派」的抽象模板——任何双随机矩阵都保边际；推理侧 (条件, 噪声) 一次性 Hungarian 指派可直接套 Lemma 3.2 论证方差降低，Stable coupling 提供了 $O(k^2\log k)$ 的免代价函数替代。
2. 接 Top-10 #5：Theorem 4.2 + Theorem D.8 给了单调性但无速率；把 (A1)–(A3) 下 $\mathbb{E}_{q^{(k)}}\|x_1-x_0\|^2-W_2^2$ 的 $k$-速率与维度 $d$ 显式化，再接到 Lemma 3.2 的方差界，就是「batch→方差→曲率」传导定理的现成骨架。
3. 评测建议：同时报 FID-vs-NFE 曲线与 Table 3 式 consistency，后者对少步模型更敏感；单点自适应求解器 FID 会掩盖耦合收益（Table 6 vs Table 1）。
