# T2V-Turbo: Breaking the Quality Bottleneck of Video Consistency Model with Mixed Reward Feedback

> Jiachen Li, Weixi Feng, Tsu-Jui Fu et al. · NeurIPS 2024 · [arXiv](https://arxiv.org/abs/2405.18750) · 证据级 [P] · 课题 T19 视频生成与时序一致性中的 OT/流
> **一句话**：在 VCM 一致性蒸馏中混入图文/视频文本奖励反馈，4 步生成 VBench 总分超 Gen-2 与 Pika。

## 1. 问题

扩散式 T2V 模型采样慢，迭代采样过程阻碍实时应用（Sec. 1）。一致性模型（CM）可加速到 4–8 步，但 VCM 的生成质量受教师模型性能瓶颈限制，且步数减少进一步降低质量（Sec. 1）。另一条路线 InstructVideo 通过迭代采样链反传可微奖励模型（RM）梯度来对齐人类偏好，但全奖励梯度计算内存开销过大，被迫截断到最后一个 DDIM 步，优化精度受损；且它只用 image-text RM，无法捕捉视频的时序动态，实验仅覆盖少量动物相关 prompt，泛化性未知（Sec. 1）。

本文要解决的是：在保持 4–8 步快速推理的同时，突破 VCM 的质量瓶颈，使少步生成质量超过教师模型。

## 2. 方法

核心思想：把混合奖励反馈（image-text RM + video-text RM）直接接入 VCM 的一致性蒸馏（CD）过程。关键实现是**直接优化 CD loss 计算中自然产生的单步生成** $\hat{z}_0 = f_\theta(z_{t_{n+k}}, \omega, c, t_{n+k})$，从而绕开对迭代采样链反传梯度的内存约束（Sec. 3）。

训练损失为三项线性组合（Eq. 10）：

$$L(\theta, \theta^-; \Psi) = L_{CD}(\theta, \theta^-; \Psi) - \beta_{img}J_{img}(\theta) - \beta_{vid}J_{vid}(\theta)$$

其中 CD loss 沿用 LCM 形式（Eq. 6）：

$$L_{CD}(\theta, \theta^-; \Psi) = \mathbb{E}_{z,c,\omega,n}\left[d\left(f_\theta(z_{t_{n+k}}, \omega, c, t_{n+k}), f_{\theta^-}(\hat{z}^{\Psi,\omega}_{t_n}, \omega, c, t_n)\right)\right]$$

$\hat{z}^{\Psi,\omega}_{t_n}$ 由数值增强 PF-ODE solver $\Psi$（DDIM）估计，$k$ 为跳步间隔（Eq. 7）。$f_\theta$ 参数化为 $f_\theta(z, \omega, c, t) = c_{skip}(t)z + c_{out}(t)F_\theta(z, \omega, c, t)$，满足 $c_{skip}(\epsilon)=1, c_{out}(\epsilon)=0$（Eq. 5）。

两个奖励目标：
- **逐帧图文奖励**（Eq. 8）：从解码视频 $\hat{x}_0$ 随机采样 $M$ 帧，最大化 HPSv2.1 分数 $J_{img}(\theta) = \mathbb{E}_{\hat{x}_0,c}\left[\sum_{m=1}^{M} R_{img}(\hat{x}^m_0, c)\right]$，$M=6$（Sec. 4 Settings）。
- **视频文本奖励**（Eq. 9）：$J_{vid}(\theta) = \mathbb{E}_{\hat{x}_0,c}[R_{vid}(\hat{x}_0, c)]$，用 InternVid2 S2（VC2 教师）或 ViCLIP（MS 教师）作为 $R_{vid}$（Sec. 4 Settings）。

训练只优化 LoRA 权重，训练后合并 LoRA，使每步推理成本与教师相同（Sec. 3.3）。训练配置：8 张 A100，10K 梯度步，无梯度累积，每 GPU batch size 1，学习率 1e-5，CFG 范围 $[5,15]$，跳步 $k=20$；VC2 变体 $\beta_{img}=1, \beta_{vid}=2$，MS 变体 $\beta_{img}=2, \beta_{vid}=3$（Sec. 4 Settings）。

## 4. 实验与数字

**数据集与基线**：训练用 WebVid10M；自动评估用 VBench（16 个维度，每 prompt 生成 5 个视频）；人工评估用 EvalCrafter 的 700 个 prompt。基线包括 Gen-2、Pika、VideoCrafter1/2、Show-1、LaVie、ModelScopeT2V，以及自训的 VCM (VC2) 和 VCM (MS)（Sec. 4）。

**VBench 总分（4 步生成，Table 1）**：

| 模型 | Total Score | Quality Score | Semantic Score |
|---|---|---|---|
| ModelScopeT2V | 75.75 | 78.05 | 66.54 |
| LaVie | 77.08 | 78.78 | 70.31 |
| Show-1 | 78.93 | 80.42 | 72.98 |
| VideoCrafter1 | 79.72 | 81.59 | 72.22 |
| Pika | 80.40 | 82.68 | 71.26 |
| VideoCrafter2 | 80.44 | 82.20 | 73.42 |
| Gen-2 | 80.58 | 82.47 | 73.03 |
| VCM (MS) | 75.84 | 78.80 | 63.98 |
| **T2V-Turbo (MS)** | 80.62 | 82.15 | 74.47 |
| VCM (VC2) | 73.97 | 78.54 | 55.66 |
| **T2V-Turbo (VC2)** | **81.01** | 82.57 | **74.76** |

T2V-Turbo (VC2) 总分 81.01 超过 Gen-2 的 80.58 和 Pika 的 80.40（Table 1）。T2V-Turbo (MS) 总分 80.62，为第二高（Table 1）。VCM (VC2) 总分 73.97 低于其教师 VideoCrafter2 的 80.44，而 T2V-Turbo (VC2) 反超教师 0.57 分（Table 1）。

**人工评估（Figure 3，700 EvalCrafter prompts）**：T2V-Turbo (VC2) 4 步 vs 教师 VideoCrafter2 50 步，在 Visual Quality 上偏好率 73.1%，Text-Video Alignment 70.0%，General Preference 70.7%；8 步对应为 61.0%、59.6%、62.0%（Figure 3 顶部）。T2V-Turbo (MS) 4 步 vs ModelScopeT2V 50 步为 77.1%、71.9%、73.6%；8 步为 68.9%、63.7%、64.1%（Figure 3 底部）。4 步 vs VCM 4 步：VC2 变体 53.0%、52.6%、54.1%；MS 变体 66.9%、60.4%、61.7%（Figure 3）。作者报告 4 步相对教师 50 步为 12.5 倍推理加速（Sec. 4.2）。

**消融（Table 2）**：VCM (MS) 总分 75.84 → +Rvid 77.28 → +Rimg 79.51 → 混合 80.62；VCM (VC2) 73.97 → +Rvid 77.57 → +Rimg 80.42 → 混合 81.01。Rimg 单独带来主要质量提升，Rvid 进一步提升 Semantic Score（Table 2；Sec. 4.3）。Rvid 选择（Table 3）：T2V-Turbo (VC2) 用 ViCLIP 总分 80.92、InternVid2 S2 总分 81.01；T2V-Turbo (MS) 用 ViCLIP 80.62、InternVid2 S2 79.90（Table 3）。

## 5. 在 OT×扩散地图中的位置

本文属于视频一致性蒸馏线（VideoLCM → T2V-Turbo → MCM → OSV），是 VCM 加奖励反馈的改进，不涉及 OT/流公式。其位置在推理管线中对应「少步化蒸馏 + 偏好对齐」环节：用 CD loss 保证 PF-ODE 轨迹一致性，用混合 RM 梯度补偿少步蒸馏的质量损失。与 OT 的关联是间接的——CD 本身沿 PF-ODE 轨迹做自洽映射，而本文未引入任何传输代价、Sinkhorn 或流匹配组件。在课题地图中，它是「蒸馏主线」里一致性系的一环，被后续 MCM（解耦运动/外观）和 OSV（两阶段）继承；与 VDOT（OT-DMD）形成互补而非竞争：VDOT 用熵正则 OT 距离替换/补充反向 KL 目标，本文用奖励梯度补充 CD 目标，两者解决的是少步蒸馏质量塌缩的不同侧面。本文的「单步生成直接优化」技巧（利用 CD loss 中自然出现的 $\hat{z}_0$ 避免迭代反传）在工程上为后续少步奖励微调提供了模板。

## 6. 局限与批评

**作者承认的**：缺乏公开的、训练为反映视频-文本人类偏好的 video-text RM，只能用通用视频基础模型 ViCLIP / InternVid2 S2 充当 $R_{vid}$；未来用更强的 $R_{vid}$ 可能进一步提升（Sec. 6）。

**读出来的**：
1. VBench 总分优势幅度小：T2V-Turbo (VC2) 81.01 vs Gen-2 80.58，仅差 0.43 分（Table 1），且 VBench 各维度权重由 VBench 官方规则决定，单一总分排名的稳健性未做统计检验。
2. 奖励模型即评估模型的风险：训练用 HPSv2.1 和 InternVid2 S2/ViCLIP 作为优化目标，而 VBench 的 Image Quality、Semantic 维度可能使用同类视觉-语言基础模型，存在评估泄漏或过拟合到 RM 偏好的可能；论文未报告在独立于 RM 家族的指标上的验证。
3. 训练数据仍是 WebVid10M，教师本身质量受限；T2V-Turbo (MS) 的 Semantic Score 74.47 虽超教师 ModelScopeT2V 的 66.54，但 Quality Score 82.15 低于教师的 78.05 之外的多个基线（Table 1），说明奖励反馈对质量维度的提升在弱教师上不均衡。

## 7. 对我们的启发

1. **单步生成直接优化可作为 OT-aware 蒸馏的奖励注入点**：本文证明 CD loss 中自然产生的单步 $\hat{z}_0$ 可以零额外采样成本地接入可微目标。若把 OT 距离（如 Sinkhorn 熵正则 OT）作为该单步生成与教师轨迹终点的几何对齐项，可避免 VDOT 式真/假 score 样本对采样的额外开销——即「CD 单步 + OT 几何正则」的混合目标值得尝试。
2. **混合 RM 反馈对时序维度的增益可迁移到运动塌缩诊断**：Table 2 显示 $R_{vid}$ 单独加入时 Semantic Score 从 63.98 升到 71.35（MS），但 Motion Quality 从 48.99 升到 51.70 仍远低于教师 52.06（Table 1/2）。这说明视频级 RM 反馈不能完全修复少步蒸馏的运动退化。可结合课题切入点 #4，用帧间特征 Wasserstein 距离轨迹量化「运动 OT 谱」，检验奖励反馈是否只提升语义对齐而未恢复运动幅度。
3. **LoRA-only 蒸馏 + 权重合并的工程模式**：本文只训 LoRA 并合并，保持每步推理成本与教师一致（Sec. 3.3）。这对在 Wan/HunyuanVideo 等大教师上做保耦合蒸馏（切入点 #3）有直接参考价值：低秩约束可能天然限制蒸馏对时间耦合结构的破坏，值得作为消融变量。
