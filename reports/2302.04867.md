# UniPC: A Unified Predictor-Corrector Framework for Fast Sampling of Diffusion Models

> Wenliang Zhao, Lujia Bai, Yongming Rao et al. · NeurIPS 2023 · [arXiv](https://arxiv.org/abs/2302.04867) · 证据级 [P] · 课题 T11 免训练采样器与 ODE 求解器
> **一句话**：提出统一预测-校正框架 UniPC，校正器不增加 NFE 即提升精度，10 步 FID 达 3.87（CIFAR10）/7.51（ImageNet 256）。

## 1. 问题

扩散概率模型（DPM）采样需要多次评估去噪网络，推理成本高。训练免采样器（training-free samplers）已把采样步数从约 1000 步降到 20 步以内，但在极低步数（<10 NFE）下，现有方法仍难以生成高质量样本（Sec. 1, p.1–2）。作者指出，低步数采样在 prompt 设计、基于扩散的视觉系统训练中计算生成样本损失等场景有实际需求（Sec. 1, p.2）。

现有快速采样器的具体不足：基于扩散 ODE 的指数积分器（DPM-Solver、DEIS、DPM-Solver++）虽然收敛快于直接离散扩散 ODE，但「existing solvers of diffusion ODEs can be explicitly computed for orders not greater than 3, due to the lack of analytical forms」（Sec. 2.2, p.3），即缺少高于 3 阶的显式解析形式；DEIS 在时间域做指数积分，积分无法解析计算，高阶显式公式无法推导（Sec. 3.3, p.5）；DPM-Solver 系列即使在 3 阶以内也没有统一形式（Sec. 3.3, p.5）。数值 ODE 文献中的预测-校正范式需要每步对校正后的点重新评估函数，NFE 翻倍（Sec. 3.1, p.5）。

## 2. 方法

核心思想：在扩散 ODE 的半线性结构（指数积分器形式）上，设计一个统一解析形式的预测器 UniP 和校正器 UniC。UniC 的关键技巧是**复用当前步的模型输出** $\epsilon_\theta(\tilde{x}_{t_i}, t_i)$ 作为下一步的缓冲输入，而不是对校正后的 $\tilde{x}^c_{t_i}$ 重新评估网络，从而在不增加 NFE 的前提下把精度阶数提升 1（Sec. 3.1, p.5）。

扩散 ODE 的解在 half log-SNR 域 $\lambda_t = \log(\alpha_t/\sigma_t)$ 中可解析写为（Eq. (2), Sec. 2.2）：

$$x_t = \frac{\alpha_t}{\alpha_s} x_s - \alpha_t \int_{\lambda_s}^{\lambda_t} e^{-\lambda} \hat{\epsilon}_\theta(\hat{x}_\lambda, \lambda)\, d\lambda$$

UniC-p 的校正公式（Eq. (4), Sec. 3.1）：

$$\tilde{x}^c_{t_i} = \frac{\alpha_{t_i}}{\alpha_{t_{i-1}}} \tilde{x}^c_{t_{i-1}} - \sigma_{t_i}(e^{h_i}-1)\epsilon_\theta(\tilde{x}_{t_{i-1}}, t_{i-1}) - \sigma_{t_i} B(h_i) \sum_{m=1}^{p} \frac{a_m}{r_m} D_m$$

其中 $h_i = \lambda_{t_i} - \lambda_{t_{i-1}}$，$D_m = \epsilon_\theta(\tilde{x}_{s_m}, s_m) - \epsilon_\theta(\tilde{x}_{t_{i-1}}, t_{i-1})$，辅助时间点 $s_m = t_\lambda(r_m h + \lambda_{t_{i-1}})$，$r_1 < r_2 < \cdots < r_p = 1$ 为递增序列。系数 $a_p$ 通过匹配式 (4) 与理论解展开式 (6) 的低阶项确定，取 $a_p = R_p^{-1}(h_i)\phi_p(h_i)/B(h_i)$，其中 $R_p$ 是 Vandermonde 矩阵，$\phi_n(h) = \frac{h^n}{n!}\varphi_{n+1}(h)$，$\varphi_n$ 由递推 $\varphi_{n+1}(h) = \frac{\varphi_n(h) - 1/n!}{h}$，$\varphi_0(h) = e^h$ 定义（Theorem 3.1, Sec. 3.1）。$B(h)$ 是任意满足 $B(h) = O(h)$ 的非零函数，如 $B_1(h) = h$ 或 $B_2(h) = e^h - 1$（Sec. 3.1, p.4–5）。

UniP-p 是 UniC-p 去掉含 $D_p$ 的项（因为 $D_p$ 涉及 $\tilde{x}_{t_i}$ 自身），只用前 $p$ 个点，精度为 $p$ 阶（Corollary 3.2, Sec. 3.2）。UniP 与 UniC 共享同一解析形式，UniPC-p = UniP-p 作为预测器 + UniC-p 作为校正器，总精度 $p+1$ 阶（Sec. 3.2, p.5）。

实现上，设 $r_m = (\lambda_{t_{i-m-1}} - \lambda_{t_i})/h_i$ 即得多步（multistep）版本，复用之前的评估结果，在有限 NFE 下经验上更高效（Sec. 3.4, p.5）。数据预测模型（$x_\theta$）版本在 Appendix A 给出，公式为 Eq. (10)–(11)，用于 guided sampling 配合 dynamic thresholding（Sec. 3.4, p.5–6）。

## 3. 理论结果

**Theorem 3.1（UniC-p 的精度阶数）**：对任意非零递增序列 $\{r_i\}_{i=1}^p$ 和 $h > 0$，若系数 $a_p$ 满足 $|R_p(h_i) a_p B(h_i) - \phi_p(h_i)| = O(h_i^{p+1})$（$|\cdot|$ 为矩阵的 $l_1$ 范数），则在 Appendix E.2 的正则条件下，UniC-p 具有 $p+1$ 阶精度（Sec. 3.1, p.4）。

**Corollary 3.2（UniP-p 的精度阶数）**：对递增序列 $r_1 < \cdots < r_{p-1} < 1$，去掉 $D_p$ 项且系数满足 $|R_{p-1}(h_i) a_{p-1} B(h_i) - \phi_{p-1}(h_i)| = O(h_i^p)$ 的求解器具有 $p$ 阶精度（Sec. 3.2, p.5）。

**Proposition A.1（数据预测模型 UniPC-p 的精度阶数）**：在正则假设 E.3 下，若 $0 \neq B(h) = O(h)$ 且系数满足式 (13) 的两个匹配条件，则数据预测模型的 UniPC-p 精度为 $p+1$ 阶（Appendix A.2, p.13）。

作者进一步说明：在 Appendix D 的额外正则条件下，基于 Theorem 3.1 和 Corollary 3.2，UniPC-p 的收敛阶达到 $p+1$（Sec. 3.2, p.5）。校正器中用 $\epsilon_\theta(\tilde{x}_{t_i}, t_i)$ 替代 $\epsilon_\theta(\tilde{x}^c_{t_i}, t_i)$ 造成的失配误差不影响精度阶数（Appendix E.7，Sec. 4.2, p.8 提及）。

## 4. 实验与数字

**无条件采样**（Fig. 2, Sec. 4.1）：CIFAR10（pixel-space DPM，来自 [35]）、LSUN Bedroom 和 FFHQ（latent-space DPM，来自 [29]）。UniPC 用 UniP-3 + UniC-3（精度 4 阶），DPM-Solver++ 用 multistep 3 阶版本。相比 DPM-Solver++，UniPC 在 CIFAR10、LSUN Bedroom、FFHQ 上分别改善 FID 达 6.0、5.9、8.5（Sec. 4.1, p.6）。

**条件采样**（Fig. 3, Sec. 4.1）：ImageNet 256×256（pixel-space，classifier guidance，scale 8.0/4.0，dynamic thresholding），UniPC 用 UniP-2 + UniC-2，DPM-Solver++ 用 2M。MS-COCO2014 文本到图像（stable-diffusion，classifier-free guidance scale 1.5），指标为与 999 步 DDIM 真解的 $l_2$ 距离（$\|x_0 - x_0^*\|_2/\sqrt{D}$），UniPC 一致低于 DPM-Solver++（Fig. 3c）。

## 5. 在 OT×扩散地图中的位置

UniPC 属于「免训练采样器与 ODE 求解器」轴上的**高阶指数积分器 + 预测-校正格式**工作，直接继承 DPM-Solver（arXiv:2206.00927）和 DPM-Solver++（arXiv:2211.01095）的 half log-SNR 指数积分框架，与 DEIS（arXiv:2204.13902）在时间域指数积分形成对照。其核心贡献是把「预测-校正」从数值 ODE 文献中「NFE 翻倍」的范式改造为「零额外 NFE」的扩散专用格式，方法上属于求解器结构设计，不涉及时间步调度优化或轨迹几何分析。

在课题地图中，UniPC 处于 2022–2023「稳定性与统一」阶段：它解决了 DPM-Solver 系列「无统一高阶形式」的问题，但未触及后续 2023–2024 几何转向揭示的核心矛盾——低步数误差主要由轨迹曲率与调度失配主导，而非求解器阶数不足。GITS/TORS 的结论（调度 > 求解器阶数）在 UniPC 的 Table 4 中已有端倪：盲目提高阶数（123456）反而使 FID 恶化到 22.98/60.99，说明高阶格式在低 NFE 下不是充分条件。UniPC 的「任意阶」能力在后续调度优化成为主战场后，其相对重要性下降，但作为 diffusers 生态默认求解器之一，它仍是 few-NFE 采样的工程基线。

与 OT 的关联是间接的：UniPC 求解的是 PF-ODE，而 PF-ODE 在 Lavenant–Santambrogio 意义下是 Schrödinger 桥问题的最优传输近似。UniPC 不改变轨迹几何，只提高离散解对真轨迹的逐点逼近精度。因此它对应「推理管线」中的离散化环节，而非传输结构设计环节。

## 6. 局限与批评

**作者承认的**：
1. UniPC 仍落后于训练基方法（如 progressive distillation [31]），如何缩小 training-free 与 training-based 的差距需要未来工作（Sec. 4.2, Limitations, p.9）。
2. UniC 与 UniC-oracle 之间的差距（Table 3）表明，用 $\epsilon_\theta(\tilde{x}_{t_i}, t_i)$ 替代 $\epsilon_\theta(\tilde{x}^c_{t_i}, t_i)$ 造成的失配误差在低步数下仍有实质影响，作者明确说「UniC still has room for improvement」（Sec. 4.2, p.8）。
3. $B(h)$ 的选择影响性能且无理论指导：$B_1(h)=h$ 在极低 NFE（5–6）下优于 $B_2(h)=e^h-1$，但 NFE 增大后 $B_2$ 反超，guided sampling 中 $B_1$ 一致更差（Sec. 4.2, p.7）。作者将更好的 $B(h)$ 设计留作未来工作。

**读出来的**：
1. 阶数调度（Table 4）暴露了一个未解决的问题：UniPC 提供任意阶能力，但如何为给定 NFE 预算选择最优阶数序列没有原则性方法，只能靠搜索。这与后续 GITS/AYS 等工作的核心发现一致——真正需要优化的是调度而非阶数，但 UniPC 本身没有朝这个方向推进。
2. 所有理论结果（Theorem 3.1, Corollary 3.2, Proposition A.1）都是局部截断误差的阶数分析，依赖 Appendix E.2/E.3 的正则条件（$\hat{\epsilon}_\theta$ 的导数有界等），没有给出全局误差界或与 FID 等分布级指标的关联。低 NFE 下高阶格式的 FID 优势（如 Table 4 中 123456 的崩溃）无法从阶数理论预测。
3. 实验覆盖的模型均为 2022 年前后的 checkpoint（CIFAR10 pixel-space、ImageNet 256 pixel-space、stable-diffusion 1.x），未在更大规模或更新架构上验证。Stable-Diffusion-XL 的对比只有定性图（Fig. 4），无定量指标。

## 7. 对我们的启发

1. **「零额外 NFE 校正」的思路可迁移到 OT-aware 采样调度**：UniC 的核心洞察是「复用当前步的模型输出，不重新评估校正点」。在 OT×扩散的推理管线中，如果我们要在采样过程中引入传输代价感知的修正（例如向 OT 映射方向微调），同样可以复用已有的 score 评估，避免额外 NFE。这为「免训练 batch 级保边缘噪声指派（MPNA）」提供了一个实现模板：用当前步的 score 信息做一次零成本修正，而不是重新计算。
2. **Table 4 的阶数调度实验是「调度 > 阶数」的早期证据**：NFE=7 时 1234567 得 FID 60.99，而 1223334 得 6.29，差距近 10 倍。这直接支持课题背景中「低步数误差主要由曲率与调度失配主导」的判断，可作为我们论证 OT-aware 调度必要性的引用证据——不是求解器不够高阶，而是高阶格式在错误的调度下反而放大误差。
3. **UniC-oracle 的 gap 提示「校正点失配」是一个可量化的误差源**：Table 3 中 UniC 与 UniC-oracle 在 5 步时 FID 差 7.73（LSUN Bedroom），说明校正后点的 score 与预测点 score 的差异在低步数下不可忽略。在 OT 视角下，这个失配可以理解为「预测轨迹与校正轨迹之间的传输代价」，或许可以用局部曲率或 Wasserstein 距离来刻画，进而设计更优的校正策略。
