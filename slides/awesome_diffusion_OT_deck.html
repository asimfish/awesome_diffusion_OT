两条辩论线都以反例收尾

综合报告 §3.2–3.3

扩散 ≟ OT（T02）

  • 正方：高斯情形 DDPM encoder = Monge map（Khrulkov，ICLR 2023）
  • 反方定论：PF-ODE 逐时刻是梯度场，复合后不是凸势梯度——Hessian 非交换项（Lavenant–Santambrogio）
  • 补丁：特定条件下有限区间成立；W₂ ≤ C·√(score loss)
  • 缺口未被量化（原作者明示 open problem）

拉直 ≠ OT（T09）

  • RF：保边缘、单调不增一切凸代价、直线度 O(1/K)；直 ⇔ 路径不相交，是 c-最优的必要非充分条件（仅 1D 重合）
  • 反例：迭代 rectification 有非最优不动点（Hertrich，NeurIPS 2025）
  • 八月修复 ×2：c-RF 梯度类投影恒收敛到 OT（2608.02487）；reflow×minibatch-OT 极限 = N-循环单调耦合（2608.07042）
  • 结论：「直线度」与「最优性」是两个自由度，加一个投影约束就能接上

四大理论张力（+ 一条工程张力）

综合报告 §3.8
  • 耗散 vs 测地：扩散走 KL 梯度流（JKO），OT 走测地线（Benamou–Brenier）——同一 P₂ 流形上两种变分结构不重合
  • 逐时刻最优 vs 全局最优：每一瞬是梯度场，复合起来不是（Lavenant 反例的本质）
  • 直 vs 最优：直线化降代价但不动点未必最优；c-RF / N-循环单调条件修复
  • 加速 vs 统计精度：迭代复杂度与统计率各自 sharp，联合前沿无人刻画
  • 改耦合 vs 保边缘（深读新增）：实例级噪声/端点选择提高兼容性但改变有效初始分布；文献几乎不报告漂移 → MPNA 的立项动机

样例：MPNA——免训练 batch 级保边缘噪声指派

~/Code/mpna/PROPOSAL.md
  • 问题：top-1-of-k 噪声选择提高兼容性，但噪声人口分布 qk ≠ N(0,I)：分布偏移、同质化、verifier hacking
  • 形式化：maxπ Eπ[s(c,z)] s.t. π ∈ Π(μ,ν)——Kantorovich 问题；batch 置换 = 经验 Kantorovich（Hungarian O(B³)）
  • Lemma 1：任意数据依赖置换不改变噪声多重集 → 人口统计量与 iid 同分布
  • Prop. 2：s = f(c)+g(z)+h(c,z)，置换对「通用好噪声」g 完全盲、只收获 h；top-1-of-k 的漂移正来自 g
  • Prop. 3：B→∞ 收敛到半离散 OT，条件噪声分布 = Laguerre 胞腔；共享库检索把胞腔退化为单点
  • 方法：无条件单步 x̂₀(z) + CLIP 相似度矩阵 + Hungarian；+1 NFE / 输出，与 k 无关

MPNA 实验计划（claim-driven）

~/Code/mpna/PROPOSAL.md §6–§7
  • C1（主导）：GenEval / T2I-CompBench 上 Hungarian(B=128, +1 NFE) 提升对齐指标，且人口边缘与 iid 统计不可区分；同等增益的 top-1-of-k 产生可测漂移
  • C2（支撑）：增益来自 verifier 的提示特异分量，通用分量（美学分）是漂移源——λ 消融，预测 Hungarian 对 λ 不变
  • 核心块：B1 SDXL-Turbo pilot → B2 top-1-of-k / NoiseQuery 基线 → B3 漂移套件（范数直方图 · BW-W₂² · DINOv2 多样性 · FID/KID/P-R · 同提示 LPIPS）→ B4 λ 消融 → B5 缩放与松弛（B、κ、Sinkhorn ε）
  • 预注册判据：GenEval ≥ iid + 1.5 pt 且 ≥ top-1-of-4 增益的 60%；漂移套件两样本检验 p > 0.1
  • 失败转向：h 分量太弱 → 条件单步评分 / 中段重排；多样性下降可感知 → κ>1 或熵项；只在少步模型成立 → 限定为端侧初值工程
  • 时间表：W3–4 pilot · W5–8 B2–B4 · W9–12 B5 + ICLR 2027 骨架

写作红线（从 446 篇的反例总结）

综合报告 §9.1
  • 不说「实现了最优传输」——说「以 OT 为设计目标并度量偏差」
  • 少步比较固定 NFE 口径并报告多样性（DDBM 的 N=40 实为 NFE 118）
  • 会议归属与「已接收」必须官方可核验；预印本结论一律 [R] 限定

  • 条件生成中的 OT 声明过 C²OT 检查；语义对应线须证明增益来自耦合结构而非 attention 重命名
  • 桥模型横向比较前统一评测协议（训练集/测试集、NFE 口径）
