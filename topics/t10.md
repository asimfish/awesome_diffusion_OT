# T10 · 一致性模型与少步蒸馏的 OT 视角

> 板块 B · 15 篇 · 课题背景笔记 [`source/kb/t10_consistency_distillation_ot.md`](../source/kb/t10_consistency_distillation_ot.md)

## 课题综合

本课题解决的核心问题是：少步生成模型（一致性模型、分布匹配蒸馏、对抗蒸馏）的训练目标与噪声-数据耦合选择如何影响其与教师/数据分布之间的 Wasserstein 距离。方法谱系呈现三条演进线：一致性线（CM→iCT→CTM→sCM→Shortcut）从逐点回归走向连续时间与两时间 flow map，FMM 与 Li 等给出 W2/W1 上界与步数下界；分布匹配线（DMD→DMD2→SiD→VDOT）从 KL+回归锚定走向纯 GAN 匹配再到熵正则 OT 距离；对抗线（ADD→ASD）把判别器统一为 IPM/W1 对偶。当前共识是：蒸馏损失可被形式化为分布差异最小化，且耦合选择决定训练目标偏差（Issenhuth 的 R(θ) 公式）。分歧在于：GAN+真数据带来的'超越教师'是忠实蒸馏还是分布漂移（DMD2 FID 1.28 但 recall 下降；CTM recall 0.57 vs CD 0.63），以及 OT 耦合的收益在 batch=4 时是否实质（VDOT 消融中 OTD 边际贡献仅 0.2–3.9 个百分点）。

## 跨论文观察

- **一致性训练的理论分析从逐点 l2 损失转向 Wasserstein 距离最小化，且蒸馏与免蒸馏情形的估计率存在维度依赖差异。** Dou 等把 CM 训练形式化为 W1 最小化，蒸馏情形估计率 n^{-1/(2(d+5))}，免蒸馏情形 n^{-1/d}；Li 等给出免教师 CT 的 W1 步数下界 O(L_f^3 d^{5/2}/ε)，其中 d^{3/2} 来自 T1 项、d^{5/2} 来自 T2 项。 证据：[`Theory_of_Consistency_Diffusion_Models`](../reports/Theory_of_Consistency_Diffusion_Models.md) [`2402.07802`](../reports/2402.07802.md)
- **CT 与 CD 的差异在连续时间极限不为零，根源是独立耦合的单样本 score 估计方差，换耦合可同时降低偏差与传输成本。** Issenhuth 证明 R(θ) 由耦合决定，OT 耦合（无碰撞）使其为零；iCT 用 Pseudo-Huber 与对数正态调度压制方差，CIFAR-10 一步 FID 2.51 首次反超 CD 的 3.55。 证据：[`2406.09570`](../reports/2406.09570.md) [`2310.14189`](../reports/2310.14189.md)
- **GAN+真数据的对抗项是少步蒸馏质量提升的主因，但代价是 recall 下降与耦合漂移，FID 无法区分忠实蒸馏与分布漂移。** DMD2 去掉 ODE 回归后一步 ImageNet-64 FID 1.28 超越教师；CTM 加 GAN 后 FID 1.92 但 recall 从 CD 的 0.63 降至 0.57；ADD 消融中仅对抗项 FID 20.8，加蒸馏项仅改善 0.2。 证据：[`DMD2_Improved_Distribution_Matching_Distillation`](../reports/DMD2_Improved_Distribution_Matching_Distillation.md) [`2310.02279`](../reports/2310.02279.md) [`2311.17042`](../reports/2311.17042.md)
- **OT 距离作为蒸馏目标的边际贡献在极小 batch 下有限，且作用位置（score 空间 vs 数据空间）影响其几何约束效果。** VDOT 在 score 空间算熵正则 OT，batch=4 时 OTD 项消融差距仅 0.2–3.9 个百分点，GAN 项退化幅度更大；DMD 的回归项是唯一耦合锚，但 DMD2 删掉后 FID 反而更好。 证据：[`2512.06802`](../reports/2512.06802.md) [`2311.18828`](../reports/2311.18828.md)

## 开放问题

- **OT 耦合能否降低一致性训练步数下界中的维度依赖 d^{5/2}？** Li 等的 d^{5/2} 来自独立耦合下 T1/T2 项的逐项控制，换 OT 耦合可能改变条件期望结构，但尚无理论证明或高斯玩具模型上的数值验证。 (2402.07802, 2406.09570)
- **teacher-anchored Wasserstein 评测协议能否区分'超越教师'中的忠实蒸馏与分布漂移？** DMD2/CTM/ADD 的 FID 改善伴随 recall 下降，但现有评测只有 FID/CLIP，缺少以教师样本云为参照的 W2 或 sliced-W2 度量。 (DMD2_Improved_Distribution_Matching_Distillation, 2310.02279, 2311.17042)
- **minibatch OT 在 batch=4 的少步蒸馏中是否实质有效？** VDOT 的 OTD 边际贡献小且未消融 ε 与 batch 大小，Issenhuth 的 batch-OT 比较只用 b≤2048，小 batch 是 minibatch OT 的已知弱点。 (2512.06802, 2406.09570)
